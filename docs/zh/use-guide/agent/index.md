# 智能体

智能体是软件内置的助手，用对话的方式操作工作区里的数据和图表。它能列出数据集、查列统计、筛选数据、画图、改图上的样式、跑 Python 脚本、读写文件、把结果整理成报告。

和其他对话工具的区别在于它真的会动手：每调用一次工具，软件里就发生一件可以看见的事，比如多出一张图、多出一个数据集。每一次工具调用在对话里都有一张卡片，能看到它调了什么、返回来什么。

## 章节目录

- [会话与对话](session.md)：开新会话、看流式回复、停止、关闭后继续后台运行、会话管理。
- [内置工具](tools.md)：智能体能调用的每一个工具，以及它们能做什么。

- [子智能体](subagent.md)：定义专职的子任务，让主智能体并行派发。

## 建议的读法

必须按这个顺序开始：[配置模型](model-config.md) → [会话与对话](session.md)。没配模型时对话不会回话，只会给一句提示。

用起来之后读[权限控制](permission.md)。默认是全自动模式，落盘和跑代码都不会先问；不注意这一点，文件会在没有确认的情况下写进磁盘。

想反复做同一类分析，读[提示词库](prompt-library.md)，把分析要求写成一个条目，以后一键调用。

## 安全上的两点提醒

默认权限模式是全自动，代码执行和文件写入都不会先问。第一次启动如果上一次选过全自动，会出现一张确认卡片。

系统目录的写入在任何模式下都被拒绝，这条规则不能编辑，也不能从界面上移除。
