# 内置工具

智能体自己不直接操作软件。它把要做的事翻译成一次工具调用：工具名加一组参数，交给软件执行，再把结果读回去。每一个工具都是一段固定的功能，参数由软件校验，效果和手工点出来的一致。

每调一次工具，对话里就多一张卡片，卡片上写着工具名、参数和返回的内容。看到卡片就能知道智能体对项目动了什么，不用猜。工具结果的显示和截断规则见[会话与对话](session.md)。

这一章按分组列出随软件发布的全部工具：每个工具做什么、要哪些参数、默认值是多少、会改动项目还是只读，以及一句能触发它的提问。哪些工具在运行前会征求确认，见[权限控制](permission.md)。

## 怎么看这一章

每个工具的名字用代码格式写在三级标题上，就是对话卡片里显示的那个名字。参数列表里标注「必填」的必须给出，其余参数不写时用默认值。只读工具不会改动任何东西，改动类工具的效果立即反映在对应的面板里。

工具清单不是固定的：插件可以注册新工具，停用插件之后它带来的工具一起消失，见[插件管理](../plugin/manager.md)。这一章写的是随软件发布的那两批。

## 数据工具

五个工具围绕数据管理面板里的数据集工作，都按数据集名称定位。名称就是数据管理面板里显示的名字，大小写要一致。

### `list_data`

列出当前已加载的全部数据集，给出名称、类型、行数和列数。没有参数。

只读工具。

可以说：「现在软件里有哪些数据集？」

### `get_data_info`

查看一个数据集的结构和前若干行数据，用来确认列名、列类型和取值的样子。

| 参数 | 含义 | 默认值 |
|---|---|---|
| `data_name` | 数据集名称，必填 | |
| `preview_rows` | 预览的行数 | 10 |

只读工具。

可以说：「看一下 sales 这个数据集有哪些列，各是什么类型。」

### `query_data`

按 pandas 的查询表达式筛选行，返回筛选结果的预览。表达式写在 `expr` 里，写法与 pandas 的 `query` 一致，比如 `amount > 100 and city == "Beijing"`。

| 参数 | 含义 | 默认值 |
|---|---|---|
| `data_name` | 数据集名称，必填 | |
| `expr` | pandas 查询表达式，必填 | |
| `preview_rows` | 预览的行数 | 10 |

只读工具，不改动数据集本身，筛选结果不写回。

可以说：「筛出金额大于 1000 且城市是北京的订单，看看有多少行。」

### `get_column_stats`

对一个列做描述统计，返回计数、均值、标准差、最值、分位数这一组数字。

| 参数 | 含义 | 默认值 |
|---|---|---|
| `data_name` | 数据集名称，必填 | |
| `column` | 列名，必填 | |

只读工具。

可以说：「算一下 price 这一列的均值和四分位数。」

### `export_data`

把一个数据集导出成文件，可以选 CSV 或 Excel。

| 参数 | 含义 | 默认值 |
|---|---|---|
| `data_name` | 数据集名称，必填 | |
| `file_path` | 输出文件路径，必填 | |
| `format` | 输出格式，`csv` 或 `excel` | `csv` |

读数据集、写文件，不改动内存里的数据。写文件属于需要确认的一类，见[权限控制](permission.md)。

可以说：「把清洗完的数据导出成 Excel，放到工程目录下。」

## 图表工具

十一个工具围绕绘图工作。定位一个绘图有两种写法：`figure_name` 填绘图标签页的名字；`chart_id` 填某个图表的标题或序号，留空表示当前活动的那个图表。

### `create_chart`

新建一个绘图，并在里面画一张图表。如果 `figure_name` 与已有的绘图同名，图表加进那个已有绘图，用来往同一个画布里继续加内容；否则新建一个绘图。`y` 传数组，一个元素画一条曲线，多个元素在一次调用里画多条曲线。当 x 列是日期时间类型时，x 轴自动切换成时间轴。

| 参数 | 含义 | 默认值 |
|---|---|---|
| `type` | 图表类型，`line`、`scatter`、`bar`、`hist`、`box` 之一，必填 | |
| `data_name` | 数据集名称，必填 | |
| `x` | x 轴列名，必填 | |
| `y` | y 轴列名，数组形式，必填 | |
| `title` | 图表标题；`figure_name` 为空时它同时用作绘图名 | |
| `figure_name` | 目标绘图名，同名则加图，为空则新建 | |
| `x_label` | x 轴标签 | |
| `y_label` | y 轴标签 | |

改动类工具，新建的绘图出现在「Charts Manager / 绘图管理」面板里；返回的绘图标识可以出现在回复的跳转链接里。

可以说：「用 date 作横轴、sales 作纵轴画一条折线，标题写月度销售额。」

### `add_curve`

往已有图表上加一条曲线，数据来自某一个数据集的两列。

| 参数 | 含义 | 默认值 |
|---|---|---|
| `chart_id` | 图表标识，标题或序号，留空表示当前图表 | |
| `figure_name` | 目标绘图名，留空表示当前绘图 | |
| `data_name` | 数据集名称，必填 | |
| `x_column` | x 轴列名，必填 | |
| `y_column` | y 轴列名，必填 | |
| `name` | 曲线显示名，会出现在图例里 | |
| `color` | 颜色，十六进制或颜色名，比如 `#FF0000` 或 `red` | |
| `width` | 线宽 | |
| `style` | 线型，`solid`、`dash`、`dot`、`dashdot` | |

改动类工具。

可以说：「在同一张图上再加一条 cost 列，颜色用绿色。」

### `set_chart_style`

设置图表的标题、轴标签、图例、网格和背景这些样式。

| 参数 | 含义 | 默认值 |
|---|---|---|
| `chart_id` | 图表标识，留空表示当前图表 | |
| `figure_name` | 目标绘图名 | |
| `title` | 图表标题 | |
| `x_label`、`y_label` | 轴的标签 | |
| `legend` | 是否显示图例，`true` 或 `false` | |
| `grid` | 是否显示网格 | |
| `x_axis_type` | x 轴刻度类型，`datetime` 或 `normal` | |
| `x_date_format` | 时间轴的日期格式，比如 `yyyy-MM-dd` | `yyyy-MM-dd hh:mm:ss` |
| `background_color` | 画布背景色 | |
| `border_color` | 画布边框色 | |
| `grid_major_color` | 主网格线颜色 | |
| `grid_major_style` | 主网格线线型，`solid`、`dash`、`dot` | |
| `legend_position` | 图例位置，`top`、`bottom`、`left`、`right` | |
| `legend_background_color`、`legend_text_color` | 图例的底色和文字色 | |
| `figure_background_color` | 最外层绘图的背景色，与画布背景不同一层 | |

改动类工具。不填的参数保持原样，一次调用里只改填了的项。

可以说：「把横轴改成时间刻度，日期格式显示到天，网格线用虚线。」

### `set_axis`

单独配置某一个坐标轴的刻度类型、范围和外观，比 `set_chart_style` 里的轴设置更完整。

| 参数 | 含义 | 默认值 |
|---|---|---|
| `chart_id`、`figure_name` | 目标图表和绘图 | |
| `axis` | 要配置哪个轴，`x` 或 `y`，必填 | |
| `scale_type` | 刻度类型，`normal` 线性或 `datetime` 时间轴；留空保持不变 | |
| `date_format` | 时间轴的日期格式 | `yyyy-MM-dd hh:mm:ss` |
| `min`、`max` | 轴的上下限，只对线性轴有效 | |
| `color` | 轴的颜色 | |
| `label_rotation` | 轴标签旋转角度 | |

改动类工具。

可以说：「y 轴从 0 开始，到 5000 结束。」

### `update_curve_style`

修改一条已有曲线的样子：颜色、线型、线宽、标记点和填充色。

| 参数 | 含义 | 默认值 |
|---|---|---|
| `chart_id`、`figure_name` | 目标图表和绘图 | |
| `curve_name` | 曲线的标题或序号，从 0 开始，必填 | |
| `color` | 线条颜色 | |
| `width` | 线宽 | |
| `style` | 线型，`solid`、`dash`、`dot`、`dashdot`、`dashdotdot` | |
| `symbol` | 数据点标记，`none`、`ellipse`、`rect`、`diamond`、`triangle`、`dtriangle`、`utriangle`、`cross`、`xcross`、`star1` | |
| `symbol_size` | 标记大小，单位像素 | 8 |
| `fill_color` | 曲线下方填充色，支持八位十六进制表示透明度，比如 `#0000FF80` | |

改动类工具。曲线名不知道时先让智能体列一遍，`list_chart_items` 会给出图例名和序号。

可以说：「把第一条曲线改成蓝色带圆点标记。」

### `remove_chart_item`

从图表里删掉一条曲线、一个标注或一个区间。

| 参数 | 含义 | 默认值 |
|---|---|---|
| `chart_id`、`figure_name` | 目标图表和绘图 | |
| `item_name` | 图元的标题或序号，必填 | |
| `item_type` | 限定类型，`curve`、`annotation`、`region` 或 `any` | `any` |

改动类工具，删除不可撤销。

可以说：「把刚才加的那条参考线删掉。」

### `add_annotation`

往图表上加标注，四种形式：文字、箭头、点、区间高亮。文字和点用 `position` 给坐标；箭头用 `start` 和 `end`；区间用 `start_x` 和 `end_x` 标出一段竖直色带。时间轴上的 x 坐标可以写 Unix 秒、Unix 毫秒或 ISO 时间字符串，工具自己换算。

| 参数 | 含义 | 默认值 |
|---|---|---|
| `chart_id`、`figure_name` | 目标图表和绘图 | |
| `type` | 标注类型，`text`、`arrow`、`point`、`region`，必填 | |
| `position` | 文字或点的坐标，`[x, y]` | |
| `start`、`end` | 箭头的起止坐标，`[x, y]` | |
| `start_x`、`end_x` | 区间的左右边界 | |
| `text` | 标注文字，箭头和区间也用它写说明 | |
| `color` | 标注颜色 | |

改动类工具。区间高亮的用法是原 `add_region` 的功能并入这个工具，不需要单独的工具名。

可以说：「在 3 月那一段画一条竖直高亮，写上促销期。」

### `create_subplots`

新建一个带网格布局的绘图，比如 2 行 2 列四个坐标系。每次调用都新建绘图，不会往已有绘图里加。

| 参数 | 含义 | 默认值 |
|---|---|---|
| `layout` | 网格布局，写成 `行x列`，比如 `2x2`，必填 | |
| `figure_name` | 绘图名，显示在标签页上；留空自动生成 | |

改动类工具。创建出来的空格子后续可以用 `create_chart` 指定 `figure_name` 往里放图表。

可以说：「建一个 2 行 2 列的画布，准备放四张图。」

### `save_chart_image`

把一个图表保存成图片文件，支持 PNG、PDF 和 SVG 三种格式。

| 参数 | 含义 | 默认值 |
|---|---|---|
| `chart_id`、`figure_name` | 目标图表和绘图 | |
| `file_path` | 输出文件路径，必填 | |
| `format` | 图片格式，`png`、`pdf`、`svg` | `png` |
| `width`、`height` | 输出宽高，PNG 按像素算，矢量格式按点算 | |

写文件，不改动图表本身。矢量格式适合放进论文排版，PNG 适合快速查看。

可以说：「把这张图导出成 SVG，宽度 800。」

### `list_figures`

列出当前所有绘图和其中的图表，给出绘图名、图表标题和图表序号。没有参数。

只读工具，用来在执行修改前确认绘图名和图表序号。

可以说：「现在开了哪几个绘图，里面各有什么图？」

### `list_chart_items`

列出某个图表里的全部图元，包括曲线、标注和区间，每个给出序号、图例名、显示名、类型、是否可见、颜色和数据点数。

| 参数 | 含义 | 默认值 |
|---|---|---|
| `chart_id`、`figure_name` | 目标图表和绘图 | |
| `item_type` | 限定类型，`curve`、`annotation`、`region` 或 `any` | `any` |

只读工具。它没有出现在内置的风险分级表里，权限行为按未分级工具处理，见[权限控制](permission.md)。

可以说：「这张图上现在有几条曲线，分别叫什么？」

## 文件与报告工具

三个工具直接读写磁盘上的文件，作用范围不限于项目，还有一类是把分析结果整理成报告。

### `read_file`

读一个文本文件的内容。系统目录被禁止访问，即使把路径写出来也不会读。文件编码按 UTF-8 处理。

| 参数 | 含义 | 默认值 |
|---|---|---|
| `file_path` | 要读的文件路径，必填 | |

只读工具。

可以说：「看一下工程目录里 notes.txt 写了什么。」

### `write_file`

把一段文本写进文件，文件不存在时创建，存在时覆盖。

| 参数 | 含义 | 默认值 |
|---|---|---|
| `file_path` | 要写的文件路径，必填 | |
| `content` | 写入的文本内容，必填 | |

改动类工具，会覆盖同名文件的原有内容，属于需要确认的一类。系统目录同样被禁止。

可以说：「把这几行说明写进 README.txt。」

### `save_report`

把一段 Markdown 报告保存成文件，并按需要直接打开。输出格式有四种：Markdown、HTML、PDF、DOCX。PDF 和 DOCX 由渲染流程生成。

| 参数 | 含义 | 默认值 |
|---|---|---|
| `content` | 报告内容，Markdown 写法，必填 | |
| `file_path` | 输出文件路径，必填 | |
| `format` | 输出格式，`md`、`html`、`pdf`、`docx` | `md` |
| `open_after_save` | 保存后是否打开查看，`true` 或 `false` | `true` |

改动类工具，会写文件并可能占用查看器窗口。写长报告时比 `write_file` 合适，因为它负责格式转换和打开。

可以说：「把刚才的分析结论整理成一份 PDF 报告，保存到桌面。」

## 脚本工具

两个工具执行 Python 代码，用来做内置工具覆盖不到的加工。它们共用一份运行空间，变量在同一个会话里跨调用保留，不同会话之间互相隔离。

运行空间在第一次调用时创建，之后一直在。一次调用里定义的变量，下一次调用可以直接用：

- `run_code` 里写下 `df = da_app.getCore().getDataManagerInterface().getAllDataframes()["sales"]`，之后 `run_script` 里可以直接引用 `df`。
- 反过来也一样，脚本里算出的中间结果在下一次 `run_code` 里还在。
- 会话关掉之后运行空间释放，变量不再保留；把需要的结果存成数据集或文件再关会话。

这个环境与脚本工作区共用一套约定：`da_app`、`da_interface`、`da_data` 已经在运行空间里导入好，标准输出和标准错误会被捕获进工具结果。数据访问和绘图的写法见[脚本工作区](../script/workspace.md)。

两个工具都在主线程上执行，运行期间界面会卡住不动，长任务要留意超时。默认超时 300 秒，超时后脚本被中断，工具结果里带上中断的说明。运行空间里可以读取一个名为 `args` 的字典，内容就是调用时传进来的 `args` 参数，用来给同一段代码传不同的值。

### `run_script`

执行工程脚本工作区里的一个脚本文件。脚本路径相对于工作区根目录，比如 `scripts/analyze.py`，因此这个工具需要先有一个保存过的工程；没有工程时换成 `run_code`。脚本必须是 UTF-8 编码，运行时的当前目录就是工作区根目录。脚本可以用 `__result__` 变量给出一个返回值，这个值会出现在工具结果的摘要里。

| 参数 | 含义 | 默认值 |
|---|---|---|
| `path` | 脚本路径，相对工作区根目录，必填 | |
| `args` | 注入运行空间的参数字典，键值在脚本里按 `args` 读取 | |

改动类工具。脚本能读写文件、改数据、画图，能力与手工运行脚本一致，属于需要确认的一类。

可以说：「运行工作区里的 analyze.py，把 clean 参数设成 true。」

### `run_code`

直接执行一段写在参数里的 Python 代码，不需要工程，也不需要事先存文件。适合临时计算、格式转换这类一次性的加工。

| 参数 | 含义 | 默认值 |
|---|---|---|
| `code` | 要执行的 Python 代码，必填 | |
| `args` | 注入运行空间的参数字典 | |

改动类工具，能力与 `run_script` 相同，属于需要确认的一类。

可以说：「用 Python 把刚才那张表的日期列统一成 yyyy-MM-dd 格式。」

## 文献工具

两个工具随论文撰写插件发布，用来在写作时查证参考文献。它们需要能访问互联网上的文献元数据服务，通过网络代理连接时按系统的代理环境变量走。插件停用后这两个工具从清单里消失。

### `search_literature`

按关键词检索真实的学术文献，来源是 CrossRef 和 OpenAlex 两个免费元数据服务。返回的每条结果带 DOI、标题、作者、期刊、年份和文献类型。

| 参数 | 含义 | 默认值 |
|---|---|---|
| `query` | 检索关键词，比如 `linear regression air quality`，必填 | |
| `max_results` | 最多返回几条，上限 20 | 8 |
| `source` | 检索来源，`crossref`、`openalex` 或 `auto` | `auto` |

只读工具，不联网时返回失败说明，不会编造文献。

可以说：「找几篇 2020 年以后关于空气质量与线性回归的论文。」

### `verify_doi`

核对一个 DOI 是否存在，并取回它的准确元数据：标题、期刊、年份、作者。写参考文献列表之前用它确认，避免引用不存在的条目。

| 参数 | 含义 | 默认值 |
|---|---|---|
| `doi` | 要核对的 DOI，允许带 `https://doi.org/` 前缀，必填 | |

只读工具，数据来自 CrossRef。

可以说：「核对一下 10.1038/s41586-020-2649-2 这个 DOI 对不对。」

## 不在插件工具清单里的两个

有两个名字会出现在对话的卡片上，但它们不是插件注册的工具，因此不会出现在子智能体编辑器的工具勾选列表里，也不在插件工具清单中：

- `ask_user`，提问工具。智能体需要用户拿主意时调用它，界面上渲染成一张提问卡片，选项和自由输入框的用法见[会话与对话](session.md)。这个工具由智能体运行程序在需要交互的场合注入，子智能体没有它。
- `dispatch_subagents`，派发工具。智能体把一个大问题拆成若干子任务，一次性交给几个子智能体并行处理，调用结果渲染成一张进度卡片。它的参数结构按当前已有的子智能体定义动态生成，见[子智能体](subagent.md)。

两个都由运行侧提供，卡片上照常显示调用过程和结果，只是不在设置页的工具清单里出现。子智能体编辑器里能勾选的工具来自插件注册的那一批，所以列表里看不到它们的名字。
