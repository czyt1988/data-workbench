# 表内快速绘图

选中表格里的列，点一下就能在表格上方弹出一个图表浮窗；看着合适可以随时关掉，也可以一键转入绘图区变成正式图表。

## 1. 从哪里打开

| 入口 | 位置 |
|---|---|
| Ribbon「快速绘图」 | 数据表上下文标签的「列」面板（与重命名、定位最大、描述统计同一个面板） |
| 列头右键「快速绘图」 | 在表头任意列上右键 |

- Ribbon 入口使用**当前选区**；没有选中任何列时按钮置灰。
- 列头右键：如果右键的那一列已经在多选里，保留整个多选；如果不在，就只选这一列再出图。
- 列视图里被隐藏的列不参与绘图。

## 2. 浮窗里能做什么

| 区域 | 说明 |
|---|---|
| 图型按钮 | 只列出当前选区可行的图型，默认选中最合适的那一个；切换只换图元，不重开浮窗 |
| 聚合方式 | 分类 + 数值时出现，默认「平均值」，可换最小/最大/求和/中位数/计数/标准差/方差 |
| X 轴 | 多列数值或时间 + 数值时出现：行号、某个已选数值列，或低基数数值列的「作为分类」 |
| 图表区 | 真图表：缩放、平移、十字线等绘图区里的交互都能用 |
| 底部说明 | 采样行数、缺失值剔除行数、Top N 说明、数据变化提示 |
| 更新为当前选区 | 按表格里现在的选区重画（尽量保持当前图型） |
| 转入绘图区 | 默认新建一个绘图标签页；下拉可选「追加到当前图表」 |

浮窗可以拖动标题栏移动，按 `Esc` 或右上角关闭。

## 3. 选中什么出什么图

| 选区 | 默认 | 还能切到 |
|---|---|---|
| 1 列数值 | 折线 | 直方图、箱线图 |
| 1 列文本/布尔 | 柱状（按类别计数） | — |
| 2 列数值 | 散点 | 折线、箱线图、柱状（把低基数那一列当分类） |
| 时间 + 数值 | 折线 | 散点 |
| 文本 + 数值 | 柱状（按文本分组聚合） | 按类别箱线图 |
| 3 列及以上数值 | 多序列折线 | 箱线图（每列一个箱） |
| 时间 + 2 列以上数值 | 多序列折线 | — |

以下组合暂时不支持，浮窗不会出现，消息区会说明原因：

- 只有一列时间列（请再选一列数值）；
- 两列文本（交叉柱状图后续提供）；
- 一个文本列 + 两个以上数值列（分组柱状图后续提供）。

## 4. 数据口径

- **分类柱状图**：同名类别会合并，默认取平均值；柱子默认按数值从高到低排。类别特别多时只显示前 30 类，底部会写「显示前 30 类 / 共 N 类」。
- **箱线图**：固定按 1.5 倍四分位距画触须、显示离群点，不带置信区间；需要调参请用统计绘图向导。
- **采样**：小于 5000 行的小表全量绘制；大表折线/散点约 2000 点、直方图约 2 万个值，底部会标注「基于 N / M 行采样」。
- **精确优先**：分类聚合与箱线图在内存表且行数不大时对全量计算，不标注采样；只有超大表或外部表才采样并标注近似。
- 分类或数值缺失的行在绘图前剔除，底部会写「已忽略 N 行缺失值」。

## 5. 转入绘图区

- 默认**新建一个绘图标签页**，不污染已有图表；下拉「追加到当前图表」会把图元加进当前图表。
- 转入后浮窗自动关闭，图表区选中新图，图进入工程、可编辑、随工程保存。
- 一次 `Ctrl+Z` 可以把整个转入撤销掉（新标签页一起消失），`Ctrl+Y` 整体恢复。
- 转入后坐标轴范围会按正式图表尺寸重新自适应；需要更细的样式、轴范围、图例设置，在绘图区的图表设置面板里调。

## 6. 与完整向导、统计向导的分工

| 需求 | 用哪个 |
|---|---|
| 看表时临时看一眼趋势/分布 | 快速绘图 |
| 要精确口径、要调分箱/置信区间/whis 等参数 | 绘图区「添加绘图」向导 或 统计绘图向导 |
| 要 KDE、ECDF、热图、回归、等高线 | 统计绘图向导（快速绘图不覆盖） |
| 要拖拽式排版、多子图 | 绘图区 |

快速绘图刻意不提供「更多设置」：需要高级配置时先转入绘图区，再在图表设置里改。
