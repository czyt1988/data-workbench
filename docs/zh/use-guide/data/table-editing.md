# 表格编辑功能总览

这一章汇总数据表格的全部编辑能力：每项功能从哪里进（Ribbon 面板 / 表体右键菜单 / 快捷键）、大致怎么用、撤销行为是什么。单项功能的深入细节（参数、落位规则、边界情况）在[表格视图](./table.md)与[表格样式](./style.md)里，本章按「能力清单」组织，方便按图索骥。

所有写数据的动作都进当前标签页的撤销栈，`Ctrl+Z` 逐步回退；「撤销历史」面板（见本章末尾）可以看到整条操作记录并一键回退到任意一步。校验是只读操作，不改数据也不进撤销栈。

## 表头排序

点击列头即按该列排序（首次升序、再点降序），按住 `Shift` 或 `Ctrl` 点击其它列头可追加为次排序列，列头上显示方向箭头与优先级序号。排序是破坏式重排（数据行真的换位置），撤销走置换记录：`Ctrl+Z` 一次还原行序，样式、批注等按行记录的元数据跟着行一起回来。只读数据源上排序入口不生效。详见[表格视图](./table.md)的「行头与列头」一节。

## 查找 / 替换

`Ctrl+F`（或右键「查找…」）在表格上方唤出非模态浮动查找条，输入即扫（带去抖），命中格以金黄高亮、当前命中以蓝色高亮，上下按钮循环导航；`Ctrl+H` 展开替换行。替换当前命中或全部替换都进撤销栈——全部替换是**一个**撤销单元，`Ctrl+Z` 一次还原。变更格数超过上限（100 万格）时会降级为「本次不可撤销」并先征求确认。`Esc` 关闭查找条并清除查找高亮。

## 条件格式

「Table Style / 表格样式」页「Conditional / 条件格式」面板或表体右键「条件格式…」打开规则编辑对话框（一窗两栏），对选中列配置三类规则：单元格规则（大于/小于/介于/等于/包含/为空/非空 → 前景/背景/字体）、双色/三色色阶、数据条。编辑期间表格实时预览，确定后按差异入撤销栈。规则随工程保存；色阶与数据条需要全列统计，惰性/只读数据源上这两类在对话框内置灰。详见[表格样式](./style.md)。

## 计算列 / 分列 / 合并列 / 分组聚合 / 转置与 melt

这五项在[表格视图](./table.md)各有专章（「计算列」「分列与合并列」「分组聚合」「转置与宽转长」），这里只记要点：

- **计算列**：写表达式生成新列（禁止覆盖已有列），列头有 ƒx 三态标识（有效/待重算/失效），重算是手动的，创建与重算都进撤销栈。
- **分列 / 合并列**：右键菜单按选区列数自动启用（单列选区→分列，多列选区→合并）；预览与执行同一算法；撤销一次完全还原列序/列数/内容。
- **分组聚合**：产出长格式**新数据集**（原名_GroupBy），原表不动；注册动作可撤销。
- **转置 / melt**：默认产出新数据集（原名_Transposed / 原名_Melted），可选「就地替换」——就地时确认框列出将被清除的元数据条目数，超大表降级为不可撤销。

## 填充

选区上的 Excel 式填充，五个动作都在「Edit / 编辑」面板「Fill / 填充」下拉与表体右键「填充」子菜单里：

- **向下填充**（`Ctrl+D`）：每列用选区**首行**的值填满其余选中行；
- **向上填充**：每列用选区**末行**的值填满其余行；
- **向下填充空值（ffill）**：选区内把空值用上方最后一个非空值补齐；
- **向上填充空值（bfill）**：选区内把空值用下方第一个非空值补齐；
- **序列填充…**：对话框生成数值等差（起始值/步长/终止值）或日期步进（天/周/月/年）序列，写入选中列的选中行，对话框内实时预览前几个值。

填充按**列独立**处理：多列选区里每列在自己的选中行区间内传递，互不串列；不规则多选（Ctrl 点选）只对选中的连续行段生效。空值判定（NaN/NaT/None）由 pandas 完成，各 dtype 下语义一致。一次填充 = 一条撤销记录，`Ctrl+Z` 一次还原。选区不足两行时向下/向上/ffill/bfill 菜单项置灰。

> **💡 与「数据清洗」里 Fill None / Fill Interpolate 的区别**
>
> 数据分析插件「Data Cleaning / 数据清洗」面板里的 Fill None（列级/全表缺失值填充：值/ffill/bfill/均值/中位数/众数）与 Fill Interpolate（插值）是**面向整列的清洗动作**，产出新数据并可进工作流；本章的「填充」是**面向选区的表格编辑动作**，直接改当前表。两者语义不同、都保留。

## 数据校验

「Data Tools / 数据工具」面板与表体右键提供两个入口：

- **校验规则…**：管理当前表的列级规则——数值区间、日期区间、枚举集合、非空、唯一、正则（整格匹配），每条规则带「错误/警告」级别与启用开关。规则按**列名**引用（重名列以「第 n 个同名列」区分），随工程保存；列改名时提示「有 N 条校验规则引用它」并可自动同步。
- **执行校验**：按全部启用规则一键校验（只读：不改数据、不进撤销栈），违规格在表内高亮（错误=橙红、警告=金黄，与查找命中互不干扰），并弹出报告对话框——按规则分组、显示违规数与样例行，点击样例行直接定位到表格单元格，报告可导出为 HTML/PDF/Word。「清除高亮」只清违规高亮，不影响查找命中。

唯一性校验在大表上按列缓存重复集合：数据没变时重复点「执行校验」不会重算（100 万行混合四类规则实测约 0.1~0.2 秒一轮）。枚举规则还附带编辑增强：被枚举规则覆盖的列在双击编辑时出现下拉框，「允许其他值」开关关闭时只能从列表内取值（只读数据源不会出现编辑器）。

## 单元格批注

右键「插入批注」（或 Ribbon「Edit / 编辑」面板「Note / 批注」下拉）在当前单元格旁弹出小编辑层，写纯文本后保存；有批注的格右上角出现金黄小三角角标，鼠标悬停显示批注全文。「编辑批注 / 删除批注 / 清除本表批注」同入口，全部动作进撤销栈（清除本表批注是一条命令）。

批注跟着行走：排序、插入/删除行列后批注自动跟随原行移动，不会错位。批注随工程保存、重开恢复；它是元数据**不进 DataFrame**——导出 CSV/Excel、进工作流、给智能体读数据都不含批注内容。

## 撤销历史面板

「View / 视图」页「Undo History / 撤销历史」（右侧边栏，点击即弹出）显示**当前激活页面**的撤销记录：每条是命令的中文描述（来自翻译），点击任意条目一步跳到该状态（等价连续撤销/重做到那一步），切换表格标签页时面板内容自动跟随。

面板顶部可调整**撤销深度**（每个表格页保留的最大撤销步数，默认 20）：调大后对全部已打开与新建的表格页生效，并持久化到配置文件（`dawork-config.xml` 的 `undo-stack-limit` 键）。调大的内存风险很小——绝大多数命令只记录改动量或索引；只有转置/melt 的「就地替换」（Swap 类）会让旧对象驻留内存，该场景已有超大表降级提示兜底。

> **⚠️ 撤销记录跟着标签页走**
>
> 每个表格标签页有自己的撤销栈，面板显示的是当前激活页的记录；关闭标签页后该页的撤销记录清空（已生效的数据修改保留）。工作流与图表页的撤销栈同样注册在全局撤销组里，激活时面板同样跟随。
