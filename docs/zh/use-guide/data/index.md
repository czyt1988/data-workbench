# 数据

这一部分讲数据从进入软件到离开软件的全过程：导入、在面板里管理、在表格里查看和修改、设置显示样式、导出。

软件把导入进来的每一份数据叫做数据集。数据集在「Data Manager / 数据管理」面板里有一个名字，双击某个数据集会打开表格视图。工作流、图表、智能体都围绕数据集展开，因此这一部分是后面几部分的基础。

## 章节目录

- [导入数据](import.md)：支持的文件格式、各格式的参数、文本文件的导入向导。
- [数据管理面板](manager.md)：数据集的列表、重命名、删除、搜索。
- [表格视图](table.md)：查看和编辑单元格、增删行列、改列类型、复制粘贴。
- [表格样式](style.md)：单元格底色和字体的设置与清除。
- [导出数据](export.md)：四种单文件格式、批量导出、导出成多工作表的 Excel 文件。

## 建议的读法

导入和表格这两章是必须看的，其余按需要跳读。只用表格做快速核对的话，[表格样式](style.md)可以完全略过。

## 和别的部分的关系

- 表格视图里改的是内存里的数据，改完要保存工程才会写进工程文件。
- 数据清洗、筛选、排序这类批量操作不在这一部分，它们在[筛选、计算与排序](../analysis/query.md)和[数据清洗](../analysis/cleaning.md)里。
- 工作流也能产出数据集，见[工作流基础](../workflow/basics.md)里结果去了哪里一节。
