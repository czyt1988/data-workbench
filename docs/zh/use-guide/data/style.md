# 表格样式

表格的底色和字体是覆盖在数据上的一层显示设置。改样式不会改单元格里的值，导出文件也不带样式，它的作用范围只限软件里的这张表。这一章讲三个样式面板的用法、样式写在什么层级、样式存在哪里，以及与显示格式的区别。样式随数据集保存，关掉表格标签页、重开工程都不丢。

## 样式面板在哪

打开任一数据集得到表格标签页后，Ribbon 上会出现上下文标签页「DataFrame」，它有两页：「Operate / 操作」和「Table Style / 表格样式」。样式相关的控件都在第二页上，分成三块。

| 分组标题 | 内容 |
|---------|------|
| `Fill` / 底色 | 一个颜色按钮，管单元格底色 |
| `Font` / 字体 | 字体、字号、粗体斜体下划线、字体颜色 |
| `Clear` / 清除 | 两个清除样式的动作 |

没有打开任何表格时这个上下文标签页不出现，也就用不了这些控件。

## 底色

「Fill / 底色」面板是一个带下拉箭头的颜色按钮。点箭头打开调色菜单：上面一格一格的「Theme Colors」主题色，中间是 `None`（不给底色），下面是「Custom Color」，选完后由系统取色器挑任意颜色。当前版本里点按钮主体不套用颜色，选色在菜单里进行。每次选色都立即作用到当前选区。

底色只影响单元格的背景，字仍是原来的颜色。深色底配深色字会看不清，这时顺带把字体颜色也改掉。

## 字体

「Font / 字体」面板里可以改字体族、字号、粗体、斜体、下划线和字体颜色，改哪一项就套用哪一项，底色的设置不受影响。

字体族下拉框里是系统里可用的字体，字号有下拉与加减按钮两种改法，粗体、斜体、下划线三个按钮各自独立。面板上的取值会跟着选中区的实际样式反向更新：选中一片已经有样式的格子，面板上显示的就是它们的字体；选中区里各格子的某项样式不一致时，那一项对应的控件保持不动，这时改它会一次覆盖整片选区。

## 样式写在哪个层级

底色和字体的设置会按选中范围自动落到三个层级之一，这个区别决定了它对多少单元格生效。

| 选中方式 | 落到哪一层 | 影响范围 |
|---------|-----------|---------|
| 点列标题选中整列 | 列级 | 该列全部行，包括之后插入的新行 |
| 选中整行 | 行级 | 该行全部列 |
| 选中若干单元格 | 单元格级 | 只有这些格子 |

渲染一个格子时，列级、行级、单元格级三层样式依次叠加，越具体的一层越优先。同时给整列设了底色、又给列里某个单元格单独设了字体，那个格子的底色来自列、字体来自单元格。

把新设置合并进选区的写法意味着只覆盖本次改的属性。先给一批格子设了底色，再给同样的格子改字号，底色保留；只选了一部分格子改字号，那部分格子的底色仍是列级或行级带下来的。

三者同时存在时，清除要选对层级：清单元格级的样式只需选中那几个格子，清列级要把整列选中。选中范围决定了清除动作落在哪一层。

样式接口里另有一个「整体替换」的写法（传入的样式把选区原有样式整套盖掉），它是给格式刷预留的，当前界面上没有对应的按钮。

没有选中任何单元格时，点样式面板里的控件只会提示需要先选择有效的单元格，不做改动。

## 自定义颜色

`Custom Color / 自定义颜色` 打开系统取色器，可以选任意颜色。这类颜色直接生效，不会加进上面的主题色格子里；调色菜单上半部分的主题色来自界面框架的标准调色板，一格一个颜色。

同一批单元格反复调整时，每次调整形成一条撤销记录，撤销按调整顺序逐条回退。要一次回到默认外观，用「Clear All Style / 清除所有样式」比逐条撤销快。

## 样式记录的粒度

样式记录只保存被显式设置过的属性。给一个格子上只设了底色，这条记录里就只有底色，字体这一项不写；渲染时没有被设置的属性按默认显示走。这样叠加三层时各层各管一部分，不会互相覆盖掉对方没碰过的属性。

工程保存时写出的也是这些已设置的属性，没有样式的数据集在文件里根本不出现条目，所以一份全新的数据集打开后是默认外观，不需要额外的样式信息。

## 改动立即生效

样式面板没有确认按钮，改一项就应用一项：调色菜单里点一个颜色，选区底色当场变化；字体面板里点一下粗体，选区的字当场加粗。面板上的控件与选中区保持同步，选中区一变，面板上显示的取值跟着换成新选中区的样式，所以连续给不同区域设样式时不用手动重置面板。

## 列宽与行高不在样式里

这套样式记录里只有底色、字体、字体颜色三层记录和列级的显示格式，列宽与行高不在其中。列宽靠拖动列头之间的分隔线调整，它是表格视图自己的显示状态：清样式不动列宽，改列宽也不影响样式。

## 一次完整的设置过程

给一张表做出「表头整列加深底色、表头文字加粗」的效果，步骤是下面这些。

1. 在数据管理面板里双击数据集，打开表格标签页。
2. 点某一列的列标题，整列被选中，落点定在列级。
3. 打开「Fill / 底色」的调色菜单选一个颜色，整列底色立即变化。
4. 保持整列选中，在「Font / 字体」面板里点粗体按钮，字加粗，底色保留。
5. 逐列重复第 2 到第 4 步；各列设置互不影响。
6. 改错了按 Ctrl+Z 逐条回退；想一次清干净，用「Clear / 清除」面板里的「Clear All Style / 清除所有样式」。

第 2 步的选中范围决定了后面所有动作落在哪一层。同一个效果如果只选中了表格中间几格，落点就是单元格级，插入新行时那几格不会跟着变化。

## 清除

「Clear / 清除」面板有两个动作。

- 「Clear Selected Style / 清除选中样式」按选中的层级清掉样式记录：整列选中时清列级，整行选中时清行级，只选中格子时清这些格子上的单元格级记录。
- 「Clear All Style / 清除所有样式」清掉当前数据集在三个层级上的全部样式记录。

两者都把底色、字体、字体颜色一起清掉，没有「只清底色」的按钮。想只去掉底色、保留字体，清除后重新设一次字体。清除按选中的层级判断范围：只选中几个格子时，清的是这些格子上直接写的样式，列级和行级带下来的样式还在，要动那一层就整列或整行选中再清。

## 样式与显示格式的区别

「Format / 格式」面板（见[表格视图](./table.md)）改的是「值怎么显示」：把 `3.14159265` 显示成 `3.14`，或者把日期显示成另一种格式串。它按列保存，进的是另外一套记录，改完数值本身没有变，复制和导出拿到的仍是原值。

本章的样式改的是「看起来什么样」：底色、字体、字体颜色。它和数据里的值毫无关系，三层都可以写。

两套记录互相不干扰：清除样式不动显示格式，反过来把某一列的显示格式设回「General / 通用」也不动底色和字体。

## 样式影响不到的地方

样式是显示层的设置，覆盖范围只到软件里的表格。

- 数据本身不变。选中单元格看内容、用描述统计算出来的结果、工作流节点读到的值，都是原值。
- 导出的文件里没有样式。CSV、Excel、Parquet 这些格式里只会有列名和数据，底色与字体不跟着走，见[导出数据](./export.md)。
- 复制到剪贴板的也只是文本。复制取的是显示格式处理后的字符串，底色和字体不会跟着贴到别的程序里。
- 绘图与智能体读到的也是数据。样式不会改变图表上的点，也不会改变智能体读到的值。

要在别的程序里保留表格外观，用截图，或者导出 Excel 之后在那个程序里重新设置格式。

## 样式存在哪里

样式不跟着表格标签页走，它跟的是数据集。

- 关掉表格标签页再打开，样式还在。
- 保存工程时，样式写进工程压缩包里的 `table-styles.xml`，每份数据对应一条记录，用数据的内部标识（`data-id`）作匹配键，名字作为附带的参考写在同一处。
- 打开工程时先按标识找对应的数据，找不到才退回到按名字匹配，这个回退是为了兼容更早的工程文件。
- 数据集改名不影响样式，因为匹配键是内部标识，名字只是附带的参考。
- 与样式关联的还有一件事：删除数据集后撤销回来，样式跟着一起回来。

工程里样式和数据是分开存的：数据本身是工程压缩包里的 `datas/` 目录下一份 Parquet 文件，表格样式只是薄薄一层显示设置，见[工程文件](../getting-started/project.md)。

## 同一个数据集在哪儿看到的样式都一样

样式挂在数据集上，一份数据集只有一个样式记录。拖动表格标签页、把它分屏、改标签的停靠位置，样式都不跟着变；关掉标签页再打开也是同一份记录。工程关闭再打开时，样式在数据装载完成后回填到数据集上，随后打开这张表的标签页就能看到，不需要重新设置。

## 样式与撤销

设置底色、改字体、清除样式都会压入撤销命令，走当前表格标签页的撤销栈，用主页标签页、「Clipboard / 剪切板」面板里的「Undo / 撤销」（快捷键 Ctrl+Z）逐步撤回，同一面板的「Redo / 重做」把刚撤回的那一步再应用一次（快捷键按系统约定，Windows 上是 Ctrl+Y）。每个表格标签页有自己的撤销栈，切换标签页时撤销按钮作用的对象也跟着切换。

行列的增删会同步调整样式记录：插入行或列时，被顶到后面的样式记录跟着挪位；删除行或列时，落在被删行列上的样式记录一起丢掉。也就是说在带样式的行上方插入新行，新行不带样式，原来那几行的样式跟着下移，位置不错乱。

!!! warning "删除行列会带走样式"

    删除行或列之后，落在被删行列上的样式记录会一起消失，撤销删除能恢复数据，样式不会跟着回来。样式较复杂时，先导出数据留一份底，再动行列。

## 常见问题

- 给整列设了底色，后来插入的新行也有底色：列级样式对所有行生效，包括新插入的行。
- 只想改一个格子的底纹：只选中那个格子再选颜色，落点就是单元格级，列级和行级带下来的其它属性保持不变。
- 单元格级和列级都设过底色，后来想去掉单元格上的那一层：选中那几格后点「Clear Selected Style / 清除选中样式」，列级带下来的底色还在，重新露出来；去掉列级要把整列选中再清一次。
- 关掉表格标签页会不会丢样式：不会，样式跟的是数据集。打开同一份数据看不到之前的样式时，先确认是不是删过行列，或者看的其实是另一个工程里的同名数据。
- 重命名数据集后样式丢了：样式按数据标识匹配，改名不影响；找不到样式通常是数据被删除重建过，新建的数据集是一份新数据。
- 清除样式后显示格式还在：显示格式与样式是两套记录，清样式不动显示格式，把格式下拉框选回「General / 通用」才会去掉。
- 深色底看不清字：底色不动字体颜色，改完底色再在「Font / 字体」面板里把字体颜色一起改掉。
- 换了机器字体不一样：工程里存的是字体族名字，另一台机器上没有这个字体时，系统用替代字体显示，底色和字号不受影响。
- 想把带样式的表格交给别人看：样式只在本软件里显示，导出文件不带样式。交给同样装了软件的同事可以直接给工程文件；只要数据就给导出文件，见[导出数据](./export.md)。
