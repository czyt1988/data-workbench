# 导出数据

导出把数据管理面板里的数据集写成文件，交给别的软件继续用。软件有四种导出方式：数据标签页的单文件导出、数据分析插件的单个数据集另存为、一次导出多个数据集到文件夹，以及把多个数据集写进一个多工作表的 Excel 文件。这一章按这四种方式讲入口、参数和结果，最后说明哪些东西导不出来。

导出的对象是数据框。数据管理面板里的一级条目大多数是数据框，能直接导出；脚本里以其它对象形式加进来的数据集不是数据框，走数据标签页的导出会被拒绝，提示「Only DataFrame data can be exported / 仅支持导出 DataFrame 数据」。数据集里没有可取出的数据对象时提示「Data is empty, cannot export / 数据为空，无法导出」。

导出的来源不限：导入的文件、脚本构造的数据框、工作流输出到数据管理器的结果，只要在数据管理面板里，都能用下面的方式写出文件。导出读的是数据集当前的内容，导出本身不修改数据，也不清理工程，要留下改动还得保存工程。

## 单文件导出：Export Data

入口是 Ribbon 数据标签页、「Export / 导出」面板里的「Export Data / 导出数据」按钮，按钮提示为「Export the selected data to a file / 导出选中的数据到文件」。按钮带下拉箭头：

- 点按钮主体，弹出保存对话框，四个格式都在过滤器列表里，按选中的过滤器决定格式。
- 点箭头展开菜单，菜单里四项直接指定格式：「Export CSV / 导出 CSV」、「Export Excel / 导出 Excel」、「Export Pickle / 导出 Pickle」、「Export Parquet / 导出 Parquet」。

导出哪一个数据集，按两处依次判断：数据管理面板里选中的那个优先；没有选中时用当前打开表格对应的数据集；两处都没有时提示需要先选中要导出的数据，不弹对话框。保存对话框的标题是「Export Data / 导出数据」，文件名默认填数据集的名字，过滤器有 `CSV File (*.csv)`、`Excel File (*.xlsx)`、`Pickle File (*.pkl)`、`Parquet File (*.parquet)`。点按钮主体时，格式按这三层依次判断：菜单里指定的格式、保存对话框里选中的过滤器、文件名后缀；都没给出格式时提示无法确定导出格式，需要在文件名里带上后缀。文件名没写后缀时软件按当前格式补一个。

四种格式的差别在读者和类型信息上。

| 格式 | 后缀 | 适合的用法 |
|------|------|-----------|
| CSV | `.csv` | 交给别的软件做后续处理，任何表格软件都能打开 |
| Excel | `.xlsx` | 给人看、需要手工调整的单表数据 |
| Pickle | `.pkl` | 在 Python 之间搬运，保留列类型与索引 |
| Parquet | `.parquet` | 大表在 pandas 与数据库工具之间传递，体积小、读得快 |

CSV 与 Excel 写出时不带行号：写文件时关掉了行索引（`index=false`），文件里只有列名和数据行。Pickle 与 Parquet 会把行索引一起写进文件，这两种格式的惯例就是这样，读回来时索引还在。

写这四种格式时有几处值得留意。CSV 与 Excel 都不保存列的类型，数字列与文本列在文件里看不出区别，读回来会按内容重新推断；需要连类型一起交出去时选 Parquet 或 pkl。Parquet 与 pkl 依赖 Python 侧的扩展包（pyarrow 与 pandas），环境里缺包时导出会失败，提示里带原因。四种格式都写出当前数据集里的全部行列，导出的范围就是这个数据集本身。

导出由 Python 侧完成，是一次等待完成的操作。文件被别的程序占用、磁盘没有权限一类的失败会以提示的形式给出路径和原因：「Data export failed, path: %1, reason: %2 / 数据导出失败，路径:%1，原因:%2」；成功时提示「Data exported successfully, path: %1 / 数据导出成功，路径:%1」。

## 导出单个数据集：Export Individual Data

这一条是数据分析插件提供的，入口在同一个数据标签页、「Data Operation / 数据操作」面板里：「Export Individual Data / 导出单个数据」。

用法是先在数据管理面板里选中一个数据集，再点这个按钮；没有选中任何数据集时，软件只在消息窗口提示需要先选中要导出的数据，不弹对话框。接下来弹出的是系统的另存为对话框，标题也是「Export Data / 导出数据」，过滤器列表比前一条长：

| 过滤器 | 后缀 |
|--------|------|
| `Csv Files (*.csv)` | `.csv` |
| `Excel Files (*.xlsx)` | `.xlsx` |
| `Parquet Files(*.parquet)` | `.parquet` |
| `Feather Files(*.feather)` | `.feather` |
| `Python Files (*.pkl)` | `.pkl` |
| `HTML Files (*.html)` | `.html` |
| `Json Files (*.json)` | `.json` |
| `All Files(*.*)` | 按文件名后缀 |

格式由文件名后缀决定。各格式的写法略有差别：CSV、Excel、Parquet、HTML 都不写行号；Feather 会先把索引还原成普通列再写，读回来时它是一列数据；Pickle 按 pandas 的原样写出；JSON 写出时中文不做转义，文件里能直接看到中文。写出的成功提示为「Successfully exported %1 to %2 / 成功把%1导出到%2」，出现在消息窗口里。

与第一种方式相比，这条多了 Feather、HTML、JSON 三种格式，代价是一次只处理一个数据集。

## 批量导出：Export Multiple Data

入口是「Data Operation / 数据操作」面板里的「Export Multiple Data / 导出多个数据」，按钮提示说明它把数据管理面板里的数据逐个导出到文件夹。

点击后弹「Export Data Setting / 导出数据设置」对话框，内容三块。

- 文件夹路径输入框，右边按钮的提示是「Select Folder To Export / 选择要导出的文件夹」，打开系统的目录选择框。文件夹路径留空时，点 OK 会提示需要选择导出文件夹，不开始导出。
- 导出范围：`Export All` / 导出所有（默认选中）与 `Export Selected` / 导出选中。选后者时只处理数据管理面板里选中的数据集。
- 格式单选列表，每项后面有一句说明：

| 选项 | 说明 |
|------|------|
| `csv` | 逗号分隔的文本，通用格式，适合交换数据和基础分析 |
| `xlsx` | 微软 Excel 格式，支持多工作表和格式 |
| `Parquet` | 列式二进制格式，压缩率高、查询快，适合大数据量 |
| `Feather` | 轻量二进制格式，读写很快，适合作中间数据 |
| `Pickle` | Python 专有二进制格式，保留完整的对象结构 |
| `JSON` | 人可读、方便网页使用的文本格式 |
| `HTML` | 网页格式，保留表格样式，适合放进报告或邮件 |

每个数据集写成文件夹里的一个文件，文件名是数据集的名字加上所选格式的后缀。选择「导出选中」而面板里没有选中任何数据集时，导出会正常结束，只是文件数为 0。

写文件前软件会检查目标文件夹能不能用：给出的路径是一个已存在的普通文件时导出失败。导出过程中关掉软件会留下写了一半的文件，重新导出覆盖即可。

导出在后台线程里跑，界面可以继续操作。状态栏上出现一条进度，显示当前正在写的文件与已用时间（格式为「%1. Elapsed: %2:%3 / %1,已用时%2:%3」），全部写完后再给出一句结果与总耗时。导出成功后软件把导出文件夹打开，方便直接查看结果。

目标文件夹在导出开始前不存在时，软件会新建它。每个文件落在文件夹的顶层，不按数据集再分子目录，一次导出一百个数据集就会有一百个文件并列在同一个目录里，导出前把目标目录选在一个空目录下更清爽。

## 批量导出到一个 Excel：Export To Excel

入口是「Data Operation / 数据操作」面板里的「Export To Excel / 导出Excel」，提示说明它把数据管理面板里的数据写进一个 Excel 文件，每个数据集占一个工作表。

流程分两步。第一步是系统的另存为对话框，标题「Save as Excel File / 保存为 excel 文件」，过滤器只有 `Excel (*.xlsx)` 一项。第二步弹「Export Setting / 导出设置」对话框，里面「Select Export Range / 选择导出的范围」有两个选项：`Export All` / 导出所有与 `Export Selected` / 导出选中。

确认后每个数据集写成一个工作表，工作表名就是数据集的名字，写入前软件把名字里的 `/`、`\`、`*`、`?`、`[`、`]` 六个字符替换成下划线，因为 Excel 不允许这些字符出现在工作表名里。两份数据的名字如果只有这几个字符的差别，替换之后会撞到同一个工作表名，写入失败，这一次导出整体不成功。工作表内容不带行号，行索引不写出。

这个任务同样在后台线程里跑，状态栏显示进度和当前正在写的工作表名，完成后给出结果和耗时。中途失败时，软件会把已经写出来的不完整 Excel 文件删掉，不会留下一个半成品文件。

## 导不出来的东西

- 只有数据框能被导出。数据管理面板里的一级条目基本都是数据框，脚本里以 Series、普通 Python 对象等形式存在的数据集不在这四种方式的处理范围内。
- 绘图、坐标系、图表没有导出数据的命令。绘图可以复制成图片或导出图片，做法见[复制与保存图表](../chart/save.md)；要拿图表背后的数据，导出画它用的那个数据集。
- 导出的是整个数据集，没有「只导出选中的单元格区域」这个功能。需要局部数据时，先把不需要的行删掉或筛掉再导出，筛选见[筛选、计算与排序](../analysis/query.md)。
- 表格的底色和字体不会写进导出的文件，它们只是软件里的显示设置，见[表格样式](./style.md)。
- 显示格式也不写进文件。表格里看到两位小数，是因为这一列设了显示格式；导出的文件里写的是原始值，这是前面「Export Data」一节里说明过的差别。
- 数据集的描述与工程里的打开状态同样不进入导出文件，导出文件只有列名和数据。

工作流里另有一个 `Data Export` 节点，支持 csv、json、excel、parquet、feather 五种格式，适合把每次运行的结果固定写到一个位置，见[数据分析节点手册](../workflow/nodes-analysis.md)。

导出失败不会动到数据集。写文件出问题时，数据管理面板里的数据保持原样，改好目标路径或关掉占用文件的程序再导出一次即可。

## 导出与保存工程的分工

保存工程把数据留在工程里，导出把数据交给别的程序，两者互不替代。工程里存的是 Parquet 副本与界面状态，只有打开这个软件的人能接着用；导出的文件里只有数据，任何能读该格式的程序都能用。需要连数据和自己的工作状态一起交给同事时给 `.dapro` 工程文件，只需要一张表时给导出文件，见[工程文件](../getting-started/project.md)。

## 导出文件里的内容

导出的文件里只有列名和数据行，没有表格样式、没有显示格式，也没有表格里当时的选中状态。日期时间列在 CSV 里写成文本，读回来时是不是日期类型取决于读的一方的解析，这也是导入时会做日期自动识别的原因；要保住类型，用 Parquet 或 pkl。

导出的是内存里当前的数据集，包含还没保存到工程的修改。导出之前不必先保存工程，但工程本身要及时保存，导出不会代替保存。

写文件时目标是独占的。目标文件正在被 Excel 之类的程序打开时写入会失败，提示里会带上路径和原因；先关掉占用它的程序再重试。

## 四种方式怎么选

| 方式 | 一次处理 | 可选格式 | 是否需要选中数据集 | 是否后台执行 |
|------|---------|---------|-----------------|------------|
| Export Data / 导出数据 | 一个 | csv、xlsx、pkl、parquet | 选中或用当前打开的表 | 否，导出期间等待 |
| Export Individual Data / 导出单个数据 | 一个 | csv、xlsx、parquet、feather、pkl、html、json | 需要 | 否，导出期间等待 |
| Export Multiple Data / 导出多个数据 | 全部或选中的多个 | csv、xlsx、parquet、feather、pickle、json、html | 选「Export Selected」时需要 | 是，状态栏有进度 |
| Export To Excel / 导出Excel | 全部或选中的多个 | xlsx 单文件多工作表 | 选「Export Selected」时需要 | 是，状态栏有进度 |

日常用的两种情形可以直接对上：只交出一份数据，用数据标签页的「Export Data / 导出数据」，一步到位；要把整份工程的数据打包交出去，用「Export Multiple Data / 导出多个数据」；对方只需要一个 Excel 文件时，用「Export To Excel / 导出Excel」。

共同点有三个：导出的都是整个数据集，都只处理数据框类型的数据集，都不把表格样式写进文件。批量导出的这一条方式不弹保存对话框，目标文件名直接取数据集名字，名字里带上系统不允许出现在文件名里的字符时，先把数据集改名再导出。

智能体还有一个 `export_data` 工具，参数是数据集名字、输出路径和格式（csv 或 excel，默认 csv）。它按 pandas 的默认写法输出，CSV 里会多出一列行号，与上面四种方式的写法不同；批量或需要注意行号时用界面上的入口，见[内置工具](../agent/tools.md)。

## 常见问题

- 导出时提示数据为空：数据集里的数据对象不存在或者已经被清空，这条提示与行数为零无关。行数为零的数据集会写出一份只有列名的文件。
- CSV 用 Excel 打开是乱码：写出时不指定编码，用的是 pandas 的默认编码（UTF-8）。在 Excel 里用「数据」选项卡的文本导入功能指定 UTF-8 可以正常显示，或者改用 Excel 格式导出。
- 批量导出少了几个数据集：只有数据框会被写出，其它类型的数据集跳过。
- 导出的 CSV 里多了一列行号：检查是不是用了别的方式写出的文件；这四种方式里的 CSV 与 Excel 都不写行号。
- 大表导出时界面卡一会儿：数据量很大时写文件要花时间，可以用批量导出的两种方式，它们在后台线程里跑，状态栏有进度。
- 导出选中却一个文件都没出：数据管理面板里没有选中数据集，选好之后重新执行。
- 导出的 Excel 打不开：写入中途失败时软件会把不完整文件删掉，此时目录里不会有这个文件；文件存在却打不开，先确认没有别的程序正占用它。
- 想要图里的数据：绘图本身导不出数据，导出画这张图用的数据集即可，见[复制与保存图表](../chart/save.md)与[统计绘图](../analysis/stats-plots.md)。
- 导出以后想核对内容：把导出的文件重新导入一次就能并排比较，导入方式见[导入数据](./import.md)。核对完记得把多出来的数据集删掉。
- 同一个工程导出到同一目录两次：第二次会覆盖同名文件，保存对话框会先询问，批量导出不询问。
- 导出的 xlsx 里为什么只有一个工作表：这种方式一次导出一个数据集，一个数据集一个工作表。要多个数据集共用一个文件，用「Export To Excel / 导出Excel」。
