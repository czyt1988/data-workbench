# 表格视图

表格视图是把数据集摊开来看、直接动手改的地方。打开一个数据集就得到一个表格标签页，里面能改单元格、增删行列、改列类型、设显示格式。这一章按操作顺序讲这些功能，包括每个动作作用在哪一层（单元格、行、列），以及越界、重名、类型不符这些情况下软件怎么处理。

## 打开一个数据集

在数据管理面板里双击一级条目，软件在「Data Operate / 数据操作」停靠面板里为它开一个标签页，同时把这个面板抬到最前面。双击列子条目也一样，只是打开后会把该列滚动到可见位置并整列选中。

面板被别的面板挡住时，用 Ribbon 的「View / 视图」标签页、「Display / 视图显示」面板里的「Show Table Area / 数据操作区域」把它抬到前面。

一个数据集对应一个标签页，再次打开同一个数据集只会把已有标签页提到前面，不会开出第二个。同一份数据集的标签页里改的内容立即反映到数据集本身，绘图和工作流之后再取数拿到的是改过的数据。

标签页标题就是数据集名字，鼠标停上去的提示是数据集描述。数据集改名后标题跟着变；数据集在别处被删除后，标题后面会加上「`[deleted]`」标记（中文界面显示为「[已删除]」）。关闭标签页时软件弹出一个确认框（提示文字为「Whether to close the data table widget / 是否关闭数据表窗口」），确认后只关掉这个视图，数据仍然在数据管理面板里。标签页可以在这个停靠面板内部拖动分屏，标签的位置默认在底部，位置设置在[设置项说明](../reference/settings.md)里。

## 编辑单元格

双击单元格进入编辑，或者选中单元格后直接键入内容，回车提交，Esc 放弃。每次提交都会让数据集立刻变化，并且压入撤销命令，主页标签页、「Clipboard / 剪切板」面板里的「Undo / 撤销」（快捷键 Ctrl+Z）可以撤回这一步。

内容与列类型不符时写不进去，单元格保留原值，也没有提示。比如往整数列里输入 `abc`，回车后该单元格还是原来的数字。要把这类内容存进来，先按下面「改列的数据类型」把列转成文本类型再输入。

## 复制、剪切与粘贴

复制有两种方式，效果相同：在表格里按 Ctrl+C（或 Ctrl+Insert），或者用主页标签页、「Clipboard / 剪切板」面板里的「Copy / 复制」（焦点在表格上时）。复制的文本按选区的外接矩形拼成：行内用制表符分隔，行间用换行分隔，外接矩形里没有被选中的格子留空。格子的内容取的是显示格式处理后的文本，也就是说设了两位小数，复制出去的就是两位小数。

粘贴用同一个面板里的「Paste / 粘贴」。粘贴没有键盘快捷键，Ctrl+V 不生效。粘贴的内容从选区左上角开始填，能贴到哪里由数据表的行列数决定，规则有三条。

- 填充到数据表边界为止：超出数据表右边界和下边界的内容丢弃。粘贴时如果发生了丢弃，消息窗口给出提示：「Paste partially dropped: %1 row(s) and %2 cell(s) outside the table were ignored / 粘贴部分丢弃：%1 行与 %2 个单元格超出表格范围被忽略」。
- 起点落在数据表之外时（比如选中的是右侧空白列里的格子）不写入任何内容，也不提示；整条内容都落不进去时提示「Nothing to paste: the clipboard content exceeds the table boundary」，不做改动。
- 内容与列类型不符时，整条粘贴回滚，一个格子也不写，提示「Paste failed: the content does not match the column data type / 粘贴失败：内容与列数据类型不匹配」。剪贴板本身为空时提示「Clipboard is empty / 剪贴板为空」。

粘贴成功后同样进入撤销栈。粘贴进来的文本不经过显示格式，它按原始字符串写入列里。

剪切用主页标签页、「Clipboard / 剪切板」面板里的「Cut / 剪切」（焦点在表格上时）。它先把选区按复制格式写进剪贴板，再把原位置上的值设成缺失值。表格里没有右键粘贴的菜单，右键菜单只出现在列标题和数据管理面板的条目上。

## 把单元格设为缺失值

选中单元格后，用 Ribbon 的「DataFrame」上下文标签页、「Operate / 操作」页、「Axes」面板里的「Remove Cell / 删除单元格」，或者用主页标签页、「Clipboard / 剪切板」面板里的「Delete / 删除」（焦点在表格上时），两者都把选中单元格的值设成缺失值。它不影响其它单元格，可以撤销。

## 插入与删除行

行操作都在「Axes」面板里。

- 「Insert Row / 插入行」在选中行的下面插入一行；按钮右侧的下拉菜单里有「Insert Row(Above) / 插入行(上)」，插在上面。
- 「Remove Row / 删除行」删除所有选中的行，后面的行号上移。

插入的行内容为空。行操作按当前选中的行确定位置，选中多行时删除会一次删掉这些行，插入只取其中一行作为参照。

## 插入与删除列

「Insert Column / 插入列(右)」在选中列的右边插入，按钮下拉菜单里的「Insert Column(Left) / 插入列(左)」插在左边。点这两个动作都会先弹「Insert New Column / 插入新列」对话框。

对话框里有三组内容：`Name` / 名称，`dtype` / 数据类型（下拉框，可选项与其他地方的类型下拉框一致），以及「Fill Setting / 填充设置」里的两种填充方式。「Fill in the same value / 填充相同值」用同一个值填满整列，值填在 `default value` / 默认值 输入框里；「Generate growth value / 生成递增值」用起点和终点生成一列等差的值，起点、终点分别填在 `start`、`stop` 两个输入框里，类型选日期时间时输入框换成日期时间控件，中间的值按等差算出。名称留空时软件提示必须指定列的名字，不插入。

「Remove Column / 删除列」删除选中的列。列被删掉之后，原来存在它上面的单元格样式一起消失，撤销删除能恢复数据，样式不会跟着回来，原因见[表格样式](./style.md)。

## 重命名列

两种方式：表头右键菜单里的「Rename Column / 重命名此列」改一列，Ribbon 的「Rename Columns / 重命名列」打开一个对话框把整表的列名列成一张表，逐行改完确认。

单列改名会被两种输入拒绝，两种情况都在消息窗口提示，列名保持不变。

| 情况 | 提示 |
|------|------|
| 名字为空 | `Column name cannot be empty` / 列名不能为空 |
| 名字与表中已有列名重复（包括与它自己原来的名字相同） | `Column name "%1" already exists, please use another name`，含义是该名字已被占用，换一个再提交 |

走对话框那种做法的检查方式不同：它只校验整张表里有没有重名，发现重复时提示 `Duplicate column name "%1", please reset the column name of column %2`，含义是某一列的名字与其它列撞上了，改过之后重新确认。

改名会立刻传给数据管理器，打开着的其它视图和绘图里的列引用随之更新，操作可以撤销。

## 改列的数据类型

「Type / 类型」面板里有三种方式。

下拉框前缀写着 `Type` / 类型，显示当前选中列的类型，选择另一个类型就按 pandas 的类型转换规则改这一列。可选的类型包括浮点的 `float64`、`float32`、`float16`，整数的 `int64`、`int32`、`int16`、`int8`，无符号的 `uint64`、`uint32`、`uint16`、`uint8`，`str`、`bytes`、`bool`、`object`、`complex64`、`complex128`、`datetime64`、`timedelta64`，以及可空系列 `Int64`、`Int32`、`Int16`、`Int8`、`UInt64`、`UInt32`、`UInt16`、`UInt8`、`boolean (nullable)`、`string (nullable)` 和 `category`。转换失败时该列保持原样，没有提示。

下拉框右边的按钮组提供两种带参数的转换，适用于文本列里混着数字或日期、直接选类型转不过来的情况。

- 「To Numeric / 转换为数值类型」打开「Cast To Numeric / 转换为数值」对话框。`errors` 三个选项决定解析不了的值怎么处理：报错中止（invalid parsing will raise an exception）、置为缺失值（invalid parsing will be set as NaN，默认选中）、保留原文（invalid parsing will return the input）。`downcast` 选项决定结果的精度取向：不降级（默认，None）、浮动（float）、整数（integer）、有符号整数（signed）、无符号整数（unsigned）。
- 「To Datetime / 转换为日期类型」打开「Cast To Datetime / 转换为日期时间」对话框。常用的是 `format` / 格式串与 `errors`：格式串留空时按 pandas 的推断解析，填入格式串（对话框里给了一个 `%d/%m/%Y` 形式的示例）时按格式解析；`errors` 的三项与数值转换相同，默认置为缺失值。其余选项对应 pandas 的名称，包括 `infer datetime format`、`exact`、`origin`（默认 unix，可选 julian）、`unit`（D、s、ms、us、ns，默认 ms）、`day first`、`year first`、`utc`、`cache`。

按钮组里还有一个「To String / 转换为字符串类型」，点击后弹出的是「功能未实现，只保留了界面」的提示，暂时不要用它来把列转成文本。

「To Index / 转换为索引」把选中列设为数据框的行索引，表格左侧的行头随之换成这一列的值。它同样可以撤销。

## 表头右键菜单

在列标题上点右键，软件先选中这一列，再弹出菜单。菜单六项的作用如下。

| 菜单项 | 作用 |
|--------|------|
| `Rename Column` / 重命名此列 | 改光标所在列的名字，拒绝规则与上一节相同 |
| `Remove Column` / 删除列 | 删除当前列 |
| `Copy Column Name` / 复制列名 | 把列名写进剪贴板 |
| `Goto Max` / 跳转到最大值 | 找到该列最大值所在的行，选中并滚动到那个单元格 |
| `Goto Min` / 跳转到最小值 | 同理，跳到最小值 |
| `Show Statistics` / 显示统计信息 | 用 pandas 的 `describe` 算出该列的各统计量，在弹窗里逐项列出 |

跳转的两项在该列没有可比较的值时（空列、全是缺失值、类型不可比较）不跳转，只提示这一列找不到最大值或最小值。同一个菜单也挂在数据管理面板的列子条目上，在那里右键会先打开对应的表格再弹菜单。

这一列是[计算列](#计算列)时，菜单末尾会多出一组三项：`Edit Formula` / 编辑公式、`Recompute` / 重新计算、`Remove Formula (Keep Data)` / 移除公式（保留数据）。

## 计算列

用一段表达式基于其它列算出一个新列，公式被记录下来：依赖列的数据变化后列头会提示「待重算」，随时可以手动重算。入口有两个——Ribbon「Operate / 操作」页的「Data Tools / 数据工具」面板里的「Computed Column / 计算列」按钮，或表体右键菜单的「计算列…」。

对话框分三块：

- **目标列名**：计算结果写入的新列。只能是一个不存在的新列名——不允许覆盖已有列，也不允许表达式引用目标列自己（比如 `A = A + 1` 会被拒绝），这样「移除公式、保留算好的数据」这条退路永远成立。
- **表达式**：赋值号右边的算式本身，列名直接当变量用（`price * qty`、`score >= 60`、`sqrt(value)`）。加减乘除用 `+ - * /`，乘方 `**`，取余 `%`，比较用 `== != > < >= <=`，布尔组合用 `and or not`；数学函数可直接写 `abs() sqrt() log() exp() sin() cos() floor() ceil()` 等。含空格或特殊字符的列名要用反引号包起来（`` `Area (cm^2)` ``），从下方列名列表点选插入时软件会自动处理。
- **预览**：对话框对表格头部前 10 行实时试算（与正式执行用同一套算子），表达式有语法错误或引用了不存在的列时，状态行给出提示、确定按钮置灰，不会改动数据。

点「OK」后立即求值并把新列物化进表格（表尾追加一列），这一步进撤销栈，`Ctrl+Z` 会把列和公式一起撤掉。

### 列头上的三态标识

计算列的列头有专门的标识：底色是浅蓝色（表示这一列不是原始数据），左侧有一个 `ƒx` 角标，角标颜色表示公式状态：

| 角标颜色 | 状态 | 含义 |
|---|---|---|
| 蓝 | 有效 | 列值与公式一致 |
| 金黄 | 待重算 | 依赖列（或本列）的数据被改动过，列值可能过期 |
| 橙红 | 失效 | 依赖列被删除，或公式求值失败 |

鼠标悬停在列头上会显示公式全文与当前状态。重算是**手动**的：列头右键「重新计算」重算这一列，「Data Tools」面板的「Recompute All / 全部重算」一次重算当前表所有待重算/失效的计算列（一次撤销单元）。重算同样进撤销栈，`Ctrl+Z` 恢复到重算前的值。排序不会触发「待重算」（行顺序变化不影响列值）。

### 与列改名、删列的联动

- 重命名一个被公式引用的列时，会提示「有 N 个计算列引用它」，确认后引用随改名自动批量更新（与改名同一个撤销单元）。
- 删除一个被引用的列时，相关计算列转「失效」（列数据保持原样，不清空），界面给出提示。
- 删除计算列本身时，它的公式定义一并移除；`Ctrl+Z` 恢复列时公式也一起恢复。

公式随工程保存。重新打开工程**不会**触发任何重算——列值已经存在工程里；即使公式与当前环境不兼容，最坏结果也只是该列退化为普通列并标「失效」，数据不受影响。

## 分列与合并列

「Data Tools / 数据工具」面板与表体右键菜单提供一对互逆的整理动作：**分列**把一列文本拆成多列，**合并列**把多列拼成一列。

### 分列

选中**一列**后点「Split Column / 分列」。对话框左侧选分隔模式，右侧对头部前 10 行实时试算——预览与正式执行用同一套算法，所见即所得。

| 分隔模式 | 参数 | 说明 |
|---|---|---|
| 分隔符 | 单个字符或字符串（默认逗号） | 按分隔符切分，连续分隔符产生空字段 |
| 正则 | 带捕获组的表达式 | 每个捕获组一列，如 `(\d{4})-(\d{2})-(\d{2})` 拆日期 |
| 固定宽度 | 逗号分隔的正整数（如 `3,5,8`） | 按累计宽度切片，短字符串的越界片段为空 |

「最大列数」限制结果列数（0 = 不限），超出时按「溢出策略」处理：**丢弃超出部分**、**剩余并入最后一列**（保留原文）或**报错**（数据不变）。「结果列尝试数值解析」默认开启：整列非空值都能解析成数字才转数值列，解析不了保持文本。结果列名默认「原列名_1、原列名_2……」，可以改（逗号分隔；不允许与现有列重名）。

落位规则：**原列保留**，结果列插在它的右侧。`Ctrl+Z` 一次完全还原（含列顺序与列数）。10 万行量级的分列在亚秒级完成，期间显示忙等待光标。

### 合并列

选中**多列**后点「Merge Columns / 合并列」。左侧列表用上下箭头调整拼接顺序（自上而下），分隔符可以为空；「跳过空值」开启时空单元格不参与拼接、也不会留下多余分隔符（关闭则空值按空串占位）。结果列名默认是各源列名用 `_` 连接，可以改（不允许与现有列重名）。

落位规则：结果列**替换被合并列的位置**（插到最左侧源列处），源列删除；整行都是空值时结果为空。`Ctrl+Z` 一次完全还原全部源列。若被合并的列正被某个计算列引用，相关计算列会转「失效」并给出提示。

## 分组聚合

「Data Tools / 数据工具」面板或表体右键「Group By / 分组聚合」：按分组键把行聚合成一张**长格式结果表**。对话框左侧多选分组键与聚合列，每个聚合列在下方选一个聚合函数——`mean`（均值）、`sum`（求和）、`size`（计数），与透视表的函数集合一致；同一列可以选两次配不同函数。右侧实时给出全表聚合结果的预览（前 10 行）与总组数。

点「OK」后结果注册为**新数据集**，命名为「原名_GroupBy」，原表完全不动；数据管理面板里 `Ctrl+Z` 一次可撤销这次注册。结果表是普通表格，可直接进图表或作为工作流节点输入。分组键里的空值单独成组（与 SQL 的 GROUP BY 一致）；聚合列全为空时结果为空值。

需要 Excel 透视表那种「组头行 + 展开明细」的折叠视图时，本功能只提供长表这一半，折叠视图在后续版本单独提供。

## 转置与宽转长

「Data Tools / 数据工具」面板与表体右键提供两个形状变换动作，**默认都产出新数据集**（原名_Transposed / 原名_Melted），原表与它的样式、计算列等元数据完全不动；注册动作可撤销。对话框内可勾选「就地替换当前表」。

- **转置（Transpose）**：行列互换。结果第一列名为 `index`、内容是原列名，其余每列对应原来的一行。混合类型的表转置后各列为通用类型，进图表前可再转类型。
- **宽转长（melt）**：选「保留列」（id_vars，随行重复）与「展开列」（不选 = 其余全部列），指定变量名列名（默认 `variable`）与值列名（默认 `value`）。结果行数 = 原行数 × 展开列数。

melt 有规模守卫：预估输出行数超过 5000 万时默认拒绝并给出预估行数，确认后可以强制继续。

勾选「就地替换」时，确认框会**列出将被清除的元数据类别与条目数**（样式、列宽、条件格式规则、计算列）——行列互换后这些按位置或按列名记录的元数据全部失去意义。数据替换与元数据清理是同一个撤销单元，`Ctrl+Z` 一并还原。超大表（超过 5000 万单元格）就地替换会提示降级为「本次操作不可撤销」（保留旧数据用于撤销会让内存翻倍）。

## 显示格式

「Format / 格式」面板管的是显示文本，不改数据本身。

前缀为 `Format` / 格式 的下拉框列出格式类别：`General` / 通用、`Number` / 数值、`Scientific` / 科学计数法、`Percentage` / 百分比、`Date/Time` / 日期时间、`Datetime as Number` / 时间显示为数字、`Text` / 文本。列表会按选中列的类型裁剪：数值列才有数值、科学计数法、百分比；日期时间列才有日期时间、时间显示为数字；通用和文本一直可选。选中一个类别，软件用该类别的默认参数设到整列上；选回「General / 通用」等于清除这一列的显示格式。

面板右边的「Format Cells... / 设置单元格格式...」按钮打开「Format Cells / 设置单元格格式」对话框，左侧选类别，右侧给参数，上方实时预览。数值、科学计数法、百分比共用「Decimal places: / 小数位数:」，范围 0 到 20，默认 2；日期时间有「Preset: / 预设:」下拉框（`yyyy-MM-dd`、`yyyy-MM-dd HH:mm:ss`、`yyyy-MM-dd HH:mm:ss.zzz`、`yyyy/MM/dd`、`HH:mm:ss`、`yyyy-MM-ddTHH:mm:ss`）和「Pattern: / 格式串:」输入框，格式串留空时用 `yyyy-MM-dd HH:mm:ss`；时间显示为数字有「Seconds since epoch / epoch 秒」与「Milliseconds since epoch / epoch 毫秒」两个选项，默认毫秒；文本类别没有参数，按纯文本显示。

显示格式按列保存在数据集的样式里，撤销栈里能撤回。它和单元格底色、字体是两套记录，详见[表格样式](./style.md)。导出文件时写的是原始值，与显示格式无关，见[导出数据](./export.md)。

## 行头与列头

表格左侧的行头显示数据框的索引值。没有专门设过索引时，它就是 pandas 默认的 0、1、2……；用「To Index / 转换为索引」设过索引后，行头换成那一列的值。索引是复合索引时，各级的值用竖线连接后显示在一格里。

表格顶部是列头，显示列名。列头的右键菜单见上一节，列宽可以拖动列头之间的分隔线调整。

表格在数据的列之外还会多显示一列空白列，列数不少于 4 列；行数按数据本身的行数显示。右侧这列空白在当前版本里输入不进去：往里写字不会给数据追加一列，需要增加行或列时用「Axes」面板里的插入动作。

## 一个标签页里的表都会变

表格视图直接改数据管理面板里那份数据集，磁盘上的文件只是它的来源。所以在表格里做的每一步修改都立即生效于整份数据：其它已经打开同一数据集的入口（绘图取数、数据清洗动作、智能体读取数据）之后拿到的都是改过的内容。反过来，其它地方对同一份数据的改动也会回到这个标签页上，编辑前先确认没有别的窗口正在用同一份数据。

撤销栈跟着标签页走。每个标签页有自己的撤销栈，切换标签页后按 Ctrl+Z 撤回的是当前标签页上的操作，不会误撤到另一张表上去。标签页关闭再打开时撤销记录清空，已经生效的修改留在数据里。

## 大表怎么滚动

表格模型按块向数据源取数，一次取 512 行，每次取数的起点都落在 512 的整数倍上，所以只有跨过块边界那一下才会向数据源要下一块。滚动时不会对每个可见单元格单独发起一次调用，行数很多时滚动也不会被逐格取数拖慢。分块只影响界面取数的节奏，pandas 数据框本身是完整读进内存的；如果某个数据源声明自己可以按需取数，界面同样只取看得到的那些块。

## 上下文标签页里的动作分布

表格相关的动作都在「DataFrame」上下文标签页上，它只在当前有表格时出现，分两页。知道每个动作在哪一块，找起来快一些。

| 面板 | 这一章涉及的动作 |
|------|----------------|
| `Operate` / 操作 页的 `Axes` | 插入行、插入列、删除单元格、删除行、删除列、重命名列、转换为索引 |
| `Operate` / 操作 页的 `Column` / 列 | 重命名此列、复制列名、跳转到最大值、跳转到最小值、显示统计信息 |
| `Operate` / 操作 页的 `Type` / 类型 | 类型下拉框、转换为数值、转换为字符串、转换为日期 |
| `Operate` / 操作 页的 `Format` / 格式 | 显示格式下拉框、设置单元格格式 |
| `Operate` / 操作 页的 `Edit` / 编辑 | 查找（Ctrl+F）、替换（Ctrl+H）、填充下拉（向下 Ctrl+D / 向上 / ffill / bfill / 序列…）、批注下拉（插入 / 编辑 / 删除 / 清除本表批注） |
| `Operate` / 操作 页的 `Data Tools` / 数据工具 | 计算列、全部重算、分列、合并列、分组聚合、转置、宽转长（melt）、校验规则、执行校验 |
| `Table Style` / 表格样式 | 底色、字体、清除、条件格式，见[表格样式](./style.md) |
| `View` / 视图 页（主页标签页） | 撤销历史面板（QUndoView，跟随当前页撤销栈，可调撤销深度） |

复制、剪切、粘贴、删除、撤销这几个动作不在这个上下文标签页上，它们在主页标签页的「Clipboard / 剪切板」面板里，按当前焦点判断作用对象。

## 常见问题

- 改完单元格怎么恢复：每次修改都进了撤销栈，按 Ctrl+Z 逐步回退；撤销栈跟着标签页走，切到另一个表格标签页时按 Ctrl+Z 撤回的是那个标签页上的操作。
- 粘贴只写进去了一部分：超出数据表右边界或下边界的内容被丢弃并有提示，选区大小不影响粘贴范围。想一次填更多格，先给表格增加行或列。
- 粘贴整条失败：内容里出现了与该列类型不符的值，比如往数值列里贴了文字和数字混排的列。先改列类型再粘贴。
- 想给整列填上同一批值：插入新列时可以在对话框里一次填满（填充相同值或生成等差值）；已经存在的列要批量改值，用数据清洗里的填充类动作或工作流的计算类节点，见[数据清洗](../analysis/cleaning.md)。
- 行头变成了一列的数据：这一列被设成了索引，用「Undo / 撤销」可以还原。
- 表格里的数字显示成了两位小数：这是显示格式，值没有改。下拉框选「General / 通用」可以恢复原样。
