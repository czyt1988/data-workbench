# Data Workbench 使用指南

Data Workbench（软件内显示为 DAWorkBench）是一个数据分析和绘图工具。它把数据处理的过程画成一张图：每一步是一个节点，节点之间用连线表示数据的流向。改一次参数，整条流程就能重新跑一遍。除了工作流，软件也提供直接对着表格点击的数据清洗工具、面向论文的绘图功能，以及一个可以调用这些功能的 AI 智能体。

这份指南按功能分成八个部分，从打开软件开始，按「先会用、再用好、最后扩展」的顺序排列。

## 怎么读这份指南

想尽快做出第一张图，读第一部分的[安装与首次启动](getting-started/install.md)，然后跳到第二部分的[导入数据](data/import.md)和第五部分的[创建图表](chart/create.md)。

想把重复的数据处理固定下来，读第三部分。先看[工作流基础](workflow/basics.md)，再按需查两本节点手册。

想用 AI 帮忙分析，读第六部分。必须先做[配置模型](agent/model-config.md)，否则智能体收不到回复。

只在找某个参数的默认值或者某个格式的支持情况，直接看第八部分的参考章节。

## 关于界面文字

软件界面上的菜单、按钮和字段名用英文。正文提到它们时写成「英文 / 中文」的形式，比如「Run Workflow / 运行工作流」，这样在任一语言的界面上都能对上。

源码里存在但界面上还没有入口的功能，本指南会明确写出目前只能从脚本或代码调用，不会把它写成可以点击的操作。
