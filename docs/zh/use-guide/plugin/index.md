# 插件

插件往软件里加功能。装插件不需要重新编译主程序，把文件放进指定目录即可。

## 章节目录

- [插件管理](manager.md)：插件放在哪里、怎么启用和停用、插件能带来什么、加载失败怎么排查。

## 随软件发布的插件

| 插件 | 类型 | 带来什么 |
|------|------|---------|
| DataAnalysis | 编译库加 Python 包 | 数据清洗、数据过滤、统计三个面板，导出单个数据、导出多个数据、导出到 Excel 三个动作，以及二十一个数据分析工作流节点 |
| DASystemNodes | 编译库加 Python 包 | 流程控制、常量、文本显示、结果发布共七个工作流节点 |
| DAAgentTools | 编译库 | 智能体的数据、绘图、文件、报告和脚本工具，以及图表和数据集的跳转链接约定 |
| DAPaperAgent | 编译库 | 文献检索与 DOI 校验两个工具，以及论文撰写助手提示词 |

前两个在插件管理器里分成两行：一行是编译库，一行是 Python 节点包，两行各自可以启用和停用。后两个只有编译库一行。

插件管理器里还有一个 `plugin-template` 目录，那是给写新插件用的脚手架，不参与构建，也不会出现在管理器里。

## 停用一个插件会怎样

停用会连带去掉它带来的界面元素，所以停用之前先确认没有工作流正在使用它的节点。

停用 DataAnalysis 的编译库那一项，数据表上下文标签页上的三个面板和导出动作会消失；它的 Python 节点包是另一行，两行分别控制，只停编译库不会让工作流节点面板少掉节点。

停用插件的详细规则、加载失败的排查办法见[插件管理](manager.md)。
