# 信号分析

信号分析插件把「一段随时间变化的测量数据」读进来，算出它的频谱、时频图和主要峰值，并且可以边播放边看波形上的位置。它面向的是**通用时序信号**：音频、传感器采样、振动数据都行——只要你知道它的采样率。

插件装好后，主工作区多出一个「信号分析」页面（与绘图、表格、工作流并列），功能区顶部多出一个「信号分析」标签页。

## 导入信号

三种来源，都在「信号分析」标签页的「信号」面板里：

- **导入音频**：支持 WAV、AIFF、FLAC、OGG 直接读取；MP3、M4A、AAC 需要系统里装有 FFmpeg（会在后台自动转成临时 WAV）。
- **导入视频**：用 FFmpeg 抽出视频里的音频轨再分析。没装 FFmpeg 时这个入口会提示先指定 FFmpeg 路径。
- **导入数据帧**：从数据管理器里已有的数据表导入。需要指定：
  - **时间列**（可选）：选了一列时间数据后，软件按「相邻两行的时间差的中位数」推断采样率并自动填好；不选时间列时要自己输入采样率。
  - **幅值列**（可多选）：每一列成为一个通道。
  - **信号名**：默认是「数据帧名.列名」。

音频/视频文件的采样率直接从文件头读，不能改；数据帧的采样率**必须由你确认**——推断值只是预填，点「导入」才算数。

## 页面结构

导入成功后，页面右上出现信号的标签页，每个信号一个。页面分三块：

- **上半：波形**——整段信号的包络（按屏幕宽度降采样，不会因为数据量大而卡），下方滑条控制当前位置，橙色虚线是播放头，浅蓝矩形是当前短时傅里叶变换的分析窗口。
- **下半左：频谱**——默认按整段信号算的幅值谱，右侧下拉切线性/对数频率轴。
- **下半右：时频图**——默认是二维热图，颜色越亮表示该时刻该频率的能量越强；右上两个控件分别选色带和 dB 动态范围下限。功能区「显示」面板可以在二维、三维曲面瀑布、隐藏之间切换。

## 播放

「播放」面板的播放/暂停/停止控制音频。播放时播放头会跟着走；拖动滑条或直接点波形会跳到那个时间。数据帧导入的信号在第一次播放前会在后台导出成临时音频文件，这期间播放按钮短暂不可用。

## 分析参数

「分析设置」打开统一的参数对话框，分六组：

| 分组 | 主要项 |
|---|---|
| 信号预处理 | 去直流、去趋势（常数/线性） |
| 频谱 | 窗函数、幅值口径（峰值幅度/均方根）、dB 参考、频率分辨率 |
| 功率谱 | 平均方式（均值/中位数）、重叠率 |
| 短时傅里叶变换 | 窗长（毫秒）、跳步重叠率、零填充 |
| 峰值查找 | 模式（简单/高级）、前 N 个、相对门限；高级模式额外有突出度、最小间距、绝对高度门限 |
| 标定 | 标定系数、幅值单位 |

几点约定：

- **频率分辨率**而不是「FFT 点数」是主输入：软件按分辨率反推段长，对话框下方随时反显「段长 = … 点（… 毫秒）、实际分辨率 = … 赫兹」。
- 峰值查找的**最小间距**默认是当前频率分辨率的 5 倍，改了会保留你手填的值。
- 改完参数点确定，立即重算一次。参数不进撤销栈；每个信号标签页记住自己的参数，对话框里有「恢复默认」。

## 峰值

排在前 N 的峰会显示在：

- **峰值窗口**（右侧停靠区，与设置、智能体同一个区域）：上半是峰值表（序号、频率、幅值、相对主峰多少分贝、占全部峰的比例），下半是「每帧第 N 名的频率随时间变化」的曲线，第 1 名到第 N 名的颜色固定。第一次导入信号成功时这个窗口会自动切到前面一次。
- **频谱图上的标记点**：功能区「峰值标记」开关控制。

「前 N 个」可在 10、20、50 之间切换；曲线的全帧扫描可能要几十秒，期间状态栏显示进度，可以点停止。

## 导出

- **导出峰值表**（下拉）：峰值表 CSV、频谱曲线 CSV、热图矩阵 CSV。热图矩阵可能很大，导出前状态栏会给单元数提示。
- **导出图片**：把当前信号页面整体保存为 PNG（三维视图是 OpenGL 渲染，截图中可能不完整）。
- **峰值窗口里的按钮**：把峰值表直接送进数据管理器成为新的数据表（列名英文，表名带信号名），或单独导出 CSV。

## 工程保存

保存工程时，插件只记录信号的**来源引用**（文件路径或数据帧名+列名）、导入时确认的采样率和分析参数，不保存分析结果。重开工程后按参数自动重算；源文件或数据帧找不到时会提示「信号源缺失」。
