# 信号分析

信号分析插件把「一段随时间变化的测量数据」读进来，算出它的频谱、时频图和主要峰值，并且可以边播放边看波形上的位置。它面向的是**通用时序信号**：音频、传感器采样、振动数据都行——只要你知道它的采样率。

插件装好后，**主页「创建」面板**多出一个「信号分析」大按钮。主工作区里的「信号分析」页面按需创建：程序启动时不显示，点「信号分析」按钮才创建并显示（与绘图、表格、工作流并列）；关闭页面后再点该按钮可恢复显示，导入信号时也会自动打开。插件不再占用一个常驻的顶级标签页——它的入口集中到「信号分析」页获得焦点时出现的两个上下文标签页（见「功能区上下文标签」）。

## 导入信号

三种来源收在「分析设置」上下文页「导入导出」面板的「导入」大按钮菜单里：

- **导入音频**：支持 WAV、AIFF、FLAC、OGG 直接读取；MP3、M4A、AAC 需要系统里装有 FFmpeg（会在后台自动转成临时 WAV）。
- **导入视频**：用 FFmpeg 抽出视频里的音频轨再分析。没装 FFmpeg 时菜单里的这一项置灰，悬浮提示到「设置 → 信号分析」指定 FFmpeg 路径。
- **导入数据帧**：从数据管理器里已有的数据表导入。需要指定：
  - **时间列**（可选）：选了一列时间数据后，软件按「相邻两行的时间差的中位数」推断采样率并自动填好；不选时间列时要自己输入采样率。
  - **幅值列**（可多选）：每一列成为一个通道。
  - **信号名**：默认是「数据帧名.列名」。
- 分隔线下的**重新指定数据帧来源**：把「来源缺失」占位信号重新指向现有数据帧（只在当前信号来源缺失时可用）。

音频/视频文件的采样率直接从文件头读，不能改；选好文件后对话框会只读显示采样率、通道数与时长（需要 FFmpeg 转码的格式在导入后才显示）。数据帧的采样率**必须由你确认**——推断值只是预填，点「导入」才算数。

视频与压缩音频（MP3/M4A/AAC）的转码在后台进行：导入期间界面保持可交互，状态栏显示进度，整个「导入」按钮暂时置灰；需要中止时点状态栏进度条右侧的停止按钮，已生成的半成品临时文件会被清理。

> **ℹ️ 缺少 soundfile 时**
> 运行时没有安装 `soundfile` 时：WAV 仍可直接读取；AIFF/FLAC/OGG 在装有 FFmpeg 时会自动转成临时 WAV 后分析，没有 FFmpeg 则给出明确提示。安装 `soundfile` 可恢复全部直读格式。

 > 若信号非常大、估算内存超过 1.5 GB 预算，软件会弹窗让你三选：**降低精度**（热图减少栅格与分块、峰值曲线隔帧扫描）、**只扫可见区段**（热图/峰值曲线只算当前波形可见的时间范围）、或**取消**。峰值曲线采用局部扫描时，峰值窗口上会显示「局部扫描」标注，提醒曲线只覆盖可见区段或使用了更粗的帧步进。
>
> **ℹ️ 长信号的内存占用**
> 频谱、功率谱与时频图按块读取信号，内存占用与信号长度基本无关（不会把整段信号或整张时频矩阵常驻内存）；1 小时 / 48 kHz 单通道信号完成一次频谱计算的峰值内存约 190 MB。波形、峰值表等仍与信号长度相关，超长信号会在开始前提示内存预算。

## 页面结构

导入成功后，页面右上出现信号的标签页，每个信号一个。每个信号页按 2×2 网格摆放三块图：

- **上半：波形**。整段信号的包络（按屏幕宽度降采样，不会因为数据量大而卡），窗口底部播放器控制条的时间滑块控制当前位置（单位毫秒，长信号也能精细定位），橙色虚线是播放头，浅蓝矩形是当前短时傅里叶变换的分析窗口。
  - **点击波形任意位置**可跳到该时间（矩形范围内单击同样会跳转）；**按住浅蓝矩形拖动**可整体平移分析窗口（窗宽不变，不能拖边）。按下后移动超过系统的拖动阈值才进入平移，避免把单击吃掉。
- **下半左：频谱**。默认按整段信号算的幅值谱；打开「信号显示」上下文页「显示」面板的「对数频率」可切到对数频率轴，打开播放器控制条的「跟随播放」后显示当前帧的谱。
- **下半右：时频图**。默认是二维热图，颜色越亮表示该时刻该频率的能量越强。色带与瀑布模式（二维/三维曲面瀑布/隐藏）在「显示」面板里选，dB 动态范围下限与「自动滚动」在播放器控制条上调。

## 绘图操作

信号分析的图是一份图表文档，外观设置、绘图工具、导出都复用绘图区那套能力。

### 右侧设置面板与图表管理树

打开信号分析窗口时，右侧自动切到「设置」面板，编辑对象是当前子图：

- 单击某个子图让它成为当前子图，设置面板跟着切换。右下单元格在二维时频图和三维瀑布之间切换，当前是三维时设置面板自动切到三维页。
- 设置面板能改标题、坐标轴、网格、图例、字体、背景等外观项，改完立即生效；子图比例与添加的图元可撤销。
- 左侧「图表管理」树列出当前信号的图元：包络曲线、频谱曲线、时频图、峰值标记，以及自己添加的参考线、文本、标注等。点选条目后设置面板切到对应图元页。
- 播放头与短时傅里叶分析窗口矩形也列在图元树中，随播放位置更新，可选中调整可见性、颜色等；信号分析页的图元树不提供删除图元、删除坐标系的入口，删除动作只在绘图区可用。

### 功能区上下文标签

信号分析窗口激活时，功能区出现插件自己的两个上下文标签页（默认停在「分析设置」），切到数据/绘图/表格/工作流等窗口后自动隐藏：

- **「分析设置」页**（常用分析参数，改后立即生效）：
  - **导入导出**：导入▾（音频/数据帧/视频/重新指定来源）、导出数据▾、导出图片▾；
  - **预处理**：去直流、去趋势（无/常数/线性）；
  - **频谱**：窗函数、幅值口径（峰值幅度/均方根/dBFS/dB re 1.0）、频率分辨率；
  - **时频**：窗长、跳步重叠，以及只读的 Δf 提示；
  - **峰值**：标记数量（10/20/50）、模式（简单/高级）、相对门限；
  - **更多**：高级设置…（打开参数对话框，只放零填充、功率谱、峰值高级项、标定）。
- **「信号显示」页**：
  - **显示**：通道、对数频率、色带、色标、瀑布模式（2D/3D/隐藏）；
  - **峰值标注**：峰值标记、标记显示、峰值窗口；
  - **工具**：「添加图元」，打开与绘图区相同的图元对话框，往当前子图添加参考线、文本、箭头等，操作可撤销。

此外还会出现与绘图区共用的「绘图操作」标签（自动指向信号图）：绘图样式（网格、缩放/平移、十字/XY/Y 拾取、联动拾取、图例、主题、复制到剪贴板、导出当前子图）与图表编辑（选区工具、辅助标记工具）。这些动作都作用于当前信号的图，不会改到别的绘图窗口。计算进行中时，中止入口是状态栏进度条右侧的停止按钮，不占用丝带面板。

三维瀑布子图激活时，「绘图操作」标签保持显示，主题/复制/导出仍可用；网格、缩放、拾取等二维类动作暂时置灰，切回二维子图后恢复。与信号图结构不匹配的动作（新建绘图窗口、新建坐标系、调整子图大小、数据探针）在信号分析窗口中不可用。「应用到所有绘图」只作用于当前信号图的二维子图。

通道只在多通道信号上可选，一次分析一个通道，切换后频谱、时频图和峰值都按新通道重算。峰值相关入口按用途分两页：搜索参数在「分析设置 → 峰值」，标注与窗口在「信号显示 → 峰值标注」，不再有重复入口。

### 窗口底部播放器控制条

信号分析窗口激活时，窗口底部出现播放器控制条（从左到右）：

- **跟随播放**：频谱和峰值表显示播放头所在帧，不再显示整段结果。
- **▶ / ⏸**：同一个切换按钮，点一下播放、再点一下暂停，图标随状态切换。
- **■**：停止播放并把播放头归零。
- **时间滑块**：拖动定位到指定时间，与点击波形、播放头位置保持同步。
- **时间文本**：`当前位置 / 总时长`（如 `00:12.3 / 01:30.5`），播放时随播放头刷新；没有可播放源时显示 `--:--.- / --:--.-`。
- **dB 下限**：时频图色标的下限（dB），数值越小显示的动态范围越大。
- **自动滚动**：播放推进时让时频图的时间轴跟着平移。

页面失活（切到别的窗口）时会自动停止播放，不会出现切走后声音还在响的情况；打开设置、峰值窗口等工具停靠窗口不会打断播放。

### 调整子图比例

把指针移到两个子图之间的分隔带上，指针变成左右或上下双箭头后拖动，只调整相邻两行或两列的比例，其它子图跟着让位。轨道有最小宽度，不会被拖到消失。松手后这次调整记入撤销栈，可按 Ctrl+Z 撤销；拖动过程中按 Esc 取消并恢复原比例。

### 导出图表

「导入导出」面板的「导出图片」下拉提供：

- **整页（PNG）**：把当前信号页保存为 PNG。三维瀑布可见时按它在页面上的实际位置合成进图片，不会出现黑块。
- **当前子图（PNG/SVG/PDF）**：只保存当前子图，格式以保存对话框中选择的文件类型为准。SVG 与 PDF 是矢量输出，适合论文排版；当前子图是三维瀑布时固定导出 PNG，对话框只提供 PNG 文件类型，万一发生格式降级会给出明确提示。
- **复制整页到剪贴板**、**复制当前子图到剪贴板**：直接粘贴到 Word、PPT 或图片编辑器。

当前子图是最后激活的子图：单击子图、切换瀑布模式都会更新它，没点过时默认为波形。峰值表、频谱、功率谱和热图矩阵属于数据导出，见下一节。

## 播放

窗口底部播放器控制条的播放/暂停、停止控制音频，播放的是当前查看的通道。播放时播放头会跟着走；拖动控制条的时间滑块或直接点波形会跳到那个时间。数据帧导入的信号在第一次播放前会在后台把该通道导出成临时音频文件（同一信号同一通道会缓存，切回来不再重复导出）：导出期间播放/暂停/停止按钮置灰、状态栏显示进度，界面不再卡住；完成后自动恢复可用。

长任务（功率谱密度、每帧峰值曲线扫描、数据帧播放音频导出）进行中时，状态栏会出现进度条与「停止计算」按钮；小计算耗时很短，不会让状态栏闪一下。点停止按钮即可中止全部在跑的后台计算；取消只清进度，不弹失败提示。

## 全局设置（FFmpeg）

FFmpeg 只有视频导入和压缩音频转码（MP3、M4A、AAC）才用得到，WAV、AIFF、FLAC、OGG 直接读取不受影响。它的路径是插件级设置，与具体信号无关，入口在 Ribbon 主页的「Config」/ 配置 面板：点 `Setting` / 设置 打开设置对话框，切到末尾的「Signal Analysis / 信号分析」页。没有导入任何数据时也能配置，不必先打开信号分析页面或导入信号。

这一页只有「外部工具」一组，其中「FFmpeg 可执行文件」一项是路径输入框加浏览按钮。输入框下方的状态行随输入即时变化：

- 留空时使用系统 PATH 里的 ffmpeg，状态行显示探测到的路径；PATH 里也没有 ffmpeg 时显示橙红色的提示，指定可执行文件后才能导入视频。
- 路径指向存在的文件时显示绿色的「FFmpeg 路径有效」。
- 路径指向不存在的文件时显示橙红色的「文件不存在」。

点 `Apply` / 应用 或 `OK` / 确定 后路径写入配置文件，视频导入入口的可用状态立即刷新，不需要重启，消息面板里会留一条结果提示。路径无效时这一项不写入配置，按上一次有效的路径继续工作，状态行会说明文件不存在，消息面板里也会提示路径未保存。

路径保存在配置目录的 `signal-analysis-config.json` 里，与色带、峰值窗口显隐等插件偏好共用一个文件。频率分辨率、窗函数、峰值门限、标定这些按信号生效的分析参数不在这里，下一节说明。

## 分析参数

常用参数直接放在「分析设置」上下文页上，改完立即生效，不需要打开对话框：

| 面板 | 参数 | 影响与重算范围 |
|---|---|---|
| 预处理 | 去直流、去趋势（无/常数/线性） | 频谱、时频图、峰值 |
| 频谱 | 窗函数、幅值口径、频率分辨率 | 窗函数/分辨率改后重算频谱、时频图、峰值；幅值口径只重绘 |
| 时频 | 窗长、跳步重叠、Δf（只读提示） | 窗长改后连同频谱一起重算；跳步重叠只重算时频图与峰值曲线 |
| 峰值 | 标记数量、模式、相对门限 | 只重算峰值表与峰值曲线，不重算频谱 |

「更多 → 高级设置…」打开参数对话框，只放不常改的项：

| 分组 | 主要项 |
|---|---|
| 频谱（高级） | 零填充点数 |
| 功率谱 | 平均方式（均值/中位数）、重叠率 |
| 时频（高级） | 零填充点数 |
| 峰值查找（高级） | 突出度、最小间距、绝对高度门限（只在峰值查找模式选「高级」时生效） |
| 标定 | 标定系数、幅值单位 |

几点约定：

- **频率分辨率**而不是「FFT 点数」是主输入：软件按分辨率反推频谱段长（峰值表也按它取段长），时频面板随时反显由窗长派生的实际 Δf。**频率分辨率与 STFT 窗长二选一联动**：改分辨率时时频图窗长同步变化（Δf = 1/窗长），反之改窗长也会更新分辨率。
- **零填充点数**表示在段长之外额外补的点数（频谱与 STFT 口径一致），只增加频点密度、不改变实际分辨率，属于高级项。
- **幅值口径**有四种：峰值幅度、均方根、dB（相对满量程）、dB（相对 1.0）。dB 参考不再单独设置——选「dB（相对 1.0）」就是以前的「dBRef1 + 相对 1.0」，其余口径一律按满量程参考。幅值口径只在**显示与导出层**换算：计算层始终产出峰值幅度，切换后不重算，频谱图、峰值表与 CSV 三处数值一致。
- 参数改动按上表的范围分级重算，不会每次改动都重算整段频谱；状态栏进度条表达重算进度。
- 峰值查找的**最小间距**默认是当前实际频率分辨率的 5 倍；没手改时会跟随分辨率联动，改完保留手填值。
- 对话框点确定后按新参数全量重算一次（频谱、时频图、矩形与峰值表一起刷新）；对话框里没出现的字段保持丝带上的当前选择，不会被重置。参数不进撤销栈；每个信号标签页记住自己的参数，对话框里有「恢复默认」。

## 峰值

排在前 N 的峰会显示在：

- **峰值窗口**（右侧停靠区，与设置、智能体同一个区域）：上半是峰值表（序号、频率、幅值、相对主峰多少分贝、占全部峰的比例），下半是「每帧第 N 名的频率随时间变化」的曲线，第 1 名到第 N 名的颜色固定。打开播放器控制条的「跟随播放」后，峰值表会切换成当前帧的数据并多出一列帧时间。第一次导入信号成功时这个窗口会自动切到前面一次；但如果你之前手动关掉过它，插件会记住这个偏好，重开程序或加载工程后不会强行显示。入口是「信号显示」上下文页「峰值标注」面板的「峰值窗口」。
- **频谱图上的峰值标记**：倒三角标记的尖端对准曲线上的峰顶，标记上方显示文字，颜色统一。标记随工程保存，重开工程后恢复。

峰值相关的设置项按用途分成两处：搜索参数在「分析设置 → 峰值」，标注与窗口在「信号显示 → 峰值标注」。

| 按钮 | 作用 |
|---|---|
| 峰值标记 | 显示/隐藏频谱图上的峰值标记（默认显示文字） |
| 标记数量 | 标记多少个峰：10、20、50 |
| 模式 | 峰值查找模式：简单 / 高级（高级模式的额外参数在「更多 → 高级设置…」里） |
| 相对门限 | 只保留低于最强峰不超过该门限（dB）的峰 |
| 标记显示 | 编辑标记上方显示的文字（弹出设置窗口） |
| 峰值窗口 | 显示/隐藏右侧峰值窗口 |

「标记显示」打开一个简单的模板编辑器：一排占位符按钮（序号、频率、幅值）把占位符插入编辑框，编辑框下方实时显示渲染结果（例如模板 `{index}-{fre} Hz` 渲染为 `1-32.5 Hz`）。三个占位符可任意组合、可加单位或前后缀，留空则不显示文字。这个模板是插件级显示偏好，对所有信号生效并保存在 `signal-analysis-config.json` 里。

曲线的全帧扫描可能要几十秒，期间状态栏显示进度条与停止按钮。

## 导出数据

- **导出峰值表**（下拉）：峰值表 CSV、频谱曲线 CSV、功率谱密度（PSD）CSV、热图矩阵 CSV。峰值表与频谱 CSV 的幅值列按当前显示口径（峰值/均方根/dB）输出；PSD 是韦尔奇单边功率谱密度，按 10·log10 转 dB（相对 1.0/赫兹）导出，与幅值口径无关。热图矩阵很大时导出前会弹体积确认，并提供 2 倍降采样。
- **峰值窗口里的按钮**：把峰值表直接送进数据管理器成为新的数据表（列名英文，表名带信号名），或单独导出 CSV（UTF-8 BOM，Excel 直接打开不乱码）。

图表图片与剪贴板导出见「绘图操作」一节的「导出图表」。

## 工程保存

保存工程时，插件记录：

- 信号的**来源引用**（文件路径，或数据帧名 + 列名）、导入时确认的采样率、分析参数。
- 信号的**绘图状态**：2×2 网格的行列比例、各子图的坐标轴/网格/图例等外观设置、峰值标记，以及自己添加的参考线、文本、标注等图元；三维瀑布的视角、坐标轴与主题也随工程保存。

分析结果（包络、频谱曲线、时频图、峰值数据）不保存，打开工程后按参数重新计算并重建这些结果图元。旧版本保存的工程没有绘图状态记录，会按旧存档里的视图状态（瀑布模式、频率轴、色带、dB 下限、自动滚动、分割比例）重建默认的 2×2 布局。

打开新工程、新建工程或关闭工程时会先清空上一工程残留的信号与临时文件（只清本插件本次会话产生的临时音频）。

信号源找不到时：

- **文件/视频来源**：提示「信号源缺失」，可以直接选择文件的新位置继续恢复（采样率与参数保留），选择跳过则忽略该信号。
- **数据帧来源**：工程里记录的数据帧在当前工程中不存在时，该信号会保留为「来源缺失」占位（标签页仍在、参数与列名保留，但不参与计算）。这时「导入导出」面板「导入」菜单里的「重新指定数据帧来源」变为可用：点它从数据管理器里选一个现有数据帧，插件会用原来记录的列名与采样率重建该信号，并尽量保留视图状态。
