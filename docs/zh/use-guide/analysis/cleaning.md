# 数据清洗

数据清洗面板把常见的表格整理动作做成了一排按钮：删掉有空值的行、去掉重复记录、把空缺的位置补上、按统计方法挑出异常值、把偏态的分布往中间收。这些动作都在当前打开的那张表上直接改，改完可以撤销，不需要写任何代码。

面板要对付的是四类问题。空值（缺失值）是某个单元格没有内容，来自采集失败、导入时的空缺或人为留白。重复记录是同一条数据在表里出现两次及以上，来自多次合并或导出。异常值是数值明显偏离整体水平的数据点，可能来自录入错误，也可能只是少见的正常值。偏态是整列数值的分布在某一侧拖出很长的尾巴，直方图上会看到一侧高耸、另一侧平缓。

计算由软件内嵌的 Python 环境完成，用的库是 pandas 和 numpy，参数由界面上的表单收集，填完点「OK」执行。直方图、箱线图这类检查分布的图见[统计绘图](stats-plots.md)。

## 面板在哪里

打开一份数据集后，Ribbon 上会多出一个「DataFrame」上下文标签页，页内「Operate」/ 操作 分类下是数据表相关的面板。数据分析插件往这里加了三个面板：

- 数据清洗面板，标题「Data Cleaning」/ 数据清洗，七个按钮，本章逐个说明。
- 数据过滤面板，标题「Data Filtering」/ 数据过滤，五个按钮，见[筛选、计算与排序](query.md)。
- 统计面板，标题「Statistics」/ 数据统计，两个按钮，见[描述统计与透视表](statistics.md)。

上下文标签页只在数据操作面板里打开着数据表时出现。数据管理面板里列出的数据集要先双击打开成表格，按钮才能用；没有打开的表时，点按钮会收到一条提示，要求先选择一个数据集。

面板里七个按钮和它们弹出的对话框对应如下：

| 按钮 | 对话框标题 | 对数据的改动 |
|---|---|---|
| 「Drop None」/ 删除缺失值 | 「Remove Missing Values」/ 删除缺失值 | 删掉含空值的行 |
| 「Drop Duplicates」/ 删除重复值 | 「Remove Duplicate Rows」/ 删除重复行 | 删掉内容重复的行 |
| 「Fill None」/ 填充缺失值 | 「Fill Missing Values」/ 填充缺失值 | 把空值换成指定值或统计量 |
| 「Fill Interpolate」/ 插值填充 | 「Interpolate Values Parameter Settings」/ 插值参数设置 | 用插值推算出的值填空 |
| 「IQR Outlier Handling」/ IQR 异常值处理 | 「Remove Outliers (IQR Method)」/ 移除异常值（IQR 方法） | 按四分位距判断并处理离群值 |
| 「Z-Score Outlier Handling」/ Z-Score 异常值处理 | 「Remove Outliers (Z-score)」/ 移除异常值（Z-score 方法） | 按标准分数判断并处理离群值 |
| 「Transform Skewed」/ 转换偏态数据 | 「Transform Skewed Data」/ 变换偏态数据 | 用函数变换把偏斜的分布拉正 |

清洗用的 Python 模块里还有五个函数：替换指定值、上下限过滤、数据缩放、文本清洗、标签编码。界面上没有对应的按钮，只能从脚本工作区调用，本章不再展开。

## 操作对象、列选择和撤销

每个动作都作用在数据操作面板当前标签页里的那张表。表在数据管理面板里还叫原来的名字，操作不会另存一份，改的就是这一份数据，随后画图、统计、工作流拿到的都是改过的内容。

清洗的多数动作支持缩小范围：在表格里选中一列或多列的表头再点按钮，只有这些列参与计算。

- 删除类动作（删除缺失值、删除重复值）在选中列时，只按选中的列判断哪些行该删；没有选中任何列时按整表判断。
- 填充类的动作（填充缺失值、插值填充）只在选中的列上填；没有选中任何列时处理全部列。
- 异常值处理和偏态转换只处理数值列。选中的列里如果不是数值列，会被跳过；没有选中任何列时，自动取表里全部数值列。

每个动作在动手之前会把整张表的状态记下来，压进数据操作面板的撤销栈。撤销和重做按钮在窗口左上角的快速访问工具栏里，也可以按 `Ctrl+Z` 和 `Ctrl+Y`。撤销恢复的是操作前的整张表，包括行号和列的类型。

操作结束后，结果会以一条消息出现在「Log」/ 消息 停靠面板里，同时显示在窗口底部的状态栏。消息中的数字按操作类型不同，含义不完全相同：删除类给出减少的行数，填充缺失值给出被写入的单元格个数，插值和偏态转换因为不改变行数，给出的数字固定是 0。各节里会把这些写法单独点出来。

参数对话框会被缓存：同一个按钮第二次打开时，上一次填的参数还在，便于对同一批数据反复用同一组设置。

取消对话框（点「Cancel」）不会对表做任何改动。

## Drop None / 删除缺失值

删掉含有空值的行。表格里显示为空的单元格在内部记作 NaN，这一节的操作针对的就是它们。对话框标题是「Remove Missing Values」/ 删除缺失值，分「Basic Settings」/ 基础设置 和「Advanced Settings」/ 高级设置 两组。

| 参数 | 类型 | 默认 | 取值范围 | 含义 |
|---|---|---|---|---|
| 「Removal Criteria」/ 删除条件 | 单选 | any | any / all | 一行里出现任意空值就删，还是整行全空才删 |
| 「Minimum Non-NA Values」/ 最少非空值数量 | 整数 | 0 | 0 及以上的整数 | 一行至少要有几个非空值才保留，0 表示不用这条规则 |
| 「Reset Row Numbers」/ 重置行号 | 开关 | 开 | 开 / 关 | 删除之后是否把行号从 0 重新编号 |

两个删除条件对应的选项文字是「Remove row if ANY value is missing」/ 行中任意值为空时删除，以及「Remove row if ALL values are missing」/ 行中所有值为空时删除。

「最少非空值数量」填大于 0 的数时，会取代「删除条件」起作用：一行里的非空值个数少于这个数就删掉。比如一行有 10 列，这里填 8，那么空值超过两个的行全部删除。两个参数一起用时，起作用的是「最少非空值数量」。

完成后消息里给出「Removed N rows with missing values」/「删除了 N 个包含缺失值的行」，N 是减少的行数。

三种删除条件在一张五行四列的小表上结果不同，表里的「空」表示表格中的空单元格：

| 温度 | 浓度 | 批次 | 设备 | 非空值个数 |
|---|---|---|---|---|
| 20.1 | 空 | A | 空 | 2 |
| 空 | 15.0 | B | 空 | 2 |
| 22.3 | 18.5 | 空 | D1 | 3 |
| 空 | 空 | 空 | 空 | 0 |
| 24.0 | 21.0 | C | D2 | 4 |

按「行中任意值为空时删除」处理，只有最后一行保留；按「行中所有值为空时删除」处理，只删掉第四行；「最少非空值数量」填 3 时，保留最后两行。同一份数据因为判定标准不同，剩下 1 行、4 行或 2 行，选定条件之后再看一眼行数变化。

什么时候用：从 CSV、Excel 导入的数据经常有零星空缺，后续画图或做统计时这些行会带来麻烦。选「行中任意值为空时删除」最保守，得到的表干净但行数损失最多。列很多、而关心的问题只涉及其中几列时，先在表格里选中这几列再执行，判断范围会缩小到选中的列，避免因为无关列的空值丢掉有用的行。

注意删除之后行数减少，行号如果不重置会留下断号，这正是「重置行号」开关要处理的问题。断号本身不影响后续计算，但导出成 CSV 之后再拿回来，行号就成了普通的一列。

## Drop Duplicates / 删除重复值

把内容重复的行去掉，只保留其中一条。对话框标题是「Remove Duplicate Rows」/ 删除重复行。

| 参数 | 类型 | 默认 | 取值范围 | 含义 |
|---|---|---|---|---|
| 「Which to Keep」/ 保留哪个 | 单选 | first | first / last / none | 一组重复行里保留哪一条 |
| 「Reset Row Numbers」/ 重置行号 | 开关 | 开 | 开 / 关 | 删除之后是否从 0 重新编号行 |

三个选项的文字是「Keep first occurrence, remove rest」/ 保留首次出现，删除其余、「Keep last occurrence, remove rest」/ 保留最后出现，删除其余、「Remove all duplicates」/ 删除所有重复值。第三个选项把重复出现过的组整组删除，一条都不留，适合「出现两次即视为不可信记录」的场合。

判断重复时看的是整行的全部列。在表格里选中若干列再执行，判断范围缩小到选中的列，同一列组合出现多次就算重复。

完成后消息里给出「Removed N duplicate rows」/「删除了 N 个重复行」。

什么时候用：合并多份数据之后，同一条记录常常出现两次；从数据库导出时也可能带上重复行。判断重复前先想好哪些列构成「一条记录」的身份，把不参与判断的列（时间戳、备注、采集设备号）排除在外，再执行。全列判断时，两行只要有一个单元格不同就不算重复，容易出现「重复没被删掉」的错觉，先选中真正标识记录的列是稳妥做法。

保留第一条还是最后一条，取决于数据的先后顺序：后导入的数据往往覆盖了前面的记录，这时保留最后一条；反之保留第一条。两种选择得到的行数相同，只有被保留的那一条的内容不同。

## Fill None / 填充缺失值

把空值换成指定的内容或统计量。对话框标题是「Fill Missing Values」/ 填充缺失值，分「Fill Method」/ 填充方法 和「Fill Value Settings」/ 填充值设置 两组。

| 参数 | 类型 | 默认 | 取值范围 | 含义 |
|---|---|---|---|---|
| 「Fill Method」/ 填充方法 | 单选 | value | value / forward / backward / mean / median / mode | 用什么填 |
| 「Fill Value」/ 填充值 | 小数 | 0.0 | 任意小数 | 选择「用特定值填充」时写进空位的内容 |
| 「Maximum Consecutive Fills」/ 最大连续填充数 | 整数 | 留空 | 1 到 1000，留空表示不限 | 一段连续空值最多填几个 |

六种填充方法的含义：

- 「Fill with a specific value」/ 用特定值填充，写入「填充值」里填的数字。0.0 是默认值，缺测在业务上代表零的时候直接确认即可；想填别的数字，先改「填充值」。
- 「Use previous non-missing value」/ 使用前一个非缺失值，把上方最近的一个有效值向下延续。数据按时间先后排列时等同于「保持上一次的读数」。
- 「Use next non-missing value」/ 使用后一个非缺失值，把下方最近的一个有效值向上延续。
- 「Fill with column average」/ 用列平均值填充，只对数值列生效。
- 「Fill with column middle value」/ 用列中位数填充，只对数值列生效。
- 「Fill with most common value」/ 用最常出现的值填充，取该列出现次数最多的那个值，文本列也可以用，比如按出现最多的类别填补空缺的类别名。

均值和中位数只处理数值列，文本列用这两种方法填不上；众数则不区分类型。

「最大连续填充数」限制的是连续空值的个数：一段空值超过这个数量时，超出部分保持为空。留空表示不限制，一段多长都填满。前向填充时这个限制按「连续多少个空位」计数，中间的已知值会打断计数。

完成后消息里给出「Filled N missing values」/「已填充 N 个缺失值」，N 是被写入的有效单元格个数。表里没有空值时不会出现这条消息。

六种方法对同一列数据的结果，用一列浓度为「空、10.0、空、空、20.0、50.0」的数据做对照：

| 方法 | 填充后的取值 | 说明 |
|---|---|---|
| 用特定值填充 | 0.0、10.0、0.0、0.0、20.0、50.0 | 填充值保持默认的 0.0 |
| 使用前一个非缺失值 | 空、10.0、10.0、10.0、20.0、50.0 | 开头的空位上面没有值，保持为空 |
| 使用后一个非缺失值 | 10.0、10.0、20.0、20.0、20.0、50.0 | 末尾的空位下面没有值，保持为空 |
| 用列平均值填充 | 26.67、10.0、26.67、26.67、20.0、50.0 | 非空值的平均值为 26.67 |
| 用列中位数填充 | 20.0、10.0、20.0、20.0、20.0、50.0 | 三个非空值 10、20、50 的中位数是 20 |
| 用最常出现的值填充 | 10.0、10.0、10.0、10.0、20.0、50.0 | 三个值各出现一次，众数并列时取最小的 10.0 |

平均值和中位数在这一列上给出的结果不同，原因是 50 这个偏大的值把平均值抬高了；中位数不受影响。挑选方法时把这一列里有没有远离中心的数考虑进去。

什么时候用：均值和中位数填充适合数值列里的个别空缺，两者都不会改动非空单元格；差别在于平均值受极端值影响，一列里有几个很大的数就会把平均值抬高，中位数不受影响，数值分布偏斜时优先用中位数。前后值填充适合有先后顺序的数据，但它假设空位前后的数值变化平缓，连续空值很长时这个假设容易失效，配合「最大连续填充数」限制填充长度是常见做法。

用同一个常数填空值时，后续算平均值、标准差会把空值按这个常数计进去，适合缺测本身有含义的情况（没有记录就代表零）；缺测只是没测到时，这条捷径会把分布往常数方向拉。在表格里选中指定的列再执行，只有这些列会被填充。

## Fill Interpolate / 插值填充

用插值计算出的值填补空位：缺失点按相邻数据构成的曲线取估计值，比直接取一列的平均值更贴合数据的变化趋势。对话框标题是「Interpolate Values Parameter Settings」/ 插值参数设置。

| 参数 | 类型 | 默认 | 取值范围 | 含义 |
|---|---|---|---|---|
| 「Interpolation Method」/ 插值方法 | 单选 | linear | 十六种方法 | 用哪种曲线推算缺失点 |
| 「Interpolation Limit」/ 插值限制 | 整数 | 留空 | 1 到 10000，留空表示不限 | 一段连续空值最多插几个 |
| 「Spline Order」/ 样条阶数 | 整数 | 3 | 1 到 10 | 样条类和多项式类方法的阶数 |
| 「Inplace Interpolation」/ 原地插值 | 开关 | 开 | 开 / 关 | 在原表上改，还是返回一份新表 |

### 十六种插值方法

十六种方法分成两类。第一类不看行与行之间的横向间隔，把每一行当成等距排列；第二类会读取行号或索引值，按真实间隔推算。

| 方法 | 界面文字 | 适合的情况 |
|---|---|---|
| linear | 「Linear interpolation」/ 线性插值 | 默认方法。相邻两点之间连直线，数据变化平缓时最稳，不确定用哪种时先用它 |
| pad | 「Pad interpolation」/ 填充插值 | 用上一个有效值填补后面所有空位，等同于不做插值的前向填充 |
| nearest | 「Nearest interpolation」/ 最近邻插值 | 用距离最近的已知点取值，结果只取原值里已有的数 |
| zero | 「Zero-order hold」/ 零阶保持 | 保持上一个有效值不变，直到下一个有效值出现，形成台阶状的取值 |
| time | 「Time-based interpolation」/ 基于时间的插值 | 行索引是日期时间、且数据按固定时间间隔采样时使用 |
| index | 「Use index values」/ 使用索引值 | 行号本身有数值含义（比如按距离编号）时，按行号的实际数值计算 |
| slinear | 「Spline linear interpolation」/ 样条线性插值 | 一阶样条，效果接近线性插值，但按行号间隔计算 |
| quadratic | 「Quadratic interpolation」/ 二次插值 | 数据弯曲、需要二阶曲线衔接时 |
| cubic | 「Cubic interpolation」/ 三次插值 | 比二次更平滑，采样点较密时用 |
| spline | 「Spline interpolation」/ 样条插值 | 按「样条阶数」指定的阶数做样条插值，阶数默认 3 |
| polynomial | 「Polynomial interpolation」/ 多项式插值 | 用指定阶数的多项式穿过所有已知点，阶数越高越容易在两端抖动 |
| barycentric | 「Barycentric interpolation」/ 重心插值 | 多项式插值的数值稳定写法，点数较多时效果比直接多项式好 |
| krogh | 「Krogh interpolation」/ Krogh 插值 | 需要同时得到多个阶数导数信息时使用的插值形式 |
| piecewise_polynomial | 「Piecewise polynomial interpolation」/ 分段多项式插值 | 分段低次多项式拼接，兼顾平滑和局部稳定 |
| pchip | 「PCHIP interpolation」/ PCHIP 插值 | 保形分段三次插值，不会凭空造出原数据里没有的极大极小值 |
| akima | 「Akima 插值」 | 保形插值的一种，折线转折较多时比三次样条更贴合原始形状 |

一段数据内部的取值随时间单调变化（温度、浓度、电压）时，线性插值、PCHIP、Akima 三者的差别不大，选默认的线性即可。数据本身有明确的振荡或弯曲时，二次、三次、样条这类平滑方法更贴合形状，但点数太少时高阶方法会在空位附近甩出估算值。多项式类和重心插值对点数敏感，只有空位两侧各有很多数据点时才稳定。

同一列读数「1.0、空、3.0、空、空、8.0」用五种方法算出的结果：

| 方法 | 六个位置上的取值 |
|---|---|
| 线性插值 | 1.0、2.0、3.0、4.667、6.333、8.0 |
| 最近邻插值 | 1.0、1.0、3.0、3.0、8.0、8.0 |
| 零阶保持 | 1.0、1.0、3.0、3.0、3.0、8.0 |
| PCHIP 插值 | 1.0、1.876、3.0、4.383、6.058、8.0 |
| Akima 插值 | 1.0、1.833、3.0、4.444、6.111、8.0 |

最近邻和零阶保持只会搬运已有的数值，不会造出新数值；另外三种都会算出原表里没有的数。这一点在报告数据来源时值得区分：插值填出来的位置，取值是推算的。

只有数值列会被插值，文本列保持原样。选中的列里不是数值列的会被跳过；没有选中任何列时，处理全部数值列。

完成后消息里给出「Interpolated N missing values」/「插值填充了 N 个缺失值」。这里的 N 按行数变化算出，而插值不改变行数，所以显示的数字是 0，实际填了多少个空位要看表格里列值的变化。

几点注意。插值方法依赖空位前后的数据，一段空值太长时推算值没有参考，尽量配合「插值限制」使用，比如限制成 3，超过 3 个的连续空位保持为空。基于时间的插值要求行索引本身是日期时间；清洗过程中「重置行号」会把行号重排成从 0 开始的整数，之后再用时间插值不会生效。某些插值方法在个别列上会算不出来（点数太少、数值全相同都属于这类情况），这时该列保持原样，不报错，需要自己核对结果；当前的 pandas 版本也不再接受填充插值这一项，选中它等于不做处理。

插值是猜测，猜出来的值会进入后续统计和绘图。数据本身的规律比较强（传感器按时间等间隔采样、物理量连续变化）时值得用；数据只是一堆无序记录时，线性插值也未必比直接删掉这些行更可靠。

## IQR Outlier Handling / IQR 异常值处理

用四分位距判断哪些数值离群得过分，再按指定的方式处理。对话框标题是「Remove Outliers (IQR Method)」/ 移除异常值（IQR 方法），分「Detection Settings」/ 检测设置 和「Action Settings」/ 操作设置 两组。

| 参数 | 类型 | 默认 | 取值范围 | 含义 |
|---|---|---|---|---|
| 「IQR Multiplier」/ IQR 乘数 | 小数 | 1.5 | 0.5 到 10 | 判定边界离四分位有多远 |
| 「Action on Outliers」/ 对异常值的操作 | 单选 | remove | 五种处理方式 | 判定为异常值之后怎么处理 |
| 「Custom Replacement Value」/ 自定义替换值 | 小数 | 0.0 | 任意小数 | 选择「用自定义值替换异常值」时写入的数字 |
| 「Reset Row Numbers」/ 重置行号 | 开关 | 开 | 开 / 关 | 删除行之后是否重新编号，只对删除方式有意义 |

### 四分位距是什么

把一列数值从小到大排列，处在 25% 位置上的数是下四分位数 Q1，处在 75% 位置上的数是上四分位数 Q3，两者之差就是四分位距，英文缩写 IQR。它衡量的是中间一半数据的散布宽度，只用中间区间，两端的极端值影响不到它。

判定边界取成 Q1 减去 IQR 乘数倍，以及 Q3 加上 IQR 乘数倍：小于下边界或大于上边界的值算异常值。

乘数 1.5 是箱线图沿用多年的习惯值。在正态分布下大约只有千分之几的数据落在界外，既能抓住明显离群的点，又不会把正常的长尾砍掉。调小到 1.0 以内会更激进，判为异常的点明显增多；调到 3 会宽松很多，只有离得很远的点才被处理。对话框里给出的建议区间是 1.5 到 3。

拿一列十个数据当例子：10.0、11.0、12.0、12.5、13.0、13.5、14.0、14.5、15.0、60.0。下四分位数是 12.125，上四分位数是 14.375，四分位距是 2.25。乘数取默认的 1.5 时，下边界是 8.75，上边界是 17.75，只有 60.0 落在界外，被当作异常值处理；把乘数改成 3，上边界抬高到 21.125，60.0 仍然越界，而边界更宽之后，落在 17.75 到 21.125 之间的数不再被判为异常。十个数里有一个 60.0 的时候，四分位距只用了中间的数据，两侧的极端值进不来。

### 五种处理方式

两种异常值处理动作共用同一套处理方式，区别只在异常值怎么判定：

- 「Remove rows with outliers」/ 删除包含异常值的行，默认方式。行数减少，表格里直接看不到这些行。
- 「Replace outliers with column mean」/ 用列平均值替换异常值，行数不变，越界的值换成该列的平均值。
- 「Replace outliers with column median」/ 用列中位数替换异常值，行数不变，越界的值换成该列的中位数，比平均值更抗离群点。
- 「Replace outliers with boundary values」/ 用边界值替换异常值，行数不变，偏大的换成上边界，偏小的换成下边界，相当于把数据截断到边界上，越界越远改得越多。
- 「Replace outliers with custom value」/ 用自定义值替换异常值，行数不变，越界的位置统一写成「自定义替换值」，比如用 −1 这类约定的缺失标记，后续按缺失值处理。

选择哪种方式，取决于异常值本身是不是要保留的信息。删除会把整行丢掉，同一行里其它列的正常数据也一起消失；替换保留行数，适合按行配对的分析（同一时刻的多个测点、同一个样本的多项指标）。平均值和中位数替换会把多个不同的极端值压成同一个数，边界值替换只压掉越界的部分，自定义值替换适合把「异常」当作一种状态标记出来。

### 结果反馈

选择删除方式时，消息里给出「Removed N rows containing outliers using IQR method」/「使用 IQR 方法移除了 N 行含异常值的数据」，没有检测到异常值时给出「No outliers detected using IQR method」/「使用 IQR 方法未检测到异常值」。选择替换方式时给出「Outlier values processed using IQR method (动作名)」/「使用 IQR 方法处理了异常值（动作名）」，此时行数没有变化。

### 使用场合

多列参与判断时，只要有一列判定为异常，整行就会被删掉，列选得越多删掉的行越多。先对关键的一两列做，确认删除比例合理，再考虑扩大范围。

处理之前值得先看一眼分布：一列本身就有大量极端值（收入、流量这类长尾数据）时，按 1.5 倍 IQR 一刀切会删掉相当大比例的正常数据。这种情况下先换成替换类操作，或者把乘数调到 3，只处理离得最远的点。删除之后行数变化，适合配合「重置行号」。判断过程只在选中的数值列上进行，表格里可以先只选中关心的列。

## Z-Score Outlier Handling / Z-Score 异常值处理

用每个值离平均值有多远来判断异常，再按同一套方式处理。对话框标题是「Remove Outliers (Z-score)」/ 移除异常值（Z-score 方法），参数分组和 IQR 方法一致。

| 参数 | 类型 | 默认 | 取值范围 | 含义 |
|---|---|---|---|---|
| 「Z-score Threshold」/ Z-score 阈值 | 小数 | 3.0 | 1 到 10 | 绝对值超过这个数就判为异常 |
| 「Use Robust Statistics」/ 使用稳健统计 | 开关 | 关 | 开 / 关 | 用中位数和绝对中位差代替平均值和标准差 |
| 「Action on Outliers」/ 对异常值的操作 | 单选 | remove | 五种处理方式 | 判定为异常值之后怎么处理 |
| 「Custom Replacement Value」/ 自定义替换值 | 小数 | 0.0 | 任意小数 | 选择「用自定义值替换异常值」时写入的数字 |
| 「Reset Row Numbers」/ 重置行号 | 开关 | 开 | 开 / 关 | 删除行之后是否重新编号，只对删除方式有意义 |

### Z 分数和稳健模式

Z 分数（标准分数）是这样一个数：把值减去这一列的平均值，再除以这一列的标准差。它回答的问题是「这个值离平均值有几个标准差」。阈值填 3 表示只处理偏离平均值三个标准差以上的值。正态分布下绝对值超过 3 的数据大约占千分之三，这正好是 3 被当作常用阈值的原因。

普通模式依赖平均值和标准差，而这两个量本身会被极端值拉动：一个特别大的离群点足以把标准差抬高，让同一个阈值变得过松，反而抓不到别的异常值。打开「使用稳健统计」后，判断改用中位数和绝对中位差（MAD，各值与中位数之差的绝对值的中位数）。绝对中位差乘 1.4826 之后再当作标准差的估计值，这个系数是为了让正态分布下两者的量级相当。稳健模式对非正态、长尾的数据更可靠，代价是计算出的边界与普通模式不同，阈值 3 的严格程度也不完全一样。

还用上面那列十个数据：10.0、11.0、12.0、12.5、13.0、13.5、14.0、14.5、15.0、60.0。平均值是 17.55，标准差是 14.995，被 60.0 抬高了。60.0 的 Z 分数只有 2.83，阈值 3 下反而不判为异常，整列一个异常值都抓不到；换成稳健模式，中位数是 13.25，绝对中位差是 1.25，乘 1.4826 得到 1.853，60.0 的 Z 分数是 25.2，稳稳越界。同一列数据、同一个阈值，两种模式结论相反，什么时候开稳健模式由此可判断。

### 结果反馈

删除方式给出「Removed N rows containing outliers using Z-score method」/「使用 Z-score 方法移除了 N 行含异常值的数据」或「No outliers detected using Z-score method」/「使用 Z-score 方法未检测到异常值」；替换方式给出「Outlier values processed using Z-score method (动作名)」/「使用 Z-score 方法处理了异常值（动作名）」。

### 使用场合

Z 分数方法假设数据大致对称。明显偏斜的分布（只有一侧长尾的浓度、产量数据）用普通模式容易在长尾那一侧误判，先做[偏态转换](#transform-skewed--转换偏态数据)，或者改开稳健模式。

选择边界值替换时，两种模式的边界含义不同：普通模式的边界是平均值加减阈值倍标准差，稳健模式是中位数加减阈值倍的中位数绝对偏差估计值。「用列平均值替换」和「用列中位数替换」两种替换方式在两种模式下取值相同，都是按整列算出的统计量。

处理方式与 IQR 方法完全一致，含义见[IQR 异常值处理](#iqr-outlier-handling--iqr-异常值处理)一节里的五种处理方式。

### 两种异常值方法怎么选

IQR 方法只用四分位和分布的形状，不涉及平均值、标准差，对分布形态没有要求；Z 分数方法把每个值折算成「离中心几个标准差」，在数据接近对称时判断更细致。数据量不大（几十行）时，四分位数的稳定性比标准差好，IQR 方法更稳妥；数据量大、分布接近对称时，两种方法给出的结果接近，选哪个都可以。

两边的乘数、阈值都不建议照搬，处理之前先用箱线图或直方图看一眼结果是否合理。

## Transform Skewed / 转换偏态数据

把明显偏向一侧的数值分布通过函数变换拉回中间，让后续的统计量和使用正态分布假设的方法更可靠。对话框标题是「Transform Skewed Data」/ 变换偏态数据。

| 参数 | 类型 | 默认 | 取值范围 | 含义 |
|---|---|---|---|---|
| 「Transformation Method」/ 转换方法 | 单选 | log | log / sqrt / reciprocal / power | 用哪种函数变换 |
| 「Power Lambda」/ 幂 Lambda 值 | 小数 | 0.5 | −5 到 5 | 幂转换的指数，其他方法忽略这个值 |
| 「Add 1 before transformation」/ 转换前加 1 | 开关 | 开 | 开 / 关 | 在对数和平方根转换前给每个值加 1 |

四种变换对分布的作用：

- 对数转换，界面文字「Logarithm transformation (log(x))」/ 对数转换（log(x)），对数值取自然对数。数值成倍增长、跨度很大的数据（浓度、计数、金额）常见右偏，取对数之后大值被压缩、小值被拉开，分布向中间收拢。
- 平方根转换，「Square root transformation (sqrt(x))」/ 平方根转换（sqrt(x)），比对数的压缩力度轻，适合计数类数据里偏离程度还不算严重的情况。
- 倒数转换，「Reciprocal transformation (1/x)」/ 倒数转换（1/x），1 除以数值，压缩效果最强，同时把大小顺序翻转。只适合右偏很严重、且数值远大于 0 的正数，0 会变成空值。
- 幂转换，「Power transformation (x^lambda)」/ 幂转换（x^lambda），用指数 lambda 搓出中间形态。lambda 取 0.5 相当于平方根，取 1 等于不变，取更大的值会加大偏斜，取负数接近倒数。默认的 0.5 是介于「什么都不做」和「开方」之间的温和选择，需要更强或更弱的力度时改这个值。

「转换前加 1」之所以存在，是因为对数和平方根在 0 和负数上没有定义：不勾选时，对数转换要求值大于 0，平方根要求值不小于 0，不满足的位置会变成空值；勾选后给每个数先加 1，0 变成 1 可以参与计算，负值仍然会变成空值，平方根则允许 −1 以上的值。转换之后出现新的空值是预期行为，需要的话再用填充缺失值处理。

一列典型的右偏数据「1、1、2、3、5、8、13、21、100」取自然对数前后的对照：

| 位置 | 原始值 | 取对数（加 1）后的值 |
|---|---|---|
| 1 | 1.0 | 0.693 |
| 2 | 1.0 | 0.693 |
| 3 | 2.0 | 1.099 |
| 4 | 3.0 | 1.386 |
| 5 | 5.0 | 1.792 |
| 6 | 8.0 | 2.197 |
| 7 | 13.0 | 2.639 |
| 8 | 21.0 | 3.091 |
| 9 | 100.0 | 4.615 |

原始值里最大的 100 与最小的 1 相差百倍，变换之后 4.615 与 0.693 只相差几倍，右侧的长尾被压短，多数数据点之间的距离被拉开，分布向中间聚拢。

转换只作用于数值列，选中的列里不是数值列的会被跳过，没有选中任何列时处理全部数值列。变换结果直接写回原来的列，原始数值不再保留，撤销可以恢复。

完成后消息里给出「Transformed N columns」/「变换了 N 列数据」。这里的 N 按行数变化算出，变换不改变行数，所以显示的数字是 0，实际变换了几列直接看表格里的列值。

什么时候用：后面要做回归、t 检验这类假设分布近似对称的分析时，右偏很重的变量先取对数再进入模型，比拿原始值硬算稳妥。先画直方图确认偏斜方向：右侧拖长尾的分布用 log，轻微的用 sqrt，只有少数极端大值的可以试 1/x 或取负的 lambda。转换的目标是让分布接近对称；变换后的数值已经不再是原来的物理量，报告结果时要么保留原单位下的统计量，要么在方法里写清楚做过变换。

## 清洗顺序建议

七个动作可以单独使用，也可以接连使用同一张表。动作的先后会影响结果，按下面这个次序推进比较常见。

先删行、后填值。删除缺失值和删除重复值都会减少行数，放在前面，后面的填充和插值面对的是确认保留下来的行，补出来的值不会浪费在马上要删掉的位置上。

重复记录尽早处理。同一份记录在表里出现两次时，平均值、计数、众数都会被算两遍，去重放在统计类动作之前。

判断异常值放在填充之后。填充会写入一批新数值，四分位数和平均值随之变化，先补全再判断，边界建立在完整数据上；反过来先判断异常、后填补空位，补进来的值不在判断范围内。

偏态转换放在异常值处理之后。IQR 方法和 Z 分数方法都在原始尺度上计算边界，转换会改变每个数的大小和相对位置，转换过的列再去做异常值判断，阈值 1.5 和 3 的含义已经不同。

补充新列的动作随时可以做。数值计算（见[筛选、计算与排序](query.md)）产生的新列不参与前面的判断，放在清洗流程的最后一步，用最终的数据算派生指标。

每一步都可以撤销，拿不准的顺序先做一遍、看消息里的行数变化，不满意就按 `Ctrl+Z` 退回去换一种做法。

## 一次完整清洗的示例

假设刚导入一份实验记录表，字段有采样时间、样品编号、温度、浓度、批次、备注、设备、读数，行数一千多。下面是一套常见的处理次序，参数都是真实可选的值。

1. 打开表格。在数据管理面板里双击数据集名，数据操作面板出现表格标签页，Ribbon 上出现「DataFrame」上下文标签页。
2. 删掉温度为空的行。选中温度列的表头，点「Drop None」，删除条件保持「行中任意值为空时删除」，重置行号保持打开。消息区给出的行数就是被删掉的记录数。
3. 去掉重复记录。点「Drop Duplicates」，在表格里选中样品编号和采样时间两列作为判断依据，保留方式用「保留首次出现，删除其余」。两列的组合重复才是重复记录，备注、读数不同不影响判断。
4. 补浓度的空位。点「Fill Interpolate」，插值方法用默认的线性插值，插值限制填 3，超过 3 个的连续空位留空不猜。
5. 补批次这种文本列的空位。点「Fill None」，填充方法改成「用最常出现的值填充」，选中批次列执行，文本列也能填上。
6. 看一眼读数的分布。在列标题上点右键选「Show Statistics」查看这一列的统计量，或者用[统计绘图](stats-plots.md)画箱线图和直方图，确认偏斜方向和大致的离群范围。
7. 处理离群值。点「Z-Score Outlier Handling」，阈值填 3，打开「使用稳健统计」，对异常值的操作用「用边界值替换异常值」，保留全部行数。
8. 把偏斜的读数拉正。点「Transform Skewed」，方法用对数转换，「转换前加 1」保持打开，变换之后这一列的分布接近对称，适合进入后续的回归分析。
9. 保存工程。清洗结果就是当前的表本身，保存工程时随之写入工程文件。

每一步之间都可以按 `Ctrl+Z` 退回，也可以只做其中一两步。示例里没有用到的三个动作在其它数据上同样适用，选择依据是数据本身的问题类型，而不是工序的完整性。

## 检查清洗结果

清洗不产生新的数据集，结果就是当前打开的表。核对结果从这几处入手。

表格视图直接看。行数在表格底部和滚动条长度上都有体现，行号断号说明有删除动作且没有重置行号。列标题右键菜单里的「Show Statistics」给出这一列的计数、均值、分位数等，对比清洗前后计数是否如预期。

消息面板里看数量。每个动作结束都会在「Log」/ 消息 面板留一条消息，删除类给出减少的行数，填充缺失值给出被填充的单元格个数。两三次操作连做时，按消息出现的先后顺序核对。

图上确认。直方图和箱线图能看出填充是否把分布压成了尖峰，异常值处理是否把长尾削得过头，偏态转换是否把分布拉到了中间。这些图在[统计绘图](stats-plots.md)里有现成的类型。

撤销栈回看。数据操作面板的撤销栈记录了每个动作的名字，鼠标悬停在撤销按钮上可以看到最近一步的动作名，据此判断上一步做的是哪个操作。

列类型顺带检查。用平均值、中位数、插值、对数变换填过的列会得到小数，原本的整数列会变成浮点列，表格里的显示格式随之改变。这是计算结果的正常表现，需要回到整数显示时，用「Type」/ 类型 面板改列类型。

不满意就撤销，换一组参数重来。清洗改动的是内存中的数据，只有保存工程才会写进文件。

## 常见问题

按钮点了没有反应。先确认数据操作面板里有打开的数据表（数据管理面板里双击数据集名），再看 Log 面板里的提示。数据集不是表格类型（比如 Series）时，这些按钮都不能用。

删除类操作没有删掉预期中的行。检查表格里是否选中了列：选中了列时，判断范围只在选中的列上。另外，全列判断重复时只要有一个单元格不同就不算重复。

行号出现断号。删除行之后没有重置行号就会这样。断号不影响计算和绘图，导出时按需要决定是否重新编号，可以再执行一次删除重复值并打开「重置行号」，或者直接接受断号。

消息里的数字是 0。插值填充和偏态转换的完成消息都按行数变化计算，这两类操作不改变行数，数字固定是 0，看表格里的列值即可。

执行之后发现错了。按 `Ctrl+Z` 撤销，一次撤销回到操作前的整张表。撤销栈是每个数据表标签页一份，切到别的表之后撤销不会影响原来的表。

空值在表格里长什么样。表格视图里的空单元格就是缺失值，行号照常显示，取值处留白。删除类操作针对的是这些位置，填充类操作要填的也是这些位置。

选了列之后结果和预期不一样。选中的列会限制参与判断的列：删除类只看选中的列有没有空值或重复，填充类只填选中的列。把列选中取消之后范围回到整表，行数变化会明显不同。

「填充值」填了但没有生效。这个输入框只在填充方法为「用特定值填充」时起作用，方法选成平均值、中位数、众数、前值、后值时，输入框里的数字不参与计算。

同一个动作连续点两次。第二次一般不会有变化：已经删掉的行不在了，已经填上的位置没有空位。消息里的数字会变成 0 或者出现「未检测到异常值」这类提示，属于正常现象。

操作作用到了另一张表上。动作的目标是数据操作面板当前标签页里的那张表。同时打开了多张表时，先确认标签页选中的是哪一张，再点按钮。

转换之后这一列多了空值。对数、倒数、平方根在非正数上没有定义，原来取 0 或负数的位置会变成空值。把「转换前加 1」打开可以救回 0，负值要先处理掉再转换。

一列数值完全相同。四分位距为 0，IQR 方法的上下边界都落在那个数值上，不会判出异常值；标准差为 0 时 Z 分数的分母接近 0，实现里给了保护，同样不会判出异常值。
