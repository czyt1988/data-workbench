# 筛选、计算与排序

数据过滤面板把「按条件挑数据」「算出新的一列」「按某一列排队」「在表里找一个值」四类操作放在一起。前四个动作改动当前打开的表，可以撤销；数据检索只是把光标移到找到的单元格上，不改数据。

这些动作都在数据操作面板当前标签页的那张表上进行，面板位置和列的选中规则与[数据清洗](cleaning.md)一致：Ribbon 的「DataFrame」上下文标签页、「Operate」/ 操作 分类下的「Data Filtering」/ 数据过滤 面板。

## 面板里的五个按钮

| 按钮 | 对话框标题 | 对数据的改动 |
|---|---|---|
| 「Eval Data」/ 数值计算 | 「Eval Data」/ 数值计算 | 新增一列或替换某一列的值，行数不变 |
| 「Query Data」/ 条件筛选 | 「Query Data」/ 条件筛选 | 保留符合条件的行，其余删除 |
| 「Filter by Column」/ 列数据过滤 | 「Data Filter」/ 数据过滤 | 只保留某一列上落在区间内的行 |
| 「Sort」/ 数据排序 | 「Sort」/ 数据排序 | 按一列重排行的顺序，行数和取值都不变 |
| 「Data Retrieval」/ 数据检索 | 「Dataframe Search」/ 数据检索 | 不改数据，把表格视图滚动并选中到匹配的单元格 |

「Eval Data」按钮在中文界面上显示的是「列运算」，「Data Retrieval」显示的是「数据检索」，其余按钮的中文文字与上表一致。

四个改动数据的动作都会压入数据操作面板的撤销栈，撤销和重做按钮在窗口左上角的快速访问工具栏，快捷键是 `Ctrl+Z` 和 `Ctrl+Y`。取消对话框不会改动数据。

筛选和排序不重排行号：行号跟着原来的行一起走，被删掉的行留下的号不再出现。行号因此可以作为原始行位置的标记，回溯某一行的来历很方便。

四个改动数据的动作可以连着用。常见的组合是先算后筛：用数值计算得出派生的列，再用条件筛选把关注的行挑出来。也可以先筛后算：先把范围缩小到有代表性的子集，再在这个子集上计算派生指标，减少无谓的计算量。排序通常放在最后一步，前面的动作都会改变行的顺序。

## Eval Data / 数值计算

用一段表达式在表上做计算，结果写进一列。对话框标题是「Eval Data」/ 数值计算，窗口里有三个部分：上方的「The string to evaluate」/ 要计算的字符串 标签下面是表达式输入框，中间的「Explanation：」/ 说明 下面是这个功能的用法说明，最下面是「OK」和「Cancel」。表达式为空或点「Cancel」时不做任何改动。

计算交给 pandas 的 `eval` 完成。它把列名当成变量来用，写法接近普通算式：列与列之间可以直接做加减乘除。表达式必须带赋值，用「新列名 = 计算式」的形式给出；只写一个计算式而不写赋值时，pandas 会拒绝执行，提示不能在原地计算，表格保持原样。

下面这组表达式分别演示新增列、比较取值和调用数学函数。`total` 是不存在的列名，赋值给它就在表尾新增一列；`score`、`value` 是表里已有的列名。

```python
total = price * qty
flag = score >= 60
square_root = sqrt(value)
```

第一行把单价和数量相乘，得到一个新的列 `total`，每一行的取值都是同一行两个单元格的乘积。第二行是列与常数比较，`flag` 这一列的取值是 True 或 False，True 表示这一行的分数不低于 60。第三行调用 `sqrt()` 函数对 `value` 列开平方，函数名直接写在算式里，同类函数还有 `abs()`、`log()`、`exp()`、`sin()`、`cos()` 等。三个表达式的行数都与原表相同。表达式出错时命令不会执行，表保持原样，报错内容写在日志文件里，界面上不弹提示。

方括号、运算符和关键字：

- 加减乘除用 `+`、`-`、`*`、`/`，乘方用 `**`，取余用 `%`。
- 比较用 `==`、`!=`、`>`、`<`、`>=`、`<=`，判断相等要写两个等号。
- 多个条件用 `and`、`or`、`not` 连接，比如 `grade = score >= 60 and score < 90`，得到的是布尔列。

### 可以调用的函数

数学函数写在算式里，函数名后面跟一对括号。下面这些函数名可以直接使用：

| 函数 | 作用 |
|---|---|
| `abs()` | 绝对值 |
| `sqrt()` | 平方根 |
| `log()`、`log1p()` | 自然对数；`log1p()` 计算 log(1+x)，接受 0 |
| `exp()` | e 的幂 |
| `sin()`、`cos()`、`tan()` | 三角函数，输入按弧度 |
| `sinh()`、`cosh()`、`tanh()` | 双曲函数 |
| `arctan()` | 反正切 |
| `floor()`、`ceil()` | 向下、向上取整 |

`trunc()`、`sign()`、`maximum()`、`minimum()`、`clip()` 这几个名字在当前的 pandas 版本里不在支持列表内，写进去会报函数不受支持。需要取整和裁剪时改用其它办法：取整用 `floor()` 或 `ceil()`，裁剪用条件筛选把范围外的行去掉，或者在[清洗](cleaning.md)里按边界值处理异常值。

### 含空格或特殊字符的列名

列名里有空格、括号、连字符这类字符，或者以数字开头时，在表达式里要用反引号（键盘左上角、数字 1 左边的那个符号）把列名裹起来，写成 `` `列名` ``。表达式输入框下方的提示文字给出的例子是：一个名为「Area (cm^2)」的列，在表达式里写成 `` `Area (cm^2)` ``。

列名恰好是 Python 关键字（`list`、`for`、`import` 之类）时，用反引号也能正常引用。下面两个例子分别引用带括号的列名和带空格的列名。

```python
density = value / `Area (cm^2)`
gap = `end time` - `start time`
```

第一行用 `value` 列除以 `` `Area (cm^2)` `` 列，得到密度一列；反引号只包住名字本身，不参与运算。第二行同理，两个用反引号引用的时间列相减，得到时长一列。写成 `Area (cm^2)` 而不加反引号时，括号会被当成算式的一部分，执行失败。

在下面这张六行小表上执行 `ratio = reading / temp`，新列 `ratio` 的取值依次是 0.714、1.255、0.410、1.519、空、1.061：

| 行号 | temp | reading | ratio |
|---|---|---|---|
| 1 | 21.0 | 15 | 0.714 |
| 2 | 25.5 | 32 | 1.255 |
| 3 | 19.5 | 8 | 0.410 |
| 4 | 27.0 | 41 | 1.519 |
| 5 | 22.0 | 空 | 空 |
| 6 | 24.5 | 26 | 1.061 |

第 5 行的输入里有空值，算出来的结果同样是空，空值不会按 0 参与计算。这一列和原表行数一致，逐行一一对应。表里的「空」表示表格中的空单元格，下同。

### 结果出现在哪里

新列加在表的最后一列，表格视图立刻刷新，列名就是赋值号左边的名字。把已有列名写在赋值号左边等于替换这一列，取值全部按新算式重算。

覆盖已有列时新结果的数据类型要与原列相容：往整数列里写小数结果会失败，提示不能把算式的结果赋给目标列。需要小数时就先把这一列的类型改成浮点（「Type」/ 类型 面板），或者把结果写到新的列名上。

取余和乘方在派生指标里也常用。下面两个表达式分别对数量取余数、对读数做平方，说明运算符可以直接写在算式中间。

```python
remainder = qty % 2
squared = value ** 2
```

第一行求出每个数量除以 2 的余数，用来判断奇偶；第二行把读数平方，用来构造二次项。两个表达式都新增一列，`remainder` 只取 0 和 1，`squared` 的取值范围随原值放大。整数列做除法或取余时结果符合预期，混合了小数时得到的列会是浮点列。

### 使用场合

派生指标是这里最常见的用法：单价乘数量得到金额，长度除以宽度得到长宽比，两个时间点相减得到时长，把浓度按稀释倍数换算成原始浓度。条件赋值也有用：用比较得到一列 0/1 或 True/False 标记，后续按这一列做筛选或分组。

对话框自带的说明里给出了一种 `where(条件, x, y)` 的条件赋值写法，当前常见的 pandas 版本不接受这个函数名，执行会报错。需要按条件取值时，用比较运算得到布尔列，再用[条件筛选](#query-data--条件筛选)把两类行分开，或者在工作流的 Python 节点里处理。

表达式在整列上生效，没有逐行条件判断的写法；要按不同条件给不同的值，分几次执行，每次把关心的行筛出来再做计算。

## Query Data / 条件筛选

写一段条件，把满足条件的行留下来，其余删掉。对话框标题是「Query Data」/ 条件筛选，字段与数值计算对话框相同：上方是「The query string to evaluate」/ 要计算的查询字符串，下方是「Explanation：」/ 说明，按钮是「OK」和「Cancel」。

计算交给 pandas 的 `query`。条件写成一个整体为真或假的表达式，满足条件的行构成结果表。

### 运算符

| 写法 | 含义 |
|---|---|
| `==`、`!=` | 等于、不等于 |
| `>`、`<`、`>=`、`<=` | 大于、小于、大于等于、小于等于 |
| `and`、`&` | 两个条件同时成立 |
| `or`、`\|` | 两个条件至少一个成立 |
| `not` | 条件取反 |
| `in`、`not in` | 取值属于、不属于给出的列表 |
| `.between(a, b)` | 取值落在 a 和 b 之间，两端都算在内 |
| `.str.startswith("A")` | 文本列以某个片段开头 |
| `.str.contains("John")` | 文本列包含某个片段 |

### 表达式示例

下面这组条件覆盖了数值范围、列间比较和集合判断。`A`、`B` 是数值列，`city` 是文本列。

```python
A > 2 and B < 8
A > B
city in ("S", "C")
(A * 3 > 1) or ((B + 12.5) < 5)
```

第一行要求两列各自满足一个范围，两个条件同时成立的行才留下。第二行比较同一行的两列，留下 A 大于 B 的行。第三行判断文本列的取值是否在给出的两个值里，写法是列名加 `in` 加一对括号包起来的取值列表。第四行的括号把两个子条件分开，`or` 表示满足其中之一即可留下，这里的 `A * 3` 和 `B + 12.5` 说明条件里可以先做算术再比较。

### 区间和文本条件

区间判断可以写成 `between`，文本列可以用字符串方法按前缀、包含关系筛选。`A.between(2, 8)` 与 `A >= 2 and A <= 8` 等价，包含两端的 2 和 8。`Ticket.str.startswith("A")` 留下文本列以大写 A 开头的行，把 `startswith` 换成 `contains` 就是包含某个片段，换成 `endswith` 就是结尾匹配。

```python
A.between(2, 8)
Ticket.str.startswith("A")
```

第一行留下 A 列取值落在 2 到 8 之间的行，两端都算在内；第二行只做前缀匹配，留下文本列以大写 A 开头的行，`str` 表示接下来用的是文本列的方法。

文本比较区分大小写：取值写成大写 S 时匹配不到小写 s。要忽略大小写，先把这一列转成统一的大小写再比较，`str.lower()` 把取值转成小写，`str.contains()` 的取值可以用方括号列出一组字符。下面两行分别用这两种写法匹配大写 S 和小写 s。

```python
city.str.lower() == "s"
city.str.contains("[sS]")
```

第一行把每个取值转成小写之后与 `"s"` 比较，大写小写都能匹配上。第二行把 `s` 和 `S` 放进方括号作为一组候选字符，`contains` 判断取值里是否出现其中之一。字符数较多时更省事的写法是统一转换成小写再比较。

### 反引号规则

列名含空格、括号、连字符或由数字开头时，用反引号把列名包起来，比如列名「Embarked On」在条件里写成 `` `Embarked On` ``。做字符串比较时，比较值本身用一对引号（单引号或双引号都可以），列名用反引号，两者不要混在一起。

```python
`Embarked On` == "S"
`Embarked On` in ("S", "C")
```

第一行留下登船港为 S 的行，反引号包住的是列名，引号包住的是取值。第二行的取值列表里有多个文本值，此时保留列名外的反引号，比较值按文本写法加引号。列名打成 `Embarked On` 而不加反引号时，空格会把名字切成两截，报出错找不到列。

### 执行结果

执行后行数减少，保留下来的行保持原来的行号和顺序，被删掉的行整行消失。撤销可以一次恢复到筛选前。条件写错时命令不会执行，表格保持原样，报错内容写在日志文件里，界面上不弹提示。

### 在一张小表上看效果

下面六行数据带着一个空值，表里的「空」表示表格中的空单元格：

| 行号 | batch | temp | reading |
|---|---|---|---|
| 1 | A | 21.0 | 15 |
| 2 | B | 25.5 | 32 |
| 3 | A | 19.5 | 8 |
| 4 | C | 27.0 | 41 |
| 5 | B | 22.0 | 空 |
| 6 | A | 24.5 | 26 |

条件 `temp >= 22 and reading < 35` 留下第 2 行和第 6 行：第 1 行的温度不到 22，第 4 行的读数超过 35，第 5 行的读数有温度条件成立但读数是空，空值与数字比较的结果为假，这一行同样被删掉。条件 `batch in ("A", "C")` 留下第 1、3、4、6 行，按文本取值判断。空值行的去留要在写条件时想清楚，需要保留它们时把条件写成「读数为空或读数小于 35」的组合。

### 想留下被删掉的行

筛选只保留符合条件的行，不符合的整行消失。同一张表里没有同时保留两部分的开关：想拿到被排除的部分，可以先把筛选前的数据导出成文件（数据标签页的导出动作），再对表做筛选；或者在工作流里让同一份输入分叉，两支各自筛选之后分别落到数据管理面板（见[数据分析节点手册](../workflow/nodes-analysis.md)）。撤销能拿回被删的行，但撤销的作用是回到上一步，两部分不会同时存在。

### 使用场合

分析前把范围定下来：只看某一段时间、某几个批号、某个量程内的记录。也常用来切出两个子集做对照，比如按文本列取某个类别的全部行，再把类别条件换成 `!=` 取另一部分。条件的写法与[数值计算](#eval-data--数值计算)里赋值号右边的内容一致，两边可以互相搬运。

## Filter by Column / 列数据过滤

在一个下拉框里选一列，再填上下界，只保留这一列上落在两个边界之间的行。对话框标题是「Data Filter」/ 数据过滤，界面分成两行：第一行是「Data」/ 数据 标签加列名下拉框，第二行是「Range」/ 范围 标签加下限输入框、短横线和上限输入框，底部是「OK」和「Cancel」。

表格里事先选中某一列时，打开对话框会自动选中这一列，省去再挑一次。

| 字段 | 填法 | 说明 |
|---|---|---|
| 「Data」/ 数据 | 下拉选一列 | 只有数值列能比较，判断依据的这一列 |
| 「Range」/ 范围 左侧 | 小数 | 下限，值小于它的行被删掉 |
| 「Range」/ 范围 右侧 | 小数 | 上限，值大于它的行同样被删掉 |

判断规则是下限小于等于取值、取值小于等于上限，两端都算在范围内。上下限的填法决定实际效果：

- 两个都填，保留介于两者之间的行。
- 只填下限，只保留不小于下限的行，相当于不设上限。
- 只填上限，只保留不大于上限的行，相当于不设下限。
- 两个都留空，操作无法执行，不会改动表格。

输入框里填 0 等于不限制这一侧，0.0 是「不设边界」的标记，因此没法用 0 作为真正的边界值。输入的内容不是数字时，消息面板给出当前位置无法转换为浮点数的提示。

下拉框里选到文本列时无法比较，判断大小要拿数值和数值比，选到文本列会报类型错误，表格不变，报错内容写在日志文件里。动手之前可以在表格里看一眼列名旁边的类型标记，文本列的取值接近数字（编号、年份）时先改列类型，改类型的入口在「Type」/ 类型 面板。

执行后不符合条件的行整行删除，行号保持原样，撤销可以恢复。

用同一张六行数据演示：在「Data」里选 reading 列，下限填 15，上限填 32，留下的行号是 1、2、6，对应的读数是 15、32、26，第 3 行的 8 和第 4 行的 41 落在区间外被删掉，第 5 行的读数是空，空值与区间比较的结果为假，同样被删掉。把上限留空，第 4 行的 41 就会被保留。

什么时候用：和「Query Data」相比，这个动作不需要写表达式，勾一下列、填两个数就能完成一次范围裁剪，适合「只要读数在 20 到 30 之间的记录」这类一次性的窄化。规则比较多、要组合几个条件时用条件筛选更合适，范围条件写起来也更直观。

## Sort / 数据排序

按一列的值把行重新排队。对话框标题是「Sort」/ 数据排序，界面上并排两个下拉框：左边一个列出表里全部的列名，右边一个是排序方式。表格里事先选中某一列时，左边这个下拉框会预选这一列。

排序方式有两项：「Ascending」/ 升序 和「Descending」/ 降序。升序把最小的值排在最前面，降序把最大的排在最前面。数值列按大小排，文本列按字符顺序排，日期列按时间先后排。

空值排在末尾：升序时空值位于所有数值之后，降序时同样在最后，不会因为排在开头而挡住正常数据。

排序是整行一起移动，同一行的各列取值保持配对，行号跟随原来的行。按一列排序之后，这一列的值从小到大或从大到小排列，其它列的顺序随之改变。执行后数据操作面板的撤销栈里出现「Data Sort」/ 数据排序 一项，撤销恢复排序前的顺序。表格里事先选中列只用于预选下拉框，排序不会只作用于选中的列。

同一张六行数据按 reading 列升序排列后，行号顺序变成 3、1、6、2、4、5，读数为 8、15、26、32、41，最后一行读数空缺，排在末尾；降序排列得到 4、2、6、1、3、5，空值那一行同样在末尾。升序和降序下空值都固定在最后，不会混进数值中间。

什么时候用：找最大值、最小值所在的行时，先按这一列降序或升序排一次，靠前的几行就是要注意的记录；按时间列排序把乱序导入的数据恢复成时间顺序；导出前排序，让文件里的行按某一列有序排列，便于比对。多个排序关键字（先按批次、同批次内再按时间）不支持一次完成，只能每次按一列排。先按次要关键字、再按主要关键字排两遍时，主要关键字取值相同的行不保证保留第一次的顺序。

## Data Retrieval / 数据检索

在表格视图里查找一个数值，把视图滚动到它所在的位置并选中该单元格。对话框标题是「Dataframe Search」/ 数据检索，界面是一个标着「Seacrch」的分组框（原文如此），里面有「Find item:」/ 查找条目 标签和输入框，下面一行是「From Begin」/ 从开头 按钮和一处结果显示区，底部是「Next」/ 下一个 和「Close」/ 关闭。

用法如下：

1. 在「Find item:」输入框里填要查找的数值。
2. 点「Next」，表格视图滚动到第一个匹配的单元格并选中它，结果区显示「Found at column 列名, line 行名」/「在第…行、第…列找到」，两个占位符分别代入命中的行名和列名。
3. 继续点「Next」会依次跳到后面的匹配位置，走到最后一个之后回到第一个。
4. 没有匹配时结果区显示「Cannot find item」/ 无法找到条目。
5. 「From Begin」按钮在当前版本里没有绑定动作；想从头重新查找，把输入框里的内容改一下再点「Next」即可，内容变化会触发重新匹配。
6. 点「Close」关闭对话框，表格视图停在当前位置。

查找按数值匹配，输入的内容会被当作数字处理。输入非数字的内容会按 0 处理，想找文本内容时改用条件筛选或者列标题右键菜单里的其他工具。查找范围是整张表的全部单元格，命中的位置按行列顺序排列，从第一行第一列开始。

这个动作不改数据，不会进入撤销栈，也不设置工程的未保存标记。

在上面那张六行小表里查找 32，视图会选中第 2 行 reading 那一格，结果区显示命中的列名和行号。表里如果只有一个 32，连续点「Next」会在同一格上反复选中；换成查找 26，命中的是第 6 行。查找范围覆盖全部列，同一行里其它列出现同样的数值时也会被命中，按行列顺序逐个经过。

什么时候用：核对某个读数在表里的位置，从一个已知数值反查它属于哪一行；在长表里找上次记下的数值；排查重复记录时确认某个值出现了几次。需要按条件列出全部匹配行时，用条件筛选；只是想把视图移过去看上下文，用这里。

## 四个动作怎么选

| 想做的事 | 用哪个 | 结果 |
|---|---|---|
| 由已有的列算出新的一列 | 数值计算 | 表增一列或某一列被重算，行数不变 |
| 按一段条件留下部分行 | 条件筛选 | 行数减少，保留的行原样 |
| 在某一列上按上下界裁剪 | 列数据过滤 | 行数减少，不用写表达式 |
| 调整行的先后顺序 | 数据排序 | 行数不变，顺序改变 |
| 在表里定位一个数值 | 数据检索 | 数据不变，只移动视图 |

数值计算和条件筛选的区别落在结果上：前者改变的是列，行数不动，算式写在赋值号右边；后者改变的是行，满足条件的留下，条件本身就是数值计算里赋值号右边的那种表达式。

## 常见问题

点了按钮没有反应。确认数据操作面板里有打开的数据表，并注意按钮作用于当前标签页的那张表。同时打开多张表时容易改错表，先确认标签页。

表达式执行失败。检查三处：是否带了赋值（数值计算必须写「新列名 = 计算式」）；往整数列写小数结果时先改列类型；含空格或特殊字符的列名加反引号。

条件筛选之后一条数据都没有。条件里列名拼写与表里的列名要完全一致，文本取值要加引号，数值和文本不要混用比较。

筛选或排序之后行的顺序和行号对不上。两个动作都不重排行号，行号记录的是这一行在操作前的位置，数据本身的行序在筛选后保持原样，排序后按排序键排列。

查找数字找不到。搜索按数值匹配，跨列查找时命中的可能是别的列里同样的数；确认要找的值在表里是数字而不是文本，文本形式的数字不会被匹配。

操作做错了。按 `Ctrl+Z` 撤销，数值计算、条件筛选、列数据过滤、数据排序都可以恢复；数据检索不改数据，不需要撤销。

算出来的列不想要了。撤销可以退掉刚做的计算；已经确认要留下的表里想去掉一列，用列标题右键菜单里的删除列，或者在数据清洗之前先删列。计算出来又长期用不上的一列留在表里不影响其它功能，删除与否按最终数据的样子决定。

条件的写法有什么限制。条件只做比较和布尔组合，不做赋值；同一段文字在数值计算里写在赋值号右边、在条件筛选里直接填进输入框，两处可以互相搬运。写条件前先在表里确认列名的拼写和类型，拼错列名时命令不会执行。
