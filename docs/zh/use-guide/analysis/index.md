# 数据分析

这一部分讲不开工作流、直接对着打开的数据表做的操作。数据表打开之后，Ribbon 上会多出一个「DataFrame / 数据表」上下文标签页，这些功能都长在那个标签页的面板上。

改动直接作用在当前打开的数据集上，可以撤销。要保留原始数据，改之前先把数据集另存一份，或者先用工作流把处理步骤固定下来。

## 章节目录

- [数据清洗](cleaning.md)：补缺失值、去重、插值、异常值处理、偏态转换，共七个命令。
- [筛选、计算与排序](query.md)：条件筛选、表达式计算、按列范围过滤、排序、查找，共五个命令。
- [描述统计与透视表](statistics.md)：一次点击得到数据的分布特征，以及按分类汇总。
- [统计绘图](stats-plots.md)：九种按列自动成图的图表，从直方图到回归图。

## 建议的读法

数据脏的时候先读[数据清洗](cleaning.md)，那一章解释了每个统计量的含义，不只说怎么点。

要挑出行或者算新列，读[筛选、计算与排序](query.md)。那一章开头有一张对照表，按目的选命令。

想看数据长什么样、或者要往报告里放一张分布图，读[统计绘图](stats-plots.md)。

## 这一部分没有的功能

软件不含假设检验、方差分析、相关矩阵、聚类和主成分分析。想要这些分析需要自己在脚本工作区里写 Python，见[脚本工作区](../script/workspace.md)。

信号处理类的辅助函数（滤波、峰值分析、小波变换等）在代码里存在，但界面上没有入口，只能从脚本调用。
