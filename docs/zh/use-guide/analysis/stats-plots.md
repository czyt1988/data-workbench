# 统计绘图

统计绘图面板上有九个按钮，点一个就得到一类常见的统计图：直方图、核密度、箱线图、热力图、散点图、柱状图、回归图、累积分布。每个按钮弹出的设置窗口里只需选列、填几个参数，图上要用的数字由软件内嵌的 Python 环境算好，图形由软件自己绘制，整个过程不需要写 Python。

九种图都画进当前的绘图窗口。同一张图可以反复生成，换一个参数再点一次「OK」，新的图表就叠在同一个坐标系里，便于对照。

## 从哪里进入

统计绘图在 Ribbon 的「Figure」/ 绘图 分类下，面板标题是「Stats Plot」/ 统计绘图。九个按钮是：

| 按钮 | 提示气泡 | 设置窗口标题 |
|---|---|---|
| 「Histplot」/ 直方图 | 直方图，可叠加核密度曲线 | 「Stats Histplot Settings」/ 统计直方图设置 |
| 「KDE 1D」/ 一维核密度 | 一维核密度图 | 「Stats KDE 1D Settings」/ 统计 KDE 一维设置 |
| 「KDE 2D」/ 二维核密度 | 二维核密度图 | 「Stats KDE 2D Settings」/ 统计 KDE 二维设置 |
| 「Boxplot」/ 箱线图 | 统计箱线图 | 「Stats Boxplot Settings」/ 统计箱线图设置 |
| 「Heatmap」/ 热力图 | 热力图 | 「Stats Heatmap Settings」/ 统计热力图设置 |
| 「Scatter」/ 散点图 | 统计散点图 | 「Stats Scatterplot Settings」/ 统计散点图设置 |
| 「Barplot」/ 柱状图 | 统计柱状图 | 「Barplot Settings」/ 柱状图设置 |
| 「Regplot」/ 回归图 | 回归图，含置信区间 | 「Regplot Settings」/ 回归图设置 |
| 「ECDF」/ 累积分布 | 经验累积分布图 | 「ECDF Plot Settings」/ ECDF 图设置 |

面板上的按钮分两档大小：直方图、一维核密度、二维核密度三个占大按钮，箱线图、热力图、散点图、柱状图、回归图、累积分布六个占小按钮，鼠标停上去会显示上表里的提示气泡，括号里就是提示的原文。

## 点击之后发生什么

点任意一个按钮，动作分三步：

1. 数据管理面板被抬到前面，图上要用哪份数据一目了然。
2. 弹出引导对话框，窗口标题是「Statistics Chart Guide」/ 统计图表向导。左侧是九个图表类型的列表，右侧是选中类型的设置页，两部分用堆叠页面切换，点左侧的项就换右侧的设置。底部是「OK」和「Cancel」。
3. 点「OK」之后，设置页检查有没有选数据，通过就把图画进当前坐标系。

当前没有任何绘图窗口时，软件会先建一个绘图和一个坐标系，再把图画进去，因此不必事先手工新建绘图。

对话框一次只画一个图表。想在同一个坐标系里叠第二张图，保持对话框开着，改完参数再点一次「OK」。

## 数字从哪里来

九个图表用到的统计量都在软件内嵌的 Python 环境里算出来：直方图的分箱计数、核密度曲线、箱线图的五数概括、透视矩阵、分类汇总、多项式拟合、自举置信区间、累积分布，算完的结果是一批数字，交回软件绘制。用了 pandas、numpy、scipy 这几个库，绘图本身由软件的绘图组件完成，matplotlib 只在二维核密度里被借用来提取等高线的顶点。

对使用者来说，这套分工的可见结果是两点。图表里的数字都可以用[描述统计](statistics.md)复核，比如箱线图的中位数就是这个列统计量里的 50%；图上不会出现 Python 窗口，也不需要提前装什么库，软件启动时会自己找到解释器。找不到 Python 解释器时，这些按钮点下去会在消息面板里给出提示，处理办法见[常见故障](../reference/troubleshooting.md)。

## 图表怎么选

九个图表按要回答的问题分成几类。下面的表按问题列，找到问题对应的行即可。

| 想回答的问题 | 用哪个图 | 需要什么列 |
|---|---|---|
| 这一列数值大概怎么分布 | 直方图 | 一列数值 |
| 这一列数值的分布平滑形状 | 一维核密度 | 一列数值 |
| 有几个峰、是不是混了两类样本 | 直方图或一维核密度，配合分组列 | 一列数值加一列分组 |
| 两个数值一起看时集中在哪 | 二维核密度 | 两列数值 |
| 几组数据的中位数和分散程度谁高谁低 | 箱线图 | 一列或多列数值，可选分组 |
| 两个数值之间有没有关系 | 散点图，需要拟合时用回归图 | 两列数值 |
| 关系的形状和这条关系有多确定 | 回归图 | 两列数值 |
| 各类别的汇总值谁高谁低 | 柱状图 | 一列分类，可选一列数值 |
| 两类交叉之后哪些组合高、哪些组合低 | 热力图 | 两列分类，可选一列数值 |
| 有多少比例的样本不超过某个值 | 累积分布 | 一列数值 |
| 两组的累积分布差多少 | 累积分布加分组列 | 一列数值加一列分组 |

形状类的问题（分布、峰、尾）用直方图、一维核密度、箱线图、累积分布；关系类的问题（两个量怎么一起变）用散点图、回归图、二维核密度；比较类的问题（按类别比高低）用柱状图、箱线图、热力图。

同一份数据可以连着画几张图对照。先画直方图看形状，发现两个峰再画箱线图看两组的差异，最后用累积分布读出两组各有多少比例超过某个阈值，整个过程都在同一份数据、同一个坐标系上完成。

图表类型选错不必撤销重建。九种图共用同一个引导对话框，开着对话框点左侧列表换一个类型，填好参数再点「OK」即可；已经画上去的图元留在坐标系里，不满意的删掉就行。

## 选数据列的方式

九种图的设置页里，选列的地方是一块列表加两个小按钮：

- 列表显示当前已经选好的列。
- 加号按钮「Add series」/ 添加序列，点开之后引导对话框暂时隐藏，屏幕上浮出一个「Select Series」/ 选择序列 的小窗口。
- 减号按钮「Remove selected series」/ 移除所选序列，把列表里当前选中的一项去掉。

浮出来的小窗口上有一行输入框和一行提示，用法是：

1. 数据管理面板里展开数据集，点其中的某一列；或者点开的数据表里，点某一列的表头。输入框里会自动填上 `数据集名['列名']` 这样的表达式。
2. 确认表达式没错，点右侧的勾按钮「Return to add chart」/ 回到添加绘图，这一列就加进了设置页的列表，引导对话框重新出现。
3. 表达式解析不了时弹出警告，提示期望的格式是 `data['column']`，改好再点。

也可以直接在输入框里手打表达式，格式与上面一致，单引号和双引号都能用。

没有选列就点「OK」时，引导对话框不会关闭，消息面板里给出提示，要求先选择数据列。热力图和二维核密度需要两个方向的列，缺一个也会给同类提示。

## Hue 是什么

九种图里有六种的设置页带一个「Hue (optional grouping column)」/ 分组列（可选）分组，分组框本身是一个可以勾选的标题：不勾选表示不用分组，勾选之后再选一列，这一列就是分组依据。直方图、一维核密度、箱线图、散点图、柱状图、累积分布六种带这个分组，其余三种（二维核密度、热力图、回归图）没有分组列这一项。

分组列的作用是把数据按它的取值切成几组，每组各画一套图形。比如数据里有一列「处理方式」，取值是「对照」「处理A」「处理B」，把它选作分组列之后，直方图会画出三个直方图，核密度画出三条曲线，散点图画出三组颜色不同的点，箱线图在每个数据列里按分组排开箱体。

分组的计算在整份数据上一次完成，每组共用同一套坐标尺度：直方图的所有分组共用一套分箱边界，一维核密度的所有分组共用同一段横轴范围，散点图的两个分组共用同一套横纵轴。各组的图形因此可以并排比较，不会因为各自取范围而显得一样高。

分组列取值的个数就是组数，取值太多（比如每行都不同）时图会变成一堆看不清的碎块，选分组列之前先看看它的取值个数，通常控制在十个以内。

分组列必须与数据列在同一份数据集里。

## 关于外观选项

设置页里有一部分选项只影响外观：标记大小与形状、透明度、线宽、柱宽和箱宽、方向（横向或纵向）、是否显示图例、是否标注数值、是否填充等高线、热力图的 vmin 与 vmax 等。这些选项目前只记录在参数里，图上的外观由软件的绘图组件统一决定，改动不会反映到图上。

图上的外观可以在绘图窗口里调整：图形由若干可以单独选中的图元组成，柱形、曲线、散点、置信带各是一件图元，鼠标点选之后在属性面板里改颜色、线宽、符号等，具体操作见[二维图表设置](../chart/settings-2d.md)。

## Histplot / 直方图

把一列数值的取值范围切成若干个区间，数每个区间里有多少个观测，用柱子的高低表示。它回答的问题是「这些数集中在哪一段、分布有没有第二个峰、有没有拖得很长的尾巴」。

直方图适合第一次拿到一列数值时使用：量级范围、集中位置、离群点都能从形状上看出来。分组之后还能对比几组数据的分布是否错开。

### 参数

「Data」/ 数据 组里选一列数值。下面的参数按对话框的分组排列：分箱参数在「Bins」/ 分箱 组，统计量与叠加选项在「Statistics」/ 数据统计 组。

| 参数 | 类型 | 默认 | 范围 | 说明 |
|---|---|---|---|---|
| 「Number of bins」/ 分箱数量 | 整数 | 10 | 1 到 10000 | 把取值范围切成几段 |
| 「Bin width (0 = auto)」/ 分箱宽度（0 = 自动） | 小数 | 0 | 0 到 1000000 | 每段的宽度，大于 0 时取代分箱数量 |
| 「Bin range min (blank = auto)」/ 分箱范围下限（留空 = 自动） | 小数 | 0 | −1000000 到 1000000 | 分箱的起点 |
| 「Bin range max (blank = auto)」/ 分箱范围上限（留空 = 自动） | 小数 | 0 | −1000000 到 1000000 | 分箱的终点 |
| 「Y-axis statistic」/ Y 轴统计量 | 下拉 | count | 见下 | 柱子的高度用什么量 |
| 「Overlay KDE curve」/ 叠加 KDE 曲线 | 复选 | 不勾选 | | 在柱形上再画一条密度曲线 |
| 「KDE bandwidth」/ KDE 带宽 | 下拉 | scott | scott、silverman | 叠加曲线的平滑程度 |
| 「Cumulative」/ 累积 | 复选 | 不勾选 | | 柱子表示累计到该段的数量 |
| 「Fill bars」/ 填充柱形 | 复选 | 勾选 | | 外观项 |

分箱数量决定柱子的根数：同一列数据分成 5 段时形状很粗，分成 100 段时形状细碎，同一批数据换一个分箱数量可能看出不同的结论，先看默认的 10 段，再调整两三档对比。分箱宽度填成大于 0 的数时，软件按宽度均匀切分，分箱数量那一项就不再起作用，适合不同图表之间统一分组尺度。

「分箱范围下限」和「分箱范围上限」两个值都保持 0 时按数据的实际范围自动取；只要其中一个改成非 0 的数，两个值就一起生效，此时另一个填 0 会被当成真实的 0 参与计算。要在图表上留出空白边界、或者让两张图共用同一段横轴时用这两个值。

### Y 轴统计量

五个选项改变柱子的高度代表的含义：

- 「count」/ 计数：每段里的观测个数，默认选项，读数最直接。
- 「density」/ 密度：每段内的概率密度，柱子的面积之和等于 1；横轴单位变化时形状不变，最容易与核密度曲线放在一起看。
- 「frequency」/ 频率：每段的个数除以总观测数。
- 「probability」/ 概率：与频率相同，软件里这两项算出的是同一个数，都是每段个数除以总观测数，保留两项是为了照顾不同的表述习惯。
- 「percent」/ 百分比：频率乘 100，柱子高度直接读成百分之多少。

「累积」勾上之后柱子变成累计的数量，最后一根柱子的高度等于所有观测的个数，横轴某点处的柱高表示「取值不超过这一点的有多少个」。

### 叠加核密度曲线

勾上「Overlay KDE curve」之后，软件在同一列上再算一条核密度曲线画在柱形上。曲线的纵坐标是密度值（曲线下面积等于 1），与「count」或「percent」的柱子量级不同，叠加时曲线会显得很矮；把 Y 轴统计量改成「density」，两者就落在同一尺度上。

「KDE 带宽」控制曲线的平滑程度，两种方法的区别见[一维核密度](#kde-1d)一节。叠加曲线要求这一列至少有 2 个有效取值。

### 分组

勾选「Hue」并选好分组列之后，每个分组各画一套柱子。所有分组共用同一套分箱边界，边界由整份数据算出，因此各组柱子落在相同的位置上，可以直接比较哪一组往左偏、哪一组的尾巴更长。

### 分布形状怎么读

柱子排出来的形状有几种典型的样子，各自的含义不同。

一个高耸的峰、两侧平缓下降，说明大多数观测集中在中间，这是最常见的样子。峰偏在左边、右边拖一条长尾，说明这一列里有少数很大的值（浓度、金额、计数常见），右边那条尾巴上可能藏着异常值，用[箱线图](#boxplot)再确认一遍。峰偏在右边、左边拖长尾，情况相反，少数很小的值拉长了左侧。

出现两个峰时，说明这一列里混了两类观测：温度记录里混了冬夏两季、产量记录里混了两台设备，都属于这种情况。这时把可能的分组列选进「Hue」再看，两个峰往往会分开到两组里，每组各是一个单峰。

分箱数量太少看不出双峰，太多会把随机起伏放大成一堆小峰。同一列数据用 10、20、30 三种分箱数量各画一次，三次都出现的峰是真实的，只在某一次出现的小起伏来自分箱方式。

### 例子

一批样品的水分含量列，先用默认设置画一张直方图看集中在哪一段，再把分箱数量调到 30 看有没有第二个峰；发现有两组样品时，把「批次」选作分组列，两组的分布并排比较。

## KDE 1D / 一维核密度

把一列数值的分布画成一条平滑曲线。做法是在每个数据点的位置上放一个对称的小鼓包，把所有的鼓包叠加起来再连成线，得到的就是核密度曲线。它与直方图说的是同一件事，形状不受分箱边界影响。

直方图的形状会随分箱数量和起点变化，核密度曲线更平滑，适合用来看分布的整体形状，也可以和直方图叠在一起互相印证。

### 参数

下面的参数按对话框的分组排列：带宽三项目在「Bandwidth」/ 带宽 组，填充与累积在「Options」/ 选项 组，两个阈值取值在「Threshold fill (requires fill)」/ 阈值填充（需启用填充）组。

| 参数 | 类型 | 默认 | 范围 | 说明 |
|---|---|---|---|---|
| 「Bandwidth method」/ 带宽方法 | 下拉 | scott | scott、silverman、custom | 决定鼓包的宽度 |
| 「Custom bandwidth value」/ 自定义带宽值 | 小数 | 0.5 | 0.01 到 10 | 带宽方法选 custom 时使用 |
| 「Grid size (smoothness)」/ 网格大小（平滑度） | 整数 | 200 | 10 到 10000 | 曲线由多少个点连成 |
| 「Fill area under curve」/ 填充曲线下区域 | 复选 | 勾选 | | 曲线与横轴之间的区域着色 |
| 「Shade mode (low alpha)」/ 阴影模式（低透明度） | 复选 | 不勾选 | | 外观项 |
| 「Cumulative distribution」/ 累积分布 | 复选 | 不勾选 | | 曲线变成累积分布曲线 |
| 「Common normalization (hue)」/ 统一归一化（按分组） | 复选 | 勾选 | | 分组归一化选项 |
| 「Fill x <=」/ 填充 x <= | 复选加数值 | 不勾选，值 0 | −1000000 到 1000000 | 阈值填充的下侧取值 |
| 「Fill x >=」/ 填充 x >= | 复选加数值 | 不勾选，值 0 | −1000000 到 1000000 | 阈值填充的上侧取值 |

### 带宽与两种方法

核密度曲线的形状几乎完全由带宽决定。带宽大，鼓包宽，曲线平滑，但数据里真实存在的两个峰会被抹平成一个宽峰；带宽小，鼓包窄，曲线贴近每个数据点，噪声也跟着显出来。默认的 scott 是常用的折中档。

scott 和 silverman 是两条按数据量算带宽的经验规则：两者都用样本量和数据的标准差算出一个比例系数，再乘到数据上。同一列数据用两种方法算出的带宽很接近，silverman 一般略大一点，曲线因此更平滑。两者都不满意时选 custom，把自定义带宽值直接设成一个数，0.5 是默认值，调小看细节、调大看趋势。

「网格大小」决定曲线由多少个点连成，200 个点足够画出平滑的线，调到几十会让曲线显出折线感，调大不会让形状更准，只是画得更细。

「累积分布」把密度曲线积分并归一化到 0 到 1，得到的曲线与累积分布图的含义相同：横轴某点处的纵坐标是不超过这一点的观测占比。

### 分组

勾选分组列之后，每个分组各算一条曲线，所有曲线共用同一段横轴范围，范围由整份数据算出。分组结果里每条曲线各自归一化成面积为 1，因此高度可比的是形状，不是组的大小。

### 需要留意的两项

「阈值填充」组里的两个取值和「阴影模式」当前不参与曲线裁剪与着色，勾选与填数都不会改变图上的曲线。「统一归一化（按分组）」的分组归一化也还没有接到计算上，各分组仍各自归一化。曲线本身、填充、累积分布三项按选项正常生效。

### 和直方图的关系

核密度曲线和直方图描述的是同一列数据的同一件事，直方图的柱子越高、曲线在同一位置的纵坐标也越大。两条路径的差别在画法上：直方图把数值切成段再数个数，形状随分箱方式变化；核密度把每个点摊成一个鼓包再叠加，形状只随带宽变化。

想同时看两件事时，先用直方图看每个区间里的记录数，再勾上「Overlay KDE curve」看分布的整体走向；或者分别画一张直方图、一张核密度图对照。曲线的纵坐标是密度值，柱子的高度是计数时，两条曲线的相对高低没有可比性，只看形状。

### 例子

对照三种处理条件下产量数据的分布，三条曲线叠在一起看峰的位置和宽窄；峰位置接近、宽度差别大，说明几组数据的离散程度不同。

## KDE 2D / 二维核密度

把两列数值放在一起估联合分布，用颜色的深浅表示每一点的密度高低，也就是把一维核密度推广到两个变量。它回答的问题是「这两个量一起看时集中在哪个区域」。

一维核密度看单个变量的形状，二维核密度看两个变量之间的聚集关系：沿对角线拉长说明两者一起变化，分成两团说明样本里混了两种情形。

### 参数

下面的参数按对话框的分组排列：带宽三项目在「Bandwidth」/ 带宽 组，等高线三项目在「Contours」/ 等高线 组，归一化项在「Options」/ 选项 组。

| 参数 | 类型 | 默认 | 范围 | 说明 |
|---|---|---|---|---|
| 「Bandwidth method」/ 带宽方法 | 下拉 | scott | scott、silverman、custom | 两个方向上的平滑程度 |
| 「Custom bandwidth value」/ 自定义带宽值 | 小数 | 0.5 | 0.01 到 10 | 带宽方法选 custom 时使用 |
| 「Grid size (resolution)」/ 网格大小（分辨率） | 整数 | 100 | 10 到 10000 | 每个方向上的网格点数 |
| 「Number of contour levels」/ 等高线层数 | 整数 | 5 | 0 到 50 | 密度分层的数量 |
| 「Threshold (0-1)」/ 阈值（0-1） | 小数 | 0.05 | 0 到 1 | 低于峰值密度这个比例的位置不画 |
| 「Fill contours」/ 填充等高线区域 | 复选 | 不勾选 | | 等高线选项 |
| 「Show heatmap」/ 显示热力图 | 复选 | 勾选 | | 用颜色画密度 |
| 「Common normalization (reserved for hue)」/ 统一归一化（为分组预留） | 复选 | 勾选 | | 标签写明为分组预留 |

X 轴和 Y 轴各选一列，两列都选好才能出图。

### 阈值的作用

阈值是这样用的：先找出网格上密度最高处的值，密度低于它这个比例的位置视为没有内容，不参与着色。默认的 0.05 表示只保留密度达到峰值 5% 以上的区域，落在外围的稀疏区域留白。

阈值是过滤画面噪声的开关。调小到 0，外围的零星点也会被算出颜色，图上出现大片淡色；调大到 0.2，只有密度较高的核心区域保留下来，聚集区看起来更清楚，范围也看起来更小。按想要突出的内容来定，观察整体范围时用小值，观察聚集核心时用大值。

平滑程度由带宽和网格大小共同决定，含义与一维核密度里的同名参数一致。等高线层数用于把密度分层，只在画等高线时起作用。

### 需要留意的两项

热力图始终按密度着色，「显示热力图」开关和「填充等高线区域」目前不影响结果，等高线本身也没有叠加到图上。两个方向的列选好、带宽和阈值定好之后，图上出现的是一张按密度着色的图。

### 颜色怎么读

图上颜色越亮、越靠近色图高端的区域，表示那附近的数据点越密集；颜色平淡的区域，表示落在那里点很少。颜色是相对值，同一张图内比较有意义，两张图之间比较要看数值。

点沿一条斜线聚集，说明两个量一起变：斜着从下到上是同向，从上到下是反向。点分成两团且中间颜色很淡，说明样本里混了两类情形，两团的中心各代表一种状态。点集中成一个大团、四周散落零星的点，说明两种状态之间联系不大，散落的点可能是异常样本。

带宽决定团的轮廓：带宽大，团被抹成一个宽的淡团；带宽小，团的边界清楚，个别点也会单独留下一个小色斑。观察整体聚集位置用较大的带宽，观察聚集的核心范围用小一些的带宽。

### 例子

一列温度、一列浓度，画出来看两天的数据是不是落在同一个区域；图上出现两团，说明两天采集的样品来自不同的状态。

## Boxplot / 箱线图

用五个数概括一列数值的分布：下四分位数、中位数、上四分位数，以及两条须线。箱体是中间一半数据的范围，箱体里的横线是中位数，须线延伸到正常取值的边界，边界之外的点单独画出来。

箱线图适合在一张图上并排比较多列或者多组的分布：中位数谁高谁低、中间一半数据谁更分散、有没有离群点，三眼就能看完。它比直方图省地方，同一张图里放十几个箱也可以。

### 参数

须线倍数与三个外观项都在「Options」/ 选项 组里。

| 参数 | 类型 | 默认 | 范围 | 说明 |
|---|---|---|---|---|
| 「Whisker multiplier (IQR)」/ 须线倍数（IQR） | 小数 | 1.5 | 0 到 10 | 须线延伸到离箱体多少倍四分位距处 |
| 「Box width (0-1)」/ 箱体宽度（0-1） | 小数 | 0.8 | 0.1 到 1 | 外观项 |
| 「Show outliers」/ 显示离群点 | 复选 | 勾选 | | 外观项 |
| 「Show means」/ 显示均值 | 复选 | 不勾选 | | 外观项 |

「Data」/ 数据 组的标题写明可以选一列或多列：加号点一次挑一列，重复添加即可放进多列。多列时每个列对应一个箱，横轴的刻度文字就是列名。

### 须线的含义

须线的位置由「须线倍数」决定，算法与[数据清洗](cleaning.md)里的 IQR 乘数一致：下边界是下四分位数减去这个倍数乘四分位距，上边界是上四分位数加上同样的量。须线只画到边界以内的最远数据点，边界以外的点就是离群点，单独画成小点。

倍数 1.5 是箱线图的常规取值，在正态分布下大约只有千分之几的数据落在须线之外。倍数调大，须线变长、离群点变少，极端值被当成正常范围的一部分；倍数调小，须线变短、更多取值被画成离群点。倍数取 0 时须线收到箱体边缘，箱体之外的全部取值都成为离群点。

### 分组

勾选分组列之后，在每个数据列内部按分组类别排开箱体，同一列里几个类别的箱并排放在一起，箱体之间留出半个位置的间隔，横轴刻度显示的是分组类别的名字。选一列数据加上一个分组列，得到的是一列若干箱的图，每箱是一类；选多列数据加分组列，图上按列成组排列。

### 五数概括

箱线图里的五个数字合称五数概括：最小值一侧的须线端点、下四分位数、中位数、上四分位数、最大值一侧的须线端点。中间的三个数把数据分成四段，每段占四分之一：箱体从下四分位数到上四分位数，装的是中间一半的数据，箱体高度就是四分位距。

读图时按顺序问三个问题。箱体哪个高，比的是中间一半数据的水平。箱体哪个厚，比的是中间一半数据的分散程度，箱体厚的组波动大。须线和离群点长什么样，看的是极值和异常：某一组上方戳出很多点，说明这一组里有一批偏大的记录，可能是真实的长尾，也可能是录入错误。

中位线的位置也能说明分布的形状：中位线靠近箱体下缘、上四分位数离得远，说明这一列往大的一侧拖尾；反过来是往小的一侧拖尾。这一点和直方图上看出的偏斜方向应当一致，两处对不上时检查数据里有没有空值或筛选过的子集。

### 例子

四台设备各测了三十个样品，把四列数据一起选中画箱线图，中位数的横向差和箱体高度直接反映设备之间的差异，某台设备箱体特别长说明它的波动大于其它设备。

离群点在图上始终以点画出来，「显示离群点」和「显示均值」两个开关目前不改变结果；均值在数据里已经算好，需要标出均值时可以在图上手工加一条标记线。

再补充一句读图的顺序：先看各箱的中位线在哪，再看箱体的厚薄，最后看须线和外面的点。三步走完，一组数据和另一组数据的差别基本能说清楚。

## Heatmap / 热力图

把一个交叉表里的每个数字用颜色深浅表示，行列两个方向分别是两个分类维度，颜色表示第三个数值的大小。它回答的问题是「两个维度交叉之后，哪些组合高、哪些组合低、哪些组合缺数据」。

热力图适合看二维表格里的模式：设备与日期交叉的产量、样品与检测项目交叉的结果，颜色成片地变化能一眼看出趋势或异常块。

### 参数

下面的参数按对话框的分组排列：聚合、色图、标准化三项在「Aggregation && Colour」/ 聚合与颜色 组，三个范围值在「Value Range (0 = auto)」/ 数值范围（0 = 自动）组，标注两项在「Annotations」/ 标注 组。

| 参数 | 类型 | 默认 | 范围 | 说明 |
|---|---|---|---|---|
| 「Aggregation function」/ 聚合函数 | 下拉 | mean | mean、sum、count、median、max、min | 同一行列组合里多个取值如何汇总 |
| 「Colour map」/ 色图 | 下拉 | viridis | viridis、plasma、inferno、magma、cividis、coolwarm、RdBu_r | 颜色到数值的映射 |
| 「Standardisation」/ 标准化 | 下拉 | None | None、row、column | 按行或按列做最小最大归一化 |
| 「vmin (0 = auto)」/ 最小值 vmin（0 = 自动） | 小数 | 0 | −1000000 到 1000000 | 配色范围下限 |
| 「vmax (0 = auto)」/ 最大值 vmax（0 = 自动） | 小数 | 0 | −1000000 到 1000000 | 配色范围上限 |
| 「center (0 = none)」/ 中心值 center（0 = 无） | 小数 | 0 | −1000000 到 1000000 | 每个格子减去这个数 |
| 「Annotate cells」/ 标注单元格 | 复选 | 不勾选 | | 在格子里写数值 |
| 「Format string」/ 格式字符串 | 文本 | .2f | | 标注的格式，两位小数 |

「X 轴（列方向）」、「Y 轴（行方向）」两个组各选一列，行和列的角色不要弄反：「Y 轴（行方向）」选的列决定表的行，「X 轴（列方向）」选的列决定表的列。「数值列」（Value column）组是可选的：勾选并选一列时，这一列的值参与汇总；不勾选时按行列组合计数。

### 标准化

标准化的作用是把每一行（或每一列）的数据映射到 0 到 1 之间：按行标准化时，每一行里最小的格子变成 0、最大的变成 1，中间的按比例落位；按列标准化是对每一列做同样的事。

这样做的意义在于消除量级差异。不同行的数值水平差很多时（一个设备产量上千、另一个只有几十），直接着色看的只是水平高低；按行标准化之后，每一行内部的相对高低才是着色的依据，适合比较各组的形状是否一致。反过来，保持 None 时颜色忠实反映数值大小，适合看整体水平。

「中心值」给每个格子减去一个数，常与双向颜色（RdBu_r、coolwarm）配合：减去均值之后，高于均值的格子偏一种颜色、低于均值的偏另一种，正负偏差一眼分开。

### 颜色和空白的读法

颜色成片的地方说明这些组合的数值接近，颜色突变的边界说明跨过这条线之后数值换了一档。整行颜色相近说明这一行的汇总值在各列之间差不多，某个格子与同行其它格子反差很大时，这个组合值得单独查。

格子留白表示这个行列组合在原表里没有记录，与「数值是 0」不同。一片空白说明那一类样本整体缺失，可能是没有采集，也可能是筛选的时候被排除掉了。核对空白用透视表的计数版本更直接：用[描述统计与透视表](statistics.md)生成一张计数透视表，数一遍每格有几条记录。

### 需要留意的地方

热力图这一项在当前版本里点「OK」之后不会画到坐标系上：对话框里的行列选择没有传到绘图环节，图上不会出现内容。这一节列出的参数是设置窗口提供的项目，可作为功能说明来读。

要得到一张等效的热力图，先用[描述统计与透视表](statistics.md)生成透视表，再用「Figure」/ 绘图 面板里的「Add Cloud Map」/ 添加云图 建一张谱图，数据选透视表，行列标签和色图在[创建图表](../chart/create.md)的建图向导里设置。

另外，vmin 和 vmax 两个值目前不改变配色范围。

### 例子

按月做行、按产品做列、产量做值生成一张透视表，用它画热力图，哪几种产品在年末冲高从颜色上一眼看出。

## Scatter / 散点图

把两列数值配成一对，对应的点在图上画一个位置，用来观察两个量之间有没有关系。它回答的问题是「一个变大时另一个怎么变」。

散点图是看相关关系的首选：点带从左上到右下说明两者反向变化，从左下到右上说明同向变化，散成一片说明关系不明显，个别远离开的点可能是录入错误或特殊样本。

### 参数

四个选项都在「Marker」/ 标记 组里。

| 参数 | 类型 | 默认 | 范围 | 说明 |
|---|---|---|---|---|
| 「Marker size」/ 标记大小 | 整数 | 6 | 1 到 100 | 外观项 |
| 「Marker style」/ 标记样式 | 下拉 | circle | circle、square、diamond、triangle、cross、plus、star | 外观项 |
| 「Alpha (transparency)」/ 透明度（Alpha） | 小数 | 0.85 | 0.05 到 1 | 外观项 |
| 「Show legend (hue)」/ 显示图例（分组） | 复选 | 勾选 | | 外观项 |

X 轴、Y 轴各选一列，两列都选好才能出图。两列来自同一行数据，取值的配对关系按行决定，行里的空值会被跳过。

### 分组

勾选分组列之后，软件按分组列的取值把点分成几组，每组画成一系列不同颜色的点，颜色按固定的顺序分配，前几种颜色依次是蓝、橙、绿、红、紫。分组后各组共用同一套横纵轴范围，组之间的位置关系可以直接比较。点分组的依据是分组列的取值，与坐标无关。

### 点重叠的时候

数据点多的时候点会叠在一起，判断不了密度。这时分两步处理：先把坐标轴改成对数坐标看数量级差得多的数据（坐标轴设置在属性面板里，见[缩放与取值](../chart/interaction.md)），再按分组列拆成几组分别看。

分组本身也是一种缓解重叠的办法：两组数据各画一套不同颜色的点，重叠时颜色混在一起可以区分。点还是太密时，考虑先按条件筛选出一个时间段或一个批次再看，或者改用二维核密度看整体密度。

### 例子

一列反应温度、一列产率，画散点看温度升高时产率是否跟着上升；再把「催化剂型号」选作分组列，如果两组的点带明显错开，说明型号的影响比温度更大。

四个外观选项目前不影响图上的点，点的大小和形状由绘图组件决定，需要调整时在图上选中散点图元，到属性面板里改。

## Barplot / 柱状图

按一个分类列把数据分成若干组，每组算一个统计量，用柱子的高度表示。它回答的问题是「各类之间哪个高、哪个低」。

与直方图相比，柱状图的横轴是类别而不是数值区间：直方图的一根柱子是一段数值范围里的记录数，柱状图的一根柱子是一个类别（或一个分类组合）的汇总值。

### 参数

六个选项都在「Statistics」/ 数据统计 组里。

| 参数 | 类型 | 默认 | 范围 | 说明 |
|---|---|---|---|---|
| 「Estimator」/ 估计函数 | 下拉 | mean | mean、median、sum、count、std、var | 每组如何折成一个数 |
| 「Confidence interval」/ 置信区间 | 下拉 | None | None、68、95、99 | 是否在柱子上画误差线 |
| 「Bootstrap iterations」/ Bootstrap 迭代次数 | 整数 | 1000 | 100 到 10000 | 重抽样的次数 |
| 「Orientation」/ 方向 | 下拉 | vertical | vertical、horizontal | 外观项 |
| 「Bar width」/ 柱宽 | 小数 | 0.8 | 0.1 到 1 | 外观项 |
| 「Show legend (hue)」/ 显示图例（分组） | 复选 | 勾选 | | 外观项 |

「X 轴（分类）」选分类列。「Y 轴」这一组是可选的：选了一列数值时按「估计函数」汇总这一列；留空时画计数图，每根柱子是这一类出现的记录条数。计数图不需要估计函数和置信区间，界面上这两项会随着 Y 轴留空而变灰。

### 估计函数

六个选项对应六种折法：均值（每个类别的平均值，默认）、中位数（抗极端值）、求和（把各类的数值加总）、计数（每类里非空的取值个数）、标准差（每类内部的波动大小）、方差（标准差的平方）。

同一批数据换一个估计函数可能得到相反的结论：某类均值高但中位数低，说明它里面有几个特别大的值在拉高平均。

### 置信区间和自举

柱子是抽样算出来的，换一批样本会有差别，置信区间给出这个差别的范围。选 68、95、99 表示区间的置信水平：区间越宽，说明这一类里的数据越散或者记录越少，柱子代表那个水平就越不牢靠。

计算方式按估计函数分两种。均值用 t 分布直接算出区间；中位数、求和这类其它统计量用自举法：从这一类里反复有放回地抽同样多的数，每次算一个统计量，重复指定的次数，把结果里按百分位截出一段作为区间。默认重复 1000 次，次数越多区间越稳定、算得越慢。

软件里的随机种子是固定的，同样的数据、同样的参数每次得到同样的区间，图上不会出现两次结果不一致的情况。选择 None 时不画区间，柱子上没有误差线；其它三个档位对应各自的置信水平。

### 分组

勾选分组列之后，每个类别里的每个分组各画一根柱子，同一类别的柱子并排放在一组，横轴刻度仍是类别名。

### 计数图的用途

Y 轴留空时画出的计数图，每根柱子的高度是这一类出现的记录条数。它常用来检查数据是否均衡：各类样本数差得很大时，后面所有按类别比较的统计都会偏向样本多的那一类。

计数图也用来核对数据完整性，比如按月份看每个月有多少条记录，某个月明显偏少说明那段时间的采集有缺口。实际数量与计划数量对不上时，先在这里发现，再回到原始数据里找原因。

### 例子

三种肥料处理下的小麦产量，把「处理」选作 X 轴、产量选作 Y 轴、估计函数用均值、置信区间选 95，三根柱子带上误差线；两根柱子的误差线重叠时，两者有没有差别就不能只看柱高。

「方向」、「柱宽」、「显示图例」三项目前不改变图上的样子。

## Regplot / 回归图

在散点图上再画一条拟合曲线，并在曲线的上下加一条置信带。它回答的问题是「两个量之间大致是什么关系，这条关系有多确定」。

散点图看出趋势之后，回归图把趋势用一条线表示出来，方便读出斜率和弯曲程度；置信带提示这条线本身的不确定性。

### 参数

下面的参数按对话框的分组排列：阶数、置信水平、迭代次数和两个开关在「Regression」/ 回归 组，标记两项在「Scatter style」/ 散点样式 组，线宽在「Regression line style」/ 回归线样式 组。

| 参数 | 类型 | 默认 | 范围 | 说明 |
|---|---|---|---|---|
| 「Polynomial order」/ 多项式阶数 | 整数 | 1 | 1 到 5 | 拟合曲线的次数 |
| 「Confidence interval」/ 置信区间 | 下拉 | None | None、68、95、99 | 是否画置信带与水平 |
| 「Bootstrap iterations」/ Bootstrap 迭代次数 | 整数 | 1000 | 100 到 10000 | 重抽样次数 |
| 「Draw scatter points」/ 绘制散点 | 复选 | 勾选 | | 散点开关 |
| 「Draw regression line」/ 绘制回归线 | 复选 | 勾选 | | 拟合线开关 |
| 「Marker size」/ 标记大小 | 整数 | 6 | 1 到 50 | 外观项 |
| 「Alpha (transparency)」/ 透明度（Alpha） | 小数 | 0.85 | 0.05 到 1 | 外观项 |
| 「Line width」/ 线宽 | 小数 | 2 | 0.5 到 10 | 外观项 |

X 轴、Y 轴各选一列。

### 多项式阶数

阶数是拟合曲线的次数。1 表示直线，也就是最常见的一次关系，两个量按固定比例一起变时用这一档；2 表示抛物线，数据先升后降或者先降后升时用；3 到 5 能贴合更复杂的弯折。

阶数越高，曲线越能穿过每一个点，也越容易在两个端点附近甩出去，或者在数据中间造出实际不存在的波动。判断的方法是：从一个阶数往上加，如果高阶曲线与低阶曲线在数据范围内几乎重合，加阶数没有带来新信息；如果曲线开始穿过每一个点并在两端翘起，说明阶数过大了。默认的 1 是稳妥的起点。

拟合用最小二乘，软件在数据的横轴范围内取 100 个点画线，曲线在数据范围之外不延伸。

### 置信区间与自举

置信带表示拟合线本身的不确定范围：带子窄说明数据把这条线定得很准，带子宽说明不同的样本可能给出不同的线。计算方式是从数据里反复有放回地抽样，每次重新拟合一条曲线，把同一横坐标上多条曲线的取值按百分位截出上下界。

「Bootstrap 迭代次数」控制重抽样的次数，次数越多上下界越稳定，计算也越慢；随机种子固定，同样的数据每次得到同样的带子。

回归图的置信区间选「None」时，图上仍会画出一条按 95% 计算的带子，这一档在对话框里关不掉；把它当成固定的 95% 来使，或者换用柱状图看同类问题。

### 需要注意的地方

「绘制散点」和「绘制回归线」两个开关目前不影响结果，散点和拟合线都会画出来；标记大小、透明度、线宽也不改变图上的外观。

### 拟合线怎么读

先看方向：线从左下往右上说明两个量同向变化，横轴每增加一个单位，纵轴平均增加多少看线的陡峭程度；线从左上往右下是反向变化；接近水平说明两者的关系不明显。

再看弯曲：直线说明变化速度恒定，抛物线或更高次的曲线说明变化速度本身在变。曲线变陡的一段表示横轴单位变化带来的纵轴变化更大，这一点在直线拟不出来的数据里很常见。

最后看置信带：带子在某一段特别宽，说明那一段的样本少或者点的分布散，线在那里最不可靠；两端带子变宽是常见现象，因为端点附近的样本客观上更少。带子很窄的一段，可以把线当作可靠的关系来引用。

### 例子

一列时间、一列累计产量，先用默认的一阶拟合看平均增速；数据前段平缓、后段陡增时把阶数改成 2，曲线上能看出加速的拐点，置信带在两端变宽正是数据支撑不足的位置。

## ECDF / 累积分布

把一列数值排序之后，画出「不超过某个值的样本占多少」的曲线。曲线从左下角向右上角上升，上升到一半时对应的横坐标就是中位数，陡的一段说明取值集中，平的一段说明这一段几乎没有数据。

累积分布回答的是「有多少比例不超过某个值」这类问题，与直方图看形状互补。它不需要选分箱，形状只由数据决定；把两条累积分布曲线画在一起比较两组数据的差异也很直观。

### 参数

四个选项都在「Options」/ 选项 组里。

| 参数 | 类型 | 默认 | 范围 | 说明 |
|---|---|---|---|---|
| 「Statistic」/ 统计量 | 下拉 | proportion | proportion、count | 纵轴是比例还是个数 |
| 「Complementary CDF (1-CDF)」/ 互补 CDF（1-CDF） | 复选 | 不勾选 | | 改画大于某个值的部分 |
| 「Line width」/ 线宽 | 小数 | 2 | 0.5 到 10 | 外观项 |
| 「Show legend (hue)」/ 显示图例（分组） | 复选 | 勾选 | | 外观项 |

「Weights」/ 权重 组是可选的一组：勾选并选一列时，各样本按权重参与累积。这一项当前取不到所选的那一列，实际按读数本身的取值加权，要按权重统计先在表里手工处理。

### 统计量与互补

「proportion」表示纵轴是比例，取值从 0 到 1，最后一点到达 1；「count」表示纵轴是个数，最后一点等于有效观测的总数。看占比用前者，核对样本数量用后者。

互补累积分布把曲线上下翻转，纵轴从 1 降到 0，某点处的纵坐标表示「大于这个值的样本比例」。它适合看尾部：长尾数据用对数纵轴时，互补曲线能把很小的比例也展开看清。

曲线画成阶梯状，每一级台阶对应一组取值相同的样本，台阶的宽度就是这些样本的多少。

### 阶梯曲线的读法

曲线上任意一点都能读出一对数字：横坐标是取值，纵坐标是不超过这个取值的样本比例。要做「有多少比例的样本低于某一水平」这类判断，在图上把纵轴定到需要的比例，横过去读横坐标即可。

几条常见的读数位置：纵轴 0.25 处是下四分位数，0.5 处是中位数，0.75 处是上四分位数，与[描述统计](statistics.md)里的 25%、50%、75% 三行完全对应。曲线在某个区间里很陡，说明大量样本落在这个取值区间；曲线平着走一段，说明这一段取值附近样本很少或者是空档。

两条曲线比较时，同一纵坐标下横坐标更小的那条曲线，说明那一组在给定比例下的取值更低；两条曲线交叉说明两组各有高低，没有一边倒的差别。

### 分组

勾选分组列之后，每个分组各画一条阶梯曲线，颜色不同，可以直接比较两条曲线的高低位置：同一横坐标下哪条曲线的纵坐标大，说明那一组的取值整体更低。分组时纵轴取比例，看的是分布形状；要看各组的样本量差别，把统计量换成个数。

### 例子

两批原料的纯度列，各画一条累积分布曲线，曲线在横轴上的左右错位说明两批的纯度整体水平不同；某条曲线在低纯度一侧更陡，说明那一批里低纯度的样本更多。

## 常见问题

点了按钮只弹出对话框，图没有出现。图是在点「OK」之后画的。没选数据列时对话框不关闭，消息面板给出提示。

引导对话框关掉之后再打开，之前填的参数还在。同一个按钮再次打开时设置页保留上次的内容；想全部恢复默认，逐个改回默认值再执行。

图上出现了两个坐标系或者画到了别的位置。图表画在当前激活的坐标系里。多坐标系绘图里先点一下目标坐标系再开对话框，或者在画好之后用属性面板把图元移到想要的位置。

计算失败，只看到一条消息。常见原因是这一列的有效取值太少（核密度至少需要两个不同的点）、选中的列是文本列、或者分组列取值太多。消息面板里的文字说明是哪一列出的问题，换一列或者先清洗数据再试。

图上的曲线或柱子想改颜色。图形都是可以单独选中的图元，点中之后到属性面板里改颜色、线宽、符号，见[二维图表设置](../chart/settings-2d.md)。

分组之后颜色分不清。分组颜色按固定顺序分配，取值多的组颜色接近。先把分组列的取值合并成几类再画，或者分别出图。

想把图上的一条曲线换成另一种图表。统计绘图每次都是新画一件图元，删除旧图元再画新的即可，图元的选中与删除见[二维图表设置](../chart/settings-2d.md)。

同一批数据想画到另一个坐标系上。图表画在当前激活的坐标系里。多坐标系绘图先用鼠标点选目标坐标系，或者把对话框开着、切到另一个坐标系再点「OK」。

画完之后数据被改了，图会跟着变吗。不会。图上画的是执行那一刻算出来的数字，源数据之后的变化不会重算，需要重新执行一次绘图动作。

分组列选成了数据列本身。每个取值都成了一个组，图上会出现一大片几乎没有内容的曲线或柱子。分组列要用另一个分类性质的列，取值个数控制在十个以内。
