# 数据管理使用指南

本指南介绍如何使用 DAWorkBench 的数据管理功能，包括数据导入、查看、编辑和导出。

## 主要功能特性

- ✅ **多格式导入**：支持 CSV、Excel、Pickle、文本文件
- ✅ **交互式表格**：基于 pandas DataFrame 的可视化表格编辑
- ✅ **数据管理面板**：统一管理所有数据对象
- ✅ **数据导出**：支持导出为多种格式
- ✅ **表格样式**：支持单元格级条件格式和样式自定义

---

## 数据管理概念

### 数据对象

DAWorkBench 中的数据以**数据对象**的形式管理，主要类型包括：

| 数据类型 | 说明 | 典型来源 |
|---------|------|---------|
| **DataFrame** | 二维表格数据（pandas DataFrame） | CSV、Excel 导入 |
| **Series** | 一维序列数据（pandas Series） | DataFrame 列提取 |
| **Python 对象** | 任意 Python 对象 | 工作流节点输出 |

### 数据管理面板

数据管理面板位于 Dock 区域，展示当前工程中的所有数据对象：

- **数据树视图**：按层次展示数据对象
- **数据操作区**：选中数据后显示其内容（表格视图）
- **右键菜单**：提供导入、导出、删除等操作

---

## 导入数据

### 通过菜单导入

1. **点击导入按钮**：在 Ribbon 工具栏中点击"导入数据"
2. **选择文件**：在文件对话框中选择要导入的文件
3. **配置导入选项**：根据文件类型配置（如 CSV 的分隔符、编码等）
4. **确认导入**：数据出现在数据管理面板中

### 支持的文件格式

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| CSV | `.csv` | 逗号分隔值文件 |
| Excel | `.xlsx` / `.xls` | Excel 工作簿 |
| 文本文件 | `.txt` | 文本格式数据 |
| Pickle | `.pkl` | Python 序列化数据 |

### 通过命令行导入

程序支持通过命令行参数导入数据，适用于自动化场景：

```bash
# 导入单个文件
DAWorkBench.exe --import-data "C:\data\input.csv"
```

!!! tip "批量导入"
    命令行参数 `--import-data` 可多次使用，批量导入多个文件。详见 [命令行参数](./command-line-arguments.md)。

---

## 查看数据

### 表格视图

选中数据管理面板中的 DataFrame 数据，数据操作区会显示表格视图：

- **列头**：显示列名和数据类型
- **行号**：左侧显示行索引
- **单元格**：显示具体数据值
- **滚动条**：支持水平和垂直滚动

### 数据信息

表格视图底部状态栏显示数据基本信息：

- **行数 × 列数**：数据维度
- **内存占用**：数据内存大小
- **当前选中**：选中的单元格范围

---

## 编辑数据

### 直接编辑

双击表格中的单元格可直接编辑数据值（部分数据类型支持）。

### 表格样式

DAWorkBench 支持单元格级条件格式：

1. **选中单元格**：选中要设置样式的单元格
2. **打开样式菜单**：右键 → "设置单元格样式"
3. **配置样式**：设置背景色、字体颜色、对齐方式等
4. **条件格式**：可基于数据值自动应用样式

!!! note "样式持久化"
    表格样式随工程文件保存，重新打开工程时自动恢复。

---

## 导出数据

### 导出步骤

1. **选中数据**：在数据管理面板中选中要导出的数据
2. **点击导出**：右键菜单 → "导出数据"
3. **选择格式**：选择导出格式（CSV、Excel 等）
4. **配置选项**：设置导出路径和参数
5. **确认导出**：数据保存到指定文件

### 导出格式说明

| 格式 | 扩展名 | 适用场景 |
|------|--------|---------|
| CSV | `.csv` | 通用数据交换 |
| Excel | `.xlsx` | 带格式的报表 |
| Pickle | `.pkl` | 保留 Python 类型 |
| JSON | `.json` | Web 数据交换 |

## 数据与工作流的交互

### 工作流输出数据

工作流执行后，节点的输出数据可以通过 `Output to DataManager` 节点写入数据管理器：

1. 在工作流中使用 `Output to DataManager` 节点
2. 将上游节点的输出连接到该节点的输入端口
3. 执行工作流后，数据自动添加到数据管理面板

### 工作流输入数据

工作流节点主要通过 `Data Source` 节点从文件读取数据。如需引用数据管理器中已有的数据，可在 Python 脚本节点中通过 DAWorkbench API 访问数据管理器。

## 常见问题

### Q：导入 CSV 时中文乱码？

**A：** CSV 文件编码可能不是 UTF-8。在导入对话框中选择正确的编码（如 GBK、GB2312）。建议将 CSV 文件转换为 UTF-8 编码。

### Q：大数据文件导入很慢？

**A：** 对于超大文件（>100MB），导入可能较慢。建议：
- 使用 Pickle 格式（比 CSV 快）
- 分批导入数据
- 参见 [性能优化建议](../reference/performance-tips.md)

### Q：如何删除数据？

**A：** 在数据管理面板中右键点击数据对象 → "删除"。删除操作支持撤销（Ctrl+Z）。

### Q：数据修改后如何保存？

**A：** 数据随工程文件保存。通过"文件 → 保存工程"保存所有数据。也可单独导出数据为文件。
