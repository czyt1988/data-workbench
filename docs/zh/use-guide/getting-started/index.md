# 入门

这一部分解决三件事：把软件装上并让它跑起来，认清界面上每一块是做什么的，明白工程文件里装了什么。读完之后就能开始导入数据和画第一张图。

## 章节目录

- [安装与首次启动](install.md)：系统要求、安装目录里有什么、第一次启动时要做的事。
- [主界面](main-window.md)：Ribbon 标签页、上下文标签页、每一个停靠面板、界面布局的保存与恢复。
- [工程文件](project.md)：`.dapro` 压缩包里装了什么、新建与保存的流程、脚本工作区的位置。

## 建议的读法

第一次接触这个软件，按上面的顺序读。

已经用过其它数据分析软件，只想知道这个软件把功能放在哪里的，读[主界面](main-window.md)一节即可，看那张停靠面板对照表就够用。

只关心工程文件怎么备份和搬运的，直接读[工程文件](project.md)。

## 从这里往后

装好之后，接下来通常是二选一：

- 手上有一份数据要清理和作图，读[导入数据](../data/import.md)，再读[创建图表](../chart/create.md)。
- 想把重复的数据处理固定成一套流程，读[工作流基础](../workflow/basics.md)。
