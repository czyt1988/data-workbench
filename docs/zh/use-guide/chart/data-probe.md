# 数据探针与数据联动表

数据探针是在图上指定一个位置、把该位置上的读数固定下来的工具。探针画出来是一条虚线加一个名称徽标，位置不动，随图一起保存；点几个位置就得到几组读数，全部汇总到「Data Link Table / 数据联动表」里的一张表格中。

这一章讲探针怎么创建、怎么设置、读数在哪里看、哪些数据读得到哪些读不到，以及两个典型的用法。

## 探针是什么

探针画在坐标系上，是一条虚线加一个小小的名称徽标。竖直的探针在固定的 X 位置立一条竖线，读各条曲线在这个 X 上的 Y 值；水平的探针在固定的 Y 位置横一条线，读曲线与这条线相交处的 X 值。竖线贯穿整个绘图区的高度，徽标贴在 X 轴那一侧，不挡数据。

探针和跟随鼠标的读数框不一样。读数框是临时的，鼠标移开就消失，读数只能看着屏幕记；探针固定在自己创建时的位置上，一直留在图里，读数进表格，可以反复对照。

探针同时是一个图元，会出现在「Setting / 设置」面板的图元下拉框和「Charts Manager / 绘图管理」的树里，可以选中、改名、调颜色，见[二维图表设置](./settings-2d.md)。

徽标上的名字就是探针名字，数据联动表的列头用的是同一个名字。有了这层对应关系，看到图上某条竖线时，能在表里立刻找到属于它的那一列。

界面里的「Data Probe / 数据探针」动作创建的是竖直探针。水平探针在代码里有实现，界面里没有创建入口，目前只能由代码创建。

探针取值时用线性插值：位置落在两个采样点之间时，按相邻两点的连线算出该位置的数值。曲线完全覆盖不到这个位置时，这一格留空。

## 探针和别的取值方式

软件里能读数的工具不止探针一种，各自的用途不同，选错了容易把随手看到的数当成结论。

| 工具 | 读数方式 | 读数留在哪里 |
|------|----------|--------------|
| 十字光标 | 跟随鼠标显示一条取景线 | 不记录 |
| Y 值拾取 | 跟随鼠标显示最近曲线的 Y 值 | 不记录 |
| XY 值拾取 | 跟随鼠标显示横纵坐标 | 不记录 |
| 标记线 | 固定在指定坐标上的横线、竖线或十字 | 留在图上，没有读数 |
| 数据探针 | 固定在指定坐标上，读取该处各曲线的值 | 留在图上，同时进数据联动表 |

跟随鼠标的三种读数适合边看边判断，位置不会保留；标记线适合标出参考值，但它本身不给读数；只有探针把位置和读数一起固定下来，并且能汇总成表。

要对比几个位置的数值，用探针；只是想看看鼠标底下是多少，用读数框就够。三种读数工具的开关在 Ribbon 的「Chart Style / 图表样式」页和数据拾取页，实际手感见[缩放与取值](./interaction.md)。

## 创建探针

创建探针要先进入探针模式。在 Ribbon 的「Chart Edit / 绘图编辑」页找到「Chart Assist Tool / 图表辅助工具」面板，点「Data Probe / 数据探针」按钮。按钮的提示文字是「Data probe: click to create probes on all charts, values are listed in the data link table」，中文提示是「数据探针：点击在各子图上创建探针，数值汇总到数据联动表」。

进入这个模式时，软件会先做几件准备：把当前绘图里每个二维坐标系的缩放、平移和十字光标都关掉，打开 Y 值拾取，并把所有坐标系的读数框加入同一个读数组。

关掉缩放和平移是为了让左键点击只用来放探针，不会顺手把图拖走。读数框加入同一个读数组之后，一次点击才能在所有坐标系上同时定位。

联动读数还有一个副作用：进入探针模式后，在任意一个坐标系上移动鼠标，所有坐标系的读数框会一起显示同一个 X 位置上的读数，等于临时得到了一组跟着鼠标走的多坐标系对照。这个效果在退出模式后仍然保留，因为联动开关没有跟着关掉。

模式打开后，在任意一个坐标系上点一下，软件按点击位置的数据坐标 X 值，在当前绘图的每个二维坐标系上各放一条同名的竖直探针，徽标都标着同一个名字。

拾取器会吸附到最近的采样点上，所以探针落在的 X 值一般是某个采样点的横坐标，不一定正好等于鼠标按下处的坐标。点在远离所有曲线的空白处时，位置按画布坐标反算成数据坐标，探针照样建出来，读数可能为空。

点一次等于建了一组探针，横跨所有坐标系；再点一次是第二组。曲线多、坐标系多的时候，一次点击就能把各坐标系在同一横坐标上的读数都摆好。

这一批操作在撤销栈里是一条记录，撤销文本是「add data probes」/ 添加数据探针。按一次撤销，整批探针一起消失，不用逐个删。

每建一组探针，右侧的数据联动表都会跳到前台并加上一列。

创建时不会跳过空坐标系。绘图里某个坐标系没有曲线时，探针照样落在它上面，只是那个坐标系在表格里的几行读数都是空的。坐标系数量多、又只关心其中几个时，可以在建图前把无关的坐标系先关掉，或者建完之后在表格里把多余的列删掉。

探针模式只作用于当前绘图。绘图操作区里开着多个绘图标签页时，探针落在当前显示的那一个绘图上，其他绘图的探针要切过去再建。

点击要落在画布范围内才会建探针。读数框只覆盖坐标系的绘图区，点在坐标轴、轴标题或者坐标系之外的空白上不会产生探针，这也是把点击和选中图元区分开的方式。

探针模式没有次数限制，想建多少组就点多少下。读完之后退出模式，探针留在图上，随时可以在表格里对照。

## 探针的命名

自动名字按 A、B、C 一路排到 Z，然后是 AA、AB、AC 这样两位字母接着排下去。命名时会跳过已经存在的名字，所以删掉中间某个探针后再新建，不会出现两个同名的探针。

同一组探针在所有坐标系上共用同一个名字，表格里也一样，一列对应一组，而不是一条探针一个名字。

改名有两条路。在数据联动表里对着表头点右键选「Rename / 重命名」，输入新名字后这一个探针组里的所有徽标一起改；在「Setting / 设置」面板里选中某一条探针改「Title / 标题」，只改这一条，其他坐标系上的同名探针不变。

表头改名不检查是否和别的探针重名，两个组取到同一个名字后，表格里会出现两列同名，后面按名字找列就容易认错，重新取一个不重复的名字更省事。

## 退出探针模式

离开探针模式有三种方式：再点一次「Data Probe / 数据探针」按钮把它取消勾选；按 Esc 键；或者切到同一个工具组里的其他动作，比如「Add Rect / 添加矩形」或指针工具。三种方式都回到普通编辑状态。

退出后，缩放、平移和十字光标保持关闭状态，不会自动恢复成进入之前的样子；探针模式打开过的 Y 值拾取和联动拾取也保持打开状态。想接着用滚轮缩放或拖动画布，在 Ribbon 的「Chart Style / 图表样式」页把它们重新打开。

反过来，探针模式开着的时候从 Ribbon 上打开缩放、平移或十字光标，探针模式会立刻退出。两种状态互斥，不会叠在一起。

模式退出后探针仍在图上，只是不再有点击建探针的响应，要看读数值就到数据联动表里看。

## 单个探针的设置

点中一条探针，右侧「Setting / 设置」面板切到探针页。这一页改的是这一条探针自己的外观，改动不跨坐标系。

| 分组 | 设置 | 默认值 | 作用 |
|------|------|--------|------|
| `Basic` / 基础 | `Title` / 标题 | 自动生成的名字 | 探针名称，同时是徽标文字 |
| `Basic` / 基础 | `Z Value` / Z值 | 图元的层叠值 | 绘制层叠顺序 |
| `Basic` / 基础 | `Probe Value` / 探针值 | 创建时的位置 | 竖直探针填 X，水平探针填 Y，范围 −1e15 到 1e15 |
| `Label` / 标签 | `Label Visible` / 标签可见 | 开 | 是否显示徽标 |
| `Label` / 标签 | `Label Position` / 标签位置 | 自动判断 | `Top / Left` / 上/左、`Bottom / Right` / 下/右 |
| `Label` / 标签 | `Label Style` / 标签样式 | `Rounded Rect` / 圆角矩形 | `Plain Text` / 纯文本、`Rounded Rect` / 圆角矩形、`Rectangle` / 矩形、`Ellipse` / 椭圆 |
| `Appearance` / 外观 | `Probe Color` / 探针颜色 | 默认颜色 | 虚线和徽标的颜色 |

`Probe Value` 是探针的位置，改它等于把虚线挪到新的位置，数值保留 6 位小数。挪动之后虚线立刻到新位置，数据联动表里的数字要在那一列上执行一次「Refresh / 刷新」才会按新位置重新取值。

`Label Position` 和 `Label Visible` 由软件按 X 轴的可见性自动判断：下 X 轴可见时徽标放在轴的底部，只有上 X 轴可见时放到顶部，两条 X 轴都隐藏时徽标也跟着隐藏。改坐标轴的可见性会触发一次重算，手工设过的位置会被这一步覆盖。

`Label Style` 决定徽标的画法。圆角矩形和矩形给文字加一个填了探针颜色的底板，文字居中显示为白色；椭圆画成椭圆底；纯文本只写文字不加底板。颜色浅的底配白字看不清时，换纯文本样式更清楚。

`Z Value` 决定这条虚线压在哪些图元上面。探针默认画在曲线之上，被某个图元的大色块盖住时可以调高它；也可以反过来把探针放到背景图元后面，用来避免细密的曲线被虚线打断。

探针的线型和线宽是固定的：一条 1 像素宽的虚线，页面里只提供改颜色的字段，改不了粗细和虚实。虚线颜色和徽标颜色是同一个值，改 `Probe Color` 时两处一起变。

同一坐标系上有多条曲线时，一条探针就够了，虚线只有一条，每条曲线各占表格里的一行。想给某条曲线单独再标一条线，用标记线，不必再加探针。

## 选择、移动和删除探针

探针选中方式和其他图元一样。在「Setting / 设置」面板顶部的下拉框里选对应的名字，或者在「Charts Manager / 绘图管理」的树里展开 `plot item` 节点点它，面板就会切到探针页。

在图上用指针工具点一下虚线也能选中它，选中后虚线出现选框。竖直探针只能用鼠标左右移动，松开后写到 `Probe Value` 里；水平探针则只能上下移动。要精确到具体数值，直接在探针页填 `Probe Value`。

删除探针有两种做法：指针工具选中后按 Delete；或者在数据联动表里对表头执行「Delete / 删除」和「Delete All / 全部删除」。两种做法都进撤销栈，撤销一次可以整组恢复。

一次撤销撤掉的是整组探针，不是单个。只想去掉其中一条，选中那一条单独删除。

## 数据联动表

「Data Link Table / 数据联动表」和「Setting / 设置」、「Agent Assistant / Agent 助手」在右侧同一个停靠区里，是其中的一个标签页。创建探针时这个停靠面板会被提到前台，不用自己去找。

表按绘图分标签页，一个绘图一个标签页，标签名就是绘图的名字。同一个绘图里的多个坐标系共用一张表，因为探针是一组一组跨坐标系创建的。

标签名在第一次建表时取自绘图名，之后给绘图改名不会改动已有的标签名。标签看不出对应哪个绘图时，把表格标签页关掉，再建一个探针，标签会按当前图名重新生成。

表格里的行是树形展开的，坐标系一行、下面的曲线缩进一层，新建行后自动全部展开，行多时手动收起某一组可以让表更短。

表格的布局如下。

| 位置 | 内容 |
|------|------|
| 第一列表头 | `Curve` / 曲线 |
| 其余列表头 | 探针组的名字，悬停显示该探针位置格式化后的 X 值 |
| 第一层的行 | 坐标系，行名取坐标系标题，为空时用 `Chart 序号` |
| 第二层的行 | 曲线，行名取曲线标题，为空时用 `Curve` / 曲线 |
| 单元格 | 该曲线在这个探针位置上的取值，保留 6 位有效数字 |

行按坐标系分组，组下每条曲线一行；列按探针组排，一列一个位置。行名和列头的可读性取决于图上有没有写标题，坐标系的标题在图表区页里改，曲线的标题在图元页里改。

列头显示的是探针名字，把光标停在表头上会看到这个位置的 X 值。这个提示文字按坐标轴的刻度格式生成：坐标系里有可见的 X 轴时用它自己的刻度格式，比如设成日期时间刻度就显示成日期；没有可见 X 轴时退化成 6 位有效数字。位置相近的几个探针名字不同、提示不同，靠提示可以确认哪一列是哪个位置。

单元格里显示的是该曲线在这个探针位置上的取值。曲线在这个位置没有数据时格子里是空的。

行名取自曲线的标题。图上把曲线改名之后，表格里的旧行名不会自动替换成新名字，表格按探针重建时会按新标题补出新行；想让行名和图上完全对上，改名后重新打开一次工程最干净。同一个坐标系上有两条同名曲线时，两行名字一样，容易看混，给曲线起区分得开的名字更省事。

表格里的行和坐标系的图元一一对应，坐标系上再加一条曲线，表格里就多一行，不需要重新建探针。

### 探针读得到的和读不到的

探针只读曲线类图元。曲线图和散点图都是用曲线图元画的，它们的读数正常；误差棒、柱状、多重柱状、直方图、箱体、云图、等高线、向量场这些图元不是曲线，不会给出读数。

这些图元仍会作为行出现在表格里，因为表格的行按坐标系里的数据图元列出，但对应的格子一直是空的。建图时如果用了这类图元，不要指望用探针取值，得回到源数据里算。

曲线被隐藏时读数也不给。用图例点掉某条曲线，或者在绘图管理树里把它的 `visible` 关掉，刷新这一列后对应的格子就是空的。

### 列的顺序

新建的探针列追加在表格右侧，创建顺序就是列顺序。表格在探针增减时会重建一次，重建后列按探针的 X 值从小到大排列，和创建顺序不一致时以 X 值为准。

删掉中间一列后，其余列保持原来的相对顺序，不会重新编号；探针名字也不变，重新建一列时新名字继续往后排。想把列排成自己习惯的顺序，最直接的办法是重新点一遍探针位置。

### 表头的右键菜单

| 菜单项 | 作用 |
|--------|------|
| `Rename` / 重命名 | 改这一列探针组的名字，图上徽标一起改 |
| `Refresh` / 刷新 | 重新取这一列的数值 |
| `Refresh All` / 刷新全部 | 重新取所有列的数值 |
| `Hide` / 隐藏 | 隐藏这一列，同时隐藏图上对应的探针 |
| `Show` / 显示 | 子菜单里列出被隐藏的列，选一项把它重新显示出来 |
| `Hide All` / 全部隐藏 | 隐藏所有探针列 |
| `Show All` / 全部显示 | 显示所有探针列 |
| `Delete` / 删除 | 删除这一列，弹出确认框「Are you sure to delete this column?」/ 确定删除这一列吗？ |
| `Delete All` / 全部删除 | 删除所有列，弹出确认框「Are you sure to delete all columns? This cannot be undone.」/ 确定删除所有列吗？此操作不可撤销。 |

隐藏一列同时把对应的探针隐藏，图上也就看不到那条虚线；显示回来时虚线一起回来。删除列会把这组探针从图上删掉，这一步走撤销栈，撤销一次整组回来。

表头没有选中某一列时，重命名、刷新、隐藏、删除这几项是灰的。「Refresh All」和另外两个批量项随时可用。

表格本身是只读的视图，内容由探针重建。探针新增或删除时表格跟着加列或减列；改过探针位置、改过数据范围、或者刚把某条曲线设成不可见，都需要在表头执行一次刷新才会看到新数值。

刷新取的是图上曲线当前的采样点，不回头去读数据管理面板里的数据框。

不同的一行可能来自不同坐标系上的曲线，同名曲线分处两个坐标系时，表格按坐标系的组分别列出，读数各归各组。

隐藏列只影响显示，不影响探针的位置和读数来源；重新建一列同名探针时，先前的隐藏状态不会带过去。

## 表格里的数字是怎么来的

一格读数经过这几步产生，明白这条路径，数字对不上时就知道该从哪里查。

1. 探针记下自己的位置，竖直探针记 X，水平探针记 Y。
2. 取值时软件遍历这个坐标系上的图元，只看曲线类，而且只算可见的曲线。
3. 对每条曲线，先看它的数据范围是否覆盖探针位置，覆盖不到就跳过，这一格留空。
4. 覆盖得到就找相邻的两个采样点，按线性插值算出探针位置上的值，探针正好落在采样点上时就直接用那个点。
5. 算出来的值写进表格的对应格子，显示为 6 位有效数字。

这套顺序解释了三种常见现象：曲线在探针位置之外时格子空着；曲线被隐藏后格子变空；采样点很稀时读数来自两个点之间的插值，不等于数据框里任何一个原始值。

刷新重新走一遍这五步，所以改动曲线数据、改坐标轴范围、改动曲线可见性之后，都要刷新一次才能看到新数字。

单元格的数字格式固定为 6 位有效数字，界面上没有小数位数或单位设置。数值很小或很大时会出现科学计数法，把表里的字抄进报告前先确认量级。

## 用表格反过来检查图

表格里的行名和列头也能当检查工具用。

行名来自曲线标题。表格里出现 `Curve` 这样的占位名字，说明这条曲线没有标题，图例和设置面板里也一样不好认，顺手在曲线页的 `Title` 里补一个。

列头的 X 值提示可以用来核对探针位置。因为点击会吸附到采样点，本来想在 `x=5` 处取值，实际可能落在最近的采样点上；看提示文字就能发现偏差，需要精确位置时在探针页的 `Probe Value` 里直接填。

整列都是空的，先查两件事：这个坐标系上的曲线是否覆盖这个位置，曲线是否被关掉了。用图例把曲线打开再看一次，如果还是空的，就说明数据没有覆盖到这个位置。

## 探针的保存与恢复

探针是图元，随图表一起写进工程：位置、名字、徽标的位置和样式、颜色都保存下来。重新打开工程后，图上原来的探针还在原来的位置，徽标也保持原样。

数据联动表不需要单独保存，工程加载完图表后，表格按图上的探针重建，重建后列的顺序按探针的 X 值排。工程内其他内容的保存机制见[复制与保存图表](./save.md)。

列的隐藏状态属于界面上的显示状态，不随工程保存。重新打开工程后所有列都显示出来，之前隐藏过的探针连同虚线一起回到图里。

撤销记录不随工程保存，重新打开工程后不能再撤销上一次会话里的删除操作。

## 两种典型用法

**在同一位置对比多条重复曲线。** 做了几组重复实验、每条曲线放在自己的坐标系里时，按下面的顺序做：

1. 把各组的曲线分别放进一个坐标系，给每个坐标系写上标题，行名才分得清。
2. 在 Ribbon 的「Chart Edit / 绘图编辑」页点「Data Probe / 数据探针」。
3. 在目标横坐标上点一下，一组探针同时落到所有坐标系上，数据联动表跳到前台并多出一列。
4. 需要更多位置就接着点，表格里每列一个位置。
5. 读完后退出探针模式，重新打开缩放和平移继续看图。

表格里同一列上下对照就是同一个测量位置的重复读数，曲线之间的差异直接看得出来。

**给报告准备一张数值表。** 想在报告里列出几个关键位置的数值，就在这几个位置各点一下，表格的行是曲线、列是位置，读出来就是一个二维的数值表。

做法是先把图调好、坐标系标题写清楚，行名和列头才会好读；探针位置按下之后可以在探针页用 `Probe Value` 精确输入，把位置对到整数值上。

位置多、又需要固定间距时，逐个点会慢，用 Python 从源数据里按等间距插值取数更快，前提是手上还有源数据。

## 缩放、平移和探针

探针绑在数据坐标上，不是屏幕坐标。缩放或平移画布时，虚线跟着数据一起移动，屏幕上的位置变了，`Probe Value` 里的数值不动，读数也不变。

一个坐标系上可以同时存在多条探针，每一组都占表格里的一列。探针密到互相压住徽标时，可以把其中几列隐藏，既收起虚线，表格也短一些。

给探针精确命名和定位之后，探针可以当作一组固定的测量点长期留在图里，配合工程的保存机制反复使用。

## 已知限制

数据联动表不能导出，也不能从界面上复制内容。要把这些数值写进文件，只能对着屏幕抄下来，或者用 Python 从源数据重新算一遍。读数来自图上的采样点，和源数据框之间没有实时联系，重新算需要自己写插值。脚本环境见[脚本工作区](../script/workspace.md)。

界面里能创建的只有竖直探针，水平探针要由代码创建。探针只读曲线，其他图元在表里有行没有值。探针的线型和线宽固定，界面只能改颜色。

表格按绘图分页，跨绘图的读数不会汇总到同一个表里，要对比两张绘图的数据，需要在同一张图里排好坐标系，或者分别记录后自己整理。

探针是画在图上的图元，复制到剪贴板的截图里会带上这些虚线和徽标。要把干净的图交给别人，先把探针删掉或隐藏，再复制，见[复制与保存图表](./save.md)。

同一组探针的各条可以分别设置徽标样式、位置和颜色，改过之后同组的徽标可能长得不一样。给一个组留同一套外观更好读，需要区分时用颜色，不要用样式。

需要长期保留的读数建议留在图里，别急着把探针删掉。工程保存后这些位置和数值关系都在，下次打开继续用；删掉再想复现，只能凭记忆重新点一遍。

## 常见问题

**点了「Data Probe / 数据探针」之后在图上点没反应。** 先确认按的是这个按钮而不是旁边的标记线动作，按钮按下后是选中状态。其次确认绘图里有二维坐标系，探针只落在二维坐标系上，纯三维的绘图里点了不会产生探针。

**表格里某一格是空的。** 常见原因有三个：曲线在这个 X 值之外；曲线被设成了不可见；这一行对应的图元不是曲线，比如柱状或直方图。同一个坐标系上的曲线全部越界时，整列都可能是空的。

**徽标不见了，表格里还有这一列。** 探针页的 `Label Visible` 可能被关掉了，也可能是这个坐标系的下 X 轴和上 X 轴都被隐藏，徽标按规则跟着隐藏。打开任意一条 X 轴，徽标就回来。

**改完探针位置，表格里的数字没变。** 数字不会自动重算，在那一列的表头点一次「Refresh / 刷新」，或者在表头点「Refresh All / 刷新全部」。

**表格里的数字和数据框里的对不上。** 表格取的是图上采样点的插值结果，而图元保存的是建图时取到的采样点。数据框后来改过、或者曲线本身经过平滑拟合时，两边会有出入，以图上的读数为准。

**退出探针模式后画布拖不动了。** 探针模式关掉了缩放和平移，退出时不会自动恢复。到 Ribbon 的「Chart Style / 图表样式」页重新打开缩放和平移即可。

**一个绘图里点了一次，另一个绘图上没有出现探针。** 探针只落在当前绘图上，每个绘图有自己的探针表和表格标签页，切到另一个绘图再建一次。

**表格里的列顺序和点击顺序不一样。** 表格重建时列按探针的 X 值排，点击顺序只在同一批创建、没有重建过的时候才等于列顺序。想核对某一列是哪个位置，把光标停在表头看 X 值提示。

**复制到剪贴板的图上有虚线和徽标。** 探针是画在图上的图元，会一起被截进去。在表头把相关列隐藏，或者删掉探针，再复制一次。

**探针能当图中标注用吗。** 能看，但不合适。探针的线型和线宽固定，样式选择只有徽标，做标注用标记线或文字标注更灵活，见[二维图表设置](./settings-2d.md)。

**表格里需要的只有一列，其他列能不能去掉。** 用表头的「Hide / 隐藏」把不看的列收起来，虚线也跟着隐藏；确定不再需要的位置再用「Delete / 删除」清掉，删除会同时删掉图上的探针。

**缩放之后探针跑到别的位置了吗。** 没有。探针绑在数据坐标上，缩放和平移只改可见范围，虚线在屏幕上的位置变了，`Probe Value` 和读数都不变。放大后徽标可能移出画面被裁掉，缩回去就能看到。

**表格标签页的名字和绘图名字对不上。** 标签名在建表时取一次，之后改绘图名字不会同步过去。把表格标签页关掉，再建一个探针，标签会按当前图名重新生成。

**探针的虚线比曲线还显眼。** 换一个和曲线色系协调的 `Probe Color`，或者把不需要的列隐藏，图面会安静很多。
