# 三维图表设置

三维图表用的是和二维分开的一套设置控件，面板顶部的下拉框里换成三维自己的条目。除了图表外观和坐标系，三维还多出光照、投影、色图和一条颜色图例；三个三维图元各自还有一组专有参数。这一章按面板上的条目顺序讲每一项设置，最后交代视角怎么调、以及三维页和二维页的对应关系。

三维绘图区是一个独立的子图，和二维坐标系一样放在同一个绘图里，位置和大小用「Resize Chart / 绘图尺寸」浮层调整，可见[绘图与坐标系](./figure.md)。选中三维子图和选中二维坐标系时，右侧面板自动在两套设置控件之间切换，不用手动去找。

## 面板的条目

在「Charts Manager / 绘图管理」的树里展开 `3D Chart` 节点，点其中的坐标系或图元，右侧「Setting / 设置」面板就切到三维设置控件。下拉框的固定条目和对应对象如下。

| 条目 | 作用对象 |
|------|----------|
| `3D Chart Area` / 3D图表区 | 整个三维绘图区的标题、背景、投影、光照和主题 |
| `Coordinate System` / 坐标系 | 坐标架的样式、颜色、字体和刻度 |
| `X Axis` | X 方向的四条轴 |
| `Y Axis` | Y 方向的四条轴 |
| `Z Axis` | Z 方向的四条轴 |
| `Color Legend` / 颜色图例 | 数值与颜色对照的那条色条 |

固定条目之后是每个三维图元各占一行，名字取图元的标题，标题为空时显示 `Unnamed Item` / 未命名项。三维只有三种图元，建图向导里的名字是 `surface 3D` / 3D曲面、`bar 3D` / 3D柱状、`line 3D` / 3D线图，见[创建图表](./create.md)。

下拉框的条目随选中对象变化。六个固定条目始终在，图元行按当前三维绘图里的图元数量增减，图元被删除后对应的行消失。

面板本身仍是右侧「Setting / 设置」停靠面板，被「Agent / 智能体」或「Data Link Table / 数据联动表」挡住时，用 Ribbon 上的「Show Setting Window / 设置窗口」把它提到最前。

页面的切换跟随选中对象。在「Charts Manager / 绘图管理」的树里点 `3D Chart` 节点，面板停在 3D 图表区页；点图元节点，面板切到那个图元的页；改 X、Y、Z 三条轴则用下拉框切，树下虽有轴节点，点它不会直接跳到某个轴页面。

树里的三维条目标题没有填写时显示 `3D Item` / 3D图元，设置面板的下拉框里则显示 `Unnamed Item` / 未命名项，两处都是占位名字。给三维图元起一个标题，两边都会跟着变，见本章各图元页的 `Title` 字段。

三维视角不在这套面板里。想看侧面或背面，直接在绘图上按住鼠标拖动；软件里没有单独的旋转按钮，也没有为旋转定义键盘操作。要把视角复位，用 3D 图表区页上的 `Reset View` / 重置视图。

### 分组和编辑器

三维页面和二维页面共用同一套属性框架，页面是一列可以折叠的分组，每个字段按类型配一种编辑器。布尔项是复选框，枚举项是下拉框，数值项是带上下限的数字框，颜色、字体、画笔各开各的对话框。取值范围写在每一页的表格里，超出范围的值输不进去。

有些字段会随别的字段变灰。`Tic Length` 与 `Tic Length Scale` 之间、`Use Data Color` 与 `Solid Color` 之间、九宫格固定位置与四个绝对几何字段之间都是这种关系，字段变灰说明当前状态下它不起作用。

## 3D图表区（3D Chart Area / 3D图表区）

| 分组 | 设置 | 默认值 | 作用 |
|------|------|--------|------|
| `Title` / 标题 | `Title Text` | 空 | 三维绘图区的标题文字 |
| `Title` / 标题 | `Title Font` | 主题自带字体 | 标题字体 |
| `Title` / 标题 | `Title Color` | 主题自带颜色 | 标题颜色 |
| `Background` / 背景 | `Background Color` | 主题自带颜色 | 绘图区底色 |
| `Projection` / 投影 | `Projection` / 投影 | `Perspective` / 透视 | 透视或正交投影 |
| `Projection` / 投影 | `Aspect Ratio` / 纵横比 | `Auto Fill` / 自动填充 | 坐标轴的缩放方式 |
| `Lighting` / 光照 | `Enable Lighting` / 启用光照 | 关 | 打开或关闭光照 |
| `Lighting` / 光照 | `Lighting Preset` / 光照预设 | `No Lighting` / 无光照 | 五种光照方案 |
| `Lighting` / 光照 | `Shininess` / 光泽度 | 5 | 0 到 128 |
| `Lighting` / 光照 | `Specular Intensity` / 镜面强度 | 0.3 | 0 到 10 |
| `Theme` / 主题 | `Theme` / 主题 | `Default` / 默认 | 十种配色方案 |
| `Theme` / 主题 | `Reset View` / 重置视图 | 按钮 | 视角回到初始方向 |

`Projection` 有两个取值。`Perspective` / 透视 按近大远小绘制，画面有纵深感；`Orthographic` / 正交 用平行投影，同样长的线段在图上一样长，读数时不会因为远近产生错觉。要给读者量长度、比高低，用正交；要让画面显得有空间感，用透视。

`Aspect Ratio` 也有两个取值。`Auto Fill` / 自动填充 让三条轴各自缩放到填满画面，数据比例会被拉变形；`Data Ratio` / 数据比例 保留数据本身的纵横比例，长宽高差距大的数据看起来不会挤成一团。三列数据的量级相差很大时先切到 `Data Ratio`，确认形状没被拉伸后再考虑是否换回自动填充。

光照相关四项只有打开 `Enable Lighting` 之后才有作用。`Lighting Preset` 提供 `No Lighting` / 无光照、`Flat Light` / 平面光、`Studio` / 工作室、`Outdoor` / 户外、`Soft` / 柔和 五种方案，方案决定光源的方向与数量；`Shininess` 控制高光斑的大小，数值越大高光越集中；`Specular Intensity` 控制高光的强度，填 0 就没有高光。曲面和柱体在光照下才有明暗过渡，线图不受影响。

`Shininess` 和 `Specular Intensity` 都存在主题里，换主题时会按新主题的值覆盖，选 `Dark` 一类预设时这两个值会跟着变。四个字段都调过还看不出差别时，先确认 `Enable Lighting` 是打开的，再确认当前看的是曲面或柱体，线图本身没有明暗面。

`Theme` 的十个取值是 `Default` / 默认、`Dark` / 暗色、`Scientific` / 科学、`Warm` / 暖色、`Cool` / 冷色、`Matplotlib` / Matplotlib、`Earth Tones` / 大地色、`Ocean` / 海洋、`High Contrast` / 高对比、`Presentation` / 演示。主题一次改掉背景、轴颜色、文字颜色、网格颜色和光照预设，换主题后如果面板上的颜色项和画面对不上，以画面上的为准，再按这一页和坐标系页逐项微调。

换主题的影响范围比看上去大：它会按预设同步打开或关闭光照，并把曲面的绘图样式、着色、网格颜色、网格线宽、色图改写一遍，柱体的柱样式和网格也跟着改。因此主题适合在动手调细节之前选好，调完单项外观再换主题，之前的改动会被覆盖。要保留调好的外观，就不要再换主题。

标题在绘图区上方居中显示，`Title Text` 留空时不显示。字体和颜色写进主题，换主题时会被主题的值覆盖，所以调好标题后不要再换主题。`Background Color` 是整块三维画面的底色，深色底色配浅色轴线读起来更省眼睛，投影到纸面时浅色底色更省墨。

`Theme` 分组末尾的 `Reset View` / 重置视图 是一个按钮而不是数值，点了立即执行。它把旋转、平移和缩放一起复位，视角回到刚创建时的方向，不影响数据范围和其他设置。

## 坐标系（Coordinate System / 坐标系）

这一页管整个坐标架，四条轴共用的部分都在这里。

| 分组 | 设置 | 默认值 | 作用 |
|------|------|--------|------|
| `Style` / 样式 | `Style` / 样式 | `Box` / 盒形 | 坐标架样式，可选 `None` / 无、`Box` / 盒形、`Frame` / 框架 |
| `Colors` / 颜色 | `Axes Color` / 轴颜色 | 主题自带 | 轴线颜色 |
| `Colors` / 颜色 | `Number Color` / 数字颜色 | 主题自带 | 刻度数字颜色 |
| `Colors` / 颜色 | `Label Color` / 标签颜色 | 主题自带 | 轴标签文字颜色 |
| `Colors` / 颜色 | `Grid Lines Color` / 网格线颜色 | 主题自带 | 贴在各侧面上的网格颜色 |
| `Colors` / 颜色 | `Interior Grid Color` / 内部网格颜色 | 主题自带 | 坐标架内部的网格颜色 |
| `Fonts` / 字体 | `Number Font` / 数字字体 | 主题自带 | 刻度数字字体 |
| `Fonts` / 字体 | `Label Font` / 标签字体 | 主题自带 | 轴标签文字字体 |
| `Ticks` / 刻度 | `Tic Length` / 刻度长度 | 0 | 0 到 100 |
| `Ticks` / 刻度 | `Tic Length Scale` / 刻度缩放 | 0.015 | 0 到 1 |
| `Ticks` / 刻度 | `Auto Scale` / 自动缩放 | 开 | 坐标轴范围自动跟随数据 |
| `Ticks` / 刻度 | `Auto Decoration` / 自动装饰 | 开 | 自动决定刻度与轴线的画法 |
| `Ticks` / 刻度 | `Tick Position` / 刻度位置 | `Bottom` / 底部 | `Bottom` / 底部、`Top` / 顶部 |
| `Interior Grid Width` / 内部网格线宽 | `Interior Major Width` / 内部主网格线宽 | 0.5 | 0.1 到 10 |
| `Interior Grid Width` / 内部网格线宽 | `Interior Minor Width` / 内部次网格线宽 | 0.3 | 0.1 到 10 |
| `Line` / 线 | `Line Smooth` / 线平滑 | 开 | 轴线抗锯齿 |

`Style` 选 `None` 时坐标架完全不画，只剩数据本身；`Box` 画一个完整的长方体框，十二条棱都有轴线；`Frame` 只画看得见的三条轴，其余棱线留空。换样式后轴标签和刻度数字的摆放也会跟着变。新建的三维坐标系默认用 `Box` / 盒形，数据被框住时视野更完整；要画面更轻就换 `Frame` / 框架。

`Colors` 分组的五项各管一处：`Axes Color` 是轴线和棱线的颜色，`Number Color` 是刻度数字，`Label Color` 是轴标签文字，`Grid Lines Color` 是贴在侧面上的网格线，`Interior Grid Color` 是坐标架内部贯穿整个空间的网格线。深色主题下默认值是浅灰和白色，浅色主题下是黑色系，逐项改之前先看画面上的层次。

`Fonts` 分组的两个字段分别设刻度数字和轴标签的字体，字号写小一点可以把密集的标签塞进画面。数字和标签两类文字用的是两套字体设置，改一处不会带上另一处。

刻度长度有两种定法。默认走自动模式，`Tic Length Scale` 是自动刻度长度，含义是刻度长度占该轴数据范围的比例，默认 0.015，改它等于把自动刻度整体放大或缩小。`Tic Length` 显示的是显式长度，自动模式下为 0；在这一项里填一个值就切到显式模式，刻度长度固定为填的数，填 0 时刻度短到看不见。想退回自动模式，把 `Tic Length Scale` 重新设一次即可，哪怕填的还是 0.015，这一动作会清掉显式长度。

`Auto Scale` 关掉后坐标轴范围不再随数据变化，改由下文的轴页面手工设定。`Auto Decoration` 关掉后刻度数字不再自动避让，重叠时也不会挪位置。`Tick Position` 决定刻度画在视觉上偏低的那条轴还是偏高的那条轴上，转动视角后哪条轴在下面会变，刻度跟着走。

内部网格是画在坐标架内部、贯穿整个三维空间的那层网格，`Interior Grid Width` 分组分别给主网格和次网格设线宽，取值都是 0.1 到 10。内部网格和轴页面里的网格不是一回事：轴页面的网格贴在坐标架的侧面上，内部网格穿过整个空间，密度大时画面会显得很乱。`Line Smooth` 打开后轴线用抗锯齿绘制，线条在斜视时更平滑。

`Auto Decoration` 关闭后，刻度的摆放和轴线装饰不再自动调整，画面可能出现和预期不同的刻度位置。除非专门为了复现某个布局，这一项保持打开。`Tick Position` 改的是刻度相对轴线的朝向，同一个方向的不同棱可以设成不同的值，混用时画面会显得不对称，三条可见轴取同一个值更整齐。

## X 轴、Y 轴、Z 轴

三个方向的轴各有一页，页面内容相同。三维里每个方向都有四条棱可以当轴，页面顶部的 `Axis` / 轴 下拉框用来选择设置哪一条，选项名为 `X1` 到 `X4`、`Y1` 到 `Y4`、`Z1` 到 `Z4`。转动视角后四条棱的可见性会变化，想给某个立面上的刻度改标签，就在这一页换 `Axis` 再改。

X、Y、Z 三页的区别只在方向：X 轴页设置的所有棱都沿 X 方向延伸，Y 轴页沿 Y 方向，Z 轴页沿 Z 方向。数据量级差得远时，三条轴的刻度数量最好分别设置，避免某一方向的标签挤在一起。

棱转到背面被数据挡住时，改动它的标签、颜色和刻度在画面上看不到效果，因为这条棱当前不可见。改之前先把视角转回能看见这条棱的角度，确认改动生效后再转回去。

| 分组 | 设置 | 默认值 | 范围或可选值 |
|------|------|--------|--------------|
| `Axis Selector` / 轴选择 | `Axis` / 轴 | 第一条 | X1 到 X4、Y1 到 Y4 或 Z1 到 Z4 |
| `Label` / 标签 | `Label Text` / 标签文本 | 空 | 这条轴的标签文字 |
| `Label` / 标签 | `Label Font` / 标签字体 | 主题自带 | 字体对话框 |
| `Label` / 标签 | `Label Color` / 标签颜色 | 主题自带 | 颜色对话框 |
| `Numbers` / 数字 | `Number Font` / 数字字体 | 主题自带 | 字体对话框 |
| `Numbers` / 数字 | `Number Color` / 数字颜色 | 主题自带 | 颜色对话框 |
| `Range` / 范围 | `Min Range` / 最小范围 | 0 | −1e15 到 1e15，保留 5 位小数 |
| `Range` / 范围 | `Max Range` / 最大范围 | 0 | −1e15 到 1e15，保留 5 位小数 |
| `Range` / 范围 | `Major Count` / 主刻度数 | 0 | 0 到 100 |
| `Range` / 范围 | `Minor Count` / 次刻度数 | 0 | 0 到 100 |
| `Appearance` / 外观 | `Line Width` / 线宽 | 1 | 0.1 到 10，保留 2 位小数 |
| `Appearance` / 外观 | `Tick Position` / 刻度位置 | `Bottom` / 底部 | `Bottom` / 底部、`Top` / 顶部 |
| `Appearance` / 外观 | `Smooth Line` / 平滑线 | 关 | 开或关 |
| `Grid` / 网格 | `Major Grid` / 主网格线 | 关 | 开或关 |
| `Grid` / 网格 | `Minor Grid` / 次网格线 | 关 | 开或关 |
| `Grid` / 网格 | `Grid Color` / 网格颜色 | 主题自带 | 颜色对话框 |

`Min Range` 和 `Max Range` 是这条轴的数据上下限，改一端时另一端保持不动。自动缩放关闭时这两项必须自己填，否则轴范围会和数据对不上。`Major Count` 和 `Minor Count` 是主次刻度的数量，填得越多格线越密，标签也越容易挤在一起。

`Line Width` 是这条轴轴线的粗细，`Smooth Line` 是它的抗锯齿开关，和坐标系页上的 `Line Smooth` 一起决定轴线的观感。`Tick Position` 和坐标系页上的同名项含义一致，轴页面里的这一项只作用于当前选中的这条棱。

`Numbers` 分组的两个字段只管刻度数字，字体调小可以缓解相邻刻度文字重叠；`Label` 分组里的字体和颜色只管轴标签那行字，两组设置互不干扰。三者都改完也看不出区别时，检查 `Auto Decoration` 是不是被关掉了，关掉后刻度的摆放需要靠自动缩放和数量一起配合。

`Major Count` 和 `Minor Count` 是主次刻度的数量。填 0 或负数会被当成 1，也就是这条轴只留一条主刻度。自动缩放打开时，主刻度数量由自动算法按数据范围推算，面板上填的值会被改写；要固定刻度数量，先关掉坐标系页的 `Auto Scale`，再回来填这两项。

`Grid` 分组里的字段作用在整个坐标架上，不区分是哪条棱：`Major Grid` / 主网格线 打开主网格，`Minor Grid` / 次网格线 打开次网格，`Grid Color` / 网格颜色 是格线颜色。三个方向的轴页面读到的是同一份状态，在 X 轴页打开主网格，切到 Y 轴页也会看到它已经打开。坐标系页的 `Grid Lines Color` / 网格线颜色 和这里的 `Grid Color` 改的是同一处颜色。曲面、柱体这类有体积的图元打开格线后能看清空间位置，线图打开太多格线反而更乱，按图的用途取舍。

颜色还有一个覆盖关系要留意。坐标系页的 `Axes Color`、`Number Color`、`Label Color` 会一次性写给十二条棱，之前逐条改过的颜色被覆盖；轴页面里的同名颜色只写给当前选中的那条棱。想给某一条棱单独配色，先把坐标系页的颜色定下来，再去轴页面微调。

## 颜色图例（Color Legend / 颜色图例）

颜色图例把数值和颜色对应起来，只在图元按色图着色时有意义，比如 3D曲面的色图、3D柱状和 3D线图的色图。

| 分组 | 设置 | 默认值 | 作用 |
|------|------|--------|------|
| `Display` / 显示 | `Visible` / 显示 | 关 | 显示或隐藏图例 |
| `Position` / 位置 | `Position` / 位置 | `Custom` / 自定义 | 九个固定位置或自定义 |
| `Position` / 位置 | `Absolute X` / 绝对位置X | 图例当前的横坐标 | 0 到 9999，仅在自定义时可用 |
| `Position` / 位置 | `Absolute Y` / 绝对位置Y | 图例当前的纵坐标 | 0 到 9999，仅在自定义时可用 |
| `Position` / 位置 | `Absolute Width` / 绝对宽度 | 图例当前的宽度 | 1 到 9999，仅在自定义时可用 |
| `Position` / 位置 | `Absolute Height` / 绝对高度 | 图例当前的高度 | 1 到 9999，仅在自定义时可用 |

四个绝对几何字段里显示的是图例当前的像素矩形，面板打开时按图例的实际位置填进去，改它就等于把图例搬到新的位置。

九个固定位置是 `Top Left` / 左上、`Top Center` / 上中、`Top Right` / 右上、`Left Center` / 左中、`Center` / 居中、`Right Center` / 右中、`Bottom Left` / 左下、`Bottom Center` / 下中、`Bottom Right` / 右下。选这些位置时四个绝对几何字段是灰的，图例按绘图区尺寸自动摆放。

把位置改成 `Custom` / 自定义后四个字段变亮，可以按像素给图例指定位置和尺寸。四个值分别是从左边缘起的横坐标、从上边缘起的纵坐标、宽度和高度，坐标和尺寸都以绘图区为参照。图例挡在数据上时，用自定义把它挪到空白处最直接。

色条本身带着一条刻度轴，数值沿色带排列，默认刻度在左侧、数值自下而上增大。刻度的方向和位置没有对应的面板字段，需要改色条的读数方式时，只能靠换色图和调整数据范围来间接处理。色条上的数字随色图和数据范围一起变，两个曲面的数据范围不同，同一个位置的颜色代表的数值也不同。

九个固定位置按画布的四角和四边摆放，选哪一项取决于数据堆在画面哪一侧。色条放左上或右上最不容易挡数据；线图轨迹偏斜时，色条放在轨迹的对角。宽度和高度只在自定义模式下才有意义，默认的色条是细长条，改宽会让它更像一块色块而不是一条刻度。

图例默认是隐藏的，画面上没有色条时先到这一页打开 `Visible`。打开后如果色条位置压在曲面上，先试九个固定位置中离数据最远的一个，再考虑 `Custom`。

## 三维图元页

三个三维图元的设置页结构相近：开头一个 `General` / 通用 分组放 `Title` / 标题，后面按这个图元能调的部分分组。三维图元不参与图例的图元对照，它们的颜色信息由颜色图例承担。页面里没有画笔、画刷这类二维专有的字段，颜色统一用色图、网格色和纯色三种方式给出。

下面按图元逐个列分组，把取值范围补在正文里。三个页面的默认外观都来自当前主题：不换主题时，曲面和柱体都是用 `Gouraud` / 平滑 着色、`Filled Mesh` / 填充网格 绘制的默认配色，线图是一条默认粗细的实线。

## 3D曲面（3D Surface / 3D曲面）

曲面用一张网格数据画出一张起伏的曲面，设置页的分组最全。

| 分组 | 设置 | 默认值 |
|------|------|--------|
| `General` / 通用 | `Title` / 标题、`Plot Style` / 绘图样式 | 图元标题为空，绘图样式为 `Filled Mesh` / 填充网格 |
| `Style` / 样式 | `Shading` / 着色、`Polygon Offset` / 多边形偏移、`Resolution` / 分辨率 | `Gouraud` / 平滑、0.5、1 |
| `Color` / 颜色 | `Colormap` / 色图、`Mesh Color` / 网格颜色、`Mesh Line Width` / 网格线宽 | `viridis`、黑色、1 |
| `Isolines` / 等值线 | `Isolines Count` / 等值线数量、`Smooth Mesh` / 平滑网格 | 0、关 |
| `Floor` / 底面投影 | `Floor Style` / 底面样式 | `None` / 无 |
| `Normals` / 法线 | `Show Normals` / 显示法线、`Normal Length` / 法线长度、`Normal Quality` / 法线质量 | 关、0.02、3 |

`Plot Style` 有五个取值，都画同一份数据，只是表现方式不同。`Wireframe` / 线框 只画网格线，像一张铁丝网，适合看数据点的密度；`Hidden Line` / 隐藏线 也在画网格线，被曲面挡住的线不再画出来，前后关系更清楚；`Filled` / 填充 用颜色铺满整个曲面，不画网格线；`Filled Mesh` / 填充网格 在填充的曲面上再叠一层网格线，既有体积感又能看清网格；`Points` / 点 只在数据点位置画点。软件默认用填充网格，兼顾体积和网格。

`Shading` 决定曲面的明暗怎么算。`Flat` / 平面 给每个小面片一个统一颜色，面片之间的过渡能看到明显棱角；`Gouraud` / 平滑 在顶点之间插值，表面看起来连续光滑，新建的曲面默认用平滑。数据本身起伏不大时，`Gouraud` 的效果更接近书本上的曲面图。

`Polygon Offset` 的取值是 −10 到 10，默认 0.5，用来在填充面上再画网格线或等值线时把后画的图形往外或往里挪一点，避免两条线叠在一起互相闪烁。`Resolution` 是绘制时取的网格步长，默认 1 表示用全部网格点，数值调大后每隔几行几列取一个点，面片变大、画面变快，代价是细节丢失。

`Colormap` 决定曲面的高度映射到哪条色带，可选色图有 `viridis`、`plasma`、`inferno`、`magma`、`cividis`、`jet`、`cool`、`hot`、`hsv`、`spring`、`summer`、`autumn`、`winter`、`gray`、`bone`、`copper`、`pink`、`seismic`、`turbo`、`terrain`、`ocean`、`gist_rainbow`，共 22 条。色图是一张从最小值到最大值的颜色对照表，曲面上的每个点按自己的数值去表上取一个颜色，画出来就能同时看出高度和分布。`viridis` 一类的连续色带亮度变化均匀，转成灰度打印后仍然能分辨高低；`jet`、`hsv` 一类的彩虹色带颜色跳变多，界线清楚但不适合灰度输出。`Mesh Color` 和 `Mesh Line Width` 是网格线自己的颜色和粗细，取值 0.1 到 10，默认 1。

色图上取到的颜色顺序和数据范围的上下限有关：数值最小的位置取色带一端，最大的取另一端。打开颜色图例后，色条上的数字就是这份对照关系的刻度。

`Isolines Count` 的取值范围是 0 到 50，默认 0，填正数后在曲面上画出这么多条等值线，把相同高度的位置连起来；`Smooth Mesh` 打开后等值线经过的网格被平滑处理，线条更顺。

`Floor Style` 决定底面投影，三个取值是 `None` / 无、`Iso` / 等值线、`Data` / 数据。`Iso` 把等值线投到底面上，像地形图的等高线；`Data` 把整个曲面按颜色压平投到底面。底面投影的作用是让立体形状在上方视角下也能估出平面分布，配合低角度视角看起伏效果最好。

`Show Normals` 打开后在曲面上画出法线向量，`Normal Length` 是相对长度，范围 0 到 1，默认 0.02；`Normal Quality` 是法线箭头的绘制精细度，默认 3，最小也要 3，数值越大越圆滑。法线主要用来检查曲面朝向和光照是否正确，正常出图时保持关闭。

## 3D柱状（3D Bar / 3D柱状）

柱状用一列数值或一张矩阵画成一排立体的柱子。

| 分组 | 设置 | 默认值 |
|------|------|--------|
| `General` / 通用 | `Title` / 标题 | 图元标题 |
| `Style` / 样式 | `Bar Style` / 柱样式 | `Filled Mesh` / 填充网格 |
| `Size` / 尺寸 | `Bar Width` / 柱宽、`Bar Depth` / 柱深 | 0，表示自动 |
| `Size` / 尺寸 | `Baseline` / 基线 | 0 |
| `Color` / 颜色 | `Colormap` / 色图、`Mesh Color` / 网格颜色、`Mesh Line Width` / 网格线宽 | `viridis`、黑色、1 |

`Bar Style` 的三个取值是 `Filled` / 填充、`Filled Mesh` / 填充网格、`Wireframe` / 线框，含义和曲面页的同名样式一致，都只改外观，不改柱高。软件默认用填充网格。

`Bar Width` 和 `Bar Depth` 是柱体底面的宽和深，取值 −1 到 10，新建的柱体显示 0。填 0 或负值表示自动，柱体宽度按相邻数据点的间距来定，大约是间距的八成；填正值就用这个值当柱宽，柱与柱之间会留下空隙。`Baseline` 是柱体底面的高度，范围 −1e9 到 1e9，默认 0，整列数据都比基线高或都低时靠它决定柱子从哪一层长起。

`Colormap` 决定柱体高度映射到哪条色带，可选的 22 条和曲面页一致。柱体用色图着色后，高低差别一眼能看出来，不用读数字；色带的两端取画面里 Z 方向的最小值和最大值，柱子越高颜色越靠色带的上端。

`Mesh Line Width` 的取值是 0.1 到 10，默认 1，在画网格线的样式下才看得出来，也就是 `Filled Mesh` / 填充网格 和 `Wireframe` / 线框。`Mesh Color` 是网格线颜色，默认黑色，浅色柱体配深色网格线最清楚。柱宽、柱深都是 2 位小数的字段，基线是 4 位小数。

## 3D线图（3D Line / 3D线图）

线图把 X、Y、Z 三列数据连成一条空间曲线。

| 分组 | 设置 | 默认值 |
|------|------|--------|
| `General` / 通用 | `Title` / 标题 | 图元标题 |
| `Line` / 线条 | `Line Style` / 线样式、`Line Width` / 线宽、`Tube Radius` / 管半径、`Tube Segments` / 管段数 | `Lines` / 线条、1、−1（自动）、8 |
| `Points` / 点 | `Show Points` / 显示点、`Point Size` / 点大小、`Point Shape` / 点形状 | 关、8、`Dot` / 圆点 |
| `Color` / 颜色 | `Use Data Color` / 使用数据着色、`Solid Color` / 纯色、`Colormap` / 色图 | 关、浅灰、`viridis` |

`Line Style` 有三个取值。`Lines` / 线条 画一条普通的折线，最快也最省资源，新建的线图默认用它；`Tube` / 管状 把曲线画成一根有粗细的管子，立体感强，适合放到论文里；`Dots` / 点 只画离散的点，用来强调采样位置。`Line Width` 的取值是 0.5 到 20，默认 1，只在 `Lines` 样式下起作用。`Tube Radius` 的取值是 −1 到 5，默认 −1，填负值表示自动，管径按包围盒对角线的一个比例算；`Tube Segments` 是管子横截面的段数，取值 3 到 64，默认 8，调大后管子更圆。

`Show Points` 打开后在每个采样点位置加一个几何体，默认关闭。`Point Size` 的取值是 1 到 50，默认 8；`Point Shape` 可选 `Dot` / 圆点、`Cube` / 立方体、`Tetrahedron` / 四面体、`Octahedron` / 八面体、`Sphere` / 球体，默认用圆点。点的形状在 `Lines` 和 `Tube` 样式下也能显示，用来标出采样位置。

颜色有三个选项。`Use Data Color` 打开后曲线按数据位置取色图上的颜色，逐点着色，颜色变化本身也能表达信息；关掉后整条曲线用 `Solid Color` 指定的单一颜色，默认是一支浅灰色。`Colormap` 只在打开 `Use Data Color` 时可改，关掉后这个字段变灰。

线图没有网格和面片，因此设置页里没有分辨率、等值线、底面投影和光照相关的项。想让线图显得立体，用 `Tube` / 管状 样式把线加粗，或者打开 `Show Points` 用球体标出采样点。

## 视角与复位

三维图上的鼠标操作用于改变观察角度，包括转动、平移和缩放，转动时数据本身不动。软件里没有单独的旋转按钮，也没有为旋转定义键盘操作，全部靠鼠标完成。三轴的方向意义会随视角变化：转到背面时原本向上的轴可能指向另一侧，读数前先看清轴标签。

三维画面里的位置感和真实距离不完全一致，尤其在透视投影下，靠前的小柱子可能看起来比靠后的大柱子矮。要比高低就切到 `Orthographic` / 正交，或者打开颜色图例按颜色读数。

`Reset View` / 重置视图 在 3D 图表区页的 `Theme` 分组里，是一个按钮，点一下把旋转、平移和缩放一起清零，视角回到刚创建时的方向。改坏了角度就点一次复位再重新转。视角和纵横比随工程一起保存，重新打开工程后画面回到保存时的角度，见[复制与保存图表](./save.md)。

## 三维图元和数据的关系

三种三维图元在建图向导里的数据要求不同，设置页上的参数都作用在已经取到的数据上，改数据要重新建图元。

**3D曲面** 有两种数据模式。`Grid (DataFrame as Z matrix)` 把整张数据框当成 Z 矩阵，行和列自动成为 Y 和 X，适合一张规整的二维表；`Scatter (X/Y/Z columns)` 指定三列，分别当 X、Y、Z。曲面适合画连续变化的场，比如地形、温度场、响应面，网格越密曲面越光滑。曲面页的 `Resolution`、`Isolines Count`、`Shading` 都作用在这份网格数据上。

**3D柱状** 也有两种数据模式。`1D Series (one column)` 用一列数值画出一排柱子；`2D Grid (DataFrame as Z matrix)` 把数据框当 Z 矩阵，行和列成为两个水平方向的坐标，柱高由矩阵值给出。另有一个 `Value Column` 指定取值的列。柱状适合离散的、逐个可数的数据，比如各分组的统计量，柱子之间留出的空隙本身也是信息。柱宽、柱深和基线都作用在柱体的几何形状上。

**3D线图** 需要 X、Y、Z 三列，把点按顺序连成一条空间曲线。线图没有网格，因此没有分辨率、等值线和底面投影这些设置，只有线样式、点和颜色三组。

三个图元的设置页里都有 `Title` / 标题，这是它们的公共字段，改标题会同步到绘图管理树和面板下拉框。三维图元页没有二维那样的 `Z Value` 排序和 `X Axis`、`Y Axis` 选择，三维图元都挂在同一个坐标架上，层叠顺序由各自的数据位置决定。

图元创建后保存的是采样点的副本，之后到数据管理面板里改数据框，图上的三维图形不会跟着变。要换数据就重新走一遍建图向导，见[创建图表](./create.md)。

## 性能、视角与保存

画面卡顿时先看三个数值：曲面页的 `Resolution` 调大可以把网格抽稀，`Isolines Count` 从几十调到 0 可以省掉等值线；线图页的 `Tube Segments` 和 `Point Size` 在点数很多时也会拖慢绘制。这些选项互换的是精细度和流畅度，出图定稿时再调回精细值。三维画面随视角转动实时重绘，先把数据量相关的参数调顺，再慢慢转视角比对，比转不动了再回头调省事。

颜色图例在曲面和柱体上用得最多，打开 `Visible` 后先看它是不是挡在数据上，再用 `Custom` 位置把色条挪到空白处。图例显示的数值范围取当前数据的取值范围，改数据范围后色条上的数字跟着变。

视角、纵横比和三维图元的参数都随工程保存，重新打开工程时画面回到保存时的状态，见[复制与保存图表](./save.md)。三维图表和二维图表可以在同一个绘图里共存，切换选中对象时设置面板会自动在三维控件和二维控件之间切换。

## 几张图的具体调法

下面三种走法都只用本章讲过的设置，可以照顺序做完。

### 一张曲面图

第一步是建图。在 Ribbon 的「Figure / 绘图」页点 `Add Chart` 里的 3D曲面，在向导里把数据框当 Z 矩阵，或者在 `Scatter (X/Y/Z columns)` 模式里指定三列，确认后绘图里出现一个三维坐标系。第二步定基调：在 3D图表区页选一个主题，打开 `Enable Lighting`，`Lighting Preset` 按需要选 `Studio` / 工作室 或 `Soft` / 柔和，`Shininess` 和 `Specular Intensity` 先留默认值。第三步定画法：在曲面页选 `Plot Style`，要网格和体积都有就选 `Filled Mesh` / 填充网格，只要干净的色面就选 `Filled` / 填充，`Shading` 用 `Gouraud` / 平滑 让表面过渡自然。

第四步补信息：把 `Isolines Count` 设成 10 到 20 之间，画面上出现高度相同的等值线；`Floor Style` 选 `Iso` / 等值线，底面出现投影，上方视角下也能读出平面分布。第五步写标签：在坐标系页把三个方向的轴标签填上，字体调小一号，数字颜色比轴线略深。第六步补色条：在颜色图例页打开 `Visible`，位置先试九个固定位置中不挡数据的一项，挡到数据就改成 `Custom` / 自定义 再用四个绝对几何字段挪开。

第七步收尾：按住鼠标把视角转到能看清起伏的角度，画面太密时把 `Resolution` 调大一位数看速度是否变好，定稿前再用 `Reset View` 回到标准视角比对一次。最后复制到剪贴板，见[复制与保存图表](./save.md)。

### 一张柱状图

柱子图和曲面图的差别在数据形态，外观上的调法大致相同。用一列数值建图后，先在 3D图表区页定主题和光照，再到 3D柱状页选 `Bar Style`，需要看清楚柱子之间的缝隙就用 `Filled` / 填充，需要强调网格线就用 `Filled Mesh` / 填充网格。柱宽和柱深留 0 让程序按间距自动定，数据点很多时自动值会把柱子压得很细，这时把 `Bar Width` 和 `Bar Depth` 填成同一量级的值，柱子形状更容易辨认。

数值有正有负时把 `Baseline` 设在 0，柱子从零平面往上或往下长；整列数据都远离 0 时把基线挪到数据附近，否则柱子会被拉得很长。想看高低分布就打开颜色图例，柱子按高度取色后不用逐个读刻度。最后在 X、Y 轴页面把两个水平方向的标签写上，柱状图的两个水平轴分别对应行和列，标签写错会让读者理解成相反的方向。

### 一张线图

线图的数据是 X、Y、Z 三列，先确认这三列的先后顺序对得上想要的轨迹。线样式按用途选：看趋势用 `Lines` / 线条，点数不多时打开 `Show Points` 并把 `Point Shape` 换成 `Sphere` / 球体，采样位置一目了然；要把曲线做成主视觉，选 `Tube` / 管状 再把 `Tube Radius` 调到 0.2 到 0.5 之间、`Tube Segments` 调到 12 以上，管子表面才圆滑。

颜色上先决定要不要按数值着色：轨迹颜色本身就是数据时打开 `Use Data Color` 并挑一条色图；只是想突出这条线时关掉它，用 `Solid Color` 挑一个和背景对比强的颜色。线图没有底面投影和等值线，剩下的功夫花在视角上：空间曲线常常要从两个角度各看一次才能确认走向，转好后用 `Reset View` 记不住就复制一张图下来。

## 三维页和二维页的对照
三维和二维的设置分属两套控件，但不少项目是对应的，找不到某个参数时可以照这张表去另一套里找。

| 想改的东西 | 二维位置 | 三维位置 |
|------------|----------|----------|
| 图题 | 图表区页的 `Title Text` | 3D图表区页的 `Title Text` |
| 底色 | 绘图区页的 `Background Brush` | 3D图表区页的 `Background Color` |
| 轴标签和字体 | 四条轴页面的 `Label` 分组 | 坐标系页的 `Fonts` 与 X、Y、Z 轴的 `Label` 分组 |
| 刻度范围 | 轴页面的 `Min Scale`、`Max Scale` | 轴页面的 `Min Range`、`Max Range` |
| 网格 | Ribbon 的 `Enable Grid` 加网格图元 | 轴页面的 `Grid` 分组加坐标系页的内部网格线宽 |
| 图例 | 图例图元的设置页 | 颜色图例页 |
| 图元外观 | 各图元自己的设置页 | 3D曲面、3D柱状、3D线图的设置页 |

## 面板里没有的设置

三维面板只覆盖三维对象自己的参数，下面这些项容易以为在这里能找到。

| 想要的效果 | 实际入口 |
|------------|----------|
| 对数刻度 | 界面里没有，只能靠脚本 |
| 三维坐标架的尺寸或位置 | 不在设置面板，用「Resize Chart / 绘图尺寸」浮层拖动调整 |
| 三维图元导出成位图或矢量图 | 没有这项设置，只能复制到剪贴板，见[复制与保存图表](./save.md) |
| 色条刻度的方向和位置 | 没有这项设置，色条按默认方向排列 |
| 把三维图上的数值导出成表 | 没有这项设置，见[数据探针与数据联动表](./data-probe.md) |

复制到剪贴板会把三维画面按当前屏幕尺寸截成位图，视角、主题、光照和色条都反映在截图上，分辨率由屏幕决定。

## 常见问题

**颜色图例的四个绝对位置输入框是灰的。** 把 `Position` / 位置 改成 `Custom` / 自定义后它们才会启用，九个固定位置下图例的几何由绘图区自动决定。

**改了主题，面板里的颜色项和画面对不上。** 主题会一次性改写坐标系颜色和光照预设，改完之后单独调过的颜色项和主题值可能不一致，画面以最后一次改动为准。要统一视觉，先定主题，再调单项。

**三维图元的轴标签改了没反应。** 每个方向有四条棱，页面顶部的 `Axis` / 轴 决定当前编辑哪一条。标签只写在选中的那条棱上，转动视角换到另一条棱后需要重新选 `Axis`。

**打开光照后线图没有变化。** 光照作用在有面片和法线的曲面与柱体上，3D线图页里没有光照相关的项，打开或关闭光照不会改变线的明暗。要让线图显得立体，改用 `Tube` / 管状样式并调大 `Tube Radius`。

**`Resolution` 改了画面看不出差别。** 这一项只在数值大于 1 时按步长抽稀网格，取 1 时不动数据。数据本身网格点不多时，抽稀后的面片数量变化不明显，数据越密，画面变化越明显。

**曲面的等值线开着但看不见。** 等值线按网格上的数值画，数据起伏很小或者色带和底色的对比太弱时不容易分辨。先把 `Isolines Count` 调大几位看线条是否出现，再换一条对比更强的色图。

**换了 `Data Ratio` 之后图形变小了。** 这个模式按数据本身的长宽高比例绘制，三种量的量级相差很大时，其中两个方向会被压扁，画面里就空出一块。要填满画面就换回 `Auto Fill` / 自动填充，或者调整数据的取值范围让三个方向量级接近。

**面板上没有画笔和填充这些项。** 三维图元不用二维的画笔、画刷，颜色由色图、网格颜色和纯色三处给出。想改曲面或柱体的颜色，从 `Colormap` 里换一条色图；想改网格线，用 `Mesh Color` 和 `Mesh Line Width`。

**三维图和二维图能不能放在同一个绘图里。** 可以。新建三维图表时如果当前绘图已经有二维坐标系，三维子图和它并排；两个子图各自选中、各自设置，复制到剪贴板时整张绘图一起截取。

**调完的曲面样式被换掉了。** 换主题会把曲面的绘图样式、着色、网格和色图一起改写，也会改写柱体的柱样式。要保住调好的外观，先把主题定下来再调单项，中途不要再换主题；已经换了就按本章的分组重新调一遍。
