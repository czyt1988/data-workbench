# 缩放与取值

画出一张图之后，接下来的动作大多落在画布上：把画面放大到关心的区间、拖着画面看别的部分、把鼠标停在一个点上读出坐标、把某条曲线或者某个标注挑出来单独设置。这一章讲这些鼠标操作，以及能做到什么程度。

Ribbon 上的相关按钮集中在「Chart」/ 绘图 上下文标签的两个页面里：「Chart Style」/ 图表样式 页的「Chart Setting」/ 绘图设置 面板管缩放、拖动、网格、拾取器和图例，「Chart Edit」/ 绘图编辑 页的「Select Tool」/ 选区工具 和「Chart Assist Tool」/ 图表辅助工具 面板管图元的选中、移动和标注。这个上下文标签在绘图区被激活时出现。

## 缩放和平移

缩放和平移是一对互斥的开关，同一个坐标系上只能打开一种。

- 「Zoom」/ 缩放 打开框选缩放。打开缩放会把拖动关掉。
- 「Pan」/ 拖动 打开平移。打开拖动会把缩放关掉，画布上的鼠标变成张开的手形。
- 拖动过程中光标变成握紧的手形，松开恢复张开手形；关闭拖动后光标回到箭头。

### 框选缩放

「Zoom」/ 缩放 打开之后，在画布上按住鼠标左键拖出一个矩形，松开鼠标，矩形覆盖的范围成为新的坐标轴范围。矩形太小会被忽略，缩放器要求框出的矩形边长大于一个小阈值才生效。

框出来的范围同时作用于这个坐标系的所有坐标轴，包括上、下、左、右四条。

### 滚轮缩放

鼠标滚轮在画布上滚动即可缩放，这个功能默认开启，不需要先打开「Zoom」。滚轮以鼠标所在位置为中心缩放，光标停在哪里，缩放就以哪里为基准，比框选更适合连续微调。

### 按比例缩放和显示全部

Ribbon 上还有三个按钮：

| 按钮 | 效果 |
|---|---|
| 「Zoom In」/ 放大 | 把当前坐标轴范围缩小两成，以视口中心为基准 |
| 「Zoom Out」/ 缩小 | 把当前坐标轴范围放大两成，以视口中心为基准 |
| 「Show All」/ 显示全部 | 重新按数据范围设定坐标轴，让全部数据回到画面里 |

「Zoom In」和「Zoom Out」都是按固定比例改范围，适合慢慢推进或者退开。「Show All」是按数据重新算一遍坐标轴范围，用在图跑丢了或者缩得太远时。

### 缩放历史

框选缩放会把每一次的坐标范围记在一份缩放历史里，最多保留 30 层。回退时按这份历史逐级返回，回到的是上一次框选时的视野，即使中途换过框选的位置也不会跳错。

这份历史由缩放器自己维护，它自带一组鼠标操作：中键回退一级、中键加 Shift 前进一级、右键回到最初的全览范围。这三组操作只在「Zoom」/ 缩放 打开时响应。Ribbon 上的「Zoom Out」/ 缩小 不走这份历史，它按固定比例缩放，两者不要混着用。

### 限定一个方向的缩放

「Disable X Zoom」和「Disable Y Zoom」这两个开关用来把滚轮和「Zoom In」/「Zoom Out」的作用限制在一个方向上。名称的含义是禁止 X 方向缩放和禁止 Y 方向缩放，勾上哪个就禁掉哪个方向。勾上「Disable X Zoom」之后，缩放只改纵向，适合只看某个横坐标邻域内的起伏；勾上「Disable Y Zoom」则相反，适合拉平纵向差异、只比较横向的位置。这两项的中文翻译还没补上，中文界面下显示的是英文原文。

这两个开关不影响框选缩放，框选仍然按矩形同时改两个方向。

## 十字光标

「Cross」/ 十字标记 打开之后，鼠标在画布上移动时有两件事跟着走：两条互相垂直的线随鼠标移动，交叉点落在鼠标位置上，旁边显示这个位置的坐标读数。这两条线是临时辅助线，鼠标移开就没了，它不改变坐标轴范围，也不影响图元。

读数按坐标轴当前的刻度格式显示，坐标轴是日期时间的刻度时读数也是日期文字。十字光标是坐标系级的开关，可以只开在某一块坐标系上。

## 鼠标读数

读数功能由「Y Picker」/ y值拾取 和「XY Picker」/ 点拾取 两个按钮控制，两者在同一个互斥动作组里，同一时刻只有一个生效。再点一次当前生效的按钮就关掉拾取。

### 两种模式各自读什么

两种模式都在鼠标附近寻找数据点，读出的内容不同。

| 模式 | 读数内容 |
|---|---|
| 「Y Picker」/ y值拾取 | 按鼠标的横坐标找到各条曲线在这个位置的值，一次读出这个坐标系里所有可见曲线的 Y 值 |
| 「XY Picker」/ 点拾取 | 找到离鼠标最近的那个数据点，读出它的横坐标和纵坐标 |

Y 值拾取适合横坐标有明确含义的场合，比如时间序列，鼠标停在某个时刻上就能一次读到所有曲线的取值。XY 值拾取适合散点，鼠标指到哪个点就读哪个点。

### 读数框的内容

读数是一块浮框，一行一条曲线。每一行以这条曲线的颜色开始，接着是曲线标题，然后是数值。多条曲线时各占一行，纵向排列。浮框的位置由「Text Placement」/ 文字位置 决定，默认停在画布顶部、随鼠标横向移动，也可以钉在某个角或者完全跟着鼠标走，见下面文字位置那一节。

读数框里显示的数值按图元类型变化，不同类型给的信息不一样：

- 曲线和散点显示这个位置上的 Y 值。
- 误差棒显示区间，两个数分别是下界和上界，写成方括号里的一对。
- 箱体显示中位数、上下四分位数和须线端点。
- 多重柱状显示同一组里各根柱子的值。
- 向量场显示向量的两个分量和它的长度。

「Show X Value」/ 显示X值 控制要不要把横坐标也读出来。打开时浮框顶部多一行横坐标的值，Y 值拾取模式下这一行只出现一次，因为各条曲线共用同一个横坐标；关闭时只留各条曲线的数值。

「Y Picker Show X Value」/ y拾取显示x值 是同一个开关在 Ribbon 菜单里的入口：勾选它等于在属性面板里打开「Show X Value」/ 显示X值。菜单项上的勾选标记不会跟着属性面板里的改动刷新，以属性面板里的值为准。

### 文字位置

读数文字可以固定在画布的角上，也可以跟着鼠标跑。Ribbon 上「Y Picker」按钮右侧的下拉箭头里有一组位置选项：

| 菜单项 | 效果 |
|---|---|
| 「At Canvas Left Top」/ 在画布左上 | 固定在画布左上角 |
| 「At Canvas Left Bottom」/ 在画布左下 | 固定在画布左下角 |
| 「At Canvas Right Top」/ 在画布右上 | 固定在画布右上角 |
| 「At Canvas Right Bottom」/ 在画布右下 | 固定在画布右下角 |
| 「Follow Mouse」/ 跟随鼠标 | 跟着鼠标移动 |
| 「Y Picker Show X Value」/ y拾取显示x值 | 切换是否显示横坐标 |

菜单最后还有一项「Data Picker Setting」/ 数据拾取设置，点它直接跳到属性面板的数据拾取页。

属性面板里的选项比 Ribbon 菜单更全。在属性面板下拉框选「Data Picker」/ 数据拾取，页面上「Basic」/ 基础 分组里的「Text Placement」/ 文字位置 一共有十个取值：Auto、Follow Top、Follow Bottom、Follow Mouse、Canvas Top Right、Canvas Top Left、Canvas Bottom Right、Canvas Bottom Left、Canvas Top Auto、Canvas Bottom Auto。Ribbon 菜单给的是常用的五个位置，「Auto」和两个带「Auto」的取值只在面板里能选到。同一页还有「Text Offset X」/ 文字偏移X 和「Text Offset Y」/ 文字偏移Y，取值 −200 到 200 像素，用来把读数文字从默认位置挪开一点，避免盖住数据。「Background Brush」/ 背景画刷 改读数框的底色。

属性面板的「Picker Mode」/ 拾取模式 下拉框也能开关拾取，取值是「Off」/ 关闭、「Y Value」/ Y值、「XY Value」/ XY值拾取，与 Ribbon 上两个按钮的状态一致。

### 特征点

「Feature Point」/ 特征点 分组控制被读到的那个数据点要不要在图上标出来。

| 参数 | 取值 | 默认值 |
|---|---|---|
| 「Draw Feature Point」/ 绘制特征点 | 开或关 | 开 |
| 「Feature Point Size」/ 特征点大小 | 1 到 30 像素 | 8 |
| 「Nearest Search Window」/ 搜索窗口大小 | 1 到 100 | 5 |

特征点是一个实心圆点，画在离鼠标最近的那个真实采样点上，颜色取这条曲线的颜色加浓，比读数框更直观地指出读的是哪个点。

「Nearest Search Window」决定在鼠标位置附近找点时的搜索范围，单位是采样点个数。曲线上的点数少于 1000 时软件直接遍历整条曲线，这个参数不起作用；点数很多时才按它限定的窗口查找，窗口调小可以加快响应，调大可以避免鼠标停在数据稀疏处时读不到值。

### 线性插值

「Interpolation」/ 插值模式 有两种取值：

- 「None」/ 无：直接取最近的采样点的值，鼠标在两个采样点之间移动时读数保持不变，到了下一个采样点才跳一次。
- 「Linear」/ 线性：按鼠标横坐标在相邻两个采样点之间做线性插值，读数随鼠标连续变化。

读数需要精确到「两个采样点之间的任意位置大约是几」时打开线性插值，横坐标是时间、浓度这类连续量时尤其有用。只想读出数据表里真实存在的那些数值时保持「None」/ 无。

## 多个坐标系联动

### 联动拾取

「Link All Picker」/ 联动拾取 打开之后，当前绘图里所有二维坐标系进入同一个拾取器组。鼠标在任意一块坐标系上移动，所有坐标系同时显示自己在这一横坐标位置上的读数。属性面板里「Linkage」/ 联动 分组的「Picker Group Enabled」/ 拾取器联动 是同一个开关。

这个按钮的作用范围是整个绘图里的所有二维坐标系。四块小图对照同一批数据时打开它，鼠标划过一条线的位置，四张图一起给出数值。

### 坐标轴范围联动

代码里有把两个坐标系的坐标轴范围绑在一起的实现，源轴的范围变化会带着跟随轴一起变。这个功能目前没有界面入口，也没有暴露给 Python，只能从 C++ 里调用。想让多个坐标系在界面上用同一对范围，做法是分别选中它们，把坐标轴面板里的最小值、最大值手工改成同一对数字，见[二维图表设置](./settings-2d.md)。

## 交互开关的作用范围

Ribbon 上的缩放、拖动、网格、十字标记、两种拾取器、图例、禁止单方向缩放，以及图表编辑页里的工具，走的都是同一条规则：作用在当前坐标系上，除非 Ribbon 上「Chart Setting」/ 绘图设置 面板里的「Apply All Charts」/ 应用到所有绘图 开关是打开的。

开关打开时，这些操作对当前绘图里所有坐标系一起下发。两块小图对照时这一点很有用，打开它一次就能把四块的缩放方向、拾取器状态调齐；只想改其中一块时把它关掉，先去画布上单击要改的那一块，再点按钮。

「Link All Picker」/ 联动拾取 是例外，它本身就是绘图级的，不受这个开关影响。数据探针同理，它按整个绘图进入取数状态。

## 图例

坐标系右侧的图例不只是名字列表，它还是显示开关。图例里的每一项对应坐标系里的一个图元，点击一项会切换这个图元的显示与隐藏，效果和到绘图管理树里双击「visible」列一样。图元多、曲线互相压住时，用图例一项一项关掉，比在树里找名字快。

图例自身的开关和位置也在 Ribbon 上：「Legend」/ 图例 按钮控制显示与隐藏，它右侧的下拉菜单里有「Legend Top」/ 图例在上、「Legend Bottom」/ 图例在下、「Legend Left」/ 图例在左、「Legend Right」/ 图例在右 四个位置。图例的字体、边框、背景和最大列数在属性面板的图元列表里，见[二维图表设置](./settings-2d.md)。

## 固定位置的取值

鼠标读数跟着鼠标走，位置一变读数就没了。要在固定的几个位置取值、并且把多次取值攒成一张对照表，用数据探针：点 Ribbon 上的「Data Probe」/ 数据探针 进入取数状态，在图上单击，软件按这个横坐标在当前绘图的所有二维坐标系里各建一个同名探针，读数汇总到「Data Link Table」/ 数据联动表 里的一个标签页。取数状态会临时关掉缩放、平移和十字标记，并把所有坐标系的拾取器并进一组。

探针的进入和退出、名字、颜色、徽标样式，以及联动表的列操作见[数据探针与数据联动表](./data-probe.md)。

## 鼠标操作一览

下表把画布上的鼠标动作收在一起。左键的含义随当前模式变化，其余动作两种模式下一样。

| 动作 | 缩放模式 | 拖动模式 |
|---|---|---|
| 左键拖动 | 拖出矩形，松开后缩放到这个范围 | 移动画面 |
| 左键单击 | 选中光标下的图元或坐标系 | 同左 |
| 滚轮 | 以光标为中心缩放 | 以光标为中心缩放 |
| 中键拖动 | 回退一级缩放历史 | 不响应 |
| 中键加 Shift 拖动 | 前进一级缩放历史 | 不响应 |
| 右键单击 | 回到最初的全览范围 | 不响应 |
| 双击文字图元 | 没有专门动作，改文字用属性面板里的「Edit Rich Text...」/ 编辑富文本... 按钮 | 同左 |
| Delete 或 Backspace | 删除选中的图元 | 同左 |

中键拖动、中键加 Shift 拖动和右键单击这三个动作由缩放器提供，缩放器在「Zoom」/ 缩放 关闭时不接收事件，因此在拖动模式下不响应。滚轮缩放由另一个组件负责，独立于缩放开关，两种模式下都能用。

十字标记和两种拾取器在代码里是各自独立的组件，但三个按钮属于同一个互斥动作组，界面上同一时刻只有一个能按下，因此十字线和读数框不会同时出现。缩放、拖动不在这组里，可以和其中任何一个同时打开。

## 读数的格式

读数框里的数字格式跟着坐标轴走。轴用普通刻度时按数值显示，轴改成「DateTime」/ 日期时间 刻度时读数框里显示的是日期文字，和轴上的刻度标签一致。刻度样式的切换在坐标轴面板里，见[二维图表设置](./settings-2d.md)。

不同类型图元的读数内容在上一节列过。误差棒、箱体、多重柱状、向量场这几类给的是组合信息，读数框把它们整理成一行紧凑的文字，比如误差棒给出区间的两个端点，箱体给出中位数和上下四分位数。各列的语义可以先在表格视图里确认，读数的含义对应的是建图时用的那几列。

## 一个例子：读出一条曲线在某个横坐标上的值

下面按操作顺序走一遍最常见的取数流程，目标是读出三条曲线在同一个横坐标位置上的取值，并把其中一条关掉对照。

1. 在画布上单击要取数的坐标系，让它成为当前坐标系。多块坐标系的绘图里这一步不能省，Ribbon 上的按钮作用在当前那一块上。
2. 点「Y Picker」/ y值拾取。按钮亮起表示拾取打开，此时鼠标在画布上移动，读数框跟着出现。
3. 把鼠标移到目标横坐标附近。读数框里一行一条曲线，每行以曲线颜色开头，后面依次是曲线标题和数值。鼠标横向移动时，几行数字一起更新。
4. 数字随鼠标跳动、不够细时，到属性面板的「Data Picker」/ 数据拾取 页把「Interpolation」/ 插值模式 改成「Linear」/ 线性。读数这时在相邻两个采样点之间连续变化。
5. 看不清读的是哪个点，就打开「Draw Feature Point」/ 绘制特征点，图上会在最近的采样点画一个圆点，颜色比曲线本身深。圆点太大或太小用「Feature Point Size」/ 特征点大小 调，1 到 30 之间。
6. 想专门看某一条曲线，点击图例里那一项把它隐藏，读数框里对应的那一行随之消失；看完再点一次恢复。
7. 需要把这一组读数留给别人看，点「Data Probe」/ 数据探针 在同一个横坐标上建探针，读数进数据联动表，见[数据探针与数据联动表](./data-probe.md)。

这套参数会随工程保存，重新打开时拾取器的模式、插值方式、特征点大小、读数框的位置和背景都在。

## 缩放之后的范围

框选、滚轮、按比例缩放都会改写坐标轴的当前范围。这个范围跟着坐标系一起存进工程，关掉工程重新打开时，看到的是离开时的范围，软件不会在打开时自动回到全览。

回到全览用「Show All」/ 显示全部，它按数据重新算一遍范围。坐标轴面板里的「Min Scale」和「Max Scale」是同一件事的手工入口，填进这两个数就等价于把范围钉死在这对数字上。几块坐标系要横向对照，可以把它们的下 X 轴填成同一对数字。

想把范围恢复成默认值而不动数据，先「Show All」再继续操作即可，不需要重新建图。

## 在图上挑图元

### 指针工具

「Pointer」/ 指针 按钮打开指针选择模式，提示写着「Select chart elements by clicking, drag to move, Delete to remove」。工作方式：

- 单击画布，命中判定从上层往下层找，命中的图元被选中，四周出现一个选框。
- 按住已经选中的图元拖动，可以把它挪到新位置。拖动过程中选框跟着走，松开鼠标后位置确定；这一次移动进入撤销栈，可以撤销。
- 按 Delete 或者 Backspace 删除选中的图元，删除同样可以撤销。
- 按 Esc 取消选中并退出指针模式。

能移动的是标记类的图元：普通标记、文字标记、箭头标记、数据探针标记。曲线、柱状、直方图、云图这些由数据决定的图元只能选中和删除，拖动不改变它们的形状，它们的位置由数据决定。

点击曲线的线条附近会命中这条曲线本身，命中时按最近采样点判断；点击画布空白处则取消当前选中。

### 形状和标记

「Select Tool」/ 选区工具 面板里还有矩形、椭圆、多边形三个按钮，用来在图上画形状标注。「Chart Assist Tool」/ 图表辅助工具 面板里有十字标线、水平标线、垂直标线、箭头、文本共五种标注工具。这些工具都是单次操作：选好工具后在画布上单击或者拖出范围，图元就落在那个位置并进入撤销栈，标注完成后自动回到普通状态。

标注画出来之后可以随时用指针工具调整位置或删除。

### 就地编辑文字

文字编辑浮窗有两个入口。新建标注时它跟着「Add Text」自动出现，编辑图上已有的标注时，先选中这个文字图元，再点属性面板里「Content」/ 内容 一栏的「Edit Rich Text...」/ 编辑富文本... 按钮，浮窗在按钮旁边弹出。

浮窗里可以直接改内容；走「Add Text」这条入口时，改动实时反映到图上。浮窗上还有加粗、倾斜、下划线、删除线、上标、下标、字体颜色、文字背景色、清除格式这些按钮，以及「OK」/ 确定 和「Cancel」/ 取消。从属性面板进去时，「OK」和「Cancel」的差别在于保留还是丢弃这次改动。

用「Add Text」新建文字标注时也是这套浮窗：单击落点之后浮窗出现，边打字边看效果，点浮窗外面保留这段文字，按 Esc 则把这个还没有确认的标注删掉。

## 界面上取不出图上的数值

框选、椭圆、多边形这三个工具画出来的图形只是图上的标注，软件不会读取框住的数据点，也没有「框选后导出这些点」这样的命令。要把图中的数值带走，可行的办法有三条：

- 用原始数据集导出，拿到的是数据表里的原始数值，见[导出数据](../data/export.md)。
- 用数据探针配合数据联动表，在图上固定位置取值并以表格形式查看，见[数据探针与数据联动表](./data-probe.md)。
- 用脚本工作区里的 Python 直接读数据集并自己计算，见[脚本工作区](../script/workspace.md)。

同理，绘图管理树、数据联动表里也没有「保存曲线数据」或者「复制数据」这类动作，图元上的数据只能看，不能在界面上取出来变成新的数据集。

## 常见问题

鼠标停在画布上想框选，结果整块画面被拖走了。当前是拖动模式，点一下「Zoom」/ 缩放 切到缩放模式，两者互斥。

滚轮缩放只改一个方向。检查 Ribbon 上的「Disable X Zoom」和「Disable Y Zoom」两个开关，把不需要限制的那一个取消勾选。

缩放回到全览之后回不到刚才那一级。框选的历史最多 30 层，超过之后最早的一级被丢掉。用「Show All」/ 显示全部 回到全览，再框选一次。

鼠标移到图上没有读数。先确认「Y Picker」/ y值拾取 或「XY Picker」/ 点拾取 是打开状态；两个按钮都不亮，或者属性面板里「Picker Mode」/ 拾取模式 停在「Off」/ 关闭，都不会出读数。

读数只在一条曲线上跳。曲线点数多的时候，读数按搜索窗口在附近找点。把「Interpolation」/ 插值模式 改成「Linear」/ 线性，读数会随鼠标连续变化。

打开联动拾取之后，别的绘图没有跟着联动。「Link All Picker」/ 联动拾取 只对当前绘图里的坐标系生效，跨绘图不联动。两张图要一起读，把它们放进同一个绘图的两块坐标系里。

想选的图元选不中。曲线要在线条附近点击，鼠标离线条太远会落空；标记、文字、形状在轮廓范围内点击即可命中，判定本身留了一点容差。点不中时先把画面放大，再对准线条或轮廓的中部点。

拖动图元时它跑到了别的位置。标记、箭头、文字这几类按数据坐标记位置，拖动后坐标跟着变，之后缩放或平移坐标轴，它仍然贴着那个数据位置。想把标注固定在画布的某个角落，用按画布定位的图元，见[二维图表设置](./settings-2d.md)。

放大之后读数和十字线都不见了。十字线和读数只在鼠标位于画布上时显示，移出画布即消失；放大到数据点很稀疏的区域时，读数按搜索窗口找不到范围内的点就不显示，把窗口调大或者用「Show All」/ 显示全部 退回全览。

按住中键拖动没有反应。中键回退缩放历史的动作只在「Zoom」/ 缩放 打开时可用，且需要缩放历史里已经有框选的记录。先框选几次再用中键试。

属性面板里的拾取模式和 Ribbon 上的按钮状态不一致。两处改的是同一个对象，通常只是当前坐标系被换掉了，面板显示的是新当前坐标系的状态。在画布上点回要改的那一块再核对。

打开工程之后画面停在放大状态。坐标轴的当前范围随工程保存，保存时缩放过就会原样恢复。点「Show All」/ 显示全部 回到全览。

想同时留十字标记和读数框。做不到，十字标记和两种拾取器属于同一个互斥动作组，按下一个另一个就弹起来。要看走势留十字标记，要读具体数值用两种拾取器。

在图上单击之后 Ribbon 上少了绘图相关的标签。「Chart」/ 绘图 上下文标签跟着焦点显示，焦点跑到数据表或者工作流上时标签会换成对应的那一组。在画布上再单击一次就会回来。

读数框里的数字位数太少。读数按坐标轴的刻度标签格式显示，想看到更多位小数时缩小坐标轴范围再读，或者改用脚本工作区里的 Python 直接算。

多块坐标系里只有一块显示读数。拾取器状态按坐标系保存，检查另外几块的拾取器是不是关着的；打开「Link All Picker」/ 联动拾取 可以让它们一起显示。

探针和读数框的数值不一致。读数框读的是鼠标位置，探针读的是它自己固定下来的横坐标，两者相差一点是正常的。以探针为准时把读数框关掉，避免来回对照。

框选出来的矩形突然消失，没有缩放。框选要求矩形的边长大于缩放器设定的最小尺寸，太小的框会被丢弃。把矩形拖得比几个像素大一些再松手。

在曲线上按住左键想拖动它，结果整块画面平移了。曲线由数据决定位置，指针工具拖不动它。想让曲线出现在画面的另一处，改坐标轴范围；想改曲线的形状，改数据之后重新建图。

想比较同一横坐标上的两个点，一个一个记数字太慢。打开「Link All Picker」/ 联动拾取 之后读数在图上是同一时刻给出的，把两块的横坐标范围调成一致，同一列的数值会同时出现在两块上。要长期留档就改用探针，见[数据探针与数据联动表](./data-probe.md)。

指针工具下选中了曲线，但拖动没有反应。曲线是数据图元，只能选中和删除。要调整它显示的形状，改坐标轴范围或者改这条曲线的数据，见[二维图表设置](./settings-2d.md)。

按 Delete 图元没被删掉。Delete 要同时满足两个条件：当前在指针模式下，并且已经选中了目标图元；焦点不在绘图窗口上时按键不会传进去。先点回画布选中图元，再按 Delete。

鼠标在画布上拖动时读数一直在变，挡着看曲线。把「Text Placement」/ 文字位置 改成画布的一个角，读数就固定在那里不动，再把「Interpolation」/ 插值模式 保持「None」/ 无，数字只在实际采样点上跳。

一块小图上又开了读数又建了探针，画面很乱。两者互不冲突，但不必常开。取数时开读数，要留档时建探针。
