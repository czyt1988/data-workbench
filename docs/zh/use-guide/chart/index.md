# 绘图

这一部分讲在软件里画图的完整流程：从选图表类型开始，到调整每一处细节，最后把图交出去。

软件里画图分两层。一个「绘图」是一个标签页，里面可以放多个「坐标系」，每个坐标系上可以画多个图元。多个坐标系放在一个绘图里适合做对比图组，多个绘图适合放在不同的标签页上分别调整。

## 章节目录

- [创建图表](create.md)：建图向导的用法，十三个图表类型各自需要什么数据。
- [绘图与坐标系](figure.md)：在一个绘图里放多个坐标系、调整它们的位置和大小、用绘图管理树挑选对象。
- [二维图表设置](settings-2d.md)：属性面板上每一个分组、每一项设置的作用。
- [三维图表设置](settings-3d.md)：三维曲面、柱体、线图的专有设置。
- [缩放与取值](interaction.md)：缩放平移、十字光标、鼠标读数、多个坐标系联动。
- [数据探针与数据联动表](data-probe.md)：在图上固定位置取值，把多个坐标系的读数汇总成一张表。
- [复制与保存图表](save.md)：把图表复制到剪贴板或者存成文件，以及图表在工程里的存放方式。

## 建议的读法

第一次画图，读[创建图表](create.md)，选一个和数据类型对得上的图表类型走一遍向导。向导接受之后图就出来了，只是样子是默认的。

接着读[二维图表设置](settings-2d.md)，按需要调标题、坐标轴范围、曲线的颜色和线型。那一章很长，当字典用，不必一次读完。

要做多子图的对比图组，读[绘图与坐标系](figure.md)。

要把图发给别人，读[复制与保存图表](save.md)。那一章说明了软件能输出什么格式、不能输出什么格式。

## 需要提前知道的三件事

- 图表画的是采样点的拷贝。源数据集后来改了，图不会跟着变。
- 界面上没有导出图表的菜单项，存文件要借智能体的保存工具。
- 对数坐标只能从脚本里打开，属性面板的坐标轴页做不到。
