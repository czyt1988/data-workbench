# 二维图表设置

这一章讲右侧「Setting / 设置」停靠面板在二维图表上的全部页面。选中一个坐标系或一个图元，面板就换成对应的设置页，页里列出这个对象所有可以改的项：标题脚注、画布底色、四条坐标轴、鼠标读数，以及每一种图元自己的参数。表中给出的默认值和取值范围取自源码，界面上确实存在的项才写进来。

## 设置面板怎么组织

「Setting / 设置」和「Agent Assistant / Agent 助手」、「Data Link Table / 数据联动表」共用主窗口右侧的同一个停靠区，三者以标签页排列。绘图设置占据其中一个标签页，具体编辑哪个对象由面板顶部的下拉框决定。

面板被别的标签页盖住时，用 Ribbon 上的「Show Setting Window / 设置窗口」把设置页提到最前。停靠面板本身可以拖动和浮动，位置随界面布局一起保存，见[主界面](../getting-started/main-window.md)。

下拉框里的条目分两类。固定条目有七个，它们和坐标系的对应关系如下。

| 条目 | 作用对象 |
|------|----------|
| `Chart Area` / 图表区 | 当前坐标系的标题和脚注 |
| `Canvas Area` / 绘图区 | 当前坐标系的画布背景和边框 |
| `Y Left Scale` / 左Y轴 | 当前坐标系左侧的 Y 轴 |
| `X Bottom Scale` / 下X轴 | 当前坐标系下方的 X 轴 |
| `Y Right Scale` / 右Y轴 | 当前坐标系右侧的 Y 轴 |
| `X Top Scale` / 上X轴 | 当前坐标系上方的 X 轴 |
| `Data Picker` / 数据拾取 | 当前坐标系的鼠标读数框 |

第二类是当前坐标系里的每个图元各占一行，图标和名字由图元自身决定，名字就是图元的标题。给曲线改一个有含义的标题，下拉框里也就好找了。选中其中一行，面板下方显示这个图元的设置页。

图元行是动态生成的，坐标系当前有哪些图元就列哪些，删掉图元后对应的行也跟着消失。图元被删掉时，如果面板正停在这一行上，页面会随条目一起消失。

面板上显示的页面一定属于某个坐标系。切换坐标系后，固定条目那七页跟着换成新坐标系的对象，图元行整批替换，之前改过的值都保存在各自的对象里。一个绘图里有多个坐标系时，先确认面板顶上是哪一个坐标系的图元，再动手改参数。

三维图表用的是另一个设置控件，下拉框里的条目和页面都不一样，见[三维图表设置](./settings-3d.md)。

### 页面里的分组和编辑器

每个页面都是一列可以折叠的分组，点分组标题可以收起或展开，收起后只剩标题，找参数时可以先把不相关的分组折起来。分组顺序从最常改的参数排到最少改的参数。

分组的每一项都对应一个具体的编辑器，操作方式按类型固定。布尔项是复选框，勾选就打开，取消勾选就关闭。枚举项是下拉框，点开后每一项显示的是界面上的名字。数值项是带上下限的数字框，可以键入，也可以用框边的上下箭头微调，超出上下限的值输不进去，小数位数由这个字段自己规定，从 0 位到 6 位不等。颜色项打开取色对话框，画笔和画刷项打开 Qt 的画笔、画刷编辑器，里面能选线宽、线型、填充风格和透明度。字体项打开字体对话框。九宫格对齐项点格子选方向。坐标轴选择是下拉框，里面列出这条轴上可用的轴名。

有的字段会随着别的字段变灰。比如曲线样式选了 `Sticks`，填充相关的两个字段就不能改；误差棒关掉后，样式和画笔两个字段变灰。字段是灰的时候，改它不会有任何效果，先把控制它的开关打开。

切换编辑对象有两条路。一条是在绘图上直接点选，另一条是在「Charts Manager / 绘图管理」停靠面板的树里点条目。树的列是「element / 绘图元素」、「visible / 可见性」、「property / 属性」，层级从绘图到坐标系，再到 `Axis` 树节点和 `plot item` 树节点。点坐标轴条目会切到对应的轴页面，点图元条目会切到该图元的那一行；图元不在当前坐标系时，面板会先把目标坐标系切过去。双击 `visible` 列会在单击的基础上多切换一次可见性，面板照样跟着这一行切换。

绘图本身的尺寸和背景不在这个下拉框里，它有单独的页面，入口是「Charts Manager / 绘图管理」标题栏上那个齿轮按钮，见本章的「绘图自身的设置」一节。

绘图里还没有坐标系时下拉框是空的，面板上没有任何页面可以展开，这时先新建一个坐标系再回到这里改参数，操作见[绘图与坐标系](./figure.md)。

## 图表区（Chart Area / 图表区）

这一页改的是当前坐标系的标题和脚注，也就是坐标系上方和下方各一行文字。

| 设置 | 默认值 | 作用 |
|------|--------|------|
| `Title Text` | 空 | 坐标系上方的标题文字 |
| `Title Font` | 系统默认字体 | 标题字体 |
| `Title Color` | 黑色 | 标题颜色 |
| `Footer Text` | 空 | 坐标系下方的脚注文字 |
| `Footer Font` | 系统默认字体 | 脚注字体 |
| `Footer Color` | 黑色 | 脚注颜色 |

标题文本留空时上方不显示任何文字，脚注同理。这两行文字随坐标系一起缩放和移动，属于坐标系自身的内容。

坐标系标题还有一处用途：数据联动表里每个坐标系占一组行，行名取的就是这个标题，标题为空时用 `Chart 序号` 顶替。给每个坐标系写上标题，联动表也更好读，见[数据探针与数据联动表](./data-probe.md)。

字体大小按点数给定，坐标系放大缩小时文字大小不变，缩放数据范围也不影响它们。图注比较多的时候，把说明放进脚注比塞进标题更容易读。

这一页没有对数刻度、图例开关和网格开关。网格和图例在 Ribbon 的「Chart Style / 图表样式」页上，对数刻度目前没有界面入口，见本章「坐标轴」一节的说明。

## 绘图区（Canvas Area / 绘图区）

绘图区指坐标轴围起来的那块画布。这一页改画布的背景和边框。

| 分组 | 设置 | 默认值 | 作用 |
|------|------|--------|------|
| `Background` / 背景 | `Background Brush` | 空画刷 | 画布底色 |
| `Border` / 边框 | `Border Width` | 0 | 边框宽度，范围 0 到 20 |
| `Border` / 边框 | `Border Pen` | 默认画笔 | 边框第二条线的画笔 |
| `Style` / 样式 | `Frame Shape` | 无边框 | 边框形状，可选 `No Frame` / 无边框、`Box` / 方框、`Panel` / 面板、`Styled Panel` / 样式面板、`Win Panel` / 窗口面板 |

背景画刷设为带颜色的画刷后，画布整块变成该颜色，复制到剪贴板的位图也带上这个底色。边框宽度为 0 时不画边框，填大于 0 的数才有边框。

画布和绘图是两层背景：绘图的底色铺在最底下，画布盖在绘图里的每一块坐标系上。把绘图背景设成浅灰、画布背景设成白色，就能得到坐标系是白底、坐标系之间是灰底的版面。

边框画笔写入的是画布调色板的文本色，Qt 用它画框架的第二条线（比如面板风格的阴影线）。只改画笔、边框宽度仍是 0、框架形状仍是 `No Frame` 时，画面上看不出变化，要配合边框宽度或框架形状一起调。

框架形状决定边框的绘制风格，`Box` 是细边框，`Panel` 和 `Styled Panel` 是带立体感的边框，`Win Panel` 是 Windows 经典风格。选 `No Frame` 时边框完全不画，边框宽度和画笔都不再起作用。

## 坐标轴（左Y轴、右Y轴、下X轴、上X轴）

四个方向各有一页，页面内容完全相同，区别只是作用在哪条轴上。每个坐标系都有四条轴：下 X 轴、上 X 轴、左 Y 轴、右 Y 轴。新建坐标系时下 X 轴和左 Y 轴默认打开，上 X 轴和右 Y 轴默认关闭，需要时在对应页面里打开。

启用和标签部分：

| 分组 | 设置 | 默认值 | 范围或可选值 |
|------|------|--------|--------------|
| `Enable` / 启用 | `Enable Axis` | 下 X 轴、左 Y 轴打开，另两条关闭 | 开或关 |
| `Label` / 标签 | `Label Text` | 空 | 轴标题文字 |
| `Label` / 标签 | `Label Font` | 系统默认字体 | 字体对话框 |
| `Label` / 标签 | `Label Font Color` | 黑色 | 颜色对话框 |
| `Label` / 标签 | `Label Alignment` | 默认对齐 | 九宫格对齐选择 |
| `Label` / 标签 | `Label Rotation` | 0 | −360 到 360，步长 1 |

`Enable Axis` 关掉后整条轴消失，包括轴线、刻度数字和轴标题。轴对应的数据图元不会跟着消失，只是没有了参照。这一页是开关轴的主要入口，绘图管理树里 `visible` 列也能达到同样效果。X 轴的可见性还会影响数据探针的徽标位置，两条 X 轴都关掉时徽标随之隐藏，见[数据探针与数据联动表](./data-probe.md)。

`Label Text` 是轴的标题文字，和刻度数字无关。`Label Font` 改的是刻度数字的字体，源码注释里明确写了它不改轴标题的字体。`Label Font Color` 写入尺度控件的调色板文本色，刻度数字和轴标题都用它。`Label Alignment` 和 `Label Rotation` 也只作用在刻度数字上。

`Label Rotation` 让刻度数字绕自身旋转，填 90 得到竖排数字，取值范围是 −360 到 360 度。刻度数字较长时旋转能省下横向空间，四个方向的轴都支持。`Label Alignment` 是刻度数字沿轴线方向的摆放位置，九宫格里的选项决定数字靠左、居中还是靠右。

刻度部分：

| 分组 | 设置 | 默认值 | 范围 |
|------|------|--------|------|
| `Scale` / 刻度 | `Margin` | 0 | −20 到 100 |
| `Scale` / 刻度 | `Min Scale` | 当前轴的最小值 | −1e15 到 1e15，保留 5 位小数 |
| `Scale` / 刻度 | `Max Scale` | 当前轴的最大值 | −1e15 到 1e15，保留 5 位小数 |
| `Scale` / 刻度 | `Ticks Inside` | 关 | 开或关 |

`Margin` 是刻度和轴标题之间的距离，负数把标题往轴线方向拉近，正数往外推。四个坐标轴页面各有一份 `Margin`，改一条轴不影响其他三条。

`Min Scale` 和 `Max Scale` 显示的是当前坐标轴上下限，改其中一个时另一个保持不动，坐标轴立即换成新范围。两者都能精确到小数点后 5 位，图元被缩放到范围之外时会被裁掉。要恢复自适应范围，用 Ribbon 的 `Show All` 动作，它按数据范围重新定轴，见[缩放与取值](./interaction.md)。

`Ticks Inside` 打开后刻度线朝画布内侧画，关闭时朝外画。外向刻度会占掉坐标系四周的空白，画紧凑排版时收进内侧能省出边距。

刻度样式是一组互斥的单选按钮：

| 选项 | 默认 | 效果 |
|------|------|------|
| `Normal` / 普通 | 选中 | 普通线性刻度 |
| `DateTime` / 日期时间 | 未选中 | 按日期时间绘制刻度，基础格式 `yyyy-MM-dd` |

四条轴的设置各自独立：把某条曲线的 `Y Axis` 选成 `Y Right` 之后，这条曲线按右轴的上下限和刻度绘制，右轴页上的 `Min Scale`、`Max Scale` 和刻度样式只管它，左轴照旧管挂在左轴上的图元。要画双纵轴图，先加一条曲线并把它的 `Y Axis` 改成 `Y Right`，再到右轴页打开 `Enable Axis` 并设好范围，两条轴的单位不同也不影响。

选 `DateTime` / 日期时间时轴的刻度换成日期时间绘制，值按时间戳解释，显示格式以 `yyyy-MM-dd` 为基础，刻度间隔变大时会自动缩短显示内容，比如只显示年月。日期格式本身没有输入框，不能在界面上改。

切换刻度样式时，普通刻度会把刻度引擎换成线性引擎。也就是说，如果之前在 Python 里把某条轴改成了对数刻度，回到这一页点一次 `Normal` 就会覆盖掉。四个坐标轴页面里都能分别选样式，把下 X 轴设成日期时间、其他轴保持普通也是允许的。

这一页不能设置对数刻度。源码里唯一能真正打开对数刻度的地方是 `da_pyplot` 的 `setXScale` 和 `setYScale`，参数填 `"log"`；对数刻度的显示文字只出现在图表管理树里。要走这条路需要写脚本，见[脚本工作区](../script/workspace.md)。

## 数据拾取（Data Picker / 数据拾取）

数据拾取就是跟随鼠标的读数框。这一页改读数框什么时候出现、显示什么、画在哪里，共四个分组。

基础部分决定读数框的行为：

| 分组 | 设置 | 默认值 | 可选值 |
|------|------|--------|--------|
| `Basic` / 基础 | `Picker Mode` | `Off` / 关闭 | `Off` / 关闭、`Y Value` / Y值、`XY Value` / XY值拾取 |
| `Basic` / 基础 | `Show X Value` | 开 | 开或关 |
| `Basic` / 基础 | `Text Placement` | `Follow Top` / 跟随顶部 | 见下方列表，共十项 |
| `Basic` / 基础 | `Interpolation` | `None` / 无 | `None` / 无、`Linear` / 线性 |

`Picker Mode` 的三个取值对应 Ribbon 上 `Y Picker` 和 `XY Picker` 两个动作，二者互斥。选 `Y Value` 时鼠标在一组曲线上移动，读数框显示最近曲线在横坐标上的数值；选 `XY Value` 时同时给出横纵坐标；选 `Off` 时读数框不再出现。

`Show X Value` 控制读数框里要不要显示 X 值，打开后 `Y Value` 模式也会带上横坐标。用 `XY Value` 模式时横坐标本来就会显示，这个开关主要影响 `Y Value` 模式。

`Text Placement` 的十个取值是 `Auto` / 自动、`Follow Top` / 跟随顶部、`Follow Bottom` / 跟随底部、`Follow Mouse` / 跟随鼠标、`Canvas Top Right` / 画布右上、`Canvas Top Left` / 画布左上、`Canvas Bottom Right` / 画布右下、`Canvas Bottom Left` / 画布左下、`Canvas Top Auto` / 画布顶部自动、`Canvas Bottom Auto` / 画布底部自动。前四项跟随数据点或鼠标，中间四项把读数框固定在画布四角，最后两项固定在画布顶边或底边并自动选择左右。数据曲线集中在画布上方时，把读数框固定到画布底部可以避免挡住曲线。

`Interpolation` 选 `Linear` 时读数按相邻两个采样点做线性插值，选 `None` 时取最近的采样点。采样点比较稀的曲线用线性插值读出来的数更接近肉眼所见的曲线位置。

特征点部分决定吸附标记：

| 分组 | 设置 | 默认值 | 范围 |
|------|------|--------|------|
| `Feature Point` / 特征点 | `Draw Feature Point` | 开 | 开或关 |
| `Feature Point` / 特征点 | `Feature Point Size` | 8 | 1 到 30 |
| `Feature Point` / 特征点 | `Nearest Search Window` | 5 | 1 到 100 |

特征点是在最近采样点上画的一个小标记，`Feature Point Size` 是它的像素尺寸，`Nearest Search Window` 是搜索最近点时的像素窗口，数值调大后更容易吸到点上。关闭 `Draw Feature Point` 后不再画标记，读数仍然显示。

文字样式部分决定读数框的外观：

| 分组 | 设置 | 默认值 | 范围 |
|------|------|--------|------|
| `Text Style` / 文字样式 | `Background Brush` | 空画刷 | 画刷对话框 |
| `Text Style` / 文字样式 | `Text Alignment` | 左上 | 九宫格对齐选择 |
| `Text Style` / 文字样式 | `Text Offset X` | 10 | −200 到 200 |
| `Text Style` / 文字样式 | `Text Offset Y` | 10 | −200 到 200 |

背景画刷给读数框加底色，默认是空画刷也就是透明。曲线穿过读数框时，加一个浅色底、不透明白色的画刷能让数字更容易看清。文字对齐是读数框里文字在框内的对齐方式，偏移量把读数框从默认位置往右下推，X 和 Y 都可以填负数往反方向移。

联动部分只有一个开关：

| 分组 | 设置 | 默认值 | 作用 |
|------|------|--------|------|
| `Linkage` / 联动 | `Picker Group Enabled` | 关 | 多个坐标系共用一组读数 |

`Picker Group Enabled` 打开后，同一个绘图里的多个坐标系共用一个读数组，鼠标在一个坐标系上移动时其他坐标系同时显示读数。Ribbon 上的「Link All Picker / 联动拾取」是这个开关的另一处入口。光标行为的具体表现见[缩放与取值](./interaction.md)。

数据探针会话会改写这一页的设置：进入探针模式后，每个坐标系的 `Picker Mode` 变成 `Y Value`，`Picker Group Enabled` 跟着打开，退出模式后这两项保持当时的状态不回退，见[数据探针与数据联动表](./data-probe.md)。

Ribbon 上的 `Y Picker` 按钮带一个下拉菜单，菜单里也能改文字位置和是否显示 X 值，菜单项的写法是 `At Canvas Left Top`、`At Canvas Left Bottom`、`At Canvas Right Top`、`At Canvas Right Bottom`、`Follow Mouse` 以及 `Y Picker Show X Value`。这些菜单项和本节字段改的是同一批底层参数，两处显示的选项名不完全一致，改哪一处都会立即反映到读数框上。菜单底部的「Data Picker Setting / 数据拾取设置」直接把设置面板切到这一页并提到最前，是打开本页最快的一条路。

## 绘图自身的设置

绘图级的设置不在上面的下拉框里。点「Charts Manager / 绘图管理」标题栏上的齿轮按钮，右侧「Setting / 设置」面板会换成绘图自身的页面，改动作用于整个绘图。

| 分组 | 设置 | 默认值 | 作用 |
|------|------|--------|------|
| `Size` / 尺寸 | `Min Width` | 0 | 绘图的最小宽度，0 表示不设下限 |
| `Size` / 尺寸 | `Min Height` | 0 | 绘图的最小高度，0 表示不设下限 |
| `Size` / 尺寸 | `Max Width` | 16777215 | 绘图的最大宽度，不主动改就是 Qt 的像素上限 |
| `Size` / 尺寸 | `Max Height` | 16777215 | 绘图的最大高度，不主动改就是 Qt 的像素上限 |
| `Background` / 背景 | `Background Brush` | 空画刷 | 绘图底色 |

四个尺寸字段的单位是像素，取值范围是 0 到 999999999，控制的是绘图画布本身能缩到多小、能放大到多大，不影响坐标系在绘图里的位置。绘图停靠区被拉宽时，画布会跟着变宽，给绘图设一个最大宽度就能让它停在上限处，超出的部分留白。

这一页没有按厘米或英寸设物理尺寸的输入框，也没有 DPI 或分辨率字段。要把图交给期刊，能调的只有这里的宽高上下限，以及坐标系在绘图里的归一化位置和大小。

背景画刷给整个绘图铺底色，和绘图区页面的画布底色是两层：画布底色盖在绘图底色上面。

四个尺寸字段和背景画刷都保存在绘图对象里，随工程一起存下来。改完不必特意保存，保存工程时这些值跟着图表一起写进工程文件，重新打开还是原样，见[复制与保存图表](./save.md)。

### 应用到所有绘图

Ribbon 的「Chart Style / 图表样式」页、「Chart Setting / 绘图设置」面板上有一个开关「Apply All Charts / 应用到所有绘图」，提示文字是「When this feature is selected, operations on the figure will apply to all plots, not just the currently selected one」。

这个开关是带勾选状态的按钮，勾选之后状态留在当前运行期间。它管的是 Ribbon 上的图表动作：勾上之后再点 `Enable Grid`、缩放、平移、拾取、图例这些动作，会对同一个绘图里的所有坐标系生效；不勾时只作用于当前选中的那一个。设置面板里的各项设置不受它影响，改参数始终只写给面板当前编辑的对象，要多改几个坐标系只能逐个选中再改，见[绘图与坐标系](./figure.md)。

需要留意的是，这项勾选状态不在界面布局保存的内容里，重新打开软件后开关回到默认状态。

## 图元页面

下拉框里图元的条目由坐标系现有的图元动态生成，图元被删除时条目也跟着消失。每个页面顶部的分组互不相同，但基本都会有一个放标题、`Z Value` 和坐标轴选择的分组。

`Title` 是图元在图表管理树和图例里显示的名字，改名只影响显示。`Z Value` 是绘制层叠顺序，数值大的画在数值小的上面，多个图元重叠时用它排先后，曲线页的范围是 −9999 到 9999。XY 类图元还有 `X Axis` 和 `Y Axis` 两个下拉框，用来选择把图元挂在哪条轴上，`X Axis` 可选 `X Bottom` / X底轴 和 `X Top` / X顶轴，`Y Axis` 可选 `Y Left` / Y左轴 和 `Y Right` / Y右轴。

替换坐标轴后，图元就按新轴的取值范围和刻度来画，双 Y 轴图靠这个实现。

图元页只列这个图元能改的项，页面上没有的参数靠别的手段也改不了。如果某个图元的下拉项点开后页面是空的，说明这个类型的图元没有配设置页，正常使用中只在少数由代码创建的对象上出现。图元的所有设置随图元本身保存，保存工程时一并写入，重新打开工程后参数还在，见[复制与保存图表](./save.md)。

### 数据图元

这一组是把数据画成图形的图元，绝大多数图形来自建图向导，见[创建图表](./create.md)。

**曲线 / Curve** 页有九个分组，是图元页里最全的一个。曲线图元由建图向导用 X、Y 两组序列创建，散点图也共用这一页，区别在创建时把样式设成了只画点。

| 分组 | 设置 |
|------|------|
| `General` / 通用 | `Title`、`Z Value`、`X Axis`、`Y Axis` |
| `Curve Style` / 曲线样式 | `Style`：`Lines` / 线条、`Sticks` / 棒状、`Steps` / 阶梯、`Dots` / 点、`No Curve` / 无曲线 |
| `Pen` / 画笔 | `Pen` |
| `Marker` / 标记 | `Enable Marker`、`Symbol` |
| `Attributes` / 属性 | `Fitted` / 拟合、`Inverted` / 反转 |
| `Legend` / 图例 | `Show Line`、`Show Symbol`、`Show Brush` |
| `Fill` / 底色 | `Enable Fill`、`Fill Brush` |
| `Baseline` / 基线 | `Baseline` |
| `Orientation` / 方向 | `Orientation`：`Horizontal` / 水平、`Vertical` / 垂直 |

`Style` 决定这条曲线怎么连点：`Lines` 用直线连，`Sticks` 从基线往每个点画竖棒，`Steps` 画成台阶，`Dots` 只画采样点。`Fitted` 打开后曲线改用平滑拟合穿过采样点，只在 `Lines` 样式下起作用。`Inverted` 只在 `Steps` 样式下可用，把台阶从右往左画改成从左往右画。`Fill` 打开后曲线与基线围成的区域填上颜色，用 `Sticks` 样式时填充会被禁用。

`Baseline` 是一个文本框，填数字，作为填充的下边界。填的不是数字时输入会被忽略，曲线维持原样。`Orientation` 影响两件事：`Sticks` 样式的棒是竖着还是横着画，填充区域以哪条方向的基线为界。数据本身还是照 X 和 Y 两组序列摆放，这个选项不交换坐标轴。

`Marker` 分组里的 `Symbol` 是一个符号编辑器，可以挑符号形状、尺寸、颜色和轮廓画笔，形状有 `No Symbol` / 无符号、`Ellipse` / 椭圆、`Rectangle` / 矩形、`Diamond` / 菱形、`Triangle` / 三角形 以及各种方向的三角形、`Cross` / 十字标记、`Diagonal Cross` / 斜十字、`Horizontal Line` / 水平线、`Vertical Line` / 垂直线等。关闭 `Enable Marker` 后不画符号。

`Legend` 分组的三个开关决定图例条目里画哪些部分，`Show Line` 画线，`Show Symbol` 画符号，`Show Brush` 画填充，三个都关掉时图例里只留文字。三个开关只影响图例，不影响曲线本身的外观。

**柱状 / Bar** 页处理单组柱体，柱子的高度直接取自 Y 序列。

| 分组 | 设置 |
|------|------|
| `Basic` / 基础 | `Title`、`Z Value` |
| `Axis` / 坐标轴 | `X Axis`、`Y Axis` |
| `Legend` / 图例 | `Legend Mode` / 图例模式：`Chart Mode` / 图表模式、`Bar Mode` / 柱状模式 |
| `Fill` / 底色 | `Enable Fill`、`Fill Brush` |
| `Edge` / 边框 | `Enable Edge`、`Edge Pen` |
| `Baseline` / 基线 | `Baseline` |
| `Layout` / 布局 | `Layout Policy` / 布局策略、`Layout Hint` / 布局提示、`Spacing` / 间距、`Margin` / 边距 |

`Legend Mode` 决定图例里出现一项还是多项。`Chart Mode` / 图表模式 只给整个图表一项，用图元的标题当文字；`Bar Mode` / 柱状模式 给每根柱子各一项，用柱子的名字当文字。新建的柱状图默认用 `Chart Mode`。

`Layout Policy` 的四个取值是 `Auto Adjust Samples` / 自动调整采样、`Scale Samples To Axes` / 采样缩放至坐标轴、`Scale Sample To Canvas` / 采样缩放至画布、`Fixed Sample Size` / 固定采样尺寸。自动调整让柱宽随数据点数量变，缩放到坐标轴让柱宽按数据单位算，缩放到画布让柱宽按像素算，固定尺寸则始终用 `Layout Hint` 指定的宽度。布局策略和布局提示两个值一起决定柱宽，新建的柱状图默认是自动调整采样，布局提示 0.5。`Spacing` 的取值是 0 到 1000，默认 10；`Margin` 的取值是 0 到 1000，默认 5，两者分别控制柱与柱之间、柱与轴之间的留白。

`Enable Fill` 关掉后柱体只画边框，`Enable Edge` 关掉后柱体只填色不勾边。填 `Baseline` 文本框里的数字可以抬高或压低柱体的起点。

**误差棒 / Error Bar** 页在曲线上加一条表示误差的区间，误差棒图元用 X、Y 和误差三列创建，区间等于 Y 加减误差列。

| 分组 | 设置 |
|------|------|
| `Basic` / 基础 | `Title`、`Z Value` |
| `Axis` / 坐标轴 | `X Axis`、`Y Axis` |
| `Error Bar` / 误差棒 | `Enable Error Bar`、`Error Bar Style` / 误差棒样式、`Error Bar Pen` |
| `Fill` / 底色 | `Enable Fill`、`Fill Brush` |
| `Curve` / 曲线 | `Orientation`、`Curve Pen` |

`Error Bar Style` 有两个取值，`Bar` / 柱状 把误差画成一根带端帽的竖线，`Box` / 方框 画成一个矩形框。`Curve Pen` 是穿过各点的连线画笔，`Error Bar Pen` 是误差线的画笔，两者可以设成不同颜色。区间是数据点加减误差列给出的值，误差列在建图时选定。

`Enable Error Bar` 关掉后误差区间不再绘制，只留下中间的曲线，样式和画笔两个字段同时变灰。`Orientation` 选 `Horizontal` 时误差棒横着画，用来表示横坐标上的误差。`Enable Fill` 打开后用画刷给曲线与基线之间的区域铺色，和误差棒是否显示无关。

**等高线 / Contour** 页用颜色表示数值大小，等高线图元用 X、Y、Value 三列创建。

| 分组 | 设置 |
|------|------|
| `Basic` / 基础 | `Title`、`Z Value`、`X Axis`、`Y Axis` |
| `Drawing` / 绘制 | `Orientation`、`Pen Width` / 笔宽、`Clip Points` / 裁剪点 |
| `Color Map` / 颜色映射 | `Color Range Min` / 颜色范围最小值、`Color Range Max` / 颜色范围最大值 |

颜色范围的最小和最大值决定哪个数值对应色带的两端，超出范围的数值被夹到端点颜色，两者都是 −1e15 到 1e15 的数值，保留 6 位小数。`Clip Points` 打开后落在画布外的点直接丢弃，能加快大数据的重绘。`Pen Width` 的范围是 0 到 10。颜色范围收窄到中间一段数值，可以把差异较小的区域拉开来看，代价是两端的数值压成同一种颜色。

**向量场 / Vector Field** 页画一串带方向的箭头，向量场图元用 X、Y、U、V 四列创建，U 和 V 是向量的两个分量。

| 分组 | 设置 |
|------|------|
| `Basic` / 基础 | `Title`、`Z Value`、`X Axis`、`Y Axis` |
| `Appearance` / 外观 | `Pen`、`Brush`、`Indicator Origin` / 箭头原点 |
| `Magnitude` / 幅值 | `Magnitude As Color` / 幅值映射颜色、`Magnitude As Length` / 幅值映射长度、`Min Arrow Length` / 最小箭头长度、`Max Arrow Length` / 最大箭头长度、`Magnitude Scale Factor` / 幅值缩放因子 |
| `Filter` / 过滤 | `Filter Vectors` / 过滤矢量、`Raster Width` / 栅格宽度、`Raster Height` / 栅格高度 |

`Indicator Origin` 决定箭头以哪一端对准数据点，可选 `Head` / 头部、`Tail` / 尾部、`Center` / 居中。幅值相关的两个开关决定箭头的大小和颜色是否随数值变化，打开长度映射后箭头长度被限制在最小和最大值之间，缩放因子把原始幅值整体乘一个系数。`Filter Vectors` 打开后按栅格抽稀，只保留栅格点上的箭头，`Raster Width` 和 `Raster Height` 是栅格在横纵方向上的像素间距。

**多重柱状 / Multi Bar** 页在一个横坐标上并排或堆叠多组柱体，图元用一列 X 和多列 Y 创建，每个 Y 序列是一组柱。

| 分组 | 设置 |
|------|------|
| `Basic` / 基础 | `Title`、`Z Value`、`X Axis`、`Y Axis` |
| `Style` / 样式 | `Orientation`、`Chart Style` / 图表样式、`Baseline` |
| `Layout` / 布局 | `Layout Policy` / 布局策略、`Layout Hint` / 布局提示、`Spacing` / 间距、`Margin` / 边距 |

`Chart Style` 只有两个取值，`Grouped` / 分组 把多组柱体并排摆放，`Stacked` / 堆叠 把它们摞成一根，新建的多重柱状默认用分组。用堆叠时同一组里的数值需要同号，正负混在一起摞出来的高度没有意义。`Layout Policy` 的四个取值和柱状页一致，但用的是 `Auto Adjust` / 自动调整、`Scale To Axes` / 缩放到坐标轴、`Scale To Canvas` / 缩放到画布、`Fixed Sample Size` / 固定采样尺寸。`Spacing` 的取值是 0 到 1000，默认 10；`Margin` 的取值是 0 到 1000，默认 5。

**直方图 / Histogram** 页把一组数值画成分布。图元由建图向导用一列数据和分箱数创建，箱子里的计数在创建时就定下来。

| 分组 | 设置 |
|------|------|
| `Basic` / 基础 | `Title`、`Z Value`、`X Axis`、`Y Axis` |
| `Style` / 样式 | `Orientation`、`Histogram Style` / 直方图样式、`Pen`、`Brush`、`Baseline` |

`Orientation` 选 `Vertical` 时柱子朝上长，选 `Horizontal` 时朝右长。`Histogram Style` 的三个取值是 `Outline` / 轮廓、`Columns` / 柱状、`Lines` / 线条，分别对应画轮廓多边形、画实心柱、只画竖向线，新建的直方图默认画实心柱。`Baseline` 是数值输入，范围 −1e15 到 1e15，默认 0，决定柱体的起点高度。`Pen` 是轮廓画笔，`Brush` 是填充画刷：`Outline` 样式下画笔勾出多边形轮廓、画刷铺多边形内部，`Columns` 样式下两者分别管柱体的边和底色，`Lines` 样式只用画笔。

直方图的分箱数在创建时确定，设置页里改不了。Y 轴显示计数还是密度同样在建图时选定。

**云图 / Spectrogram** 页把矩阵画成色块图，图元用 X 列表、Y 列表和一张矩阵创建，矩阵的每个值对应网格上的一个方块。

| 分组 | 设置 |
|------|------|
| `Basic` / 基础 | `Title`、`Z Value` |
| `Axis` / 坐标轴 | `X Axis`、`Y Axis` |
| `Display` / 视图显示 | `Display Mode` / 显示模式：`Image Mode` / 图像模式、`Contour Mode` / 等值线模式 |
| `Color` / 颜色 | `From Color` / 起始颜色、`To Color` / 终止颜色 |
| `Contour` / 等值线 | `Contour Pen` |

`Image Mode` 把每个网格值画成一个带颜色的像素块，`Contour Mode` 改画等值线。起始颜色和终止颜色构成色带的两端。`Contour Pen` 只在等值线模式下有效，图像模式下这个输入框是灰的。

### 标注与装饰图元

这一组图元本身不含数据序列，用来在图上加说明和参照。添加它们的入口在 Ribbon 的「Chart Edit / 绘图编辑」页，「Select Tool / 选区工具」面板里有 `Add Rect`、`Add Ellipse`、`Add Polygon`，「Chart Assist Tool / 图表辅助工具」面板里有 `Add Cross Marker`、`Add H Line Marker`、`Add V Line Marker`、`Add Arrow Marker`、`Add Text`。网格和图例不在那里的入口上，网格由「Chart Style / 图表样式」页的 `Enable Grid` 打开，图例由同页的 `Legend` 打开。按钮和设置页的对应关系如下。

| Ribbon 动作 | 生成的图元 | 设置页 |
|-------------|------------|--------|
| `Add Rect` / 添加矩形 | 矩形形状 | 形状 |
| `Add Ellipse` / 添加椭圆 | 椭圆形状 | 形状 |
| `Add Polygon` / 添加多边形 | 多边形形状 | 形状 |
| `Add Cross Marker` / 添加十字 | 十字标记线 | 标记线 |
| `Add H Line Marker` / 添加水平线 | 水平标记线 | 标记线 |
| `Add V Line Marker` / 添加垂直线 | 垂直标记线 | 标记线 |
| `Add Arrow Marker` / 添加箭头 | 箭头标注 | 箭头标注 |
| `Add Text` / 添加文本 | 文字标注 | 文字标注 |
| `Enable Grid` / 网格 | 网格 | 网格 |
| `Legend` / 图例 | 图例 | 图例 |

选 `Add Rect`、`Add Ellipse` 或 `Add Polygon` 之后，在画布上按住左键拖出一个框，松开后形状就留在图上，可以在形状页里改它的边和填充。形状是数据坐标系里的对象，缩放或平移时跟着数据走。

**文本标签 / Text Label** 页管理印在画布上的成段文字。

| 分组 | 设置 |
|------|------|
| `Basic` / 基础 | `Title`、`Z Value`、`X Axis`、`Y Axis` |
| `Text` / 文本 | `Text Content` / 文本内容、`Font`、`Text Color` / 文字颜色、`Alignment` / 对齐、`Margin` / 边距 |
| `Background` / 背景 | `Border Radius` / 边框圆角、`Background Brush` |

文本内容支持多行，外边距的取值是 0 到 1000 像素，边框圆角的取值是 0 到 50。

文本标签按对齐方式摆在画布上，横向纵向都对齐好之后就固定在那里，缩放或平移数据范围不影响它的位置，这一点和按数据坐标定位的文字标注不同。外边距把可用画布范围向内收缩，数值调大时文字离画布边缘更远。给文字配一个浅色背景画刷和圆角，压住底下的曲线更容易读。

**文字标注 / Text Marker** 页是另一种文字对象，可以拖到任意位置。

| 分组 | 设置 |
|------|------|
| `Basic` / 基础 | `Title`、`Z Value`、`X Axis`、`Y Axis`、`Anchor X` / 锚点 X、`Anchor Y` / 锚点 Y |
| `Text` / 文本 | `Content` / 内容、`Font`、`Text Color` / 文字颜色、`Alignment` / 对齐 |
| `Background` / 背景 | `Border Radius` / 边框圆角、`Background Brush` |
| `Layout` / 布局 | `Spacing` / 间距 |

`Content` 是一行「Edit Rich Text... / 编辑富文本...」按钮，点开一个所见即所得的编辑框改文字和格式。锚点 X 和锚点 Y 决定标注挂在哪个数据位置上，范围都是 −1e15 到 1e15。用鼠标拖动标注可以改位置。

文字标注按数据坐标定位，改坐标轴范围时它跟着数据一起移动。这一点适合给某个数据点写注释：把锚点对到那个点上，缩放后注释仍然指着它。双击图上的文字也能直接打开编辑框，改完的文字立即反映到图上。拖动标注改的是它的位置，设置页里的锚点数值要重新选中这个标注才会刷新。

背景圆角的范围是 0 到 50，布局分组的 `Spacing` 范围是 0 到 100，控制文字与背景边框之间的留白。留白给 0 时文字紧贴边框，填大一点更透气。

**标记线 / Marker** 页画横线、竖线或十字线。

| 分组 | 设置 |
|------|------|
| `Basic` / 基础 | `Title`、`Z Value`、`X Axis`、`Y Axis` |
| `Position` / 位置 | `X Value` / X值、`Y Value` / Y值 |
| `Line` / 线 | `Line Style` / 线样式、`Line Pen` / 线条画笔 |
| `Label` / 标签 | `Label` / 标签、`Label Alignment` / 标签对齐、`Label Orientation` / 标签方向、`Spacing` / 间距 |

`Line Style` 的四个取值是 `No Line` / 无线、`Horizontal` / 水平、`Vertical` / 垂直、`Cross` / 十字标记，画横线时只有 `Y Value` 有意义，画竖线时只有 `X Value` 有意义，`Cross` 两处都用。标签文本显示在线的旁边，`Label Orientation` 可选 `Horizontal` / 水平 或 `Vertical` / 垂直，`Spacing` 是标签离线的距离，取值 0 到 1000。

标记线常用来标参考值，比如把 `Y Value` 填成阈值、线型选 `Horizontal`，再在标签里写上这个阈值的名字。三条 Ribbon 动作分别对应十字、水平和垂直三种线型，添加后不需要再改线型。新建的标记线是一条红色虚线，用 `Line Pen` 换成别的颜色或线型。标记线可以用鼠标拖动，拖动把新的位置写回图元；设置页里的数值要重新选中这个图元才会刷新。

**箭头标注 / Arrow Marker** 页画带端点的箭头。

| 分组 | 设置 |
|------|------|
| `Basic` / 基础 | `Title`、`Z Value`、`X Axis`、`Y Axis` |
| `Position` / 位置 | `Position Mode` / 定位模式、`Start X` / 起点X、`Start Y` / 起点Y、`End X` / 终点X、`End Y` / 终点Y、`Length` / 长度、`Angle` / 角度 |
| `Line` / 线 | `Line Pen` / 线条画笔 |
| `Head` / 头部 | `Head Style` / 头部样式、`Head Size` / 头部尺寸、`Head Pen` / 头部画笔、`Head Brush` / 头部画刷 |
| `Tail` / 尾部 | `Tail Style` / 尾部样式、`Tail Size` / 尾部尺寸、`Tail Pen` / 尾部画笔、`Tail Brush` / 尾部画刷 |

`Position Mode` 有两个取值。`Explicit Points` / 显式起止点 用起点和终点两组坐标定位置，四个坐标的范围都是 −1e15 到 1e15；`Start Length Angle` / 起点长度角度 用起点坐标加长度和角度给出终点，长度范围 0 到 10000，角度范围 −360 到 360，两者都保留 3 位小数。头尾样式各有七个取值：`None` / 无、`Arrow Head` / 箭头、`Circle` / 圆形、`Square` / 方形、`Diamond` / 菱形、`Triangle` / 三角形、`Custom` / 自定义。头尾可以选不同的形状，比如头用箭头、尾用圆形，也能把其中一端关掉。头部尺寸和尾部尺寸的范围都是 0 到 1000，画笔和画刷分别控制端点的描边和填充。

箭头标注用来指出图上的某个位置，比如从空白处拉一支箭头指向曲线上的拐点。箭头也能用鼠标拖动，拖动时起点和终点一起平移，长度和角度按新位置重新算出来。

**形状 / Shape** 页管理 `Add Rect`、`Add Ellipse`、`Add Polygon` 画出来的图形。

| 分组 | 设置 |
|------|------|
| `Basic` / 基础 | `Title`、`Z Value`、`X Axis`、`Y Axis` |
| `Appearance` / 外观 | `Pen`、`Brush`、`Legend Mode` / 图例模式 |
| `Render` / 渲染 | `Render Tolerance` / 渲染容差、`Clip Polygons` / 裁剪多边形 |

`Legend Mode` 可选 `Shape` / 形状 或 `Color` / 颜色，决定图例里用图形还是用色块代表这个图元。`Render Tolerance` 的范围是 0 到 10，多边形边数很多时调大它能让重绘更快。`Clip Polygons` 打开后画布外的部分不参与绘制。

形状的作用是圈出图上的一块区域，配上半透明的画刷可以标出某段数据范围。形状的三个 Ribbon 动作画出来的分别是正矩形、椭圆和多边形，多边形动作支持逐点勾出任意轮廓。选中形状后用 Delete 键删除，也可以用指针工具拖动整块形状。

**区间 / Zone** 页在坐标系里高亮一段范围。

| 分组 | 设置 |
|------|------|
| `Basic` / 基础 | `Title`、`Z Value`、`X Axis`、`Y Axis` |
| `Zone` / 区间 | `Orientation`、`Interval Min` / 区间最小值、`Interval Max` / 区间最大值 |
| `Appearance` / 外观 | `Pen`、`Brush` |

区间的上下界都是 −1e15 到 1e15，横竖由 `Orientation` 决定，画笔勾边、画刷铺色。用它标出参考范围、感兴趣的时间段时，画刷设成半透明不会盖住下面的曲线。区间与形状的区别在于区间只按一段数值范围铺色，横跨整条轴，不需要在画布上拖出矩形，适合标出像温度区间这类贯穿全图的带子。

**网格 / Grid** 页控制底纹的线条。

| 分组 | 设置 |
|------|------|
| `Basic` / 基础 | `Title`、`Z Value` |
| `Axis` / 坐标轴 | `X Axis`、`Y Axis` |
| `Line Style` / 线条样式 | `Major Pen` / 主笔、`Minor Pen` / 次笔 |

主笔画主刻度位置的格线，次笔画次刻度位置的格线。把某支笔的颜色设成透明，对应的格线就不显示了。主次格线分两个颜色时，图上的读数更容易按格子对齐。网格图元挂在哪两条轴上由 `X Axis` 和 `Y Axis` 决定，改成上 X 轴或右 Y 轴后格线按那两条轴的刻度位置画。

**刻度尺 / Scale** 页在图表里额外放一条坐标尺。

| 分组 | 设置 |
|------|------|
| `Basic` / 基础 | `Title`、`Z Value`、`X Axis`、`Y Axis` |
| `Scale` / 刻度 | `Alignment` / 对齐、`Position` / 位置、`Border Distance` / 边框距离、`Sync Scale From Axis` / 同步坐标轴刻度 |
| `Font` / 字体 | `Font` / 字体 |

`Alignment` 可选 `Bottom` / 底部、`Top` / 顶部、`Left` / 左侧、`Right` / 右侧，决定刻度数字画在哪一侧，也决定刻度尺是横放还是竖放。`Position` 是刻度尺在另一条轴上的数据坐标位置，横放的刻度尺填 Y 值，竖放的填 X 值，输入框允许 0 到 100。`Border Distance` 是刻度尺离画布边界的距离，默认 −1 表示自动，范围 −1 到 9999。

刻度尺画在画布内部，和坐标轴的区别就是位置更靠里，方便把数字摆在离曲线近的地方。对齐方式决定它贴在哪条边，挂靠的轴由 `X Axis` 和 `Y Axis` 两个下拉框决定。`Font` 分组改的是刻度尺自己的数字字体，和坐标轴页的字体设置各管一处。

`Sync Scale From Axis` 打开后，刻度尺的刻度范围直接取自它挂靠的坐标轴，改轴的上下限时刻度尺跟着变。关闭时刻度尺按自己的范围显示，位置和数字可能和轴对不上。

**图例 / Legend** 页管理图元对照表。

| 分组 | 设置 |
|------|------|
| `Basic` / 基础 | `Title`、`Z Value` |
| `Position` / 位置 | `Alignment` / 对齐、`Horizontal Offset` / 水平偏移、`Vertical Offset` / 垂直偏移 |
| `Spacing` / 间距 | `Margin` / 边距、`Spacing` / 间距、`Item Margin` / 项边距、`Item Spacing` / 项间距、`Max Columns` / 最大列数 |
| `Appearance` / 外观 | `Border Radius` / 边框圆角、`Border Pen` / 边框画笔、`Font` / 字体、`Font Color` / 字体颜色、`Background Brush` / 背景画刷 |

对齐用九宫格选择图例贴在画布的什么位置，两个偏移量在 −1000 到 1000 之间，以像素为单位把图例从对齐位置推开。四个间距字段的取值都是 0 到 1000 像素：`Margin` 是图例整体离画布边缘的留白，`Spacing` 是图例内部构件之间的间隔，`Item Margin` 是每个条目内部文字与边框的距离，`Item Spacing` 是条目与条目之间的缝隙。`Max Columns` 的范围是 0 到 100，用来限制图例最多排几列，条目多的时候靠它把图例摊宽或排成长条。边框圆角范围 0 到 100，配合边框画笔和背景画刷画出圆角底板。

图例条目的内容来自各个图元：曲线页的 `Legend` 分组决定曲线在条目里画线、画符号还是画填充，柱状页的 `Legend Mode` 决定按图表给一项还是按柱子给多项，形状页的 `Legend Mode` 决定用图形还是色块表示。图例条目左侧的色块颜色取图元的颜色，曲线取画笔颜色，柱状取填充颜色。

图例位置还有一条更快的路：Ribbon「Chart Style / 图表样式」页的 `Legend` 按钮带一个下拉菜单，里面有 `Legend Top`、`Legend Bottom`、`Legend Left`、`Legend Right`。

### 箱体图

**箱体 / Box** 页把一列或多列数据的分布画成箱体。

| 分组 | 设置 |
|------|------|
| `Basic` / 基础 | `Title`、`Z Value`、`X Axis`、`Y Axis` |
| `Box` / 盒形 | `Orientation`、`Box Style` / 箱体样式、`Box Extent` / 箱体宽度、`Min Box Width` / 最小宽度、`Max Box Width` / 最大宽度、`Pen` / 轮廓画笔、`Brush` / 填充画刷 |
| `Whisker` / 须线 | `Whisker Style` / 须线样式 |
| `Median` / 中位数线 | `Median Visible` / 中位数线可见、`Median Pen` / 中位数线画笔 |
| `Mean` / 均值 | `Mean Visible` / 均值标记可见 |
| `Outliers` / 离群点 | `Outlier Jitter` / 离群点抖动 |

`Box Style` 有四个取值，`No Box` / 无箱体、`Rectangle` / 矩形、`Diamond` / 菱形、`Notched` / 带凹槽，新建的箱体默认画矩形。`No Box` 只留须线和离群点，适合只想看极值和异常值的情况。

`Box Extent` 的取值范围是 0.1 到 10，新建的箱体默认 0.6，含义是箱体宽度相对数据间距的比例。`Min Box Width` 范围 0 到 1000，默认 2；`Max Box Width` 范围 −1000 到 1000，默认 −1。两个宽度限制一起作用，用来避免数据点很少时箱体画得过宽或过窄。

`Whisker Style` 的三个取值是 `No Whiskers` / 无须线、`Standard (T-bar)` / 标准(T形)、`Min-Max Line` / 极值线，分别对应不画须线、画带横帽的须线、画到极值的线。新建的箱体默认用标准须线。

`Median Visible` 默认打开，中位数线用一条单独的画笔勾出来；关掉后箱体里不画中位数线，`Median Pen` 同时变灰。`Mean Visible` 默认关闭，打开后在箱体里加一个均值标记。`Outlier Jitter` 默认 0，范围 0 到 1000，给离群点在横向上加一点随机偏移，点很密时能看出一共有几个。

箱体页的 `Title` 和绘图管理树里的条目名字一致，建图时选一列就用列名，选多列时列名用 `|` 连接成一个标题，改成看得懂的名字更好找。

## 常见调整步骤

下面三步都是面板上现成的设置，按顺序做完就能得到对应效果。

**出图前把版面收干净。** 在绘图区页把背景画刷设成白色，边框宽度保持 0；在四个坐标轴页里关掉上 X 轴和右 Y 轴，只留下 X 轴和左 Y 轴；在图表区页把坐标系标题改成要用的图题，字号比默认大一点。网格图元那一页把 `Minor Pen` 的颜色设成透明，只留主格线。要留更多空白给图题，可以用坐标轴页的 `Margin` 把轴标题往外推。

**两根曲线对照读数。** 让两个待比较的曲线各占一个坐标系，分别写上标题。在数据拾取页把 `Picker Mode` 设成 `Y Value`，打开 `Picker Group Enabled`，再把 `Text Placement` 设成 `Follow Mouse` 或某个画布角。鼠标在任一坐标系上移动时，两个坐标系同时给出读数，读数框位置固定后不会遮住曲线。两个坐标系共用同一段横坐标时读数才能直接对比，纵轴范围不一致时以各自轴上的数值为准。

**在图上标出阈值。** 在「Chart Assist Tool / 图表辅助工具」里点 `Add H Line Marker`，在标记线页把 `Y Value` 填成阈值。`Line Style` 保持 `Horizontal`，在 `Label` 里写阈值的名字，`Line Pen` 换成灰色或浅色虚线，避开曲线的主色。横线的纵坐标是固定值，缩放横轴不会挪动它。

## 面板里没有的设置

有些参数容易以为能在设置面板里找到，实际不在这里，列出来省得反复翻页。

| 想要的效果 | 实际入口 |
|------------|----------|
| 对数坐标 | 界面里没有，只能用 `da_pyplot` 的 `setXScale`、`setYScale` |
| 网格开关 | Ribbon「Chart Style / 图表样式」页的 `Enable Grid` 及其子项 |
| 图例开关和位置 | Ribbon「Chart Style / 图表样式」页的 `Legend` 按钮及下拉菜单 |
| 缩放、平移、十字光标、读数开关 | Ribbon「Chart Style / 图表样式」页，或数据拾取页里的 `Picker Mode` |
| 绘图宽高的上下限和背景 | 「Charts Manager / 绘图管理」标题栏的齿轮按钮 |
| 坐标系在绘图里的位置和大小 | 不在设置面板，用「Resize Chart / 绘图尺寸」浮层拖动调整 |
| 两个坐标系共用同一段坐标轴范围 | 界面里没有入口，目前只能由代码绑定 |
| 按厘米或英寸设尺寸、设 DPI | 没有这项设置，复制到剪贴板按屏幕像素截取 |
| 导出 PDF、SVG 或高分辨率位图 | 没有这项设置，见[复制与保存图表](./save.md) |
| 把图上的数值存成文件 | 没有这项设置，见[数据探针与数据联动表](./data-probe.md) |

网格的开启和细分线开关在 Ribbon 的 `Enable Grid`、`X Grid`、`Y Grid`、`Xmin Grid`、`Ymin Grid` 上，设置页的网格图元只负责改主次格线的画笔。

建图向导里出现过的十三种图表都能在设置面板里找到对应页面。代码里还实现了另外一些图元，比如 K 线图，它们没有菜单入口，界面里创建不出来，正常使用中不会遇到。

## 常见问题

**改了设置，图上没有变化。** 先确认改的是不是当前选中的对象。下拉框、绘图管理树和绘图上的选中状态三者是同步的，在下拉框里改参数作用于下拉框当前那一项，对着另一个对象看画面自然没有反应。其次看有没有别的项把它盖住了：画笔颜色和背景画刷颜色接近、边框宽度是 0、`Enable Fill` 和 `Enable Edge` 都关着，都会让改动看不出来。少数外观选项在当前实现里确实不改变显示，比如画布页只改 `Border Pen` 而不设边框宽度。

**怎么知道现在选中的是哪个对象。** 面板顶部下拉框里显示的名字就是当前编辑的对象。名字来自图元的 `Title`，`Title` 为空或没有名字的图元会显示占位名字，不容易分辨，建议在下拉框或图表管理树里给图元改个名。图表管理树里被点中的条目会高亮，面板同时切到对应页面，两边可以互相印证。

**`Apply All Charts` 打开了却没有生效。** 这个开关只接管 Ribbon 上的图表动作，界面上设置面板里的参数仍然只写给当前选中的对象。要给同一个绘图里的多个坐标系套用同样的设置，逐个选中改一遍。

**下拉框里找不到刚加的图元。** 图元行只列当前坐标系的图元，图元如果加在同一个绘图里的另一个坐标系上，就要先在绘图上点一下那个坐标系，或者在绘图管理树里展开它的 `plot item` 节点，面板才会列出对应条目。三维图元不出现在这个下拉框里，它们归三维设置面板管。

**面板上什么都没有。** 下拉框为空说明当前绘图里还没有坐标系，或者面板停在了一个刚被删掉的坐标系上。先新建或选中一个坐标系，面板会重新填满。面板停在图元页上而图元被删除时，条目和图元页一起消失，需要重新在绘图上点选要编辑的对象。

**改错了想撤销。** 设置面板里的改动不进撤销栈，撤销按钮回退的是添加或删除图元、拖动图元位置、调整坐标系大小这三类操作。参数改完立刻生效，要回到原值只能手动改回去。改动一次参数前后差别不大时，可以先记下原值再动。

**改了数据管理面板里的数据，图上的曲线没变。** 图表保存的是创建时取到的采样点，不引用数据来源。要按新数据重画，需要重新走一遍建图向导建一个图元，或者用 `da_pyplot` 的 `plot` 在同一个坐标系里再画一条，见[创建图表](./create.md)和[脚本工作区](../script/workspace.md)。
