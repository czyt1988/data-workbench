# 创建图表

一张图由两件事定下来：用哪种图表类型，以及把哪几列数据交给它。软件把这两步收在同一个建图向导里，左侧挑类型，右侧填数据，点「OK」之后图元就画进当前的坐标系。这一章按向导列表的顺序，逐个说明十三个类型各要什么数据、向导上有哪些参数、什么时候选它。

## 建图向导

Ribbon 的「Figure」/ 绘图 分类下有「Add Chart」/ 添加绘图 面板，面板上每个按钮对应一个图表类型。按钮文字在界面上折成两行显示，下表按面板从左到右的顺序列出。

| 面板按钮 | 向导列表里的类型 | 类型代号 |
|---|---|---|
| 「Add Curve」/ 曲线 | curve | Curve |
| 「Add Scatter」/ 散点图 | scatter | Scatter |
| 「Add Error Bar」/ 误差棒图 | error bar | ErrorBar |
| 「Add Box Plot」/ 箱线图 | box | Box |
| 「Add Bar」/ 柱状图 | bar | Bar |
| 「Add MultiBar」/ 多重柱状图 | multi bar | MultiBar |
| 「Add Histogram」/ 分布图 | histogram | Histogram |
| 「Add Contour Map」/ 等高线图 | contour | Contour |
| 「Add Cloud Map」/ 云图 | cloud map | Spectrogram |
| 「Add Vector Field」/ 向量场图 | vector field | VectorField |
| 「Add Surface 3D」/ 3D曲面图 | surface 3D | Surface3D |
| 「Add Bar 3D」/ 3D柱状图 | bar 3D | Bar3D |
| 「Add Line 3D」/ 3D线图 | line 3D | Line3D |

点任意一个按钮，软件打开建图向导对话框，同时把「数据管理」面板抬到前面，向导的窗口标题是「Chart Guide」/ 图表向导。按钮决定向导打开时选中哪个类型，打开之后仍可以在左侧列表里换。

向导分左右两块。左侧是类型列表，列的就是上表第二列的文字，这些文字在界面上保持小写，比如 `curve`、`surface 3D`。右侧是一块堆叠区域，切换左侧的选项就换成那个类型的数据设置页。底部是「OK」和「Cancel」。

点「OK」之后依次发生四件事：设置页从界面上读出选好的列并整理成绘图用的数据；软件取当前绘图，没有绘图就新建一个；取当前坐标系，没有坐标系就新建一个；把图元加进坐标系，然后按数据范围重新调整坐标轴并重绘。所以建图之前必须先有一份数据集，数据集出现在「数据管理」面板里，导入数据见[导入数据](../data/import.md)。

## 第二条入口：把数据拖到绘图上

「数据管理」面板里的数据条目可以直接拖到绘图上。拖动时鼠标进入某个坐标系的范围，光标才显示为可放下；拖到绘图的空白处不响应。

放下的东西不同，向导打开的状态也不同：

- 拖的是一个数据集（DataFrame），向导停在 `curve`，数据不会被预先填进去，要换类型就在左侧列表里点一下。
- 拖的是序列（某一列），向导强制切到 `curve`，并把序列填进曲线页的列表：拖一列就填进 Y 列表，同时拖两列就分别填进 X 和 Y 列表。

这条入口省掉的只是点按钮那一步，填数据的过程和点按钮一样。

## 数据设置页的通用操作

多数类型的数据设置页是同一套控件：一块列表加两个小按钮。

- 列表里放当前已经选好的序列，列表表头按角色命名，比如 `x`、`y`、`error`。
- 加号按钮「Add series」/ 添加序列，点开后向导暂时隐藏，屏幕上浮出一个标题为「Select Series」/ 选择序列 的小窗口。小窗口上有一行表达式输入框、一个占位提示 `data['column']`，以及一个「Return to add chart」/ 回到添加绘图 按钮。用法是在「数据管理」面板里点某一列或者点表格里的列名，表达式自动填好，再点勾按钮确认，向导重新出现，这一列进入列表。表达式写错时弹出警告，提示期望的形式是 `data['column']`。
- 减号按钮「Remove selected series」/ 移除所选序列，把列表里当前选中的一项去掉。

列表旁边通常还有一行提示文字。曲线、散点、柱状页的提示是「Drag the data into the corresponding list」/ 把数据拖入对应的列表，因此也可以直接从「数据管理」面板把列拖进列表。

数据集下拉框出现在箱体、云图和三个三维类型的页上，用来指定这一张图的数据来自哪份数据集。

## 向导只认数值

无论哪种类型，取数的过程都是把选中的列逐行转成浮点数，转不过去的值会引发一次异常，这次建图被放弃。把某一列当成自增序列来源时，向导会弹出「Exception occurred during extracting from pandas.Series to double vector」/ 从pandas.Series提取为double vector过程中出现异常 这样的警告框；曲线、散点、柱状上 X 和 Y 都给了真实数据时没有弹窗，只在消息面板里留下一条记录。常见的三种情况是：选中的列是文本列，列里混了不能转成数字的字符，列里的空值没有先处理。

三类类型取数的规则略有区别，建图前先确认：

- 需要多列的类型（误差棒、等高线、向量场、3D线图）要求各列长度能对上；误差棒按 X 和 Y 中较短的长度取点，误差列按同一个序号取值；等高线、向量场把每列分别转成一个向量交给图元。
- 需要矩阵的类型（云图、3D曲面、3D柱状的网格模式）对维度有硬性要求，云图要求 X 的长度等于矩阵列数、Y 的长度等于矩阵行数，3D曲面的网格模式要求数据框至少 2 行 2 列，3D柱状的网格模式只要数据框不为空。云图不满足时弹出一句维度提示；两个三维类型不弹窗，直接不画图。
- 需要插值的类型只有一个：`surface 3D` 的散点模式。它要求至少 3 个点，并且依赖内嵌 Python 环境里的 scipy 库。

选中的列在界面上仍然是数据表里的那一列，图元拿到的是转换后的采样点，图上不再保留和数据表的联系，这一点在[复制与保存图表](./save.md)里有说明。

## 画上去之后

点「OK」之后，图元挂在当前坐标系上，位置由数据决定，颜色由软件按配色循环自动分配，同一个坐标系里添加的图元依次取下一个颜色，不容易撞色。图元的默认名字大多取自数据的列名：曲线、等高线、向量场分别用 Y 列、Value 列、U 列的名字；多重柱状把 Y 各列的名字用竖线连起来，同时作为图例里每一组柱子的名字；箱体把所选列名连起来；误差棒固定叫「Error Bar」/ 误差棒；柱状不带默认名字，它在绘图管理树里按位置显示成柱状图加序号。

新画的图元进入当前绘图的撤销栈，可以撤销。颜色、线型、符号、填充这些都可以之后改，见[二维图表设置](./settings-2d.md)。

同一块坐标系里可以反复叠加图元。要对照一组曲线，用「Add Curve」画完一条，把向导留着，改一列再点「OK」，第二条曲线落在同一块坐标系上；不同量级的数据更适合分成两块坐标系，见[绘图与坐标系](./figure.md)。

## 界面提示与处理办法

向导里的检查分散在各个类型的数据设置页上。下表第一列是软件弹出的提示原文，按它就能找到出问题的类型。

| 提示原文 | 出现的类型 | 处理办法 |
|---|---|---|
| Please select a series | 直方图 | 数据列表还没有放序列，回到「数据管理」面板拖一列进去 |
| Please select a dataframe | 箱体 | 数据集下拉框是空的，先确认数据管理面板里有数据集 |
| Please select at least one column | 箱体 | 列列表里一列都没勾，至少勾一列 |
| X, Y and Value must be series | 等高线 | 三个列表里有空着的，逐个补上一列 |
| X, Y, U, V must be series | 向量场 | 同上，四个列表都要补上 |
| x and y cannot be set to autoincrement at the same time | 曲线、散点、柱状 | 两个列表只留一个勾自增，另一个放真实数据 |
| The initial value of x auto increment series must be a floating-point arithmetic number | 曲线、散点、柱状 | 初始值填的不是数字，改成数字 |
| The step value of x auto increment series must be a floating-point arithmetic number | 曲线、散点、柱状 | 步长填的不是数字，改成数字 |
| The initial value and step of x auto increment must be floating-point numbers | 多重柱状 | 初始值或步长填的不是数字，改成数字 |
| Please drag a series into the X list | 多重柱状 | X 列表是空的 |
| Please drag at least one series into the Y list | 多重柱状 | Y 列表是空的 |
| The data dimensions are incorrect. The length of x should be equal to the number of columns in value, and the length of y should be equal to the number of rows in value. | 云图 | 按矩阵的实际行列数重新选 X 和 Y |
| scipy is not available, cannot perform scatter interpolation. Please install scipy: pip install scipy | surface 3D 的散点模式 | 给内嵌的 Python 环境装上 scipy，或者改用网格模式 |

除了这些弹窗提示，还有几种情况软件会直接放弃建图：曲线和散点取数时如果两列长度不一致，按短的一列取；选中的列转不成数值时抛异常并放弃这次建图，部分分支只写消息面板不弹窗；内嵌 Python 环境不可用时取数这一步拿不到数据框，建图同样会失败。

## 向导的重复使用

建图向导在整个程序里只有一个实例，点任何建图按钮、从数据管理面板拖数据进来，用的都是它。它不会每次重建，因此各个类型设置页上填过的参数都留着，再次打开时还在。打开时停在哪个类型由入口决定：点按钮就是那个按钮对应的类型，拖数据集进来是 `curve`。想从零开始，把列表、下拉框和输入框逐个改回去。

向导是可以在主界面上共存的状态，打开之后主界面照常使用：可以切到「数据管理」面板换一份数据、可以点别的坐标系把它设成当前坐标系、也可以直接在绘图上缩放平移。往列表里加序列时，向导会暂时让位给「Select Series」/ 选择序列 小窗口，确认或取消之后回到向导。

同一份参数可以连续执行多次。把向导留着，点一次「OK」画一个图元，改一列再点一次，就能在同一块坐标系里堆出一组图。每次执行都会取当时的当前坐标系，因此在两块坐标系的绘图里，想画到哪一块就先点哪一块。

三个三维类型走另一条分支：软件取当前绘图里当前的三维图表区域，没有三维图表区域就新建一块，再把三维图元挂上去。二维和三维在同一个绘图里并存，三维图表区域的画法见[绘图与坐标系](./figure.md)。

## curve / 曲线

把 X 和 Y 两列数值画成折线，点按顺序连线。列表两块：X 列表放一列，Y 列表放一列，表头就是 `x` 和 `y`。列表只接受一个序列，放第二列会替换掉第一列。

| 列表 | 放什么 |
|---|---|
| X | 自变量的一列，数值 |
| Y | 因变量的一列，数值 |

两列长度不一致时，按短的那一列取点。X 或 Y 都可以改成自动生成，见下一小节。

画出来是一条 `QwtPlotCurve`，标题默认取 Y 列的列名。曲线画上去之后可以改线型、颜色、标记符号、是否填充，见[二维图表设置](./settings-2d.md)。

按时序、按样品编号、按扫描位置看一个量的变化趋势时用曲线。数据本身带顺序，连线才有意义。

### 自增序列

X 列表和 Y 列表上各有一个「Autoincrement series」/ 自增序列 勾选框。勾上之后，这个列表不再接收数据，改由下面两个输入框生成数值：

| 输入框 | 作用 | 默认值 |
|---|---|---|
| 「Initial value」/ 初始值 | 序列的第一个数 | 1 |
| 「Self increasing step size」/ 自增步长 | 相邻两个数之差 | 1 |

序列的第 i 个值等于初始值加 i 乘步长，i 从 0 开始。举例，初始值填 0、步长填 2，生成的序列是 0、2、4、6、8。初始值和步长都按浮点数解析，填 `0.5` 合法，填非数字会弹出警告并且不画图。

自动生成的序列没有自己的长度，它跟着另一个列表里的真实序列走：X 自增时，生成长度等于 Y 列长度的 X 序列；Y 自增时，生成长度等于 X 列长度的 Y 序列。因此两个列表不能同时勾自增，软件会弹出警告。

自增序列的用处是把「编号」「序号」这类本来不存在于数据表里的轴造出来。拿到一列测得的数值但不知道采样间隔时，让 X 自增得到 0、1、2 这样的样品序号就能出图；想画一条斜率为 1 的参考线时，让 Y 自增而 X 用真实序列即可。这个勾选框在 `curve`、`scatter`、`bar` 上 X 和 Y 两个列表各有一个，在 `multi bar` 上只有 X 列表有，而它的长度按 Y 里最长的那一列算。

## scatter / 散点

与曲线共用同一套数据设置页，要的也是 X、Y 各一列，自增序列同样可用。两者的差别在绘制方式：散点把每个点画成一个符号，点与点之间不连线。

看两个量之间有没有关系、有没有分区、有没有离群点时用散点。点的顺序不重要，连线会干扰判读。

## bar / 柱状

把 Y 的每个值画成一根柱子，柱子的横坐标取 X 的对应值。数据设置页与曲线相同，X、Y 各一列，X 或 Y 可以改成自增序列。画出来是一个 `QwtPlotBarChart`。

按类别比较大小、或者按位置展示离散的计数时用柱状。

## error bar / 误差棒

在 X、Y 之外多要一列误差，画出的每一根竖线的两端分别是 Y 减误差和 Y 加误差。三列的表头是 `x`、`y`、`error`，角色标签是 X、Y、Error（中文界面下这一项显示为「错误」）。

| 列表 | 放什么 |
|---|---|
| X | 自变量的一列 |
| Y | 中心值的一列，比如多次测量的均值 |
| Error | 误差的一列，取正值，表格里不用写成 ± |

把手上的误差当成对称值处理，区间就是 Y 减去 Error 到 Y 加上 Error。X 或 Y 可以改成自增序列，误差列只取列表里的第一个序列，不能自增。三个列表里任何一个空着，点「OK」都会弹出对应的提示，说明 x、y 或 error 必须是序列。画出来的图元标题默认是「Error Bar」/ 误差棒。

有测量误差、标准误或者标准差要一起展示时用误差棒。只画均值曲线会把误差信息丢掉。

## box / 箱体

一张图上画一个或多个箱体，每个箱体对应数据框里的一列。这个类型的设置页与前面几个不同：上面是数据集下拉框，下面是一个可多选的列列表，列表上方的提示是「Select columns to plot as box charts」/ 选择要绘制箱线图的列，标题栏写的是「Columns」，中文界面下这一项显示为「柱状」。

| 输入 | 放什么 |
|---|---|
| 数据集 | 下拉框里选一份数据集 |
| 列 | 在列表里勾选一列或多列，至少要勾一列 |

每个箱体画在一列上，位置从左到右按勾选顺序排列。箱体包含中位数、上下四分位数、须线和离群点，具体算法由箱体图元自己计算。图元的标题是所选列名用竖线连接起来的一串文字，比如勾了 `a`、`b` 两列，标题就是 `a|b`。

比较几组数据的中位数和分散程度时用箱体。它比柱状多给出四分位和离群点，一组数据只有十个左右的样本也能看出差异。

## cloud map / 云图

用一列 X、一列 Y 和一张数值矩阵铺出一片带颜色的网格，颜色表示数值大小，实际上是一张热力云图。数据分三部分：

| 部分 | 放什么 |
|---|---|
| X | 一列数值，长度等于矩阵的列数 |
| Y | 一列数值，长度等于矩阵的行数 |
| Matrics / 矩阵 | 一份数据集，取它的整张数值矩阵 |

X 的长度和矩阵的列数、Y 的长度和矩阵的行数不一致时，点「OK」会弹出警告，提示数据维度不正确，图不画。画出来的图元是配色网格加等值线，颜色范围默认取数据的最小值到最大值。

数据本来就是二维阵列时用云图，比如一张光谱矩阵、一张按温度和浓度排开的响应表。

## multi bar / 多重柱状

X 一列，Y 可以很多列，每一列成为一组柱子，同一个横坐标上的多组柱子并排显示，用来对比。设置页的提示写着「Drag the data into the corresponding list. Multiple Y series will be grouped as bar sets.」/ 把数据拖入对应的列表，多个 Y 序列会组成柱状集合。

| 列表 | 放什么 |
|---|---|
| X | 一列，可以勾选自增序列 |
| Y (Multiple) / Y（多选） | 一列或多列，可以来自不同的数据集 |

Y 列表允许来自多个数据集的多个序列，至少放一列。Y 列表里每个序列的名字会成为这一组柱子的名字，出现在图例里。少了 X 或者少了 Y，点「OK」都会弹出警告。

同一批对象上有若干个指标要一起比较时用多重柱状。三四个指标并排比用柱状画三次更省地方，指标更多时柱子会变窄。

## histogram / 直方图

把一列数值按等宽区间分箱，每个区间画一根柱子。数据部分只要一列，角色标签是「Data」/ 数据；右侧两组参数决定柱子怎么分、纵轴表示什么。

| 参数 | 取值 | 默认值 |
|---|---|---|
| 「Number of bins」/ 分箱数量 | 1 到 10000 的整数 | 10 |
| 「Y Axis」/ Y轴 | 「Count」/ 计数 或「Density」/ 密度 | 计数 |

计数的含义是落在这个区间里的样本个数。密度的含义是把计数换算成概率密度，换算公式是计数除以样本总数与箱宽的乘积，这样所有柱子的面积加起来约等于 1，换一个分箱数再看图，纵轴的高度仍然可比。分箱是等宽的，取值范围从数据的最小值到最大值，最后一个区间包含最大值。所有值都相同时，软件只画一个区间：计数模式下的高度等于样本总数，密度模式下的高度是 1。

看一列数值的分布形状时用直方图。它和[统计绘图](../analysis/stats-plots.md)里的直方图不同，这里的每一个参数都在向导里当场填，统计绘图那一套还带分组和核密度叠加。

## contour / 等高线

用三列数据画等值线图：X、Y 决定位置，Value 决定高度。设置页的提示是「Select three columns (x, y, value) to render a contour map」/ 选择三列（x、y、value）绘制等高线图。

| 列表 | 放什么 |
|---|---|
| X | 位置的一列 |
| Y | 位置的另一列 |
| Value | 这一点的数值 |

三个列表各只取一个序列，缺任何一个或者选中的不是数值列时，点「OK」都会弹出警告。画出来是一片按数值着色的曲线，颜色范围取数据的最小值到最大值。

数据是散点形式的二维场时用等高线，比如按经纬度采样的温度、按两个参数扫出来的响应面。

## vector field / 向量场

每个点画一个箭头，箭头的方向由 U、V 两列决定。设置页的提示是「Select four columns (x, y, u, v) to render a vector field」/ 选择四列（x、y、u、v）绘制向量场。

| 列表 | 放什么 |
|---|---|
| X | 位置的横坐标 |
| Y | 位置的纵坐标 |
| U (vector x) | 向量在横方向的分量 |
| V (vector y) | 向量在纵方向的分量 |

缺列或者选中的不是数值列时会弹出警告。箭头长度默认随向量大小变化，可以在图元设置里改成只按颜色表示大小。

数据里带有方向信息时用向量场，比如流速场、位移场、梯度场。

## surface 3D / 3D曲面

三维曲面有两种给数据的方式，在「Data Mode」/ 数据模式 下拉框里切换，选哪一种决定下面露出哪些控件。

第一种是「Grid (DataFrame as Z matrix)」/ 网格（DataFrame 作为 Z 矩阵）。只需要从数据集下拉框里选一份数据集，数据框的行和列自动成为 Y 和 X 坐标，单元格的数值就是 Z 高度。这种方式要求数据框至少有 2 行 2 列，不足时图不画。控件旁边的说明写着「Rows and columns of the DataFrame are used as Y and X coordinates, cell values as Z height.」/ DataFrame 的行和列分别作为 Y 和 X 坐标，单元格数值作为 Z 高度。

第二种是「Scatter (X/Y/Z columns)」/ 散点（X/Y/Z 列）。在数据集下拉框之后，还要指定「X Column」/ X 列、「Y Column」/ Y 列、「Z Column」/ Z 列三列。这种模式要至少 3 个点，软件用内嵌 Python 的 scipy 做三次插值，把散点铺成 30 乘 30 的规则网格；落在散点凸包之外的网格点填 0。内嵌环境里没有 scipy 时，软件给出提示并且不画图，需要先装好 scipy 再试。

三维图表进入绘图里的一块三维图表区域，绘图里没有三维图表时软件自动新建一块。曲面的绘制方式、色图和光照在[三维图表设置](./settings-3d.md)里调。

数据本来就是矩阵、想直接看整体起伏时选网格模式；手上是三列散点、需要软件先插值成面的选散点模式。

## bar 3D / 3D柱状

三维柱状有两种给数据的方式，同样由「Data Mode」/ 数据模式 下拉框决定。

第一种是「1D Series (one column)」/ 一维序列（单列）。从数据集下拉框选一份数据集，再在「Value Column」/ 数值列 里选一列。这一列的值成为柱高，柱子的横坐标按行号从 0 开始依次排开，纵坐标固定为 0。

第二种是「2D Grid (DataFrame as Z matrix)」/ 二维网格（DataFrame 作为 Z 矩阵）。选一份数据集即可，DataFrame 的行和列成为 Y 和 X 坐标，单元格数值作为柱高，控件说明写着「Rows and columns of the DataFrame are used as Y and X coordinates, cell values as bar height.」/ DataFrame 的行和列分别作为 Y 和 X 坐标，单元格数值作为柱高。

单列的指标想在一根轴上排开对比时用一维序列模式；二维表格想按行列两个方向都排开时用二维网格模式。

## line 3D / 3D线图

用三列数据在三维空间里连成一条线：X、Y、Z 各一列，控件是三个列下拉框，依次是「X Column」/ X 列、「Y Column」/ Y 列、「Z Column」/ Z 列。

线型有实线、圆管和点三种，点还可以选形状，这些在[三维图表设置](./settings-3d.md)里改。参数按顺序变化的轨迹、空间曲线用这个类型。

## 代码里有、界面上还没有入口的类型

图表引擎里还有两类图表能画出来，也能存进工程，但建图向导的列表里没有它们，目前不能从界面上创建：

- K 线图。数据设置页已经写好，五个列表分别是 `Time`、`Open`、`Hight`、`Low`、`Close`（拼写按软件里的原文），对应的图元是 `QwtPlotTradingCurve` 加一个涨跌画刷。界面上没有打开它的入口。
- 区间曲线。要的数据与误差棒相同，画出来是一条由下界和上界围成的带子，对应的图元是 `QwtPlotIntervalCurve`。界面上没有打开它的入口。

这两类图目前只能从 C++ 或者 Python 里创建。数据设置页存在但没挂到向导列表上，不等于可以从界面调用。

## 常见问题

点「OK」之后没有任何反应。先看消息面板。没有选任何列、X 或 Y 两个列表同时勾了自增、分箱数或行列数不满足要求时，软件都会给出提示并停在这一步。

向导一次只画一个图元。想在同一块坐标系里再叠一条曲线，把向导留着，换一组数据再点一次「OK」；上一个图元留在图上，颜色由软件的配色循环自动分配，不会重叠成同色。

想换一个类型重画。向导左侧列表点一下就能换类型，右侧换成新类型的设置页，重新填参数再点「OK」。已经画上去的图元不会自动删掉，需要删掉的旧图元到绘图管理树里删，见[绘图与坐标系](./figure.md)。

向导关掉再打开，上次填的内容还在。想全部回到默认值，逐个改回去即可。

图上出现了意料之外的一条直线或者一片空白。多半是 X 列里有重复值、顺序不对，或者列里有空值。先用[表格视图](../data/table.md)核对这两列的类型和取值，缺值到[数据清洗](../analysis/cleaning.md)里补。

向导里的图元名字都来自列名，两列重名时看不出是哪一份数据画的图。建完之后到绘图管理树里用「Rename」/ 重命名改成能分辨的名字，改名同时改图例里的显示，见[绘图与坐标系](./figure.md)。

三个三维类型的设置页都填好了，点「OK」之后图没有出现在当前的二维坐标系里。三维图元进入的是三维图表区域，和二维坐标系是两块地方。看绘图里有没有多出一块三维区域，没有的话到绘图管理树里找「3D Chart」/ 3D绘图 那一层。

数据框的列很多，选列时找不到目标列。数据集下拉框和列列表会把全部列都列出来，列多时列表很长。先在「数据管理」面板里确认列名，再到列表里按名字找；也可以在表格视图里点一下目标列，用「Select Series」/ 选择序列 小窗口自动填表达式。

画上去的图和想象的不一样，先怀疑数据。同一张图换个顺序的 X 列，折线的走向会完全不同。画之前用表格视图看一眼 X 列是不是单调、有没有重复值，见[表格视图](../data/table.md)。
