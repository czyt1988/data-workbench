# 脚本与扩展

这一部分讲两件把软件用得更深的事：在工程自带的脚本目录里写 Python，以及启用和停用插件。

## 章节目录

- [脚本工作区](workspace.md)：工程自带的脚本目录、运行环境，以及三个可以照着改的例子。
- [插件管理](../plugin/manager.md)：插件放在哪里、怎么启用和停用、插件能带来什么。

## 什么时候需要脚本

软件自带的工具能覆盖常见的数据清洗、筛选、统计和绘图。遇到下面几种情况才需要写 Python：

- 要做软件里没有的分析，比如聚类、主成分分析、假设检验。
- 要把多个数据集按自定义规则合并。
- 要批量生成图表或批量导出文件。
- 要把对数坐标之类的设置加到图表上，而属性面板里没有对应项。

写好的脚本通过智能体的 `run_code` 或 `run_script` 工具执行，脚本里的变量在同一次会话里会保留。软件本身没有独立的脚本编辑器，脚本用别的编辑器写好，或者直接在对话里让智能体写完就跑。

## 什么时候需要插件

插件用来往软件里加东西：新的工作流节点、新的 Ribbon 面板和按钮、新的智能体工具、新的提示词条目。随软件发布的几个插件已经带来了两批工作流节点、数据分析面板、智能体工具和论文撰写助手。

装插件就是把文件放到指定目录，然后在 `Plugin Manager` / 插件管理 对话框里勾选。编译出来的插件可以立即生效；Python 节点包需要重启软件。
