# 快捷键

软件里由代码明确指定的键盘操作只有少数几组：撤销与重做、工作流画布上的编辑命令与缩放、退出数据探针模式的 Esc，以及数据表单元格和消息面板里的复制。这一章把它们按使用场合列全，并说明两处容易踩空的地方：大量操作没有快捷键只能点按钮，复制粘贴这类命令的效果取决于当前焦点在哪个区域。

## 全局：撤销与重做

撤销和重做由统一的撤销组管理，两个动作的按钮在主页的「Clipboard」/ 剪贴板 面板里，也放在窗口左上角的快速访问栏上。

| 按键 | 作用 |
|------|------|
| Ctrl+Z | 撤销当前编辑区的上一步操作 |
| Ctrl+Y | 重做被撤销的操作 |

撤销组跟着活动的编辑区切换：焦点在数据表上时，快捷键作用在这张表的撤销栈上；焦点在工作流画布或绘图上时作用在对应的撤销栈上。数据表的撤销栈按标签页分开，切换标签页后按 Ctrl+Z 撤回的是当前标签页上的操作，不会误撤到另一张表，见[表格视图](../data/table.md)。撤销与重做的范围、哪些操作不入栈，见[编辑器功能](../workflow/editor.md)的撤销一节。

## 工作流画布

画布上的编辑命令定义在工作流操作控件上，除了快捷键，在「Workflow Edit」/ 工作流编辑 页的「Clipboard」/ 剪切板 面板和主页的「Clipboard」/ 剪贴板 面板里都有对应按钮。

| 按键 | 作用 |
|------|------|
| Ctrl+C | 复制选中的图元，以及两端都在选中范围内的连线 |
| Ctrl+X | 剪切选中的图元 |
| Ctrl+V | 在视图中央粘贴剪贴板里的图元 |
| Delete | 删除选中的图元 |
| Ctrl+A | 全选画布上的图元 |
| Esc | 取消选择，或在拉连线的过程中取消这次连线 |
| Ctrl+= | 放大画布 |
| Ctrl+- | 缩小画布 |
| Ctrl+0 | 缩放到适合屏幕，把画布上所有图元放进可视范围 |

除键盘之外还有两个操作画布的手法：按住 Ctrl 用左键拖动选中的图元是拖动复制，松开鼠标时原地保留原件、按拖动位移粘贴出一份新的；按住鼠标中键拖动，或者按住空格再按住左键拖动，可以平移画面。这些操作的细节和粘贴内容的规则见[编辑器功能](../workflow/editor.md)。

缩放只改变视图，不改动任何图元的位置和大小，也不进撤销栈；三个缩放快捷键作用在当前工作流标签页上，几个工作流并排分屏时，那个最后获得焦点的标签页是当前工作流。

## 绘图：退出数据探针模式

数据探针模式有自己的退出键。进入这个模式后在坐标系上点击会创建探针，整批探针挂在一条撤销命令下；退出模式用 Esc，这是绘图控件在会话期间注册的窗口级快捷键。

| 按键 | 作用 |
|------|------|
| Esc | 退出数据探针的编辑状态 |

进入模式之后，绘图上的缩放、平移和十字光标被关闭，退出之后这些交互开关保持关闭状态，需要时在 Ribbon 上重新打开。探针的创建流程、数据联动表怎么用，见[数据探针与数据联动表](../chart/data-probe.md)。

## 数据表：复制单元格

表格视图里的复制由表格控件自己处理，选中单元格后按下面的按键把选区内容写进剪贴板。

| 按键 | 作用 |
|------|------|
| Ctrl+C | 复制选中的单元格 |
| Ctrl+Insert | 同上，效果与 Ctrl+C 相同 |

复制出去的文本按选区的外接矩形拼成，行内制表符分隔、行间换行分隔，规则见[表格视图](../data/table.md)。粘贴没有快捷键，Ctrl+V 在表格里不生效，改用主页「Clipboard」/ 剪贴板 面板里的「Paste」/ 粘贴 按钮。

## 消息面板：复制日志行

「Log」/ 消息 面板的日志表格也处理两个按键，用来把记录带走。

| 按键 | 作用 |
|------|------|
| Ctrl+C | 把选中的日志行复制到剪贴板 |
| Ctrl+A | 选中面板里的全部日志行 |

右键菜单里还有一个「Copy」/ 复制 项，效果与 Ctrl+C 相同，见[编辑器功能](../workflow/editor.md)里消息面板一节。日志文件本身不受这两个按键影响。

## 没有快捷键的操作

上表之外的操作都没有定义键盘快捷键，只能点 Ribbon 上的按钮或面板里的按钮。常见的几类：

- 工程的打开、保存、另存为在应用菜单和主页的「File」/ 文件 面板里。
- 新建工作流、添加绘图、添加数据在主页的「Create」/ 创建 面板里。
- 运行工作流和停止在「Workflow Run」/ 工作流运行 页的「Run」/ 运行 面板里，见[工作流基础](../workflow/basics.md)。
- 数据表的粘贴、插入行列、改列类型、排序、筛选这些在相应的 Ribbon 面板里，见[表格视图](../data/table.md)。
- 智能体对话的发送按钮没有回车快捷键：在对话输入框里按回车不会发出消息，发送要点击面板上的按钮；这一轮正在跑时按钮变成停止，同样要点按。

找不到某个操作的按钮时，按功能到对应的 Ribbon 标签页里找：数据相关在「Data」/ 数据 页，工作流运行时在「Workflow」/ 工作流 上下文页，绘图相关在「Figure」/ 绘图 页和「Chart Operate」/ 绘图操作 上下文页。面板的位置见[主界面](../getting-started/main-window.md)。

## 快捷键作用在哪个区域

复制、剪切、粘贴、删除、全选这几个命令在主页面的面板里有一组按钮，它们按最后获得焦点的区域分发：焦点在数据表上时作用在单元格上，焦点在工作流画布上时作用在图元上。键盘上能触发的范围更窄一些：

- 工作流画布定义了 Ctrl+C、Ctrl+X、Ctrl+V、Delete、Ctrl+A 和 Esc，焦点在画布所在的操作区时按这些键作用在图元上。
- 表格视图自己处理 Ctrl+C 和 Ctrl+Insert，粘贴只能点按钮。
- 绘图区域没有复制到剪贴板以外的编辑快捷键，「Copy To Clipboard」/ 复制到剪切板 按钮在绘图有焦点时也响应主页的粘贴板命令，见[复制与保存图表](../chart/save.md)。

按了没有反应的键，先看焦点在哪个区域：点了数据表却想复制图元，或者点了画布却想复制单元格，都会没有结果。需要确认焦点时点一下目标区域的空白处，再按快捷键。

## 与鼠标操作的配合

有几组操作需要鼠标和键盘一起用，列在一起方便对照。

| 操作 | 方式 |
|------|------|
| 加选或取消选择图元 | 按住 Ctrl 逐个点击 |
| 拖动复制图元 | 按住 Ctrl，用左键拖动选中的图元 |
| 平移画布 | 按住鼠标中键拖动，或按住空格再按住左键拖动 |
| 缩放画布 | 按住 Ctrl 滚动滚轮，或用三个缩放快捷键 |
| 进入单元格编辑 | 双击单元格，或者选中后直接键入内容 |
| 提交或放弃单元格编辑 | 回车提交，Esc 放弃 |

这些组合操作与快捷键的定义方式不同，它们的按键由控件在鼠标事件里读取，不占用系统级快捷键，所以不会与其它命令冲突。

## 全部按键速查

把前面各节里的按键按区域合到一起，方便一处查完。

| 按键 | 区域 | 作用 |
|------|------|------|
| Ctrl+Z | 全局 | 撤销当前编辑区的上一步操作 |
| Ctrl+Y | 全局 | 重做 |
| Ctrl+C | 工作流画布 | 复制选中的图元 |
| Ctrl+X | 工作流画布 | 剪切选中的图元 |
| Ctrl+V | 工作流画布 | 在视图中央粘贴 |
| Delete | 工作流画布 | 删除选中的图元 |
| Ctrl+A | 工作流画布 | 全选图元 |
| Esc | 工作流画布 | 取消选择或取消连线 |
| Ctrl+= | 工作流画布 | 放大 |
| Ctrl+- | 工作流画布 | 缩小 |
| Ctrl+0 | 工作流画布 | 缩放到适合屏幕 |
| Esc | 数据探针模式 | 退出探针编辑状态 |
| Ctrl+C、Ctrl+Insert | 表格视图 | 复制选中的单元格 |
| Ctrl+C、Ctrl+A | 消息面板 | 复制选中的日志行、全选日志行 |

表里没有列出的组合没有专门绑定到软件功能，按了不会有反应；输入框、文本框这类标准控件仍按系统习惯处理复制、粘贴和撤销。按习惯按的 Ctrl+S、Ctrl+O、Ctrl+N 都属于前者，对应的操作在应用菜单和主页的「File」/ 文件 面板里。
