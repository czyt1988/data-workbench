# 工程文件管理

本指南介绍如何使用 DAWorkBench 的工程文件功能，管理工作流、数据和图表的完整工作状态。

## 主要功能特性

- ✅ **工程文件格式**：`.dapro` ZIP 压缩包，包含完整工作状态
- ✅ **一键保存/加载**：所有工作流、数据、图表状态持久化
- ✅ **UI 布局恢复**：启动时自动恢复上次的 Ribbon/Dock 界面布局
- ✅ **命令行打开**：通过命令行参数直接打开工程

---

## 工程文件概念

### 什么是工程文件

工程文件（`.dapro`）是 DAWorkBench 的核心持久化格式，本质上是一个 ZIP 压缩包，包含完整的工作状态：

| 内容 | 说明 |
|------|------|
| 工作流逻辑数据 | 节点拓扑、参数值、连接关系 |
| 工作流视图数据 | 节点位置、图元属性、连线布局 |
| 数据管理器状态 | 所有数据对象的元信息 |
| 图表数据 | 图表配置和样式 |
| 表格样式 | 单元格样式和条件格式 |
| 插件数据 | 插件自定义的存档数据 |

### 工程文件结构

```
project.dapro (ZIP)
├── system-info.xml            # 系统信息（版本、创建时间）
├── workflow.xml               # 工作流信息（节点、连接、图元）
├── data-manager.xml           # 数据管理器配置
├── datas/                     # 数据文件目录
│   └── [各种数据文件]
├── charts.xml                 # 绘图信息（图表配置、数据绑定）
└── chart-data/                # 图表数据目录
    └── [图表数据文件]
```

!!! note "加载顺序"
    工程加载按系统信息→工作流→数据管理器→图表的顺序进行，每个阶段独立完成。详见 [工程文件结构](../dev-guide/project-file-structure.md)。

## 基本操作

### 新建工程

1. **点击新建**：菜单"文件 → 新建工程"
2. **确认清空**：如果当前有未保存的修改，会提示保存
3. **空白工作区**：所有面板清空，开始新的工作

### 打开工程

**通过菜单打开**：

1. 点击"文件 → 打开工程"
2. 在文件对话框中选择 `.dapro` 文件
3. 工程内容加载到工作区

**通过命令行打开**：

```bash
# 直接打开工程文件
DAWorkBench.exe "C:/projects/MyProject.dapro"
```

### 保存工程

1. **点击保存**：菜单"文件 → 保存工程"（或 Ctrl+S）
2. **选择路径**：首次保存需要选择保存路径
3. **等待写入**：工程文件以 ZIP 格式压缩保存

!!! note "保存内容"
    保存操作会持久化所有状态：工作流节点和连接、数据对象、图表配置、表格样式、UI 布局等。

### 另存为

菜单"文件 → 另存为"可将当前工程保存为新文件，原文件不受影响。

## UI 状态持久化

### UI 状态保存

程序退出时可以自动保存 UI 状态（Ribbon 布局、Dock 窗口位置等）：

| 功能 | 说明 |
|------|------|
| 自动保存 | 退出时自动保存（可配置） |
| 手动保存 | `AppMainWindow::saveUIState()` |
| 恢复状态 | 启动时 `restoreUIState()` |
| 重置状态 | `removeStateSettingFile()` 删除状态文件 |

### 配置 UI 状态保存

通过设置对话框可配置是否在退出时保存 UI 状态：

1. 菜单"工具 → 设置"
2. 找到"界面"或"通用"设置页
3. 勾选/取消"退出时保存界面状态"

## 工程文件兼容性

### 版本兼容

工程文件包含版本信息，程序会根据版本号处理兼容性：

- **向前兼容**：新版本可打开旧版本创建的工程
- **向后兼容**：旧版本可能无法打开新版本创建的工程（会提示版本不匹配）

### 升级工程文件

打开旧版本工程时，程序会自动升级文件格式。建议升级后另存为新文件。

## 常见问题

### Q：工程文件打不开？

**A：** 可能原因：
1. 文件损坏 — 检查文件是否完整（ZIP 格式可用解压软件打开验证）
2. 版本不兼容 — 确认文件版本是否被当前程序支持
3. 权限问题 — 检查文件是否有读取权限

### Q：保存后文件很大？

**A：** 工程文件包含所有数据对象。如果导入了大量数据，文件会相应增大。建议：
- 使用 Pickle 格式存储数据（比 CSV 紧凑）
- 清理不需要的数据后保存
- 数据量大时，考虑将数据文件单独存储，工程中仅保存引用

### Q：如何恢复未保存的工作？

**A：** DAWorkBench 目前不提供项目数据的自动保存功能（仅恢复 UI 布局）。建议养成定期保存的习惯（Ctrl+S）。程序异常退出后，可以通过日志文件排查问题。

### Q：工程文件可以在不同电脑间使用吗？

**A：** 可以，但需注意：
- 数据文件路径使用相对路径（相对于工程文件目录）
- 确保目标电脑安装了相同版本的 DAWorkBench
- 插件依赖需在目标电脑上安装
