# 编辑器功能

工作流画布上的编辑操作集中在 Ribbon 右侧的「Workflow / 工作流」上下文标签里，分成「Workflow Edit / 编辑」「Workflow View / 显示」「Workflow Run / 运行」三页。这一章按能力逐项说明这三页上的按钮和画布上的鼠标操作：选中与移动、复制粘贴、删除、撤销重做、缩放标记、锁定视图、绘制标注、分组、背景图、形状与字体、导出图片，以及多个工作流标签页的管理。

节点和连线怎么放、参数怎么填、怎么运行见[工作流基础](basics.md)。这几个上下文标签页只在工作流区获得焦点时出现，点开数据表或者绘图时 Ribbon 会换成对应的标签页。

## 命令都在哪一页

想找某个命令时按下表定位，表中的位置写成「标签页 → 面板」的形式。主页的「Clipboard / 剪切板」面板里的复制、粘贴、删除、全选按最后一次获得焦点的区域分发，焦点在工作流区时作用在画布上。

## 画布上的图元有哪些

画布上会出现这几类东西，它们的共同点是都能被选中、移动、复制和删除：

- 节点：从节点面板拖进来的处理单元，参与运行。
- 连线：连接两个端口，随节点的移动自动更新端点，也参与运行。
- 矩形标注和文本标注：用「Draw Rect」「Draw Text」画出来的说明文字和框，不参与运行。
- 图片图元：粘贴进来的图片。这种图元可以有很多张，随工程保存，图片数据也嵌在工程文件里。
- 背景图：作为画布底衬的那一张图片，整张画布只有一张，位置在所有图元下面，用「Add Background」添加和更换，在「Picture / 图片」页调透明度。
- 分组：把若干图元合成的一个整体，本身不显示内容。

## 用设置面板精确摆放图元

拖动和缩放之外，右侧「Setting / 设置」面板的「Item / 图元」页可以用数字摆放选中的图元，需要让几个节点严格对位时比鼠标拖动准。

这一页分成几组：Size 组有 Width（宽）、Height（高）两个数字框和 Lock aspect ratio（锁定纵横比）开关；Rotation（旋转角度）单独一个数字框；Position 组有 X、Y 两个数字框，是图元在画布上的坐标；Properties 组有 Movable（能否移动）、Resizable（能否改大小）和 Tooltip（鼠标悬停时显示的文字）。

改宽高、角度和坐标会立即作用到选中的图元上，同时记入撤销栈，可以用 Ctrl+Z 退回。关掉 Movable 之后图元拖不动，坐标数字框一起禁用；关掉 Resizable 之后控制点消失，不能再改大小，宽高数字框一起禁用。Tooltip 里填的文字会在鼠标停在这个图元上时显示出来。

「Link point position」组里的八个方位按钮（输入端口、输出端口各四个）目前不起作用：源码里对应的处理只是一个空的占位实现，点这些按钮画布上不会有任何变化。端口落在节点的哪一边，由节点定义里的端口方位决定，自定义节点时可以在定义里指定，见[开发自定义节点](custom-node.md)。

节点自己带悬停提示，显示的是节点名称、说明和当前参数。标注、图片和背景图默认没有悬停提示，需要说明时在 Tooltip 里填文字，填了以后鼠标停在图元上就会显示；节点上填的内容会盖掉它自带的提示。节点列表里的提示气泡是另一回事，那个由节点定义里的说明文字决定。

## 选中图元与批量移动

点击画布上的一个图元就把它选中。选中的图元周围会显示一圈控制点，拖这些点可以改图元主体的大小。

选中多个图元有两种做法：在画布空白处按住左键拖出一个矩形框，框住的图元都被选中；或者按住 Ctrl 再逐个点击图元，点中的图元加入选择，再点一次取消选择。全部选中用 Ctrl+A，取消全部选择按 Esc（正在拉连线时按 Esc 取消这次连线）。

选中多个图元后拖动其中任意一个，其余选中的图元跟着一起移动，相互之间的位置关系保持不变，整次移动算一个撤销步骤。选中一个图元时拖动它只移动它自己；打开「Linkage Move / 联动」之后，同一条输出链上的下游节点也会跟着走，细节见下面的分组一节。

画布上的图元没有右键菜单。右键的唯一用途是在拉连线的过程中取消这次连线，图元上的操作都用 Ribbon 命令或者快捷键完成。

## 复制、剪切与粘贴

「Workflow Edit / 编辑」页的「Clipboard / 剪切板」面板里有三个命令：「Paste / 粘贴」是大按钮，「Cut / 剪切」和「Copy / 复制」是小按钮。主页「Main / 主页」的「Clipboard / 剪切板」面板里还有一套同名命令，加上「Delete / 删除」和「Select All / 全选」，这一套按最后一次获得焦点的区域分发：焦点在工作流区时作用在画布上，焦点在数据表时作用在单元格上。

复制和剪切的内容是选中的图元，包括节点、连线和画布上的标注。复制时会把这些图元以及它们之间的连线一起打包：连线只有在两端的节点都在选中范围内时才被复制，只选中一端的线不会进入剪贴板。打包好的内容写进软件自己的剪贴板格式，可以粘贴到同一个工作流，也可以切到另一个工作流标签页再粘贴。

粘贴的位置在视图中央，不是复制时的原位置。剪贴板里保存的是图元的图形信息和端口信息，节点参数不在其中，因此粘贴出来的节点是新建的节点实例，参数取节点定义里的默认值，粘贴之后需要重新填参数。粘贴出来的节点和连线有新的节点标识，与原来的节点各自独立。

粘贴时按下面的顺序判断剪贴板里是什么，先匹配上的先用：

1. 软件自己的图元格式，也就是上一步复制的节点和连线。
2. 剪贴板里的位图，比如从截图工具或者图片查看器复制出来的一张图，粘贴后成为一个图片图元。
3. 剪贴板里的文本，如果这段文本是一个本地图片文件的路径，粘贴后把这张图片读进来成为图片图元。

从别处复制的普通文字不会被粘贴成文本框，这一条路径目前没有实现。剪贴板里既有图元又有文本时以图元为准。

粘贴出来的图元处于选中状态，可以立即拖动到想要的位置；这一份改动同样可以用 Ctrl+Z 退回。

在画布上按住 Ctrl 拖动选中的图元，是拖动复制：开始拖动时选中的内容被复制一份到剪贴板，松开鼠标时这份内容按拖动的位移粘贴出来，原地保留原件。拖动过程中鼠标指针变成拖动复制样式。这条路径也遵循上面的规则，粘贴出来的是新节点加默认参数。

剪切等于复制加删除，整个过程算一个撤销步骤。粘贴同样进撤销栈，按撤销可以撤掉刚粘贴出来的内容。

## 删除节点与连线

删除当前选中的图元用 Delete 键，或者用主页「Clipboard / 剪切板」面板上的「Delete / 删除」。这条命令对节点、连线、标注都适用：选中一条连线按删除，这条连线消失，两端的节点不受影响；选中节点按删除，节点本身以及与它相连的所有连线一起删掉，整步删除算一个撤销步骤，按撤销能一次恢复节点和它的连线。

删除只改画布上的内容，不动已经发布到数据管理面板里的数据集。工作流运行过一次之后，节点被删掉，之前发布出去的那个数据集仍然留在面板里。

## 撤销与重做

撤销和重做的按钮在主页的「Clipboard / 剪切板」面板里，名称是「Undo / 撤销」和「Redo / 重做」，快捷键是 Ctrl+Z 和 Ctrl+Y。

撤销按工作流分开记：每个工作流有自己的撤销栈，撤销命令作用在当前工作流的栈上，切换标签页时跟着换成那个标签页的栈。在一个工作流里按撤销不会动到另一个工作流的任何内容。

下面这些操作可以撤销和重做：节点的移动、多个选中图元一起移动、连线的添加和删除、粘贴、剪切、删除节点（节点和它的全部连线算一步）、分组和取消分组、添加背景图、改变选中图元的边框和底色。

下面这些操作不进撤销栈，做了就做了：显示网格的开关、锁定视图的开关、图元之间连线开关的状态、绘制矩形和绘制文本工具的状态、缩放。

撤销栈不随工程保存。重新打开工程之后每个工作流的撤销栈都是空的，只能退回本次会话里做过的操作。

## 缩放与平移

缩放用 Ctrl 加滚轮：按住 Ctrl 滚动滚轮放大和缩小，不按 Ctrl 时滚轮用于上下滚动画面。

键盘上还有三个快捷键：Ctrl+= 放大、Ctrl+- 缩小、Ctrl+0 缩放到适合屏幕。Ribbon「Workflow View / 显示」页的「View / 视图」面板里有三个对应的按钮：「Zoom to Fit / 适合屏幕」是大按钮，「Zoom In / 放大」和「Zoom Out / 缩小」是中等按钮。适合屏幕会把画布上所有图元缩放到正好铺满视图的可视范围，节点放得太散时用它把图找回来。

平移画布有两种鼠标操作：按住鼠标中键拖动，或者按住空格键再按住鼠标左键拖动。缩放和平移都只改变视图，不改动任何图元的位置和大小，也不进撤销栈。

几个工作流并排分屏时，工作流区里最后获得焦点的那个标签页是当前工作流，缩放按钮和缩放快捷键作用在它身上。

## 视图标记

「View / 视图」面板上的「View Marker / 视图标记」是一个菜单，里面有四个条目：

- 「Cross Line Marker / 十字标记线」：一条水平和一条竖直的参考线跟随鼠标。
- 「Horizontal Line Marker / 水平标记线」：只有水平参考线跟随鼠标。
- 「Vertical Line Marker / 垂直标记线」：只有竖直参考线跟随鼠标。
- 「None Marker / 无标记线」：关掉参考线。

参考线用来比对各节点的位置，只看不选中，不影响图元。标记线样式是每个工作流各自的设置，切换标签页时 Ribbon 上高亮的条目会跟着换到当前工作流的样式。

## 锁定视图与显示网格

「View / 视图」面板左侧的两个大按钮是「Lock View / 锁定视图」和「Show Grid / 显示网格」。

打开「Lock View / 锁定视图」后，画布进入只读状态：图元不能被拖动、不能改大小、不能旋转，控制点也不再显示。适合在流程图定型之后对照阅读，避免误拖。再点一次关闭，编辑能力恢复。锁定状态不随工程保存，重新打开工程是未锁定的。只读锁定不管连线，要临时禁止拉线用「Item / 图元」面板上的「Link / 连线」开关。

「Show Grid / 显示网格」控制画布背景上的方格线，默认打开。新工作流建出来时会继承最近一次的网格设置，早先建好的工作流不受影响。

## 绘制标注

「Text / 文本」面板上的两个按钮是「Draw Rect / 绘制矩形」和「Draw Text / 绘制文本」，用来在画布上画说明性的标注。

两个都是单击激活的工具：点按钮后鼠标指针变成对应的绘制图标，在画布上按住左键拖出一个范围再松开，图元就建好了，工具随即自动关闭（按钮弹起），要再画一个就再点一次按钮。激活绘制工具期间，画布上的节点不能拖动。

- 绘制矩形时，拖出的范围就是矩形的尺寸。如果某一方向拖动的距离不超过 5 像素，这个方向按 100 像素处理，避免画出一个细条。
- 绘制文本时，拖出的范围是文本框的尺寸，里面是空的，建好之后双击文本框直接输入文字。

新建的标注图元自动处于选中状态，可以立即在「Item / 图元」面板上改边框、底色和字体，也可以拖动改大小。

矩形和文本都是普通的绘图图元，不是节点的一种，也不参与工作流运行。它们同样可以被复制、删除、分组，也会随工作流一起保存。

## 分组与联动移动

「Group / 分组」面板里有三个命令：「Grouping / 分组」「Ungroup / 取消分组」和「Linkage Move / 联动」。

分组把选中的图元合成一个整体，之后点选、拖动、删除都以整体为单位。选中一个或多个图元后点「Grouping」即可；单独选中一个分组时不能再分组，防止分组套分组。取消分组时先选中一个分组再点「Ungroup」，分组解散，成员恢复成独立的图元。分组和取消分组都可以撤销。

「Linkage Move / 联动」是一个开关，影响拖动节点时的行为。打开之后，拖动一个节点，沿着它的输出连接能走到的下游节点会跟着一起移动同样的位移量，用来保持一段流程的相对排布。上游节点不受影响，同一次拖动里手动移动过的节点也不会再跟着走一次，连线跟着更新端点。联动移动产生的位移和普通移动一样进撤销栈。关闭这个开关则只移动被拖的节点。

## 背景图片

「Background / 背景」面板上有三个命令，用来在画布下面垫一张参考图，比如一张纸质的流程草图，或者一张示意图。

「Add Background / 添加背景」打开文件选择框，可以选择 PNG 和 JPG 图片，也可以选任意文件。选中的图片成为画布的背景图元，压在所有图元下面。再次点这个命令会换掉原来那张背景图，整张画布只有一个背景图元。添加和替换背景都可以撤销。

「Lock Background / 锁定背景」把背景图元变成不可选中、不可拖动，避免在选中节点时误拖背景。画布上还没有背景图时，这个命令不起作用。锁定的顺序一般是：先加背景，再调淡颜色，最后锁定。

背景图的浓淡在「Picture / 图片」页上调：选中背景图后，右侧设置面板的「Picture / 图片」页上有一项 Alpha，滑块和数字框都取 0 到 255，数字框每点一次变化 16。把值调小（比如调到 80）背景就变淡，节点和连线更容易看清；255 是不透明。锁定背景之后背景图不能被选中，也就改不了这个值，需要先解锁。

背景图的内容随工作流一起保存：图片数据嵌在工程的 `workflow.xml` 里，不记录原始图片的路径，原始文件被移动或者删除都不影响重新打开工程。粘贴到画布上的图片图元也按同样方式保存，图片多或者像素大的时候工程文件会明显变大。

「Move With Background / 元件随背景移动」打开之后，拖动背景图时画布上所有顶层图元跟着一起位移同样的距离，连线跟着更新端点，节点之间的相对位置不变。用它在背景图上重新对位整套流程时很省事。移动本身可以撤销，跟着一起移动的图元不记在同一步里，撤销之后要把它们再拖回去。

## 形状与字体面板

「Item / 图元」面板右侧是两个可以直接改样式的面板：形状面板和字体面板。它们的改动作用在选中的图元上；没有选中图元时改这两个面板，字体部分会成为新建文本的默认字体和颜色。

形状面板管边框和底色：边框的线型和线宽、边框颜色、底色的填充方式。选中图元后，面板显示的是这个图元当前的边框和底色，改动立即画到画布上，边框和底色的改动可以撤销。背景图元也有自己的设置页，面板上的选项单独列出。

字体面板管文字：字体、字号、粗体斜体下划线、字体颜色。选中文本图元时，改动作用在选中的文字上；没有选中文本时，改动决定之后新建文本的字体和颜色。

选中不同类型的图元时，面板会自动切到对应那一组的当前值：选中形状类图元读它的边框和底色，选中文本图元读它的字体和颜色。

## 图元之间的连接开关

「Item / 图元」面板上的「Link / 连线」是一个开关，默认打开，控制画布上能不能通过点端口拉出新的连线。关掉之后，点输出端口和输入端口都不会开始连线，已经连好的线照常显示、照常参与运行。

这个开关对所有打开的工作流标签页生效，不只是当前这一个。它的状态不进撤销栈，也随重新打开工程恢复成默认的打开状态。

## 连线的外观

选中一条连线，右侧「Setting / 设置」面板会切到「Link / 连线」页，这里改的是这条线本身，不影响两端的节点。页上有五项：

- 画笔（pen）：连线的颜色、线型和线宽。
- 连线样式（link style）：三选一。「Knuckle / 折线」走直角折线，「Straight / 直线」两点直连，「Bezier / 贝塞尔」是默认的曲线。
- 端点大小（end point size）：连线两端箭头的尺寸，0 到 999，填 0 让箭头消失。
- 前端点样式（front style）和后端点样式（end style）：各选「无」或者三角形箭头，默认在接收端画一个箭头。

新画的连线用贝塞尔样式和默认箭头，箭头画在接收端。这些改动直接写进连线，没有撤销记录；想让一整套流程的连线都改成折线，需要逐条选中修改。连线样式随工程保存。

## 导出画布图片

「Workflow View / 显示」页的「Export / 导出」面板上有一个「Export Image / 导出为图片」菜单，里面是两个命令：「Export To Image / 导出为图片」和「Export To PNG / 导出PNG」。两个命令走的是同一段处理，弹出同一个设置对话框，输出都是 PNG 文件，区别只在按钮上的文字，用哪个都行。对话框标题是「Export PNG / 导出PNG」。

对话框里先选分辨率：三个单选按钮「custom / 自定义」「screen / 屏幕」「print / 打印」，下面一个「DPI」数字框。选「自定义」时数字框可编辑，取值范围 1 到 1200，默认 96；选「屏幕」时数字框变成系统主屏的物理 DPI 并锁定；选「打印」时数字框变成 600 并锁定。点「Export / 导出」按钮选择保存位置，文件类型限定为 PNG；点「Cancel / 取消」直接关掉对话框，不保存。

导出的是画布上所有图元的包围范围，和当前视图的缩放、滚动位置无关，所以先把节点摆好再导出。导出图片的像素尺寸由包围范围和 DPI 决定：宽度等于包围范围的宽度乘以 DPI 再除以 72，高度同理。按默认的 96 算，导出的图比画布上的尺寸大约三分之一；选「打印」的 600 时像素是画布尺寸的八倍多，插进 Word 或论文排版时足够清晰。

导出的图片带透明背景，画布上看得见的东西都会画进去，包括标注、背景图和网格线。想让图片干净一些，导出前先关掉「Show Grid / 显示网格」。导出完成后，成功或失败都会有提示出现在「Log / 消息」面板里，成功时提示里带着保存的路径。导出只读画布，不改动任何图元，也不进撤销栈。

## 管理多个工作流

一个工作流占一个标签页，标签页排在「Workflow Operate / 工作流操作」停靠区里。点标签页标题切换工作流，切换时右侧的设置面板、Ribbon 上显示的状态、撤销与重做按钮的可用状态都会跟着换到当前工作流。

标签页可以在停靠区里并排摆放：拖动一个标签页到停靠区的边缘，会出现停靠指示，松手后两个工作流并排显示，可以对照着看。这个停靠区不允许把标签页拖成独立窗口。

标签页上的关闭按钮会先弹确认框，标题是「Question / 疑问」，内容是「Confirm to close workflow / 是否确认关闭工作流」，点确认后标签页关闭，点其它按钮取消关闭。关闭有未保存改动的工作流不会另做提示，改动随工程保存与否一并决定。

工作流的名称在新建时输入。源码里有重命名工作流的函数（`DAPyWorkFlowOperateWidget::renameWorkFlowWidget`），界面上没有触发它的入口，因此目前不能改名；源码里另有一条删除工作流的确认文字「Confirm to delete workflow:%1 / 是否确认删除工作流:%1」，同样没有界面入口，关闭标签页是当前唯一能从界面去掉工作流的途径。

重新打开工程时，标签页按保存时的名称和顺序恢复，每个标签页里先恢复 Python 侧的节点和连线（来自 `workflow-data.xml`），再恢复画布上的位置和图元（来自 `workflow.xml`）。这个先后顺序由加载流程保证，手工拼装工程文件时不要调换。

标签页的排布也随工程保存：哪个标签页在哪个位置、有没有分屏并排，一并写进工程，重新打开后恢复成保存时的样子。工程里工作流数量多的时候，可以按常用的组合把它们排开，之后每次打开都是这个布局。

## 日志面板

「Log / 消息」停靠面板显示软件运行时写给用户的提示，工作流执行时的状态提示也在这里。面板上有一张两列的表，左列是「date time / 日期时间」，右列是「message / 消息」，行高会随内容换行，点中某一行会把这一行展开到完整高度。

面板左上角有三个过滤按钮，都是开关，默认全部按下：

- 「Info / 信息」：普通提示，比如图片保存成功。
- 「Warning / 警告」：不影响继续运行的提醒，比如重复连接同一对端口时出现的「添加节点连接线失败」。
- 「Critical / 严重」：失败的提示，比如工作流执行失败。

弹起某个按钮就会隐藏这一类消息，再按下恢复显示。消息按时间从早到晚往下追加，新消息进来时面板自动滚到最新一条。右边的「Clear / 清除」按钮清空面板里的全部消息，只影响面板显示，不影响日志文件。在表格里选中若干行后点右键，选「Copy / 复制」把选中的行按制表符分隔复制到系统剪贴板，也可以直接按 Ctrl+C 复制、Ctrl+A 全选。

工作流里节点的日志不在这里。节点在 Python 里直接打印的内容（比如节点里写了 `print`）写在日志文件里，位置是 `%APPDATA%\DAWorkBench\log\da_pyscript.log`；文本显示节点的 `log_to_console` 用的是 Python 标准库的日志接口，当前版本里不会写进日志文件，也不会出现在「Log / 消息」面板里。C++ 一侧的技术诊断写在同目录的 `da_log.log` 里，工作流执行失败的具体错误文本也在那里。

## 常见问题

**复制了节点，粘贴到画布上没有东西。** 粘贴的位置在视图中央，先把画布滚动到要放节点的位置再粘贴；另外确认选中的是画布区域，剪贴板里是软件复制的图元而不是从别处复制的文字。

**粘贴出来的节点参数是空的那几个默认值。** 剪贴板里不保存节点的参数值，粘贴出来的是参数取默认值的新节点，粘贴后需要在设置面板里重新填写参数。

**撤销按钮是灰的。** 撤销作用在当前工作流的撤销栈上，刚切换到一个没有做过任何改动的标签页时按钮就是灰的；也可能是这次改动本身不进撤销栈，比如显示网格的开关和锁定视图。

**画布上的节点拖不动，也连不上线。** 检查「Lock View / 锁定视图」是不是处于打开状态，或者「Link / 连线」开关是不是被关掉了。

**导出的图片只有一部分节点，或者图很大、节点很小。** 导出范围是所有图元的包围范围，画布上散落在很远处的图元会把范围撑大。先把位置异常的图元拖回主体附近，或者删掉不再需要的图元；另外导出前关掉网格和背景图，图会更干净。

**背景图太显眼，压过了节点。** 选中背景图，在「Picture / 图片」页把 Alpha 调小让底图变淡，再点「Lock Background / 锁定背景」把它锁住。想换一张图，重新点「Add Background / 添加背景」选新图片；想去掉背景，用撤销把添加背景那一步撤掉。

**选了一堆图元，只想挪其中一个。** 先在画布空白处点一下取消选择，再点要挪的那个图元拖动；多选状态下拖动任何一个都会带着整组一起走。

**撤销能不能撤掉上一次运行。** 不能。运行不是画布编辑，撤销不会把节点的状态颜色退回去，也不会撤掉已经发布到数据管理面板的数据集。要撤掉发布的结果，在数据管理面板里删掉这份数据集，或者改好参数再运行一次覆盖它。

**画布上的改动什么时候写进文件。** 画布上的编辑只改内存，要点保存工程才会写进工程文件，关掉软件之前不保存就全部丢失。剪贴板和撤销栈也不跨会话，重新打开工程后从空白开始。

**能不能把节点复制到另一张工作流里。** 可以。剪贴板在软件内通用，复制之后切到目标工作流标签页再粘贴，节点和它们之间的连线一起过去，落点在当前视图的中央。

**视图标记线会出现在导出的图片里吗。** 不会。标记线是画在视图上的一层覆盖图形，场景渲染时不含它，导出图片里看不到参考线；网格和背景图属于场景内容，会被画进图片。

**导出之后只得到一张空白图片。** 导出范围按画布上的图元算，画布上一个图元都没有时范围是空的，导出会失败并在「Log / 消息」面板里给出保存失败的提示。画布上有内容之后再导出。

**面板被关掉了，找不到节点列表和画布。** 到「View / 视图」标签页的「Display / 视图显示」面板里点「Show Workflow Area」把画布区找回来，点「Show Workflow Manager」把节点列表找回来。

**删掉了一个节点，能不能只恢复它、不恢复别的改动。** 可以。删除节点和它的连线是一步撤销记录，点一次「Undo / 撤销」就把节点和它的全部连线一起放回来，随后做的其它改动不受影响。

**画布上连线交叉太多，看不清走向。** 选中连线，在「Link / 连线」页把连线样式改成「Knuckle / 折线」，折线走直角，交叉处比曲线容易分辨；也可以把节点拉开一些，让线走得更直。

**并排分屏之后拖动一个工作流的节点，另一个工作流会不会跟着动。** 不会。两个标签页各有各的画布，图元不共享；唯一对所有工作流同时生效的开关是「Item / 图元」面板上的「Link / 连线」。

## 键盘与鼠标操作一览

下表汇总这一章里出现的键盘和鼠标操作，界面上的按钮位置见前面的各节。

| 操作 | 方式 |
|------|------|
| 选中一个图元 | 左键单击 |
| 框选多个图元 | 在空白处按住左键拖出矩形框 |
| 加选或取消选择 | 按住 Ctrl 逐个点击图元 |
| 全选画布上的图元 | Ctrl+A，或主页面板的「Select All」 |
| 取消选择、取消正在拉的连线 | Esc |
| 移动选中的图元 | 按住左键拖动，多选时一起移动 |
| 改变图元主体大小 | 拖动选中图元周围的控制点，或在「Item / 图元」页填 Width / Height |
| 旋转图元 | 在「Item / 图元」页的 Rotation 里填角度 |
| 拖动复制 | 按住 Ctrl，用左键拖动选中的图元 |
| 复制选中的图元 | Ctrl+C，或「Clipboard / 剪切板」面板的「Copy」 |
| 剪切选中的图元 | Ctrl+X，或同一个面板的「Cut」 |
| 粘贴 | Ctrl+V，或同一个面板的「Paste」 |
| 删除选中的图元 | Delete，或主页「Clipboard / 剪切板」面板的「Delete」 |
| 撤销 | Ctrl+Z |
| 重做 | Ctrl+Y |
| 放大画布 | Ctrl+滚轮，或 Ctrl+=，或「Zoom In」按钮 |
| 缩小画布 | Ctrl+滚轮，或 Ctrl+-，或「Zoom Out」按钮 |
| 缩放到适合屏幕 | Ctrl+0，或「Zoom to Fit」按钮 |
| 平移画布 | 按住鼠标中键拖动，或按住空格再按住左键拖动 |
| 切换工作流 | 点击停靠区里的标签页标题 |
| 把一个工作流分屏 | 把标签页拖到停靠区的边缘，出现停靠指示后松手 |
| 找回被关掉的面板 | 「View / 视图」页的「Display / 视图显示」面板，用「Show Workflow Area」「Show Workflow Manager」 |
| 编辑文本框里的文字 | 双击文本图元 |
| 打开节点的参数页 | 双击节点 |
