# 工作流

工作流是软件的核心功能。一张工作流就是一张图：每个节点负责一步处理，节点之间的连线表示数据往哪里走。图搭好之后，改一个参数再点一次运行，整条流程从头重跑一遍。反复做同一套处理时，搭一次就够了。

这一部分从怎么画开始，一直讲到怎么给自己写一个新节点。

## 章节目录

- [工作流基础](basics.md)：新建工作流、放节点、连接端口、填参数、运行，以及数据在运行时怎样流动、出错停在哪一步。有两个可以照着做的例子。
- [编辑器功能](editor.md)：画布上的编辑操作，包括复制撤销、缩放视图、分组、背景图和导出图片。
- [系统节点手册](nodes-system.md)：起点、终点、条件分支、延迟、常量、文本显示、结果发布七个节点的参数说明。
- [数据分析节点手册](nodes-analysis.md)：读取、清洗、筛选、汇总、导出、绘图共二十一个节点的参数说明。
- [开发自定义节点](custom-node.md)：用 Python 写一个节点，定义参数、端口和运行逻辑。
- [把节点打包成插件](node-plugin.md)：让自定义节点出现在节点面板里，并随软件分发。

## 建议的读法

先用 [工作流基础](basics.md)把第一个流程搭出来并跑通，这一步只需要看这一章。

接着按需要查两本节点手册。手册是查阅用的，不必从头读，按分组找节点即可。

[编辑器功能](editor.md)随时可以回来看，画布上用到的操作基本都在那里。

两章节点开发面向要写代码的人。只做分析的人不需要读它们。

## 需要提前知道的两件事

- 工作流必须保存过工程才能运行，没保存过时会弹出提示。
- 运行发生在界面线程上，跑完之前窗口不响应。终止和暂停在当前版本里都没有实现。
