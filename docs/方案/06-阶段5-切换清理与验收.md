# 阶段 5：接线切换、Python 依赖清理与总验收

本阶段目标：把旁路运行时接入 `DAAgentModule`（`DA_AGENT_NATIVE_RUNTIME` 生效），删除 QProcess 桥协议层、Python agent 目录、langgraph 依赖与相关测试/文档，完成**整体总验收**。执行顺序必须是"**先接线验证、后删除**"，删除动作全部集中在本阶段末尾，保证每个中间提交都可运行、可回退。
