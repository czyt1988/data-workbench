# Agent 运行时替换方案（langgraph → NeoGraph）方案索引

本文件夹是完整的重构实施方案：**移除 Agent 对 Python langgraph 的依赖，用 C++ 库 NeoGraph 在主进程内实现全部推理**。可行性结论为"可行"，详细论证见 `00`。

## 给执行 AI 的使用说明

1. **先完整阅读 `00-总览与可行性分析.md`**——它包含现状分析、NeoGraph 能力映射、5 条关键架构决策（A1-A5）、阶段导航与通用实施约定。后续所有文档引用其中的决策编号（注意与 `src/DAAgent/AGENTS.md` 的既有 D*/T* 编号是两套体系）。
2. **严格按 01 → 06 顺序执行**，每个文件是一个独立阶段，含：目标、实施步骤表（文件级）、关键代码骨架、验收标准、风险与回退。**上一阶段验收未过不得进入下一阶段。**
3. 阶段 0 的 spike 验证结论（V1 resume value 双重去向、V7 工具集注入方式、V8 cancel_token 类型、V9 递归步数字段——V7/V8/V9 会回填对应阶段文档）会直接影响阶段 2/3 的实现细节——遇到与文档假设不符的 NeoGraph 实际行为，**以 NeoGraph 源码为准修正对应阶段文档**再实施。
4. 每阶段完成即按项目规范提交（conventional commits 中文）。
