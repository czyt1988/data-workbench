# DAGui 图标资源目录（`src/DAGui/icon/`）

> **用途**：本目录存放 DAWorkbench 主界面（DAGui 模块）所用的 SVG 图标资源。

---

## 🔴 涉及 SVG 图标设计必须阅读完整规范

**如果涉及 SVG 图标的设计（新增、替换、修改本目录下任意 `.svg` 文件），必须先阅读项目级图标与 UI 设计规范：**

📖 **[docs/zh/dev-guide/icon-ui-design-guide.md](../../../docs/zh/dev-guide/icon-ui-design-guide.md)**

该文档是本目录图标设计的**唯一权威规范**，涵盖：

- 整体风格定位（扁平化、几何简洁、语义化配色）
- 画布规格（viewBox：200×200 / 64×64 / 32×32 / 1024×1024）
- 核心色板（主蓝 `#5280C1`、中灰 `#727272`、绿 `#669E8B`、橙红 `#CE6043`、金黄 `#E6C27C` 等语义色）
- 色彩组合规则（容器型 / 功能操作 / 图表类型 / 数据类型 / 消息类型）
- UI 设计规范（图标与界面控件配色映射）
- 命名规范（`camelCase` 文件名、`kebab-case` 子目录）
- **AI 生成图标 Checklist**（新增/替换图标前逐项核对）
- 禁止事项（禁渐变/阴影、禁新色值、禁 `<text>`、禁动画等）

在新增或替换图标前，请严格按上述文档的 §10 Checklist 逐项核对，未遵循规范的图标会导致主界面视觉割裂、语义混乱，且无法通过工具栏等比缩放正确渲染。

---

## 目录结构

| 子目录 / 位置 | 内容 |
|--------|------|
| 根目录 | 功能性图标（操作类、视图缩放、展开/折叠、选择、数据、图表/绘图、节点/工作流、设置类、坐标轴、方向性、标记等） |
| `chart-type/` | 10 个图表类型图标，统一 64×64 |
| `data-type/` | 6 个数据类型图标，统一 200×200 蓝框白底 |
| `messageType/` | 4 个消息级别图标（Debug/Info/Warning/Error），统一 32×32 |

完整文件清单详见规范文档 §12。

---

## 备注

- 应用级图标资源位于 `src/APP/Icon/`，同样遵循上述规范。
- 修改色板或画布规格时，必须先在规范文档 §3/§2 登记，再用于图标。
